# 模型计价统一为百万单位

## 范围与契约

- LLM、Embedding、Rerank 固定按 M Tokens 计价，TTS 按每 1M 字符计价；STT 仍按每 60 秒计价。
- 不新增单位字段、单位切换或运行期每千单位兼容。历史换算仅存在于本任务迁移目录。
- 单价最多两位小数，不补零；输入输出单价、综合价、表单、API 写入和导入使用同一舍入函数。单次费用保留计算精度，不能按单价精度舍入。
- 综合价和阶梯价使用普通数字输入，在表单取值及失焦显示时调用公共舍入函数，避免数值组件先行舍入改变十进制中点。清空保留未配置，显式 `0` 保留免费语义。
- 本 PR 独立于缓存计价，不新增缓存单价、缓存用量字段、供应商 SDK 补丁或 Pro 改动。

## 自动迁移

任务 `20261025_token_prices_per_million` 追加在 4.17.4 注册表末尾，非阻塞后台执行，失败仅停止本次任务，后续独立任务可继续。历史安装任务先将旧配置迁入 `ai_models`；本任务遍历全部模型，转换 Token/TTS 价格而不写入 STT，不修改历史账单或使用记录。

单价通过十进制指数加 3 放大后四舍五入至两位，避免浮点乘法把 `0.000035` 转成 `0.034999999999999996` 而错误舍入为 `0.03`；正确结果为 `0.04`。比如 `0.000125 / K` 变成 `0.13 / M`，用户已接受由此产生的实际费率变化。阶梯上下界通过同一十进制移位函数将指数减 3，保留有效位：直接除法可能使 `4.1` 变成 `0.0040999999999999995`，错误缩小右闭区间。边界不按单价精度截断。

采用稳定 `_id` 游标和固定扫描上界分批处理。整批先验证源数据；事务中按原始字段值 CAS 写入新价格和 `legacyTokenPricing` 原价备份、递增目录修订号并回读验证。备份与价格原子提交，备份存在且有效即证明该记录已转换；重放不会再次放大，也不会覆盖管理员后续调整。

完整批次提交后才保存断点。坏批不写入、不推进断点，日志只输出首个模型 ID、原因和异常数量；完整错误快照记录阶段、模型 ID 和原因，管理员修复后从管理页重试，无需重启 App。重试先按批处理上次失败模型（已删除记录视为解决），业务提交后更新错误快照，再继续游标。任务返回前重新全量只读验证；验证失败时重置扫描断点，供重试修复已扫描范围。

## 升级约定

用户明确允许升级期间计费异常，不要求停机、排空在途请求或停止旧实例。这是本任务对[系统迁移规范](../../../skills/system/system-migration-development/SKILL.md)默认滚动兼容要求的明确例外，不改变其他迁移的默认规则。不增加旧节点检测、双写或窗口账单补偿。

本价格迁移不阻塞新 App 就绪或业务消费者启动，模型在后台完成转换与目录失效。迁移期间及新旧版本重叠期间的计费偏差被接受，不引入单位兼容。坏数据、事务失败和 CAS 冲突仍让本次任务失败，保留事务和断点安全；原有其他阻塞任务的启动规则保持不变。
