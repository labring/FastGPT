## 目标与已确认决策

将官方文档组织成可以完成实际任务的产品使用体系：创建应用、接入知识、配置工具、调试、发布、观察效果并持续维护。

用户已确认：

1. 默认服务应用构建者，开发者与部署运维各有独立入口。
2. 中文与英文同步完成目录、术语、正文重构，保持技术含义一致。
3. 沿用 Next.js/Fumadocs，重构内容、目录、首页和导航。
4. 以 2026-10-15 SaaS 截图中的操作界面为主线，以源码核实行为，分别注明部署版本、商业授权、套餐、配置和权限条件。
5. 原方案阶段交付调研与规格；后续实施授权覆盖双语内容、站点实现、局部验证、审查及当前分支提交。

已确认的 URL 决策：

- 历史内容与地址：用户要求从 SEO 角度推荐。建议保留现有 URL，重组导航；升级资料按版本集中管理；应用、对话、知识库 API 的旧地址更新为当前集成指南，旧参数详文单独归档并互相链接。确需合并且主题对应的页面逐页设置永久重定向。

`grill-with-docs` 指定的 `grilling` 与 `domain-modeling` 用于本次设计。其研究结果构成本次 implement 实施的输入。

## SEO 策略：沿用有效地址，按任务重构内容

推荐以 URL 连续性为基础完成信息架构重构。页面所属分区、侧栏顺序、标题、正文和内链均可重新设计；主题保持一致的页面沿用原地址。新任务使用清晰的新地址，确需合并的页面逐项建立对应关系。

| 页面情况 | 建议处理 | SEO 与读者收益 |
| --- | --- | --- |
| 原主题仍有效，正文需要更新 | 保留 URL，更新内容、标题、摘要、图注与上下游链接 | 延续已有链接和检索主题，提供当前答案 |
| `openapi/app`、`openapi/chat`、`openapi/dataset` | 原地址承载当前集成指南；旧参数详文进入有版本标识的归档并双向链接 | 让原地址继续解决当前“应用 API / 对话 API / 知识库 API”意图 |
| 快速上手包含多个完整教程 | 原 URL 成为教程入口，新建单任务教程并从入口链接 | 保留原入口价值，新增更精确的任务落地页 |
| 历史升级指南 | 保留版本 URL、自指 canonical 和清晰版本标题，链接当前升级入口 | 服务特定版本的长尾需求和已有用户 |
| 同主题页面确需合并 | 原 URL 以服务端 301 或 308 直接指向对应最终页，同时更新站内链接 | 传递迁移信号，保持阅读路径连续 |
| 当前新增主题 | 新建中英文成对页面，从相关概念、任务、参考页建立内链 | 完善主题覆盖和发现路径 |

Google 官方说明：永久重定向支持迁移信号传递；大规模改址需要重新抓取和索引，期间可能发生排名波动。URL 变更应有完整映射，重定向直达相关最终页，并尽可能长期保留（通常至少一年）。因此，本次已能通过导航和正文解决的问题，优先在原地址完成。

依据：[网站迁移](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes)、[重定向与 Google 搜索](https://developers.google.com/search/docs/crawling-indexing/301-redirects)。本轮采用静态证据模式，Search Console 点击、展示、外链与查询数据尚待接入或导出；方案中的主题优先级依据用户任务与内容缺口。

实施时的 SEO 验收重点：

- 保持中文 `doc.fastgpt.cn` 与英文 `doc.fastgpt.io` 的语言归属，检查每页 canonical、互相对应的 hreflang、sitemap 和语言切换目标。
- 当前工作区的页面元数据仍使用同一 `domain` 生成两种语言 alternates（`document/app/[lang]/(docs)/[...slug]/page.tsx:156`），语言归属 helper 和中间件已有跨域逻辑；实施时对齐并验证最终地址。这是工作区代码发现，线上实际输出仍需检测。
- 当前有效内容使用唯一、准确的标题和摘要，按任务组织 H1/H2；保留有用的旧标题锚点。历史内容在标题与摘要中显式标明版本。
- 当前页、归档页各自表达自身内容语境；版本独立的历史指南使用自身 canonical。确需合并时采用相关目标映射。
- 站内链接直接落到最终可索引地址；搜索结果明确区分当前指南与历史参考。公开图片提供描述性 alt、图注和可独立阅读的英文步骤。
- 后续如有实质 URL 迁移，先保存 URL 与流量基线，发布后按旧页、新页、语言及查询维度观察抓取、索引、点击与展示变化。

## 产品术语与边界

方案词汇表位于 [CONTEXT.md](./CONTEXT.md)，[document/CONTEXT.md](../../../document/CONTEXT.md) 已同步为维护中的词汇表。产品命名已通过截图和源码交叉核验。需要明确的关系：

- 应用分为对话 Agent、对话 Agent V2、工作流；工作流中的 Agent 节点是节点能力。
- 工具具有输入输出约定；工作流工具可供其他应用调用，也可独立运行。技能资源统一管理和发布一组或多组指令与文件。MCP 工具接入外部能力，MCP 服务对外提供 FastGPT 能力。
- 知识库包含集合；内容集合保存导入或手动添加的数据块，文件夹集合组织其他集合。数据块具有检索索引；界面按集合类型展示文件、网页、图片等对象。
- 发布版本决定实际运行内容，发布渠道决定访问方式；自动保存、手动保存和发布有各自作用。
