# 模型管理重构 — 详细设计：数据模型

> 基于主设计文档第 2.1、2.2、2.4 节展开。本文档定义完整的 MongoDB Schema、Zod 校验规则、默认模型表及类型系统。

---

## 1. MongoDB Schema — `system_models` 集合

### 1.1 设计原则

- **strict: false** — Schema 仅声明所有模型类型共享的 base 字段和价格字段。类型特有字段（如 `maxContext`、`voices`、`dimensions` 等）由 Zod schema 在写入前校验后动态存储在 MongoDB 文档中。
- **按归属作用域保证配置名唯一** — 系统模型的 `model`（provider-side model name）和 `name`（platform display name）分别全局唯一；私有模型的两个字段分别在同一 `tmbId` 作用域内唯一。这样既保证 aiproxy 按 `model` 路由时只有一个目标，也避免平台展示名歧义。
- **平台内主键** — 使用 MongoDB 自动生成的 `_id`（ObjectId）作为模型在平台内的唯一标识。

### 1.2 Schema 定义

**文件**: `packages/service/core/ai/model/schema.ts`（重构后，由 `config/schema.ts` 改名）

```typescript
import { connectionMongo, defineIndex, getMongoModel } from '../../../common/mongo';
const { Schema } = connectionMongo;
import { TeamCollectionName } from '@fastgpt/global/support/user/team/constant';
import { TeamMemberCollectionName } from '@fastgpt/global/support/user/teamMember/constant';

// ═══ 所有模型类型共享的 base 字段 ═══
// 对应 zod: BaseModelItemSchema (见第 2 节)
const BaseModelFields = {
  model:    { type: String, required: true },   // provider 侧的 model 名，如 "gpt-4o"
  type:     { type: String },                    // llm | embedding | tts | stt | rerank
  provider: { type: String },                    // 模型提供商标识
  name:     { type: String },                    // 平台内展示名/别名
  avatar:   { type: String },                    // 提供商图标 URL

  isActive:  { type: Boolean },                  // 是否启用
  isSystem:  { type: Boolean },                  // 是否系统模型（root 创建，全平台公开）
  testMode:  { type: Boolean },                  // 测试模式标记（存量字段，标记通过 test API 创建的临时测试模型）

  // 注意：tmbId 和 teamId 仅私有模型（isSystem: false）存储
  // 系统模型（isSystem: true）不维护这两个字段，不属于任何团队或个人
  tmbId:  { type: Schema.Types.ObjectId, ref: TeamMemberCollectionName },
  teamId: { type: Schema.Types.ObjectId, ref: TeamCollectionName }
};

// ═══ 价格字段（所有模型类型共享） ═══
// 对应 zod: PriceTypeSchema
const PriceFields = {
  charsPointsPrice: { type: Number },               // 1k chars = N points; 60s = N points
  priceTiers:       { type: [Schema.Types.Mixed] }, // 梯度价格（新版计费）
  /** @deprecated 旧版计费字段，仅保留用于兼容存量数据 */
  inputPrice:  { type: Number },
  /** @deprecated */
  outputPrice: { type: Number }
};

// 类型特有字段（如 maxContext, voices, maxToken, dimensions 等）不在此声明，
// 由 normalizeSystemModel() 在写入前通过 Zod schema 清洗后动态存储。
// strict: false 允许这些字段写入 MongoDB。
const SystemModelSchema = new Schema(
  {
    ...BaseModelFields,
    ...PriceFields
  },
  {
    strict: false,     // 允许类型特有字段动态存储
    timestamps: true   // 自动管理 createdAt、updatedAt
  }
);

// ═══ 索引 ═══
// 当前索引统一通过 defineIndex() 声明：系统模型的 model、name 各自全局唯一；
// 私有模型的 tmbId + model、tmbId + name 各自唯一。
// name 索引仅匹配已存在的 name 字段，以兼容历史缺失 display name 的存量文档。
defineIndex(SystemModelSchema, {
  key: { model: 1 },
  options: { unique: true, partialFilterExpression: { isSystem: true } }
});
defineIndex(SystemModelSchema, {
  key: { name: 1 },
  options: { unique: true, partialFilterExpression: { isSystem: true, name: { $exists: true } } }
});
defineIndex(SystemModelSchema, {
  key: { tmbId: 1, model: 1 },
  options: { unique: true, partialFilterExpression: { isSystem: false } }
});
defineIndex(SystemModelSchema, {
  key: { tmbId: 1, name: 1 },
  options: {
    unique: true,
    partialFilterExpression: { isSystem: false, name: { $exists: true } }
  }
});
defineIndex(SystemModelSchema, { key: { teamId: 1 } });
defineIndex(SystemModelSchema, { key: { tmbId: 1 } });
defineIndex(SystemModelSchema, { key: { isActive: 1, provider: 1 } });

export const MongoSystemModel = getMongoModel<SystemModelItemType>(
  'system_models',
  SystemModelSchema
);
```

## 2. Zod Schema 定义

**文件**: `packages/global/core/ai/model/type.ts`（重构后，由 `model.schema.ts` 改名）

### 2.1 Base Schema（重构后）

```typescript
import { ModelTypeEnum } from './constants';
import z from 'zod';

// ═══ 价格梯度 ═══
export const ModelPriceTierSchema = z.object({
  minInputTokens: z.number().min(0).optional(),
  maxInputTokens: z.number().min(0).nullish(),
  inputPrice: z.number(),
  outputPrice: z.number()
});
export type ModelPriceTierType = z.infer<typeof ModelPriceTierSchema>;

// ═══ 价格字段（所有模型类型共享） ═══
const PriceTypeSchema = z.object({
  charsPointsPrice: z.number().optional(),
  priceTiers: z.array(ModelPriceTierSchema).optional(),

  /** @deprecated */ inputPrice: z.number().optional(),
  /** @deprecated */ outputPrice: z.number().optional()
});
export type PriceType = z.infer<typeof PriceTypeSchema>;

// ═══ Base 字段（重构后：isCustom → isSystem，移除 isDefault、requestUrl、requestAuth） ═══
export const BaseModelItemSchema = z.object({
  id: z.string(),            // = String(_id)，扁平化主键
  provider: z.string(),
  model: z.string(),
  name: z.string(),
  avatar: z.string().optional(),

  isActive: z.boolean().optional(),
  isSystem: z.boolean().optional(),     // ← 替换 isCustom（语义反转）

  // 团队/创建者 — 仅私有模型（isSystem: false）存储，系统模型不维护
  tmbId: z.string().optional(),
  teamId: z.string().optional(),

  // 测试模式
  testMode: z.boolean().optional()

  // 注意：requestUrl、requestAuth 已移除 — 由渠道（channel）管理
  // 注意：isDefault 已移除 — 由 default_models 表管理
});
```

    embeddingId:        { type: String },  // 默认向量模型
    ttsId:              { type: String },  // 默认 TTS

    datasetImageLLMId:  { type: String },  // 知识库图片理解默认模型
    chatTitleLLMId:     { type: String },  // 标题生成默认模型

> **索引策略**：`default_models` 为单文档集合（仅一条系统默认配置），无需额外索引。MongoDB 自动在 `_id` 上建索引，足够满足 `findOne({})` 查询。

### 3.3 加载与回退逻辑

`loadSystemModels()` 中调用 `loadDefaultModels()` 读取系统默认配置，构建 `global.systemDefaultModel`：

```
1. MongoDefaultModel.findOne({}) — 读取系统默认文档
2. 解析为 global.systemDefaultModel（显式配置优先，未配置回退到首个系统模型）
3. 无可用模型时返回 undefined
```

## 5. `normalizeSystemModel` — 写入前数据清洗

**文件**: `packages/service/core/ai/model/normalize.ts`（新建）

所有模型创建/更新/批量导入的 handler 在写入 MongoDB 前，通过此函数按类型的 Zod schema 清洗数据，将文档规整为 DB 可存储的扁平格式：

```typescript
import { SystemModelItemSchema } from '@fastgpt/global/openapi/core/ai/model/api';

/**
 * 按类型对应的 Zod schema 清洗模型数据。
 * - 过滤掉 schema 中未定义的字段
 * - 填充 schema 中定义的默认值
 * - 校验必填字段
 * - 返回符合 SystemModelItemType 的扁平对象
 */
export function normalizeSystemModel(
  input: Record<string, unknown>
): Record<string, unknown> {
  const parsed = SystemModelItemSchema.parse(input);

  // 扁平化：合并 discriminated union 各分支的字段
  // Zod discriminatedUnion 的 parse 结果已包含对应 type 分支的全量字段
  const { id, ...fields } = parsed as Record<string, unknown>;
  return fields;
}
```

> **调用场景**：`create.ts` handler（§7.3）、`update.ts` handler（§7.4）、`updateWithJson.ts` handler（§7.8）。`normalizeSystemModel` 利用 `SystemModelItemSchema`（discriminatedUnion）按 `type` 自动匹配对应分支的 Zod schema，完成字段过滤、默认值填充和必填校验。

## 6. 迁移要求

> ⚠️ **实现修订（热升级兼容，2026-08）**：迁移语义由「破坏式（删除旧结构字段）」调整为 **additive（只补新结构字段，保留旧结构字段）**，配合缓存双 map + getters 兼容输入（见[热升级技术分析 §7](./模型管理重构-热升级技术分析.md#7-additive-migration-设计)），使热升级窗口内新老镜像均可读取存量数据。§6.1-6.3 的「新结构」均指**补充**（`$set` 缺失字段），旧字段保留至 contract release。

### 6.1 system_models 集合

```
旧结构（保留）:
{
  _id: ObjectId,
  model: "gpt-4o" (unique within its model scope),
  metadata: { type, name, provider, isCustom, isDefault, requestUrl, ... }
}

新结构（只补缺失顶层字段，metadata 整体保留）:
{
  _id: ObjectId,
  model: "gpt-4o",
  metadata: { ... },       // ⚠️ 保留，不 $unset
  type: "llm",             // 顶层缺失时从 metadata 补齐
  name: "GPT-4o",
  provider: "openai",
  isSystem: true,          // 缺失时由 isCustom/owner 推导；isCustom 保留
  isActive: true,
  tmbId, teamId,           // ⚠️ 保留数据库字段；系统模型由缓存构建在内存中清理 owner 信息
  maxContext: 128000,      // 从 metadata 补齐
  ...                      // 其他特有字段同样只补缺失
}
```

### 6.2 default_models 集合

```
新建集合。存量数据：
- 读取旧 system_models 中 isDefault 标记，创建系统默认文档（$setOnInsert）
- system_models 上 legacy isDefault* 标记保留（新镜像缓存按「default_models 有效 id → legacy flags → 同类型 fallback」解析）
- 升级后由 root 通过 updateSystemDefault API 维护
- 运行时按「显式配置 → 首个启用的同类型系统模型（type=target, isSystem=true, isActive=true）→ undefined」回退
```

### 6.3 apps/datasets 中的 model 引用

```
旧（保留 @deprecated）: model: "gpt-4o" (model 名字符串)
新（补充 required）:     modelId: "68ad85a7463006c963799a05" (ObjectId 字符串)

迁移脚本保留 legacy 字段/input key，只补 canonical 字段（解析成功时）：
- dataset: vectorModel/agentModel/vlmModel 保留，补 vectorModelId/agentModelId/vlmModelId
- workflow nodes: legacy input（key="model" 等）保留，新增 canonical input（key="modelId" 等）
- chatConfig: questionGuide/ttsConfig 保留 model，补 modelId
```
