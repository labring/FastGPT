## 1. 全局缓存结构

### 1.1 缓存 Map 一览

**新增类型 `ModelTemplateType`**：

// plugin 模型模板 — 仅包含前端查询和创建表单填充所需的字段。

> ⚠️ **实现修订（热升级兼容，2026-08）**：新增统一 `systemModelNameMap` 与类型专用 `*ModelNameMap` 兼容索引（均为 `@deprecated`），与 id map 在 `loadSystemModels` 同源构建。`resolveModelId` 查询统一索引，类型 getter 查询对应类型索引：
> - key = 模型的 provider `model` 名（必要时含别名 `name`）；同一名对应多个文档时 `isActive=true` 优先、`isSystem=true` 优先、deterministic first-wins；
> - 消费方：getters 兼容输入（参数非 ObjectId 时按名解析，见主设计文档 §2.5）、`resolveModelId` 快速路径；
> - 新代码路径一律走 id map；name map 仅用于存量 legacy 引用（W0/D0 数据），随 contract release 与 legacy 字段一并移除。

## 2. `loadSystemModels()` 重构

**文件**: `packages/service/core/ai/model/utils.ts`

### 2.1 整体流程

```
loadSystemModels(init, language)
├── 1. Provider 预加载
│       preloadModelProviders()
│
├── 2. 并行获取数据源
│       Promise.all([
│         MongoSystemModel.find({}).lean(),       // DB 中的模型（含系统+自定义）
│         pluginClient.listModels()                // plugin 提供的模型模板
│       ])
│
├── 3. 构建 modelTemplateCache
│       将 pluginClient.listModels() 的结果存入 global.modelTemplateCache
│       （不 push 到已创建模型的缓存列表中！）
│
├── 4. 遍历 DB 模型，构建各类型 Map
│       dbModels.forEach(model => {
│         // 直接从 DB 扁平字段构建，无需 plugin 模板补全
│         // pushModel(model) → 写入 6 个 Map + systemModelList
│       })
│
├── 4b. 提前构建活跃模型列表（loadDefaultModels 回退逻辑需要）
│       _systemActiveModelList = systemModelList.filter(m => m.isActive)
│
├── 5. 加载默认模型（读取 default_models 表系统默认配置）
│       systemDefaultModel = await loadDefaultModels(
│         _systemModelIdMap, _systemActiveModelList
│       )
│
└── 6. 赋值 global
```

### 2.2 伪代码实现

```typescript
export const loadSystemModels = async (init = false, language = 'en') => {
  if (!init && global.systemModelList) return;

  // 1. Provider 预加载
  await preloadModelProviders();

  // 2. 并行获取
  const [dbModels, pluginModels] = await Promise.all([
    MongoSystemModel.find({}).lean(),
    pluginClient.listModels().then(r => r).catch(() => [])
  ]);

  // 3. 模型模板缓存（plugin 结果独立缓存，不进入 model maps）
  //    ModelTemplateType 仅包含模板查询所需的字段，不包含 _id/type discriminator 等
  global.modelTemplateCache = pluginModels.map(m => ({
    provider: getModelProvider(m.provider, language).id,
    model: m.model,
    name: m.name,
    avatar: getModelProvider(m.provider, language).avatar,
    type: m.type,
    defaultConfig: m.defaultConfig,
    fieldMap: m.fieldMap,
    maxContext: m.maxContext,
    maxResponse: m.maxResponse,
    vision: m.vision,
    functionCall: m.functionCall,
    reasoning: m.reasoning,
    toolChoice: m.toolChoice,
    voices: m.voices
  }));

  // 4. 构建 DB 模型缓存
  const _systemModelList: SystemModelItemType[] = [];
  const _systemModelIdMap = new Map<string, SystemModelItemType>();
  const _llmModelIdMap = new Map<string, LLMModelItemType>();
  const _embeddingModelIdMap = new Map<string, EmbeddingModelItemType>();
  const _ttsModelIdMap = new Map<string, TTSModelType>();
  const _sttModelIdMap = new Map<string, STTModelType>();
  const _reRankModelIdMap = new Map<string, RerankModelItemType>();

  // ⚠️ 热升级兼容：name 兼容索引局部声明（与 id map 同源构建）
  const _llmModelNameMap = new Map<string, LLMModelItemType>();
  const _embeddingModelNameMap = new Map<string, EmbeddingModelItemType>();
  const _ttsModelNameMap = new Map<string, TTSModelType>();
  const _sttModelNameMap = new Map<string, STTModelType>();
  const _reRankModelNameMap = new Map<string, RerankModelItemType>();

  // ⚠️ 热升级兼容：先注册活跃模型、再注册停用模型——保证同一名命中多个文档时
  //    isActive=true 优先（first-wins 且不覆盖已注册项）；Mongo find 迭代序未定义，不能依赖顺序
  const activeModels = dbModels.filter((m) => m.isActive !== false);
  const inactiveModels = dbModels.filter((m) => m.isActive === false);

  const registerNameMap = (
    modelData: SystemModelItemType,
    map: Map<string, SystemModelItemType>
  ) => {
    if (!map.has(modelData.model)) map.set(modelData.model, modelData);
    if (modelData.name && !map.has(modelData.name)) map.set(modelData.name, modelData);
  };

  for (const dbModel of [...activeModels, ...inactiveModels]) {
    // DB 中所有字段已扁平存储（无 metadata 嵌套），直接加载
    // ⚠️ 热升级兼容（见[热升级技术分析 §3.3/§6.2](./模型管理重构-热升级技术分析.md#62-缓存双-map-与-normalization)）：
    //   迁移前的旧文档仍为 metadata 嵌套结构——normalization 规则：顶层字段存在时优先，
    //   顶层缺失时从 legacy `metadata` 补齐；`isSystem` 缺失时由 `isCustom` 和 owner 信息推导；
    //   系统模型在内存中清理 tmbId/teamId（数据库字段保留，迁移窗口内旧镜像仍需读取）。
    const normalized = normalizeSystemModel(dbModel);
    const modelData = {
      ...normalized,
      id: String(dbModel._id)
      // 注意：系统模型（isSystem: true）的 tmbId/teamId 为 undefined/null
      // 不参与团队归属和创建者校验
    } as SystemModelItemType;

    _systemModelList.push(modelData);
    _systemModelIdMap.set(modelData.id, modelData);

    switch (modelData.type) {
      case ModelTypeEnum.llm:
        modelData.priceTiers = getRuntimeResolvedPriceTiers(modelData);
        _llmModelIdMap.set(modelData.id, modelData);
        registerNameMap(modelData, _llmModelNameMap);
        break;
      case ModelTypeEnum.embedding:
        _embeddingModelIdMap.set(modelData.id, modelData);
        registerNameMap(modelData, _embeddingModelNameMap);
        break;
      case ModelTypeEnum.tts:
        _ttsModelIdMap.set(modelData.id, modelData);
        registerNameMap(modelData, _ttsModelNameMap);
        break;
      case ModelTypeEnum.stt:
        _sttModelIdMap.set(modelData.id, modelData);
        registerNameMap(modelData, _sttModelNameMap);
        break;
      case ModelTypeEnum.rerank:
        _reRankModelIdMap.set(modelData.id, modelData);
        registerNameMap(modelData, _reRankModelNameMap);
        break;
    }
  }

  // 4b. 提前构建活跃模型列表
  const _systemActiveModelList = _systemModelList.filter(m => m.isActive);

  // 5. 加载默认模型（读取 default_models 表系统默认配置）
  const _systemDefaultModel =
    await loadDefaultModels(_systemModelIdMap, _systemActiveModelList);

  // 6. 赋值 global
  global.systemModelList = _systemModelList;
  global.systemModelIdMap = _systemModelIdMap;
  global.llmModelIdMap = _llmModelIdMap;
  global.embeddingModelIdMap = _embeddingModelIdMap;
  global.ttsModelIdMap = _ttsModelIdMap;
  global.sttModelIdMap = _sttModelIdMap;
  global.reRankModelIdMap = _reRankModelIdMap;
  // ⚠️ 热升级兼容：name 兼容索引同步赋值（@deprecated，contract release 移除）
  global.llmModelNameMap = _llmModelNameMap;
  global.embeddingModelNameMap = _embeddingModelNameMap;
  global.ttsModelNameMap = _ttsModelNameMap;
  global.sttModelNameMap = _sttModelNameMap;
  global.reRankModelNameMap = _reRankModelNameMap;
  global.systemActiveModelList = _systemActiveModelList;
  global.systemDefaultModel = _systemDefaultModel;
};
```

### 2.3 关键变更：`pushModel` 逻辑

**旧逻辑**（当前 `utils.ts:60-112`）：
```
遍例 systemModels (from plugin) → pushModel
遍例 dbModels not in systemModels → pushModel (isCustom: true)
```
plugin 模型和 DB 模型混合进入同一批 Map。

**新逻辑**：
```
plugin 模型 → 仅存入 modelTemplateCache（模板缓存，供前端查询填充表单）
DB 模型 → 存入 6 个 Map + systemModelList（已创建模型缓存）
```
两个缓存彻底分离。

### 2.4 默认模型加载

```typescript
/**
 * 读取 default_models 表系统默认配置，显式配置优先，未配置的回退到首个启用的同类型系统模型
 *
 * 回退链路：
 *   显式配置 → legacy isDefault* flags（⚠️ 热升级兼容，迁移前存量数据）
 *           → 首个启用的同类型系统模型（type=target, isSystem=true, isActive=true） → undefined
 */
async function loadDefaultModels(
  systemModelIdMap: Map<string, SystemModelItemType>,
  systemActiveModelList: SystemModelItemType[]
): Promise<SystemDefaultModelType> {
  const sysConfig = await MongoDefaultModel.findOne({}).lean();

  return resolveSystemDefaults(sysConfig, systemModelIdMap, systemActiveModelList);
}

const MODEL_ID_FIELDS = [
  'llmId', 'embeddingId', 'ttsId', 'sttId', 'rerankId',
  'datasetTextLLMId', 'datasetImageLLMId', 'chatTitleLLMId', 'helperBotLLMId'
] as const;

function fieldToKey(field: string): keyof SystemDefaultModelType {
  return field.replace('Id', '') as keyof SystemDefaultModelType;
}

/** 解析系统级默认：显式配置优先，未配置的回退到 legacy isDefault* flags（⚠️ 热升级兼容），再回退到首个启用的同类型系统模型 */
function resolveSystemDefaults(
  sysConfig: any,
  systemModelIdMap: Map<string, SystemModelItemType>,
  systemActiveModelList: SystemModelItemType[]
): SystemDefaultModelType {
  const result: SystemDefaultModelType = {};

  const typeMap: Record<string, { type: ModelTypeEnum; filter?: (m: SystemModelItemType) => boolean; legacyFlag?: string }> = {
    llmId:             { type: ModelTypeEnum.llm, legacyFlag: 'isDefault' },
    embeddingId:       { type: ModelTypeEnum.embedding, legacyFlag: 'isDefault' },
    ttsId:             { type: ModelTypeEnum.tts, legacyFlag: 'isDefault' },
    sttId:             { type: ModelTypeEnum.stt, legacyFlag: 'isDefault' },
    rerankId:          { type: ModelTypeEnum.rerank, legacyFlag: 'isDefault' },
    datasetTextLLMId:  { type: ModelTypeEnum.llm, legacyFlag: 'isDefaultDatasetTextModel' },
    datasetImageLLMId: { type: ModelTypeEnum.llm, filter: (m) => 'vision' in m && !!m.vision, legacyFlag: 'isDefaultDatasetImageModel' },
    chatTitleLLMId:    { type: ModelTypeEnum.llm, legacyFlag: 'isDefaultChatTitleModel' },
    helperBotLLMId:    { type: ModelTypeEnum.llm, legacyFlag: 'isDefaultHelperBotModel' }
  };

  for (const [idField, { type, filter, legacyFlag }] of Object.entries(typeMap)) {
    const key = fieldToKey(idField);

    // 1. 显式配置
    const modelId = sysConfig?.[idField];
    if (modelId) {
      const model = systemModelIdMap.get(modelId);
      if (model?.isActive && (!filter || filter(model))) {
        result[key] = model as any;
        continue;
      }
    }

    // 2. ⚠️ 热升级兼容：legacy isDefault* flags（迁移前的存量标记；模型需 active + 通过 filter）
    if (legacyFlag) {
      const legacyDefault = systemActiveModelList.find(m => {
        if (m.type !== type) return false;
        if (!m.isSystem) return false;
        if (filter && !filter(m)) return false;
        return (m as any)[legacyFlag] === true;
      });
      if (legacyDefault) {
        result[key] = legacyDefault as any;
        continue;
      }
    }

    // 3. 回退到首个启用的同类型系统模型（type=target, isSystem=true, isActive=true）
    const fallback = systemActiveModelList.find(m => {
      if (m.type !== type) return false;
      if (!m.isSystem) return false;
      if (filter && !filter(m)) return false;
      return true;
    });
    if (fallback) {
      result[key] = fallback as any;
    }
  }

  return result;
}
```

**回退策略**：

| 优先级 | 条件 | 说明 |
|--------|------|------|
| 1 | root 显式配置 | `default_models` 中已配置且模型存在 + isActive + 通过 filter |
| 2 | ⚠️ legacy `isDefault*` flags（热升级兼容） | system_models 上旧标记（`isDefault`/`isDefaultDatasetTextModel` 等），模型需 isSystem + isActive + 通过 filter；覆盖迁移前窗口（default_models 尚未初始化时） |
| 3 | 首个系统模型 | 第一个 `isSystem=true` + isActive + 类型匹配的模型（重构前业务逻辑） |
| 4 | `undefined` | 无系统模型可用 → 返回 `undefined` |

## 3. Change Stream 与缓存刷新

### 3.1 Change Stream

**文件**: `packages/service/core/ai/model/utils.ts`

```typescript
export const watchSystemModelUpdate = () => {
  const changeStream = MongoSystemModel.watch();

  return changeStream.on(
    'change',
    debounce(async () => {
      try {
        await loadSystemModels(true);          // 重新加载模型到内存 Map
        await reloadFastGPTConfigBuffer();     // 刷新所有节点的配置缓存
        await refreshVersionKey(SystemCacheKeyEnum.modelPermission, '*'); // 刷新权限版本
      } catch (error) {
        const logger = getLogger(LogCategories.MODULE.AI.CONFIG);
        logger.error('System model change stream handler failed', { error });
      }
    }, 500)
  );
};
```

## 4. 前端模型模板集成

`getDefaultConfig` API 已移除。模型创建/编辑时，前端通过 `GET /api/core/ai/model/templates` 获取 plugin 模型模板列表。模板数据来自 `global.modelTemplateCache`（启动时从 `pluginClient.listModels()` 加载），每次请求直接返回全量列表：

```typescript
// 前端调用模板 API
const { templates } = await fetch('/api/core/ai/model/templates?provider=&type=&search=');

// 按 provider/type/name 搜索过滤
const filtered = templates.filter(t =>
  (!provider || t.provider === provider) &&
  (!type || t.type === type) &&
  (!search || t.name.includes(search) || t.model.includes(search))
);

// 用户选择模板后，自动填充 provider 默认字段：
// maxContext, maxResponse, functionCall, vision, reasoning, toolChoice, defaultConfig, fieldMap 等
```

服务端 `global.modelTemplateCache` 在 `loadSystemModels()` 时从 `pluginClient.listModels()` 加载并脱敏，作为 templates API 的数据源。模板数据仅在 plugin 更新（触发服务重启）时变化，无需增量刷新机制。
