# FastGPT Documentation

The product documentation helps readers build FastGPT apps, operate deployments, and use integrations and APIs.

## Language

**Documentation site**:
The collection of product guides, deployment instructions, handwritten API references, navigation, and discovery interfaces published together as FastGPT's official documentation. Linked video, solution, and application-generated reference sites are separate content surfaces.

**Chinese source page**:
A Chinese-language documentation page whose meaning, technical facts, and version context guide its English counterpart.

**English counterpart**:
An English-language page covering the same topic and technical guidance as its Chinese source page, written naturally for English readers.

**Archived upgrade guide**:
Historical instructions for upgrading a specific older FastGPT release. Its version context remains part of the reader-facing guidance.

**Technical parity**:
Agreement between language editions on prerequisites, procedures, configuration values, examples, limitations, and expected results.

**English media guidance**:
English instructions, captions, and explanations that make a documented procedure understandable alongside shared screenshots or videos in their original language.
