[SiliconCloud(硅基流动)](https://cloud.siliconflow.cn/i/TR9Ym0c4) 是一个提供开源模型推理 API 的平台，覆盖语言、索引（Embedding）、重排、语音合成（TTS）、语音识别（STT）等模型，可接入 FastGPT 使用。

在阅读该章之前，请先确保你阅读了[模型配置说明](/zh-CN/self-host/config/model/intro)。

## 1. 注册账号

1. [点击注册硅基流动账号](https://cloud.siliconflow.cn/i/TR9Ym0c4)
2. 进入控制台，获取 API key: https://cloud.siliconflow.cn/account/ak

## 2. 新增模型

系统内置了几个硅基流动的模型进行体验，如果需要其他模型，可以[手动添加](/zh-CN/self-host/config/model/intro#新增自定义模型)。

在**管理员 → 系统资源 → 系统模型**页面启用所需的语言模型、视觉模型（如 `Qwen2.5-72B`、`Qwen2-VL-72B`）、索引模型（如 `bge-m3`）、重排模型（如 `bge-reranker-v2-m3`）以及语音合成与语音识别模型。

![2. 新增模型：界面示例](/imgs/optimized/image-104.png.webp)


## 3. 新增模型渠道

在模型渠道页，新增一个硅基流动的渠道，选择刚刚添加的模型即可。

![3. 新增模型渠道：界面示例](/imgs/optimized/image-126.png.webp)

## 总结

如果你想快速的体验开源模型或者快速的使用 FastGPT，不想在不同服务商申请各类 Api Key，那么可以选择 SiliconCloud 的模型先进行快速体验。

如果你决定未来私有化部署模型和 FastGPT，前期可通过 SiliconCloud 进行测试验证，后期再进行硬件采购，减少 POC 时间和成本。
