[SiliconCloud](https://cloud.siliconflow.cn/i/TR9Ym0c4) provides open-source model inference APIs covering language, embedding, reranking, text-to-speech (TTS), and speech-to-text (STT) models for FastGPT.

Before reading this guide, make sure you've read the [Model Configuration Guide](/en/self-host/config/model/intro).

## 1. Register an Account

1. [Register a SiliconCloud account](https://cloud.siliconflow.cn/i/TR9Ym0c4)
2. Go to the console and get your API key: https://cloud.siliconflow.cn/account/ak

## 2. Add Models

The system includes a few SiliconCloud models by default for quick testing. If you need additional models, you can [add them manually](/en/self-host/config/model/intro#add-a-custom-model).

In **Admin → System Resources → System Models**, enable the required language and vision models (such as `Qwen2.5-72B` and `Qwen2-VL-72B`), embedding model (`bge-m3`), rerank model (`bge-reranker-v2-m3`), and speech models.

![2. Add Models — interface example](/imgs/optimized/image-104.png.webp)

## 3. Add a Model provider

On the Model providers page, add a new SiliconCloud provider and select the models you just added.

![3. Add a Model provider — interface example](/imgs/optimized/image-126.png.webp)

## Summary

If you want to quickly try open source models or get started with FastGPT without applying for API keys from multiple providers, SiliconCloud is a great option for a fast start.

If you plan to self-host models and FastGPT in the future, you can use SiliconCloud for initial testing and validation, then proceed with hardware procurement later — reducing POC time and cost.
