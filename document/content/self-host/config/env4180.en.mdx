---
title: Environment variables (V4.18.0+)
description: Environment variables for FastGPT App, Pro, Code Sandbox, and Volume Manager in V4.18.0 and later.
---

Starting with V4.18.0, environment configuration is simpler, with business settings managed in Admin. This page lists the remaining environment variables. Set them in the relevant service and restart that service after changes. Build-time variables require a new build.

Configure the Secure attribute for login cookies under Admin → Security, and the shared HTTP client response size limit under Admin → Resource limits (default: 20 MiB; 0 allows only empty responses). Legacy `AUTH_COOKIE_SECURE` and `SERVICE_AXIOS_MAX_CONTENT_LENGTH` values are imported only from the App process environment during the upgrade migration; matching Pro values are not imported. Existing form values take precedence. Changing these environment variables after upgrading has no effect. Cookie attributes apply when cookies are reissued; HTTP limits apply to subsequent requests.

### Network security and proxies

| Variable               | Default | Description                                                                                                                |
| ---------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------- |
| `TRUSTED_PROXY_ENABLE` | `false` | Validate client IP information provided by reverse proxies.                                                                |
| `TRUSTED_PROXY_IPS`    | Empty   | Trusted reverse proxy IP/CIDR list, separated by commas or whitespace.                                                     |
| `HTTP_PROXY`           | Empty   | Outbound HTTP proxy for Node and workers.                                                                                  |
| `HTTPS_PROXY`          | Empty   | Outbound HTTPS proxy for Node and workers.                                                                                 |
| `NO_PROXY`             | Empty   | Address list that bypasses proxies.                                                                                        |
| `ALL_PROXY`            | Unset   | Proxy for outbound clients that support this variable. Default fetch/OpenAI clients require `HTTP_PROXY` or `HTTPS_PROXY`. |

Protected requests through the shared HTTP client include Workflow HTTP Nodes, HTTP tools, and the chat channels and file operations that use this client. When these requests use a proxy, the FastGPT runtime must be able to resolve the destination, and the HTTP or HTTPS proxy must allow `CONNECT` to the resolved IP and port. Switch SOCKS and forward-only HTTP proxies to a compatible proxy. Destinations matched by `NO_PROXY` use a direct connection and still undergo address checks. If no request timeout is set, the proxy handshake has a 30-second deadline.

Before upgrading, use your actual Workflows and channels in a test environment to verify proxy authentication, DNS resolution, and `CONNECT` policy. If you switch proxies, update the applicable `HTTP_PROXY`, `HTTPS_PROXY`, or `ALL_PROXY` setting and restart the affected processes.
