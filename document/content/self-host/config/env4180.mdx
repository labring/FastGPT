title: 环境变量说明（V4.18.0+）
description: FastGPT V4.18.0 及后续版本的 App、Pro、Code Sandbox 和 Volume Manager 环境变量说明
---

V4.18.0 起，环境变量已简化，业务配置集中到管理员页面维护。本页仅列出仍保留的环境变量。请在对应服务中设置，修改后重启该服务；构建期变量需要重新构建。

登录 Cookie 的 Secure 属性在管理员「安全设置」中配置，共享 HTTP 客户端响应体上限在「资源限制」中配置（默认 20 MiB，0 仅允许空响应）。旧 `AUTH_COOKIE_SECURE`、`SERVICE_AXIOS_MAX_CONTENT_LENGTH` 仅从 App 进程 ENV 在升级迁移时导入，Pro 同名 ENV 不参与迁移，已有表单值优先；升级后修改这些 ENV 不再生效。Cookie 属性在重新签发时应用，HTTP 上限作用于后续请求。

## App / Pro 共用环境变量

### 基础与密钥

| 变量                  | 默认值             | 说明                                                                                                  |
| --------------------- | ------------------ | ----------------------------------------------------------------------------------------------------- |
| `DB_MAX_LINK`         | `10`               | MongoDB、PG、OceanBase、openGauss 等数据库连接池最大连接数，自动限制在 10～1000。                     |
| `FILE_TOKEN_KEY`      | 无，**必填**       | 文件读取、文件鉴权相关密钥，长度至少 6 位。                                                           |

| `ROOT_KEY`            | `fastgpt_root_key` | 当前系统管理员 API 密钥，可用于调用 `/api/admin/**` 接口，长度至少 6 位。                             |

### 安全配置

| 变量                   | 默认值  | 说明                                                                                               |
| ---------------------- | ------- | -------------------------------------------------------------------------------------------------- |
| `TRUSTED_PROXY_ENABLE` | `false` | 是否校验反向代理传入的客户端 IP。                                                                  |
| `TRUSTED_PROXY_IPS`    | 空      | 可信反向代理 IP/CIDR 列表，逗号或空白分隔。                                                        |
| `HTTP_PROXY`           | 空      | Node/worker 出站 HTTP 代理。                                                                       |
| `HTTPS_PROXY`          | 空      | Node/worker 出站 HTTPS 代理。                                                                      |
| `NO_PROXY`             | 空      | 不走代理的地址列表。                                                                               |
| `ALL_PROXY`            | 未设置  | 支持此变量的出站客户端所用代理；普通 fetch/OpenAI 默认客户端需使用 `HTTP_PROXY` 或 `HTTPS_PROXY`。 |

受保护的共享 HTTP 请求（如工作流 HTTP 节点、HTTP 工具及使用该客户端的对话渠道和文件处理）经代理时，需要 FastGPT 所在环境能解析目标域名，且 HTTP 或 HTTPS 代理允许向解析后的目标 IP 和端口发起 `CONNECT`。SOCKS 代理和仅支持转发普通 HTTP 请求的代理需切换到满足该要求的代理。`NO_PROXY` 命中的目标保持直连并继续校验地址。未设置请求超时时，代理握手最多等待 30 秒。

升级前，请在测试环境使用实际工作流和渠道验证代理认证、目标 DNS 和 `CONNECT` 策略；如需更换代理，更新对应的 `HTTP_PROXY`、`HTTPS_PROXY` 或 `ALL_PROXY` 后重启受影响的进程。

微信个人号渠道不经过上述环境代理，需由 App 容器直连 `ilinkai.weixin.qq.com`（及其子域）和 `cdn.weixin.qq.com`（及其子域，默认媒体下载使用 `novac2c.cdn.weixin.qq.com`）且解析为公网 IP；调整出网后请在容器内用不经代理的 HTTPS（如 `curl --noproxy '*'`）验证连通性，并在升级后分别复测消息与媒体。
