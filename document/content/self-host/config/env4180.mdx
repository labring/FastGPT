---

V4.18.0 起，环境变量已简化，业务配置集中到管理员页面维护。本页仅列出仍保留的环境变量。请在对应服务中设置，修改后重启该服务。

登录 Cookie 的 Secure 属性在管理员「安全设置」中配置，共享 HTTP 客户端响应体上限在「资源限制」中配置（默认 20 MiB，0 仅允许空响应）。旧 `AUTH_COOKIE_SECURE`、`SERVICE_AXIOS_MAX_CONTENT_LENGTH` 仅从 App 进程 ENV 在升级迁移时导入，Pro 同名 ENV 不参与迁移，已有表单值优先；升级后修改这些 ENV 不再生效。Cookie 属性在重新签发时应用，HTTP 上限作用于后续请求。

## App / Pro 共用环境变量

| 变量                  | 默认值             | 说明                                                                                                  |
| --------------------- | ------------------ | ----------------------------------------------------------------------------------------------------- |

### 安全配置

| 变量                   | 默认值  | 说明                                                                                               |
| ---------------------- | ------- | -------------------------------------------------------------------------------------------------- |
| `TRUSTED_PROXY_ENABLE` | `false` | 是否校验反向代理传入的客户端 IP。                                                                  |
| `TRUSTED_PROXY_IPS`    | 空      | 可信反向代理 IP/CIDR 列表，逗号或空白分隔。                                                        |
| `HTTP_PROXY`           | 空      | Node/worker 出站 HTTP 代理。                                                                       |
| `HTTPS_PROXY`          | 空      | Node/worker 出站 HTTPS 代理。                                                                      |
| `NO_PROXY`             | 空      | 不走代理的地址列表。                                                                               |
| `ALL_PROXY`            | 未设置  | 支持此变量的出站客户端所用代理；普通 fetch/OpenAI 默认客户端需使用 `HTTP_PROXY` 或 `HTTPS_PROXY`。 |

受保护的出站请求（如工作流 HTTP 节点、HTTP 工具、MCP 客户端及使用共享客户端的渠道和文件处理）在命中 `HTTP_PROXY`、`HTTPS_PROXY` 或 `ALL_PROXY` 时，支持 `http://`、`https://`、`socks://`、`socks5://` 与 `socks5h://` 代理协议，目标域名解析与出站连接均交由代理层处理，请在代理侧配置出站访问控制（禁止访问回环、内网网段及云元数据地址）以防范代理侧 DNS 重绑定导致的 SSRF 风险。`NO_PROXY` 命中的目标保持直连并继续执行本地地址与 IP 校验。

微信个人号渠道仅允许通过 HTTPS 访问 `ilinkai.weixin.qq.com`（及其子域）和 `cdn.weixin.qq.com`（及其子域，默认媒体下载使用 `novac2c.cdn.weixin.qq.com`）并禁止重定向；支持通过 `HTTP_PROXY`、`HTTPS_PROXY` 和 `ALL_PROXY` 出网（代理侧需自行做好出站访问控制），未配置代理或命中 `NO_PROXY` 时直连并校验公网 IP。

| `FASTGPT_APP_URL`                            | `http://localhost:3000`                  | FastGPT 主站内网基准地址，用于回源校验 ticket 与预览会话；官方 Compose 模板设为 `http://fastgpt-app:3000`。                 |
| `FASTGPT_APP_REQUEST_TIMEOUT_SECS`           | `10`                                     | Proxy 回源请求 FastGPT 主站的超时时间，单位秒；官方 Compose 模板设为 `60`。                                                 |
| `AGENT_SANDBOX_PROXY_ADDRESS_CACHE_TTL_SECS` | `30`                                     | Preview 文件资源的沙盒端点解析缓存时长，单位秒。                                                                            |
| `AGENT_SANDBOX_PROXY_REWRITE_HOST`           | 未设置                                   | 将主站返回的本地回环上游沙盒地址改写为容器可访问的 Host（例如开发 Compose 设为 `host.docker.internal`，生产环境一般留空）。 |
| `RUST_LOG`                                   | `info,fastgpt_agent_sandbox_proxy=debug` | Proxy 服务日志级别过滤表达式（支持 `error`、`warn`、`info`、`debug`、`trace`）。                                            |
