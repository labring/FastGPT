This page describes the environment variables commonly used in a self-hosted FastGPT deployment. `projects/app` and `pro/admin` both reuse many settings from `packages/service/env.ts`, so database, secret, object storage, vector database, and service-level variables are documented together. Variables that are only read by `projects/app` or `pro/admin` are listed separately.

## Notes

- `projects/app`: the main Next.js app, including pages, API routes, Workflows, Datasets, object storage, and vector storage.
- `pro/admin`: the commercial Admin service. Besides its own Admin variables, it also reuses App/Service settings such as database, secrets, object storage, models, and logging.
- `projects/code-sandbox`: the code execution sandbox service. It exposes the `/sandbox` endpoint and is called by App through the connection URL configured in Admin.
- `packages/service/env.ts` exports `serviceEnv`; `projects/app/src/env.ts` exports `appEnv`.
- Shared App/Admin boolean variables use `true`, `1`, `yes`, `y`, or `on` to enable a feature. Other values are treated as disabled.
- The Status column distinguishes runtime variables (`-`), migration seeds, and retired variables.
- `FILE_TOKEN_KEY`, `AES256_SECRET_KEY`, and `INVOKE_TOKEN_SECRET` are required at runtime. Use separate strong random secrets and do not use the example values in production.

### Runtime configuration and migration seeds

Starting with V4.18.0, site settings, feature switches, authentication policy, resource limits, concurrency, storage access policies, and Agent Sandbox settings are maintained in **Admin → Instance configuration**. App and Pro read the same database configuration; saved changes apply to subsequent operations without changing ENV.

Rows marked **Migration seed** below describe legacy environment variables, not runtime settings. Only App's one-time migration reads these values to initialize missing instance configuration, while preserving existing administrator values and explicitly cleared settings. Setting them only in Pro, or changing them after migration and restarting, does not override the database. The defaults shown on these rows describe the legacy migration input; check Admin for the current effective values.

All other runtime ENV changes require restarting the service that reads them. Build-time variables such as `NEXT_PUBLIC_BASE_URL` require rebuilding the image.

### Fixed runtime policies and retired variables

The following historical variables are no longer read and cannot change the current policies:

- `STREAM_RESUME_TTL_SECONDS`, `STREAM_RESUME_POST_COMPLETE_TTL_SECONDS`, `STREAM_RESUME_REDIS_MAXMEMORY_RATIO`, and `STREAM_RESUME_REDIS_MEMORY_CHECK_INTERVAL_MS`: Stream resume mirrors remain available for 300 seconds during generation and 30 seconds after completion. New mirrors are not created when Redis memory use reaches 50% of its configured `maxmemory`; memory checks are cached for 5 seconds.
- `TRACK_BATCH_UPDATE_TIME`: The tracking loop waits 5 seconds after each batch flush.
- `USE_IP_LIMIT`: Routes that register IP rate-limiting middleware always run it; this switch is no longer available.
- `DISABLE_CACHE`: System memory caching can no longer be disabled through configuration. Development mode still follows each cache item's refresh policy.

`DEFAULT_TEAM_BASIC_PERMISSIONS_ENABLED` and `RETRIEVAL_RESULTS_LIMIT` are read from each service process's environment, not from their former instance configuration fields. Restart the services that use a changed value. Keep the new-Team permission setting consistent across FastGPT and Pro Admin.

These variables are mainly validated by `packages/service/env.ts` and apply to `projects/app` and to `pro/admin` when it imports `@fastgpt/service`. A few App-side switches are still defined in `packages/service/env.ts`; they are also called out in the App-specific section below.

### Subservice connections

Starting with V4.18.0, both Community and Commercial editions can configure Code Sandbox and the MCP SSE service under **Admin → Subservice configuration**. Code Sandbox is disabled by default. To enable it, enter the service URL and token; the token must match the sandbox process’s `SANDBOX_TOKEN`. You can test the connection on the page. The related entry points are hidden when the service is disabled or its URL or token is missing.

The MCP SSE service is disabled by default. To enable it, enter an MCP SSE proxy URL accessible to clients, without a trailing `/`. The SSE publishing entry is hidden when the service is disabled or its URL is missing.

During an upgrade, a one-time migration backfills the Code Sandbox connection and the MCP SSE switch from legacy configuration, preserving administrator values and explicitly cleared settings. The legacy `CODE_SANDBOX_URL`, `CODE_SANDBOX_TOKEN`, and `SSE_MCP_SERVER_PROXY_ENDPOINT` variables are read only for migration and are no longer runtime configuration. Plugin remote debugging is controlled by the Plugin service configuration; AI Proxy has no Admin switch.

#### Enhanced PDF Parsing

In **Admin → Providers**, select a parsing provider, enter its URL or credentials, and save. FastGPT uses the selected provider; saved credentials for other providers do not change that choice. Select **None** to use the built-in parser.

##### Use the Sealos PDF Parsing Service

1. Open [Sealos AI Proxy](https://hzh.sealos.run/?uid=fnWRt09fZP&openapp=system-aiproxy) and create an API key.
2. Enter the following values in the PDF parsing settings:

```text
Custom service URL: https://aiproxy.hzh.sealos.run/v1/parse/pdf?model=parse-pdf
Custom service key: your-sealos-api-key
```

##### Use SoMark

1. Open [SoMark Studio](https://somark.ai/Studio/apikey) and create an API key.
2. Enter the following values in the PDF parsing settings:

```text
SoMark API key: sk-your-api-key
```

The SoMark synchronous parsing endpoint accepts files up to 200 MB and 300 pages. See the [SoMark API documentation](https://docs.somark.ai/en/api-reference) for the complete limits and error codes.

##### Use Another Custom PDF Parsing Service

```text
Custom service URL: https://your-pdf-parser.example.com/v2/parse/file
Custom service key: your-service-key
```

The custom service key is optional. When set, FastGPT sends it to the parsing service as `Authorization: Bearer <key>`. The service must accept a `multipart/form-data` POST request with a `file` field and return JSON in this format:

```json
{
  "pages": 10,
  "markdown": "Parsed Markdown content"
}
```

##### Use TextIn

```text
TextIn App ID: your-app-id
TextIn Secret Code: your-secret-code
```

##### Use Doc2x

```text
Doc2x key: your-api-key
```

After saving in Admin, the new settings apply to subsequent parsing requests without a restart. Enable **Enhanced PDF Parsing** when importing files into a Dataset or configuring App file uploads. PDFs use the configured enhanced parsing service only when this option is enabled; otherwise, FastGPT uses its built-in parser.
