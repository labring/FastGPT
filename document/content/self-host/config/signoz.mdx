## 介绍

[SigNoz](https://signoz.io/) 是一款开源的应用性能监控（APM）和可观测性平台，为 FastGPT 提供全面的服务监控能力。它基于 OpenTelemetry 标准，能够收集、处理和可视化分布式系统的遥测数据，包括链路追踪（Tracing）、指标监控（Metrics）和日志分析（Logging）。

**主要功能:**

- **链路追踪**：跟踪用户请求在 FastGPT 各个服务间的完整调用链路
- **性能监控**：监控 API 响应时间、吞吐量等关键性能指标
- **错误追踪**：自动捕获和记录系统异常，便于问题排查
- **日志聚合**：集中收集和管理应用日志，支持结构化查询
- **实时告警**：基于指标阈值设置告警规则，及时发现系统异常

## 配置 FastGPT

1. 修改 FastGPT 环境变量

**日志等级枚举**: `trace` | `debug` | `info` | `warning` | `error` | `fatal`

将下方地址替换为上一步获取的 SigNoz OTLP 公网或内网地址（FastGPT 在容器内运行时，`localhost` 指向容器自身，请使用容器可达的服务地址或域名）：

```dotenv
LOG_ENABLE_CONSOLE=true # 是否开启控制台打印
LOG_CONSOLE_LEVEL=debug # 控制台打印最低日志等级
LOG_ENABLE_OTEL=true # 是否开启 OTEL 日志收集
LOG_OTEL_LEVEL=info # OTEL 日志收集的最低日志等级
LOG_OTEL_SERVICE_NAME=fastgpt-client # 传递给 OTLP 收集器的服务名称
LOG_OTEL_URL=https://<signoz-otlp-地址>/v1/logs # OTLP 收集器地址，保留 /v1/logs 路径
TRACING_ENABLE_OTEL=true # 是否开启 OTEL 链路追踪
TRACING_OTEL_URL=https://<signoz-otlp-地址>/v1/traces # 链路追踪上报地址，保留 /v1/traces 路径
METRICS_ENABLE_OTEL=true # 是否开启 OTEL 指标上报
METRICS_OTEL_URL=https://<signoz-otlp-地址>/v1/metrics # 指标上报地址，保留 /v1/metrics 路径
```

`LOG_*` 只上报日志；链路追踪和指标需要分别配置 `TRACING_*` 与 `METRICS_*`。生产环境（`NODE_ENV=production`）链路追踪默认采样率为 `0.01`，可通过 `TRACING_OTEL_SAMPLE_RATIO`（`0` 到 `1`）调整。

2. 重启 FastGPT

## 注意事项

1. 调整日志存储时长

SigNoz 会持续占用较多磁盘空间，建议将 `LOG_OTEL_LEVEL` 设为 `info` 及以上，并将日志存储保留时长调整为 7 天。若发现磁盘占用写满且新监控数据停止增长，请及时扩容存储卷。
