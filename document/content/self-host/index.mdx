## 系统架构与组件拓扑

FastGPT 私有化部署由核心应用层、辅助执行层与四维数据底座协同构成：

```mermaid
graph TB
    Client[客户端 / 浏览器 / API 调用方] --> Ingress[反向代理 / Nginx / 域名网关]
    Ingress --> App[FastGPT Core 主服务<br/>Next.js Web / API / Worker]

    subgraph 执行与代理层
        App --> AIProxy[AI Proxy 统一模型路由]
        App --> CodeSandbox[Code Sandbox 代码沙箱<br/>Python / JS 轻量快速执行]
        App --> Provider[Agent Sandbox Provider API]
        Provider --> OpenSandbox[OpenSandbox / Sealos Devbox Workspace]
        Client --> SandboxProxy[Agent Sandbox Proxy]
        SandboxProxy --> OpenSandbox
    end

    subgraph 四维数据底座
        App --> Mongo[(MongoDB 副本集<br/>应用/集合/分块元数据)]
        App --> VectorDB[(向量数据库<br/>PGVector / Milvus / OceanBase / SeekDB)]
        App --> S3[(S3 / MinIO 对象存储<br/>Public 头像与 Private 原始文件)]
        App --> Redis[(Redis 缓存与消息队列<br/>BullMQ / 租约锁 / 跨节点同步)]
    end
```

## 资源规划与基准配置

使用代表性资料与提问进行容量验证。资源需求取决于向量维度、分块数量、模型延迟、导入并发及保留周期；生产限额应依据实测结果确定。

| 工作负载 | 观测指标 | 验收方式 |
|---|---|---|
| 测试体验 | 所需服务的峰值内存、磁盘占用 | 完成导入、检索和对话全流程 |
| 生产运行 | 并发请求、队列等待、p95 延迟、向量索引大小 | 代表性负载下满足服务目标 |
| 高可用 | 副本拓扑、恢复耗时、备份容量 | 在预发布环境验证故障切换与恢复 |

## 向量数据库选型与优先级

系统在启动时读取环境变量，按固定优先级选择第一个有效配置的驱动：

1. **SeekDB**（`SEEKDB_URL`）：通过 MySQL 协议接入向量驱动。
2. **OceanBase**（`OCEANBASE_URL`）：OceanBase 向量驱动，按服务端版本配置支持的能力。
3. **PostgreSQL**（`PG_URL`）：内置默认驱动，采用 pgvector 插件，运维链路极简。
4. **Milvus**（`MILVUS_ADDRESS`）：版本要求 2.5.16 以上，启用 `modeldata_v2` 单表，由 Milvus 协同存储向量与 BM25 全文。
5. **OpenGauss**（`OPENGAUSS_URL`）：国产化信创场景适配。
