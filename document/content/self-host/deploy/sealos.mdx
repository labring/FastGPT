## 多模型支持

当前 FastGPT 通过 AI Proxy 管理模型渠道。模板的组件、默认参数与镜像版本可能随发布调整，部署前在模板页面逐项核对模型、数据库和对象存储配置。

### 1. 开始部署

由于需要部署数据库，部署完后需要等待 2~4 分钟才能正常访问。默认用了最低配置，首次访问时会有些慢。

核对模板中的管理员初始凭证、数据库、对象存储、AI Proxy 等参数。历史模板可能提供 `root_password`、`openai` / `oneapi` 字段；当前字段以选定模板为准。

![1. 开始部署：界面示例](/imgs/optimized/sealos1.png.webp)

点击部署后，会跳转到应用管理页面。可以点击 `fastgpt` 主应用右侧的详情按键（名字为 fastgpt-xxxx），如下图所示。

![1. 开始部署：界面示例](/imgs/optimized/sealos-deploy1.jpg.webp)

点击详情后，会跳转到 fastgpt 的部署管理页面，点击外网访问地址中的链接，即可打开 fastgpt 服务。

如需绑定自定义域名、修改部署参数，可以点击右上角变更，根据 sealos 的指引完成。

![1. 开始部署：界面示例](/imgs/optimized/sealos2.png.webp)

### 2. 登录

用户名：`root`

密码使用模板中配置的管理员初始密码；旧模板字段名为 `root_password`。

### 3. 配置模型

登录后在模型提供商页面配置语言模型；知识库检索还需要向量模型。先测试渠道连通性，再测试具体模型。

### 4. 配置模型

模型可用后，完成[首个知识库问答](/zh-CN/guide/getting-started/knowledge-qa)，验证文件导入、索引、回答与引用。

[点击查看模型配置教程](/zh-CN/self-host/config/model/intro)

## 收费

Sealos 采用按量计费的方式，也就是申请了多少 cpu、内存、磁盘，就按该申请量进行计费。具体的计费标准，可以打开 `sealos` 控制面板中的 `费用中心` 进行查看。

## Sealos 使用

### 简介

在应用管理与数据库页面核对模板创建的全部服务，记录镜像、持久化存储和依赖关系。商业版通常还包含商业服务；实际组件数量由模板与已启用能力决定。

![简介：界面示例](/imgs/optimized/onSealos1.png.webp)

点击右侧的详情，可以查看对应应用的详细信息。

### 修改配置文件和环境变量

在 Sealos 中，你可以打开 `应用管理`（App Launchpad）看到部署的 FastGPT，可以打开 `数据库`（Database）看到对应的数据库。

在 `应用管理` 中，选中 FastGPT，点击变更，可以看到对应的环境变量和配置文件。

![修改配置文件和环境变量：界面示例](/imgs/optimized/fastgptonsealos1.png.webp)

### 如何更新/升级 FastGPT

[升级脚本文档](/zh-CN/self-host/upgrading/upgrade-instruction)先看下文档，看下需要升级哪个版本。注意，不要跨版本升级。

例如，目前是 4.5 版本，要升级到 4.5.1，就先把镜像版本改成 v4.5.1，执行一下升级脚本，等待完成后再继续升级。如果目标版本不需要执行初始化，则可以跳过。

升级步骤：

1. 查看[更新文档](/zh-CN/self-host/upgrading/upgrade-instruction)，确认要升级的版本，避免跨版本升级。
2. 打开 sealos 的应用管理
3. 按模板清单找到主服务、商业服务及需要配套升级的依赖
4. 点击对应应用右边 3 个点，变更。或者点详情后右上角的变更。
5. 修改镜像的版本号

![如何更新/升级 FastGPT：界面示例](/imgs/optimized/onsealos2.png.webp)

6. 点击变更/重启，会自动拉取最新镜像进行更新
7. 执行对应版本的初始化脚本(如果有)

### 配置自定义域名

点击对应应用的变更 ->点击自定义域名 ->填写域名 -> 操作域名 Cname -> 确认 -> 确认变。

![配置自定义域名：界面示例](/imgs/optimized/onsealos4.png.webp)

### 如何修改环境变量

打开 Sealos 的应用管理 -> 找到对应的应用 -> 变更 -> 修改环境变量 -> 点击右上角确认变。

![如何修改环境变量：界面示例](/imgs/optimized/onsealos5.png.webp)

[环境变量说明](/zh-CN/self-host/config/env)

### 修改站点名称以及 favicon

修改应用的环境变量，增加

```
SYSTEM_NAME=FastGPT
SYSTEM_DESCRIPTION=
SYSTEM_FAVICON=/favicon.ico
HOME_URL=/dashboard/agent
```

SYSTEM_FAVICON 可以是一个网络地址
