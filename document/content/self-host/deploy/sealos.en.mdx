### 1. Start Deployment

Since databases need to be deployed, wait 2–4 minutes after deployment before accessing. The default uses minimal resources, so the first access may be slow.

Inspect initial administrator credentials, databases, object storage, and AI Proxy settings. Older templates may expose `root_password` and `openai`/`oneapi` fields; the selected template defines the current parameters.

![1. Start Deployment — interface example](/imgs/optimized/sealos1.png.webp)

After clicking deploy, you'll be redirected to the app management page. Click the details button on the right side of the `fastgpt` main app (named fastgpt-xxxx), as shown below.

![1. Start Deployment — interface example](/imgs/optimized/sealos-deploy1.jpg.webp)

After clicking details, you'll see the FastGPT deployment management page. Click the link in the external access address to open the FastGPT service.

To bind a custom domain or modify deployment parameters, click **Change** in the top right and follow Sealos' instructions.

![1. Start Deployment — interface example](/imgs/optimized/sealos2.png.webp)

### 2. Log In

Username: `root`

Password: the initial administrator password configured in the template; older templates call this `root_password`.

### 3. Configure Models

After login, configure a language model in Model Providers. Knowledge retrieval also requires an embedding model. Test channel connectivity and then the selected models.

### 4. Configure Models

Complete [your first knowledge-base Q&A](/en/guide/getting-started/knowledge-qa) to verify file ingestion, indexing, answers, and citations.

## Using Sealos

### Overview

Inspect all template services in App Launchpad and Database. Record images, persistent storage, and dependencies. Commercial deployments commonly include an additional commercial service; the template and enabled capabilities determine the actual component count.

![Overview — interface example](/imgs/optimized/onSealos1.png.webp)

Click details on the right to view each app's information.

### Modifying Config Files and Environment Variables

In Sealos, open **App Launchpad** to see deployed FastGPT apps, and open **Database** to see corresponding databases.

In **App Launchpad**, select FastGPT, click **Change**, and you'll see environment variables and config files.

![Modifying Config Files and Environment Variables — interface example](/imgs/optimized/fastgptonsealos1.png.webp)

### How to Update/Upgrade FastGPT

[Upgrade script documentation](/en/self-host/upgrading/upgrade-instruction) — read the docs first to determine which version to upgrade to. Do not skip versions.

For example, if you're on version 4.5 and want to upgrade to 4.5.1: change the image version to v4.5.1, run the upgrade script, wait for completion, then continue upgrading. If the target version doesn't require initialization, skip it.

Upgrade steps:

1. Check the [update documentation](/en/self-host/upgrading/upgrade-instruction) to confirm the target version — avoid skipping versions.
2. Open Sealos app management
3. Locate the main service, commercial service, and dependencies requiring a coordinated upgrade in the template inventory
4. Click the 3 dots on the right side of the app, then **Change**. Or click details, then **Change** in the top right.
5. Modify the image version number

![How to Update/Upgrade FastGPT — interface example](/imgs/optimized/onsealos2.png.webp)

6. Click **Change/Restart** to automatically pull the latest image and update
7. Run the initialization script for the corresponding version (if applicable)

![How to Modify Environment Variables — interface example](/imgs/optimized/onsealos5.png.webp)

[Environment Variables](/en/self-host/config/env)

### Modify Site Name and Favicon

Add these environment variables to the app:

```
SYSTEM_NAME=FastGPT
SYSTEM_DESCRIPTION=
SYSTEM_FAVICON=/favicon.ico
HOME_URL=/dashboard/agent
```

SYSTEM_FAVICON can be a URL.
