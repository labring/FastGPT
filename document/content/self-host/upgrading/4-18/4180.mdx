## 升级指南

### 配置变更

- `HNSW_EF_SEARCH` / `systemEnv.hnswEfSearch` 的默认值从 `100` 调整为 `200`，适用于 PostgreSQL、Milvus、OceanBase、SeekDB 和 openGauss；显式配置的值继续生效，可按召回率与查询耗时调整。
- `HNSW_MAX_SCAN_TUPLES` / `systemEnv.hnswMaxScanTuples` 不再生效，管理台移除对应设置；PostgreSQL 的扫描上限改按本次索引检索涉及的最大知识库向量行数自动设置，上限为 `2147483647`，已有部署可移除旧配置。
- 新增 `SERVICE_AXIOS_MAX_CONTENT_LENGTH`，默认 `20` MiB，限制服务端共享 HTTP 客户端缓冲型响应的解压后大小，超限中止请求；依赖更大响应的自定义接入需调大此值。调用方显式设置的响应上限优先，流式下载仍按调用方或业务配额限制。
- 新增 `SHOW_OUTLINK_BRAND`：未配置 `PRO_URL` 时固定为 `true`；接入 Pro 后默认 `false`，可设为 `true` 启用品牌展示。前端 `show_outlink_brand` 由服务端环境派生，覆盖 `config.json` 中的同名配置。
- **插件服务部署**：Docker Compose 模板补齐 `fastgpt-plugin` 的 `FASTGPT_BASE_URL=http://fastgpt-app:3000`，将 `MONGODB_URI` 指向独立的 `fastgpt-plugin` 数据库，并显式设置 `DB_MAX_LINK=100`，避免与主库集合混用；自定义部署应填写插件容器可访问的主服务地址；若插件容器日志出现反向上传文件 `401`，优先核对该地址，修正后重建插件容器并重试工具。已有部署替换模板前应核对原插件库，保留已使用的独立库连接；若需切换数据库，先备份并迁移既有插件数据。
- 默认部署的对象存储改为 RustFS，已有部署可继续使用原存储，如需切换请参考 [MinIO 迁移到 RustFS](/self-host/docker_minio_to_rustfs)。

- **内容审核（Moderation）插件化迁移**：旧版商业版内置的百度文本审核（`censor.BAIDU_TEXT_CENSOR_CLIENTID` / `censor.BAIDU_TEXT_CENSOR_CLIENTSECRET`）、自定义审核地址（`censor.customCensorURL`）以及单模型配置中的 `censor` 开关已废弃，统一升级为由 `fastgpt-plugin` 托管的 `moderation` 插件体系。
  - 原百度审核用户请前往 **管理后台 > 内容审核 > 审核策略配置**，配置并启用官方「百度内容安全（`baidu`）」插件。
  - 原自定义审核 URL（`customCensorURL`）用户可直接安装官方「旧版自定义审核兼容（`legacy-custom-censor`）」插件零代码迁移现有 HTTP 服务，或基于 `@fastgpt-plugin/sdk-factory` 开发原生 `moderation` 插件。
  - 详细的新旧版本对比、配置映射与开发步骤见 [内容审核升级与迁移指南](/self-host/migration/content-moderation)。

### 升级脚本

**升级前提**：先在 4.17.x 完成所需历史迁移，再升级到本版本；4.18.x 已移除旧任务的注册与实现，不会继续执行，数据库中的历史状态和错误明细保留。

新增 **初始化知识库向量索引**（`20261022_initialize_dataset_vector_indexes`），仅 PostgreSQL 在启动后于后台自动执行，不阻塞业务：先核验并在线删除旧全局 `vector_index`，再分批统计有效知识库并投递索引维护任务。任务成功表示统计与投递完成，实际建图由全局串行队列继续执行；清理或扫描失败时，可在升级管理页修复问题后重试，沿已保存的断点继续，同名但定义不匹配的自建索引会保留并报错。

PG 局部索引要求支持 `halfvec`、固定向量维度在 `1–4000` 范围内，并具备在线创建、删除索引的权限及足够的内存、共享内存和磁盘资源。索引未就绪或失败期间继续精确检索，可能增加查询耗时；建图失败不会自动降低资源预算重试，排除故障后由下一次真实向量计数重新投递，缓存命中不会触发重试。

新增 **回填历史对话调用渠道**（`20261104_backfill_chat_publish_source`），启动后独立在后台批量读写，不阻塞业务，也不等待普通后台长任务；分别为对话与统计记录补齐 `publishSource`，不修改旧字段、身份、消息或统计计数。历史 API、MCP 及已删除渠道可能只能恢复类型，无法补齐渠道 ID；引用冲突或数据异常会记录失败，修复后可在升级管理页重试并沿断点续跑。

新增 **回填 API Key 类型**（`20261104_backfill_openapi_key_type`），启动后独立在后台按固定范围分批扫描，仅为缺失类型的旧密钥按 `appId` 绑定情况补齐个人或应用类型，不改变凭证、绑定、归属和额度。类型或绑定异常会记录失败项；修复后可在升级管理页重试，沿断点续跑并优先处理失败数据。

### 兼容说明

- **历史应用密钥**：已保存有效 `appId` 绑定的旧 Key 现按应用 Key 鉴权，请求中的 `appId` 或 SDK 后缀不再覆盖绑定；原先借此访问其他应用、知识库或模型接口的接入需改用个人密钥，查看、复制与修改应用 Key 需具备绑定应用的管理权限。全部鉴权节点升级后再启用应用 Key，回滚版本也必须识别密钥类型与绑定边界。
- **密钥管理脚本**：`/api/support/openapi/list` 默认仅返回本人的个人密钥，不再按 `appId` 置顶；查询历史绑定密钥的脚本需显式选择应用类型，更新应用 Key 时按可编辑字段提交，并移除 `authProxy` 与个人标签字段。
- **HTTP 工具创建**：在工具文件夹内创建 HTTP 工具现要求文件夹写入权限；原依赖日志读取权限创建的接入需调整文件夹授权。
- **根级资源移动**：移动根目录中的应用、工具、知识库、技能及其文件夹，或知识库内根级集合时，现要求被移动资源的管理权限；集合未启用独立权限时按所属知识库权限判定。仅有读取或写入权限的接入需调整授权。
- **知识库权限继承**：创建普通知识库时，`inheritPermission: false` 不再被忽略；已有固定传入该值且仍需继承父级权限的接入，应移除该值或改为 `true`。
- **团队审计查询**：商业版 `/proApi/support/user/team/audit/list` 新增必填的 `dateStart`、`dateEnd`，并要求登录成员具备团队管理权限；已有查询脚本需补齐起止时间并核对调用身份，整日查询应显式提交带偏移的日初至日末。
- **系统模型直连鉴权**：已有系统模型若设置了 `requestUrl` 却依赖默认 `AIPROXY_API_TOKEN` 鉴权，升级前需显式填写该端点的 `requestAuth`；未配置时，OpenAI SDK 与 Pi Agent 的直连请求不再回退默认凭证。
- **对话运行状态**：`chatGenerateStatus` 改由 Redis 租约计算，仅返回 `0`（生成中）或 `1`（空闲），不再持久化到 Mongo 或返回 `2`（错误）；直接读取数据库状态或依赖错误枚举的接入需改用接口及消息错误信息。升级时先停止旧实例接收新请求并等待生成任务结束，再统一切换生成与状态查询实例，避免新旧互斥机制混用。
- **动态选择选项**：用户选择节点及表单单选、多选的变量引用选项，运行时仅保留前 `200` 个有效项，单项文本最长 `100` 个 UTF-16 码元，超出部分截断；依赖超长选项值或后续候选项的流程需调整候选数据，并核对下游匹配逻辑。
- **工作流历史记忆**：内容提取、问题分类与 Pi Agent 的记忆键改按来源和调用路径隔离，直接读写 `ChatItem.memories` 的自定义集成需适配新键，不再依赖 `agentLoopMemory-${nodeId}` 或不含调用路径的子流程键。
- **API 身份参数**：API 会话不再允许更换使用者，已有会话以保存的身份为准，续聊需保持相同 `customUid`；已绑定后漏传、清空或更换，以及从默认身份改为自定义身份都会被拒绝，混用使用者的接入需改用独立 `chatId`。非空 `customUid` 仅允许 API Key 调用；它与 `authProxy` 互斥，即使为空字符串也不能同时传入，已有同时传参的接入需保留一种身份。
- **会话 ID 长度**：会话管理、文件、引用和沙盒等入口统一将 `chatId` 限制为最多 `1024` 个字符；使用超长自定义 ID 的接入需调整生成规则，并核查已有超长会话及相关引用。
- **重复生成响应**：非流式 `chat/completions` 在同会话已有生成时返回 HTTP `409`，依赖原错误状态码的自定义客户端需适配冲突响应。
- **日志 CSV**：基于「使用者」列解析团队成员的脚本需适配 `ID:name` 格式（旧版为成员名），成员缺少姓名时仅输出 ID；渠道列拆分为「调用渠道」与「渠道名」，按列名解析的脚本也需适配。
- **应用日志时间参数**：应用日志相关接口改为校验 ISO 日期或日期时间，其中图表不再接受数字时间戳；旧脚本需调整非标准格式，整日查询应显式提交带偏移的日初至日末，仅日期或无偏移值按服务器本地时间解释。
- **商业版应用图表口径**：统计按请求起点的固定偏移分组，不再读取账号时区，跨夏令时也保持起点偏移；留存仅统计所选窗口内的后续活跃，不再扩展查询，依赖旧口径的报表需显式提供所需偏移并核对留存结果。
- **调用渠道数据**：自定义对话查询与日志解析应改用 `publishSource`；新运行不再写入 `Chat.shareId`，依赖旧字段查询分享历史的集成需适配，升级期间避免将新建分享会话继续交给旧实例读取。
- **Agent 历史上下文**：Agent 运行不再读取节点的 `history` 配置，普通历史窗口统一为最近 `50` 轮，仍保留系统消息与上下文压缩检查点；依赖零历史或自定义历史数组隔离上下文的应用需重新核对上下文控制与模型用量。
- **Agent 文本输出**：`answerText` 和工具响应改为拼接本次 Agent 循环全过程的文本，包含工具调用前的说明；依赖其仅包含最后一段回答的下游节点需调整处理。
- **Agent 交互约束**：Agent 现按交互节点处理，不能放入并行容器，商业版也不再允许为含 Agent 的应用创建自动评测任务；已有并行 Agent 需移出容器，评测接入需选择不含交互节点的应用版本。
- **嵌套沙盒归属**：嵌套 Agent 与工具调用改用根应用会话的沙盒；依赖子应用独立沙盒或按子应用定位文件的流程，需适配根会话归属与父子节点共享工作区的行为。
- **沙盒初始化脚本**：工作流 Agent 与工具调用节点按应用、节点分别记录脚本成功状态，不再复用旧全局标记；已有沙盒升级后，配置了脚本的节点首次使用时会重新执行，请确认脚本可安全重复执行。
- **自建 JavaScript 代码沙盒**：Linux 启用 seccomp 时新增必需的 `fastgpt_js_launcher`；自建镜像或源码部署需重新构建并打包原生组件，将启动器与 `.node` 模块一同部署，缺失启动器时 JavaScript 进程池初始化失败。
- **系统工具管理接口**：移除 `DELETE /api/core/plugin/admin/tool/delete`，仍调用该旧接口的自定义管理端需停止使用。

## 🚀 新增内容

1. **[工具与渠道]** 新增绑定单个应用的应用 API Key，在应用发布页与个人密钥分开管理，由应用管理员共同维护，专用于该应用的对话及对话管理，不依赖归属成员的应用权限。商业版按资源交接流程转交密钥归属，删除应用时同步清理绑定密钥。
2. **[工具与渠道]** 对话及配套管理统一支持外部使用者标识与成员代理，可通过 `customUid` 进一步限定历史、消息、文件、引用和沙盒等操作的使用者范围；开启代理权限的个人密钥可通过 `authProxy` 按被代理成员的权限执行。
3. **[工具与渠道]** 免登录分享页新增适配桌面、移动和嵌入式页面的 FastGPT 标识，启用后新建链接默认展示，桌面访客可在本次访问临时关闭。团队持久隐藏需有效套餐权益，商业版支持按套餐及单条订阅控制；未保存品牌偏好的历史链接继续豁免，已关闭链接在权益失效时恢复展示，保留偏好供权益恢复后生效。
4. **[工作流与 Agent]** 工作流 Agent 节点可从模板面板添加并作为工具节点供其他 Agent 调用，知识库输入支持变量引用；独立 ChatAgent 应用也可作为工作流子应用或 Agent 工具引用，支持传入文件与交互续跑，便于组合多 Agent 流程。
5. **[工作流与 Agent]** 商业版工作流 Builder 支持按明确的新建或修改请求直接搭建、校验和修复工作流，用户要求先看方案时仍等待预览确认；候选交付前增加同一 Agent 上下文中的需求覆盖自检，仍由用户手动应用到画布。
6. **[工作流与 Agent]** 商业版工作流 Builder 支持在同一会话内切换并继续独立任务，分别保存需求、方案和草稿，上下文压缩或运行中断后可按已保存资料继续任务。恢复时仍核对任务状态与画布基线，沙盒丢失时不能保证找回未保存草稿。
7. **[模型与计费]** 商业版团队模型可通过配置接口或模板接入自定义请求地址与鉴权，作为过渡能力支持对话、Agent、向量、重排及语音直连，编辑后保留端点配置。端点在保存和请求时执行安全校验，重定向也受限制；列表隐藏端点与鉴权信息。
8. **[模型与计费]** 模型管理新增拖拽自定义排序，支持保存前取消；root 可调整系统模型，商业版启用团队模型后，具有「安装模型」权限的成员可调整自己的模型顺序。「可用模型」按本人、共享团队、系统模型分组并在组内应用自定义顺序，JSON 配置更新保留排序，客户端的最终系统模型兜底也使用该顺序。
9. **[模型与计费]** 启用权限配置的模型表格新增创建人展示，系统模型单独标识来源；成员展示页可获取最新创建人资料，外链目录不暴露成员信息。
10. **[知识库与文件]** 商业版启用知识库增强时，模板 FAQ 导入接口支持按需生成自动索引，以问题和答案共同作为输入。自动索引任务中超出处理长度上限的条目改走普通向量索引，保留条目及其输入顺序。
11. **[知识库与文件]** 知识库搜索新增「重排候选数」，可设置为 `10–100` 条，默认 `100` 条；按融合、去重后的文本召回顺序选取候选送入重排模型，便于平衡搜索效果、响应耗时和模型负载。重排成功时，超出候选数的文本分块也不会进入权重融合，避免绕过相似度过滤。
12. **[知识库与文件]** 知识库检索结果及引用记录新增重排前的文本召回排名，便于对比召回与重排效果。
13. **[知识库与文件]** 知识库集合列表接口支持按名称、创建时间或更新时间升序或降序排列，名称排序忽略大小写，中文按字符码点排序。
14. **[团队与权限]** 资源创建接口支持为知识库、应用、HTTP/MCP 工具、技能及其文件夹选择继承父级权限或独立授权，便于在创建时控制共享范围。
15. **[团队与权限]** 商业版团队审计日志支持按日期、成员和事件组合筛选，默认展示含今天的近 `7` 个本地自然日，可选择更早日期及停用成员。具备团队管理权限的登录成员可导出全部匹配记录的多语言 CSV，单次最多 `50000` 条，超量需缩小范围；CSV 中的日志时间按查询起点偏移展示，发起导出会写入审计记录。
16. **[团队与权限]** 商业版用户管理接口补充所属团队、成员名和部门路径，团队成员列表补充登录用户名，便于管理端区分账号与成员身份。
17. **[系统与运维]** 对话记录最近一次运行的调用渠道，日志区分展示渠道类型和渠道名称，支持查看渠道 ID；相关筛选、CSV 导出与商业版统计同步采用新渠道分类。
18. **[系统与运维]** 对话日志新增默认隐藏的「鉴权者」列，与「使用者」分开展示，便于区分接入方用户和实际鉴权成员；API 传入的 `customUid` 按原值显示为使用者，CSV 按所选列导出。日志表格按内容分配列宽，避免长 UID 挤压成员姓名。

## ⚙️ 优化

1. **[工作流与 Agent]** 统一 Agent 表单与工作流节点的工具、技能和知识库卡片及状态校验，运行、发布和单节点调试使用相同规则；失效、下线或未配置资源会明确提示，异步选择与保存保留已有配置。
2. **[工作流与 Agent]** 商业版工作流 Builder 预览新增标题、简短概述和待确认状态，恢复待确认方案时定位到卡片顶部，后续渲染保留阅读位置；确认、修改与取消仍使用统一交互入口。
