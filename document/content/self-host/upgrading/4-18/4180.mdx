## 升级指南

### 配置变更

本轮无环境变量或系统配置变更，从 V4.17.3 升级无需额外调整配置。

### 镜像更新

### 升级脚本

本轮无新增或调整的自动升级脚本。

### 兼容说明

- **工作流历史记忆**：内容提取、问题分类与 Pi Agent 的记忆键统一按来源和调用路径隔离。运行时兼容读取旧 Agent 键与可确定归属的旧子流程键，写入新键后清理对应旧键，无需批量迁移历史会话；直接读写 `ChatItem.memories` 的自定义集成需适配新键，不再依赖 `agentLoopMemory-${nodeId}` 或不含调用路径的子流程键。
- **历史配置与交互续跑**：普通新请求中，`history=0` 不读取旧记忆，自定义历史只读取所传历史末尾 AI 消息的记忆；显式交互续跑优先使用父流程检查点，避免历史设置清除当前交互的恢复状态。

## 🐛 修复

1. **[工作流与 Agent]** 修复多个子应用或工作流工具调用同一目标时，内部节点记忆互相覆盖的问题。按完整调用路径隔离内容提取、问题分类与 Pi Agent 状态，覆盖克隆应用共享后代工具、递归进入根应用等场景。
2. **[工作流与 Agent]** 修复 Agent、工具调用及嵌套子流程的记忆未完整回传、未执行分支的历史记忆丢失，以及并发子流程用旧状态覆盖其他节点新状态的问题；仅合并子流程本次更新，保留其他有效记忆。
3. **[工作流与 Agent]** 修复循环、并行运行中的记忆传递与失败隔离问题。循环在成功迭代间传递记忆，交互暂停保留检查点，失败迭代不提交；并行任务仅合并成功结果，失败尝试不影响重试，并按输入顺序合并，同一记忆键以靠后的成功任务为准。
4. **[工作流与 Agent]** 修复嵌套 Pi Agent 在历史为 0 或空自定义历史时无法继续提问交互的问题，续跑时恢复父流程保存的状态。
5. **[工具与渠道]** 修复繁体中文界面中部分工具名称、简介和标签的繁体翻译为空时显示空白的问题，优先回退简体中文，仍无有效文案时回退英文。

## 🛠️ 代码优化

1. **[系统与运维]** 新增可手动触发的 GitHub Actions 变更回移流程，按已合并 PR 和目标分支执行 cherry-pick，并生成草稿 PR 供维护者处理。
