## 升级指南

### 配置变更

- 默认部署的对象存储改为 RustFS，现有部署可继续使用原存储。如需切换，参考 [MinIO 迁移到 RustFS](/self-host/docker_minio_to_rustfs)。

### 镜像更新

### 升级脚本

本轮无新增或调整的自动升级脚本。

### 兼容说明

- **模型目录与默认选择**：`GET /api/core/ai/model/catalog` 传入 `orderBy=custom` 时返回分组后的自定义顺序，省略时保留运行时顺序。展示排序不改写已配置的默认模型，也不改变服务端默认回退顺序；客户端未命中符合类型及能力要求的业务默认或系统默认时，最终按新目录顺序寻找系统模型，图片知识库和对话标题的专用默认仍不自动兜底。
- **工作流历史记忆**：内容提取、问题分类与 Pi Agent 的记忆键统一按来源和调用路径隔离。运行时兼容读取旧 Agent 键与可确定归属的旧子流程键，写入新键后清理对应旧键，无需批量迁移历史会话；直接读写 `ChatItem.memories` 的自定义集成需适配新键，不再依赖 `agentLoopMemory-${nodeId}` 或不含调用路径的子流程键。
- **历史配置与交互续跑**：普通新请求中，`history=0` 不读取旧记忆，自定义历史只读取所传历史末尾 AI 消息的记忆；显式交互续跑优先使用父流程检查点，避免历史设置清除当前交互的恢复状态。

## 🚀 新增内容

1. **[模型与计费]** 模型管理新增拖拽自定义排序，支持保存或在保存前取消；root 可调整系统模型顺序，商业版启用团队模型后，具有「安装模型」权限的成员可调整自己的模型顺序。「可用模型」页依次展示本人的团队模型、共享团队模型和系统模型，各组按自定义顺序排列，JSON 配置更新保留已有展示顺序。

## ⚙️ 优化

1. **[模型与计费]** 统一移动端模型选择、语音播放、渠道绑定、模型日志与仪表盘筛选中的测试模式模型排序，将测试模式模型置后，同组内保留目录顺序。
2. **[模型与计费]** 模型管理表格统一表头与表体列宽，按行维护编辑弹窗状态，减少大列表打开弹窗时的整表重渲染。
3. **[知识库与文件]** 商业版简易应用与 ChatAgent 的标签过滤移入搜索参数的「搜索过滤」页签，并补充独立开关；手动输入模式关闭时保留条件，重新开启可继续编辑，参数提示按开关状态显示是否启用。

## 🐛 修复

1. **[工作流与 Agent]** 修复多个子应用或工作流工具调用同一目标时，内部节点记忆互相覆盖的问题。按完整调用路径隔离内容提取、问题分类与 Pi Agent 状态，覆盖克隆应用共享后代工具、递归进入根应用等场景。
2. **[工作流与 Agent]** 修复 Agent、工具调用及嵌套子流程的记忆未完整回传、未执行分支的历史记忆丢失，以及并发子流程用旧状态覆盖其他节点新状态的问题；仅合并子流程本次更新，保留其他有效记忆。
3. **[工作流与 Agent]** 修复循环、并行运行中的记忆传递与失败隔离问题。循环在成功迭代间传递记忆，交互暂停保留检查点，失败迭代不提交；并行任务仅合并成功结果，失败尝试不影响重试，并按输入顺序合并，同一记忆键以靠后的成功任务为准。
4. **[工作流与 Agent]** 修复嵌套 Pi Agent 在历史为 0 或空自定义历史时无法继续提问交互的问题，续跑时恢复父流程保存的状态。
5. **[对话体验]** 修复免登录分享对话顶部变量面板按普通对话规则展示变量的问题，外部变量不再向分享用户显示。
6. **[对话体验]** 修复免登录分享对话中的全局变量、交互表单使用模型选择器时，未携带分享鉴权信息，导致模型列表或已选模型名称加载失败的问题。
7. **[工具与渠道]** 修复繁体中文界面中部分工具名称、简介和标签的繁体翻译为空时显示空白的问题，优先回退简体中文，仍无有效文案时回退英文。

## 🛠️ 代码优化

1. **[系统与运维]** 新增手动触发的 GitHub Actions 已合并 PR 回移流程，默认目标分支为 `v4.17.x`，可按需修改，完成后生成草稿 PR。另提供仓库维护技能 `fastgpt-backport-pr`，须显式指定历史目标分支，可批量回补已合并 PR；机械冲突自动处理、逻辑冲突需人工确认，局部验证通过后直接推送 `upstream` 的目标分支。
