## 升级指南

### 配置变更

- `HNSW_EF_SEARCH` / `systemEnv.hnswEfSearch` 的默认值从 `100` 调整为 `200`，适用于 PostgreSQL、Milvus、OceanBase、SeekDB 和 openGauss；显式配置的值继续生效，可按召回率与查询耗时调整。
- `HNSW_MAX_SCAN_TUPLES` / `systemEnv.hnswMaxScanTuples` 不再生效，管理台移除对应设置；PostgreSQL 的扫描上限改按本次索引检索涉及的最大知识库向量行数自动设置，上限为 `2147483647`，已有部署可移除旧配置。
- 新增 `SHOW_OUTLINK_BRAND`：未配置 `PRO_URL` 时固定为 `true`；接入 Pro 后默认 `false`，可设为 `true` 启用品牌展示。前端 `show_outlink_brand` 由服务端环境派生，覆盖 `config.json` 中的同名配置。
- **插件服务部署**：Docker Compose 模板补齐 `fastgpt-plugin` 的 `FASTGPT_BASE_URL=http://fastgpt-app:3000`，将 `MONGODB_URI` 指向独立的 `fastgpt-plugin` 数据库，并显式设置 `DB_MAX_LINK=100`，避免与主库集合混用；自定义部署应填写插件容器可访问的主服务地址。已有部署替换模板前应核对原插件库，保留已使用的独立库连接；若需切换数据库，先备份并迁移既有插件数据。
- 默认部署的对象存储改为 RustFS，已有部署可继续使用原存储，如需切换请参考 [MinIO 迁移到 RustFS](/self-host/docker_minio_to_rustfs)。

- **内容审核（Moderation）插件化迁移**：旧版商业版内置的百度文本审核（`censor.BAIDU_TEXT_CENSOR_CLIENTID` / `censor.BAIDU_TEXT_CENSOR_CLIENTSECRET`）、自定义审核地址（`censor.customCensorURL`）以及单模型配置中的 `censor` 开关已废弃，统一升级为由 `fastgpt-plugin` 托管的 `moderation` 插件体系。
  - 原百度审核用户请前往 **管理后台 > 内容审核 > 审核策略配置**，配置并启用官方「百度内容安全（`baidu`）」插件。
  - 原自定义审核 URL（`customCensorURL`）用户可直接安装官方「旧版自定义审核兼容（`legacy-custom-censor`）」插件零代码迁移现有 HTTP 服务，或基于 `@fastgpt-plugin/sdk-factory` 开发原生 `moderation` 插件。
  - 详细的新旧版本对比、配置映射与开发步骤见 [内容审核升级与迁移指南](/self-host/migration/content-moderation)。

### 镜像更新

### 升级脚本

**升级前提**：先在 4.17.x 完成所需历史迁移，再升级到本版本；4.18.x 已移除旧任务的注册与实现，不会继续执行，数据库中的历史状态和错误明细保留。

新增 **初始化知识库向量索引**（`20261022_initialize_dataset_vector_indexes`），仅 PostgreSQL 在启动后于后台自动执行，不阻塞业务：先核验并在线删除旧全局 `vector_index`，再分批统计有效知识库并投递索引维护任务。任务成功表示统计与投递完成，实际建图由全局串行队列继续执行；清理或扫描失败时，可在升级管理页修复问题后重试，沿已保存的断点继续，同名但定义不匹配的自建索引会保留并报错。

PG 局部索引要求支持 `halfvec`、固定向量维度在 `1–4000` 范围内，并具备在线创建、删除索引的权限及足够的内存、共享内存和磁盘资源。索引未就绪或失败期间继续精确检索，可能增加查询耗时；建图失败不会自动降低资源预算重试，排除故障后由下一次真实向量计数重新投递，缓存命中不会触发重试。

新增 **回填历史对话调用渠道**（`20261104_backfill_chat_publish_source`），启动后独立在后台批量读写，不阻塞业务，也不等待普通后台长任务；分别为对话与统计记录补齐 `publishSource`，不修改旧字段、身份、消息或统计计数。历史 API、MCP 及已删除渠道可能只能恢复类型，无法补齐渠道 ID；引用冲突或数据异常会记录失败，修复后可在升级管理页重试并沿断点续跑。

新增 **回填 API Key 类型**（`20261104_backfill_openapi_key_type`），启动后独立在后台按固定范围分批扫描，仅为缺失类型的旧密钥按 `appId` 绑定情况补齐个人或应用类型，不改变凭证、绑定、归属和额度。类型或绑定异常会记录失败项；修复后可在升级管理页重试，沿断点续跑并优先处理失败数据。

### 兼容说明

- **历史应用密钥**：已保存有效 `appId` 绑定的旧 Key 现按应用 Key 鉴权，请求中的 `appId` 或 SDK 后缀不再覆盖绑定；原先借此访问其他应用、知识库或模型接口的接入需改用个人密钥，查看、复制与修改应用 Key 需具备绑定应用的管理权限。全部鉴权节点升级后再启用应用 Key，回滚版本也必须识别密钥类型与绑定边界。
- **密钥管理脚本**：`/api/support/openapi/list` 默认仅返回本人的个人密钥，不再按 `appId` 置顶；查询历史绑定密钥的脚本需显式选择应用类型，更新应用 Key 时按可编辑字段提交，并移除 `authProxy` 与个人标签字段。
- **对话运行状态**：`chatGenerateStatus` 改由 Redis 租约计算，仅返回 `0`（生成中）或 `1`（空闲），不再持久化到 Mongo 或返回 `2`（错误）；直接读取数据库状态或依赖错误枚举的接入需改用接口及消息错误信息。升级时先停止旧实例接收新请求并等待生成任务结束，再统一切换生成与状态查询实例，避免新旧互斥机制混用。
- **动态选择选项**：用户选择节点及表单单选、多选的变量引用选项，运行时仅保留前 `200` 个有效项，单项文本最长 `100` 个 UTF-16 码元，超出部分截断；依赖超长选项值或后续候选项的流程需调整候选数据，并核对下游匹配逻辑。
- **工作流历史记忆**：内容提取、问题分类与 Pi Agent 的记忆键改按来源和调用路径隔离，直接读写 `ChatItem.memories` 的自定义集成需适配新键，不再依赖 `agentLoopMemory-${nodeId}` 或不含调用路径的子流程键。
- **API 身份参数**：`chat/completions` 不再接受同时传入 `customUid` 和 `authProxy`，即使 `customUid` 为空字符串也会报参数错误；已有同时传参的调用需按使用者标记或成员代理场景保留其中一个。
- **重复生成响应**：非流式 `chat/completions` 在同会话已有生成时返回 HTTP `409`，依赖原错误状态码的自定义客户端需适配冲突响应。
- **日志 CSV**：基于「使用者」列解析团队成员的脚本需适配 `ID:name` 格式（旧版为成员名），成员缺少姓名时仅输出 ID；渠道列拆分为「调用渠道」与「渠道名」，按列名解析的脚本也需适配。
- **调用渠道数据**：自定义对话查询与日志解析应改用 `publishSource`；新运行不再写入 `Chat.shareId`，依赖旧字段查询分享历史的集成需适配，升级期间避免将新建分享会话继续交给旧实例读取。
- **Agent 历史上下文**：Agent 运行不再读取节点的 `history` 配置，普通历史窗口统一为最近 `50` 轮，仍保留系统消息与上下文压缩检查点；依赖零历史或自定义历史数组隔离上下文的应用需重新核对上下文控制与模型用量。
- **Agent 文本输出**：`answerText` 和工具响应改为拼接本次 Agent 循环全过程的文本，包含工具调用前的说明；依赖其仅包含最后一段回答的下游节点需调整处理。
- **Agent 交互约束**：Agent 现按交互节点处理，不能放入并行容器，商业版也不再允许为含 Agent 的应用创建自动评测任务；已有并行 Agent 需移出容器，评测接入需选择不含交互节点的应用版本。
- **系统工具管理接口**：移除 `DELETE /api/core/plugin/admin/tool/delete`，仍调用该旧接口的自定义管理端需停止使用。

## 🚀 新增内容

1. **[工具与渠道]** 新增绑定单个应用的应用 API Key，在应用发布页与个人密钥分开管理，由应用管理员共同维护，专用于该应用的对话及对话管理，不依赖归属成员的应用权限。商业版按资源交接流程转交密钥归属，删除应用时同步清理绑定密钥。
2. **[工具与渠道]** 免登录分享页新增适配桌面、移动和嵌入式页面的 FastGPT 标识，启用后新建链接默认展示，桌面访客可在本次访问临时关闭。团队持久隐藏需有效套餐权益，商业版支持按套餐及单条订阅控制；未保存品牌偏好的历史链接继续豁免，已关闭链接在权益失效时恢复展示，保留偏好供权益恢复后生效。
3. **[工作流与 Agent]** 工作流 Agent 节点可从模板面板添加并作为工具节点供其他 Agent 调用，知识库输入支持变量引用，便于组合多 Agent 流程。
4. **[模型与计费]** 模型管理新增拖拽自定义排序，支持保存前取消；root 可调整系统模型，商业版启用团队模型后，具有「安装模型」权限的成员可调整自己的模型顺序。「可用模型」按本人、共享团队、系统模型分组并在组内应用自定义顺序，JSON 配置更新保留排序，客户端的最终系统模型兜底也使用该顺序。
5. **[模型与计费]** 启用权限配置的模型表格新增创建人展示，系统模型单独标识来源；成员展示页可获取最新创建人资料，外链目录不暴露成员信息。
6. **[知识库与文件]** 知识库检索结果及引用记录新增重排前的文本召回排名，便于对比召回与重排效果。
7. **[团队与权限]** 商业版用户管理接口补充所属团队、成员名和部门路径，团队成员列表补充登录用户名，便于管理端区分账号与成员身份。
8. **[系统与运维]** 对话记录最近一次运行的调用渠道，日志区分展示渠道类型和渠道名称，支持查看渠道 ID；相关筛选、CSV 导出与商业版统计同步采用新渠道分类。
9. **[系统与运维]** 对话日志新增默认隐藏的「鉴权者」列，与「使用者」分开展示，便于区分接入方用户和实际鉴权成员；API 传入的 `customUid` 按原值显示为使用者，CSV 按所选列导出。日志表格按内容分配列宽，避免长 UID 挤压成员姓名。

## ⚙️ 优化

1. **[工作流与 Agent]** 统一 Agent 表单与工作流节点的工具、技能和知识库卡片及状态校验，运行、发布和单节点调试使用相同规则；失效、下线或未配置资源会明确提示，异步选择与保存保留已有配置。
2. **[工作流与 Agent]** 商业版工作流 Builder 预览新增标题、简短概述和待确认状态，恢复待确认方案时定位到卡片顶部，后续渲染保留阅读位置；确认、修改与取消仍使用统一交互入口。
3. **[工作流与 Agent]** 单选、多选配置的选项上限由 `50` 提高至 `200`，用户选择节点的手动选项也限制为最多 `200` 项；单项文本输入最长 `100` 个 UTF-16 码元。
4. **[知识库与文件]** PostgreSQL 按知识库维护 FP16 局部 HNSW 索引，向量行数超过 `10000` 时按需建图，低于 `5000` 时移除，中间区间保留已有状态；未就绪或无索引的知识库走精确检索，各组候选统一以 FP32 距离排序，原向量存储精度不变。
5. **[知识库与文件]** 商业版简易应用、ChatAgent 与工作流 Agent 的标签过滤移入搜索参数的「搜索过滤」页签，并补充独立开关；手动输入模式关闭时保留条件，重新开启可继续编辑，参数提示按开关状态显示是否启用；知识库或过滤条件使用变量引用时保留配置，避免误删无法在编辑期确认的标签。
6. **[知识库与文件]** 将文件上传按身份累计的每分钟限流额度提高至原来的 3 倍，减少连续或批量上传时触发「请求过于频繁」的情况。
7. **[模型与计费]** 统一移动端模型选择、语音播放、渠道绑定、模型日志与仪表盘筛选中的测试模式模型排序，将测试模式模型置后，同组内保留目录顺序。
8. **[模型与计费]** 模型管理表格统一表头与表体列宽，按行维护编辑弹窗状态，减少大列表打开弹窗时的整表重渲染。
9. **[对话体验]** 优化对话历史侧栏状态刷新，长列表分批查询，生成中或请求失败时持续重试；隐藏标签页暂停定时刷新，资源切换后忽略迟到响应，失败时保留上次状态和已读信息。
10. **[系统与运维]** 补充 OpenSandbox 启动排障说明，帮助排查卷权限正常但 `/workspace` 仍不可写时的宿主机 seccomp 限制。
11. **[系统与运维]** 升级管理页补充知识库与对话迁移的总量进度，只有已处理数量的阶段也会显示计数，便于判断后台任务进展。

## 🐛 修复

1. **[工作流与 Agent]** 修复多个子应用或工作流工具调用同一目标时，内部节点记忆互相覆盖的问题。按完整调用路径隔离内容提取、问题分类与 Pi Agent 状态，覆盖克隆应用共享后代工具、递归进入根应用等场景。
2. **[工作流与 Agent]** 修复 Agent、工具调用及嵌套子流程的记忆未完整回传、未执行分支的历史记忆丢失，以及并发子流程用旧状态覆盖其他节点新状态的问题；仅合并子流程本次更新，保留其他有效记忆。
3. **[工作流与 Agent]** 修复循环、并行运行中的记忆传递与失败隔离问题。循环在成功迭代间传递记忆，交互暂停保留检查点，失败迭代不提交；并行任务仅合并成功结果，失败尝试不影响重试，并按输入顺序合并，同一记忆键以靠后的成功任务为准。
4. **[工作流与 Agent]** 修复 Agent 作为子工具或子应用追问后续跑丢失上下文、计划或回答，以及交互残留影响下游节点或下一轮循环的问题；按节点保存暂停状态，恢复后输出完整回答。
5. **[工作流与 Agent]** 修复工作流及商业版辅助生成在准备阶段收到的停止请求被初始化清除的问题；MCP、定时触发等非 SSE 工作流执行也能响应显式停止。
6. **[工作流与 Agent]** 修复旧 Agent 的知识库引用回退为手动选择后，残留引用值导致保存失败的问题；Agent 与知识库搜索节点的手动选择会过滤格式异常项，并保留其余知识库选择。
7. **[工作流与 Agent]** 修复技能编辑沙盒未运行时导出失败的问题，服务端在可初始化状态下先启动或恢复沙盒，等待就绪后再打包；可编辑成员需等待沙盒就绪，只读协作者的导出入口不再受本地编辑沙盒状态限制。
8. **[工作流与 Agent]** 修复 Agent 传递交互表单时，时间点、时间范围字段丢失已配置的时间粒度及起止限制的问题，保留原配置。
9. **[工作流与 Agent]** 修复多行文本框在输入法组合输入及确认候选词时重置光标、干扰输入的问题。
10. **[工作流与 Agent]** 修复工具及表单参数配置弹窗内容较多时无法正常滚动的问题。
11. **[工作流与 Agent]** 修复 Agent 最大输出令牌和正文输出开关未完整生效的问题，关闭正文时保留必要交互及节点结果；开启异常捕获后，错误进入异常分支，不再直接拼入可见回答。
12. **[工作流与 Agent]** 修复 Pi Agent 将旧版必填标记及内部扩展字段直接传给模型，导致工具参数 Schema 被供应商拒绝的问题；工具、沙盒及内置能力统一在模型调用前归一化。
13. **[知识库与文件]** 修复阿里云 OSS 流上传已知长度时仍添加分块编码、与 `Content-Length` 冲突而被拒绝的问题。
14. **[对话体验]** 修复长时间无输出或客户端断开后生成状态失准、恢复连接持续等待的问题。持久化对话由独立续期的 Redis 租约判断忙闲，进程退出后在最后续期后最多 60 秒过期；租约获取或读取异常时会降级，故障期间无法保证同会话互斥与状态准确。
15. **[对话体验]** 修复同会话重复发送被拦截后，错误等待新回复而无法恢复原轮次的问题；回填被拒绝的文字和附件，刷新并恢复已有回复，兼容交互续跑及原回复已结束的情况。
16. **[对话体验]** 修复同一轮用户消息与 AI 回复共用 `dataId` 时，管理员反馈及关闭自定义反馈误更新用户消息的问题，现在仅更新对应 AI 回复。
17. **[对话体验]** 修复 Markdown 图片描述包含成对方括号（如 `![Image [1]](...)`）时漏识别图片的问题，图片提取与替换现可正常处理这类描述。
