## 升级指南

**升级前提**：先在 4.17.x 完成所需历史迁移，再升级到本版本；4.18.x 已移除旧任务的注册与实现，不会继续执行，数据库中的历史状态和错误明细保留。

### 配置变更

- **实例配置统一管理**：站点、登录、安全、资源与并发、文件策略、解析提供商和子服务连接改为管理员表单维护，旧数据库配置与 App 进程中的旧 ENV 通过启动迁移导入，已有管理员值及显式清空优先。迁移完成后，修改这些旧 ENV 不再生效；保留的部署环境变量见 [V4.18.0 环境变量说明](/self-host/config/env4180)。
- 原 `config.json` 和 Pro 默认配置文件不再作为运行期来源；仅依赖文件配置的部署需备份旧文件，并在升级后通过新表单核对、补齐。App 的新版 `defaultConfig.json` 仅在全部业务配置域为空时参与首次初始化，后续修改文件不会覆盖数据库配置。
- `FE_DOMAIN`、`FILE_DOMAIN` 分别迁入后台的站点访问地址 `site.publicUrl` 与文件服务域名 `storage.fileDomain`；文件域名留空时使用站点地址。对象存储下载模式、公开访问地址和 CDN 地址也改在后台维护，数据库与对象存储的基础设施连接仍由 ENV 提供。管理台显示当前对象存储提供商，并按提供商展示短链重定向的可用字段。外部访问端点仅适用于 `minio` 和 `aws-s3`，CDN 加速地址支持 `minio`、`aws-s3`、OSS 和 COS。
- 商业版团队模式改由 Pro 的 `TEAM_MODE` 控制，默认 `single`，旧数据库中的团队模式不再生效；已有多团队或外部同步部署需分别设置 `multi` 或 `sync` 后重启 Pro。`sync` 还需配置 `EXTERNAL_USER_SYSTEM_BASE_URL`，缺失时按 `single` 运行。
- `SHOW_GIT` 改为仅在 App 配置：配置 `PRO_URL` 时默认 `false`，与 License 激活状态无关；社区版固定展示。新增 `ENABLE_SAAS_ADMIN_CONFIG`，默认 `false`，控制管理员页面是否展示 SaaS 运营项，私有化部署默认隐藏这些字段。
- Code Sandbox 和 MCP SSE 改由后台「子服务配置」管理，未配置时默认关闭；原先依赖代码沙箱默认地址的部署需在后台启用并填写地址与 Token，Token 需与独立沙箱服务一致。
- `USE_IP_LIMIT` 和 `DISABLE_CACHE` 不再生效；已注册接口的 IP 限流始终执行，系统缓存按内置策略使用。
- 流式恢复的生成中、完成后保留时间固定为 `300` / `30` 秒，Redis 内存阈值固定为 `50%`、检测缓存 `5` 秒，旧 `STREAM_RESUME_*` 配置不再生效；埋点刷新间隔固定 `5` 秒，微信渠道并发固定 `1000`，不再读取 `TRACK_BATCH_UPDATE_TIME`、`WECHAT_CHANNEL_CONCURRENCY`。对象存储跳转签名最多有效 `30` 秒，Agent Sandbox 入口超时固定 `60` 秒、WebSocket 消息/帧上限固定 `64` / `16` MiB，对应旧 ENV 不再生效。
- Langfuse 仅从 App、Pro 各自的 `LANGFUSE_PUBLIC_KEY`、`LANGFUSE_SECRET_KEY`、`LANGFUSE_BASE_URL` 读取配置，不再回退旧数据库值；缺少任一项时关闭追踪，调整后需重启对应服务。
- LLM 请求追踪日志保留时长改在后台维护，调整后也作用于已有记录；调低保留时长会使已有超期记录进入自动清理。
- 登录 Cookie 的 Secure 属性与共享 HTTP 客户端响应体上限改为管理员表单配置，分别位于「安全设置」和「资源限制」。旧 `AUTH_COOKIE_SECURE`、`SERVICE_AXIOS_MAX_CONTENT_LENGTH` 仅从 App 进程 ENV 由启动迁移一次性导入，Pro 进程中的同名值不参与迁移，已有表单值优先；默认关闭 Secure、响应上限 20 MiB。共享上限按解压后缓冲响应大小计算，0 仅允许空响应，调用方显式限制优先，流式下载仍按业务配额限制。保存后后续请求使用新上限，Cookie 属性在重新签发时应用。
- `HNSW_EF_SEARCH` / `systemEnv.hnswEfSearch` 的默认值从 `100` 调整为 `200`，适用于 PostgreSQL、Milvus、OceanBase、SeekDB 和 openGauss；显式配置的值继续生效，实际检索宽度统一限制在 `100–1000`，可按召回率与查询耗时调整。
- `HNSW_MAX_SCAN_TUPLES` / `systemEnv.hnswMaxScanTuples` 不再生效，管理台移除对应设置；PostgreSQL 的扫描上限改按本次索引检索涉及的最大知识库向量行数自动设置，上限为 `2147483647`，已有部署可移除旧配置。
- 新增 `SHOW_OUTLINK_BRAND`：仅在 App 配置。未配置 `PRO_URL` 时忽略该变量并固定为 `true`；配置 `PRO_URL` 后跟随 ENV、默认 `false`，与 License 是否激活无关。前端 `show_outlink_brand` 由服务端环境派生，覆盖 `config.json` 中的同名配置。
- 评估任务最大数据行数改为后台「限制与并发」中的 `resource.evaluationMaxRows`，默认 `1000`，不含表头。旧 `EVAL_LINE_LIMIT` 不再读取或迁移，升级后新字段统一默认 `1000`，需要其他值时请在表单中修改；保存后无需重启。
- 旧 `EVAL_CONCURRENCY` 不迁移，迁移后也不再读取该 ENV；评估任务并发在管理员「资源限制」中设置，未配置时默认 `3`，已有实例配置保持不变。
- Agent Sandbox 的 CPU 与内存超卖倍数改为实例配置，仅在 OpenSandbox 的 Kubernetes 模式下展示。旧 `AGENT_SANDBOX_CPU_OVERCOMMIT_FACTOR`、`AGENT_SANDBOX_MEMORY_OVERCOMMIT_FACTOR` 仅从 App 进程 ENV 由启动迁移一次性导入，Pro 同名 ENV 不参与迁移；已有表单值优先、未配置默认 `1`；迁移后修改 ENV 不再生效。表单修改仅影响后续新建或重建的沙盒。
- 商业版新增模型下架提醒短信模板 `auth.sms.MODEL_DEPRECATION`；当前短信统一使用该中文模板，不按用户语言选择，`auth.sms.MODEL_DEPRECATION_EN` 配置暂不生效。启用短信提醒前需在管理台配置中文模板 ID。
- **插件服务部署**：Docker Compose 模板补齐 `fastgpt-plugin` 的 `FASTGPT_BASE_URL=http://fastgpt-app:3000`，将 `MONGODB_URI` 指向独立的 `fastgpt-plugin` 数据库，并显式设置 `DB_MAX_LINK=100`，避免与主库集合混用；自定义部署应填写插件容器可访问的主服务地址；若插件容器日志出现反向上传文件 `401`，优先核对该地址，修正后重建插件容器并重试工具。已有部署替换模板前应核对原插件库，保留已使用的独立库连接；若需切换数据库，先备份并迁移既有插件数据。
- 默认部署的对象存储改为 RustFS，已有部署可继续使用原存储，如需切换请参考 [MinIO 迁移到 RustFS](/self-host/docker_minio_to_rustfs)。

- **内容审核（Moderation）插件化迁移**：旧版商业版内置的百度文本审核（`censor.BAIDU_TEXT_CENSOR_CLIENTID` / `censor.BAIDU_TEXT_CENSOR_CLIENTSECRET`）、自定义审核地址（`censor.customCensorURL`）以及单模型配置中的 `censor` 开关已废弃，统一升级为由 `fastgpt-plugin` 托管的 `moderation` 插件体系。
  - 原百度审核用户请前往 **管理后台 > 内容审核 > 审核策略配置**，配置并启用官方「百度内容安全（`baidu`）」插件。
  - 原自定义审核 URL（`customCensorURL`）用户可直接安装官方「旧版自定义审核兼容（`legacy-custom-censor`）」插件零代码迁移现有 HTTP 服务，或基于 `@fastgpt-plugin/sdk-factory` 开发原生 `moderation` 插件。
  - 新旧版本对比与配置映射见 [内容审核升级与迁移指南](/self-host/migration/content-moderation)，日常配置、测试与自定义插件开发见 [内容审核指南](/plugin/moderation)。

- **全新部署**：`main` Compose 模板默认 MongoDB 更新为 `8.0.34`，初始化和健康检查统一使用 `mongosh`，副本集主节点就绪后再放行依赖服务。

### 升级脚本

本次脚本均为自动执行，无需手动执行。

1. 新增 **迁移系统配置**（`20261116_migrate_system_configs`），在启动时自动执行，成功前阻塞 App 业务启动；导入旧配置、补齐缺失字段并加密受管密钥，保留已有管理员值、显式清空、授权与实例身份，原始旧配置数据保留。不符合新保存规则的历史值会保留，日志记录对应字段，升级后可在管理台修正。安全配置损坏时，外链和跨域访问仍受限制。任务采用幂等全量重跑，失败后根据日志修正问题并重启持有租约的节点，待租约过期后自动重试。
2. 新增 **初始化知识库向量索引**（`20261022_initialize_dataset_vector_indexes`），仅 PostgreSQL 在启动后于后台自动执行，不阻塞业务：先核验并在线删除旧全局 `vector_index`，再分批统计有效知识库并投递索引维护任务。任务成功表示统计与投递完成，实际建图由全局串行队列继续执行；清理或扫描失败时，可在升级管理页修复问题后重试，沿已保存的断点继续，同名但定义不匹配的自建索引会保留并报错。
3. PG 局部索引要求支持 `halfvec`、固定向量维度在 `1–4000` 范围内，并具备在线创建、删除索引的权限及足够的内存、共享内存和磁盘资源。索引未就绪或失败期间继续精确检索，可能增加查询耗时；建图失败不会自动降低资源预算重试，排除故障后由下一次真实向量计数重新投递，缓存命中不会触发重试。
4. 新增 **回填历史对话调用渠道**（`20261104_backfill_chat_publish_source`），启动后独立在后台批量读写，不阻塞业务，也不等待普通后台长任务；分别为对话与统计记录补齐 `publishSource`，不修改旧字段、身份、消息或统计计数。历史 API、MCP 及已删除渠道可能只能恢复类型，无法补齐渠道 ID；无法识别的旧来源统一归为 `unknown`，不猜测渠道归属。此前因来源枚举失败的记录可在升级管理页直接重试，无需修改旧数据或重置进度；其他引用冲突或数据异常仍会记录失败，修复后沿断点续跑。完成校验改为分批扫描并保存断点，中断或修复校验异常后从对应批次继续；旧断点仅重新校验，保留已完成的回填。
5. 新增 **回填 API Key 类型**（`20261104_backfill_openapi_key_type`），自动分批遍历全部密钥，将缺失的 `type` 补为 `personal`，有效 `appId` 统一保存为 BSON ObjectId；保留凭证、归属、额度及默认应用或绑定语义。运行期管理查询只支持已规范化的数据格式；迁移期间或旧实例继续写入的旧格式数据不在查询兼容范围内。首次扫描上界之后的旧格式记录不会自动补迁，需另行规范化。异常数据可在升级管理页修复后重试。
6. 新增 **模型价格迁移**（`20261120_migrate_model_pricing`），系统配置迁移完成后在后台独立分阶段执行，不阻塞业务：第一阶段分批为缺少计价类型的旧 STT 模型补齐 `duration`（保留原单价与已配置 `tokens` 类型）；第二阶段在单事务内回填缺失 `tierUnit` 标记的系统 LLM 阶梯配置（含小于 `1` 的上限按 M Tokens 乘以 `1000` 四舍五入为正整数 K Tokens 并写入 `tierUnit: 'K'`；其余合法阶梯仅回填 `tierUnit: 'K'`；已带 `tierUnit: 'K'` 的记录跳过），单价仍按 M Tokens 计费；第三阶段联合校验 STT 与系统 LLM 价格配置。异常数据会在升级管理页记录失败，修复后可从断点重试。

### 兼容说明

- **系统配置自动化接入**：旧 `/api/proApi/admin/system/updateConfig` 已移除，调用它的管理脚本需改用主服务的 `/api/admin/system/config/get` 和 `/api/admin/system/config/update`。
- **管理后台搜索参数**：商业版应用列表的 `searchKey` 改用 `appName` 或 `appId`；团队、套餐及发票列表不再读取 `search`，已有管理脚本需改传对应的 `username` 或 `teamName`。
- **支付记录筛选**：商业版支付记录的 `username` 现在仅匹配实际付款人，不再返回该用户所在团队的全部订单；依赖原范围的管理脚本需改按团队筛选。
- **弃用的接入配置**：个人或团队自定义 OpenAI 账号、快速登录及外部提供商工作流变量仅兼容已有启用或非空配置；关闭或清空后不能通过管理接口重新启用，依赖这些入口的部署需提前核对。
- **支付宝证书**：证书模式要求完整的应用证书、支付宝公钥证书及根证书；使用不完整历史配置的部署需补齐后才能继续支付、查询或退款。
- **历史 API 密钥**：无需重新生成。缺少 `type` 的旧 Key 自动归为个人密钥，原 `appId` 仍作为默认对话目标，访问权限和个人管理方式不变；新建的应用 Key 则仅用于绑定应用，由应用管理员共同管理。
- **API Key 健康检查**：由于安全问题，`GET /api/support/openapi/health` 改用 `Authorization: Bearer <apiKey>` 请求头，不再从 URL 的 `apiKey` 参数读取凭证；已有健康探针需调整传参并移除 URL 中的密钥。
- **商业版验证码接入**：已有普通验证码接入需将取图地址由 `/api/proApi/support/user/account/captcha/getImgCaptcha` 改为 `/api/support/user/account/captcha/getImgCaptcha`，完成旋转验证后将返回的一次性凭证作为 `captcha` 提交至原业务接口，旧字符答案不再接受。凭证需在 `30` 秒内提交，发送失败后需重新验证。
- **系统模型直连鉴权**：已有系统模型若设置了 `requestUrl` 却依赖默认 `AIPROXY_API_TOKEN` 鉴权，升级前需显式填写该端点的 `requestAuth`；未配置时，OpenAI SDK 与 Pi Agent 的直连请求不再回退默认凭证。
- 已有 **LLM 阶梯计费** 的模型 JSON 配置和管理脚本需将有限的 `pricing.tiers[].maxInputTokens` 从 M Tokens 换算为 K Tokens 正整数；保存非空阶梯时会自动写入 `pricing.tierUnit: 'K'`。升级后请在升级管理页确认模型价格迁移完成，并在模型管理中核对现有档位：缺少 `tierUnit` 时运行时按第一档计费，不做区间匹配；若旧配置所有有限上限均不小于 `1` 且原按 M Tokens 填写，迁移仅补写 `tierUnit: 'K'`，需手动换算。未通过新版运行时校验的系统模型价格按零积分处理。
- **动态选择选项**：用户选择节点及表单单选、多选的变量引用选项，运行时仅保留前 `200` 个有效项，单项文本最长 `100` 个 UTF-16 码元，超出部分截断；依赖超长选项值或后续候选项的流程需调整候选数据，并核对下游匹配逻辑。
- **API 身份参数**：API 会话不再允许更换使用者，已有会话以保存的身份为准，续聊需保持相同 `customUid`；已绑定后漏传、清空或更换，以及从默认身份改为自定义身份都会被拒绝，混用使用者的接入需改用独立 `chatId`。非空 `customUid` 仅允许 API Key 调用；它与 `authProxy` 互斥，即使为空字符串也不能同时传入，已有同时传参的接入需保留一种身份。
- **会话 ID 长度**：会话管理、文件、引用和沙盒等入口统一将 `chatId` 限制为最多 `1024` 个字符；使用超长自定义 ID 的接入需调整生成规则，并核查已有超长会话及相关引用。
- **API 错误处理**。依赖旧 HTTP 状态码的客户端需更新错误分支，例如无效 API Key 返回 `401`、积分不足返回 `402`、文件无权访问（`unAuthFile`）返回 `403`、应用或知识库不存在返回 `404`，非流式 `chat/completions` 同会话已有生成时返回 `409`。依赖固定错误文案或翻译键的接入需改用 `code` 或 `statusText`，`message` 随请求语言变化，未指定时默认英文。已有知识库检索测试或索引模型连通性测试接入需适配向量化错误的分类状态码，例如上游鉴权失败或额度不足返回 `502`，临时限流返回 `429`。
- **文件预览与下载**：嵌入 HTML、SVG 或 XML 文件预览的集成需改为在独立页面打开。使用短链重定向模式时，这类文件由 FastGPT 代理返回，下载客户端应直接处理文件响应。在短链重定向模式下，`HEAD` 由 FastGPT 直接返回文件元数据，依赖 `Location` 获取跳转地址的客户端需改用 `GET`。曾通过 `STORAGE_EXTERNAL_ENDPOINT` 覆盖 R2 签名端点的部署，升级后需确认 R2 服务端点可从客户端访问。
- **钉钉工作区列表**：`/api/core/dataset/apiDataset/list` 返回的顶层钉钉工作区以 `parentId: null` 表示根目录。依赖旧父级标识的接入需按根目录处理。
- **模板导入文件名**。调用 `/api/core/dataset/collection/create/template` 时，曾对文件名做 URI 编码的脚本需改为在 multipart 的 `filename` 中传原始 UTF-8 文件名。
- **同义词文件下载**：下载的词表按上传格式重新生成，可直接再次上传。依赖固定 CSV 输出的接入需兼容 XLS 和 XLSX。
- **积分发放额度**：配置发放额度、新增或修改套餐及创建兑换券时，积分额度须为非负安全整数。已有脚本和配置使用不合规额度时需调整，仍需使用的不合规旧券须按有效额度重新发放。
- **日志 CSV**：基于「使用者」列解析团队成员的脚本需适配 `ID:name` 格式（旧版为成员名），成员缺少姓名时仅输出 ID；渠道列拆分为「调用渠道」与「渠道名」，按列名解析的脚本也需适配。
- **团队审计日志列表**：商业版已有接口接入需使用具备团队管理权限的登录身份，并传入 `dateStart` 和 `dateEnd`。依赖 `UPDATE_PUBLISH_APP` 筛选或解析应用操作的脚本需支持新记录中的 `SAVE_APP` 和 `PUBLISH_APP`，历史记录仍使用旧事件。依赖 `CREATE_COLLECTION` 或 `UPDATE_COLLECTION` 筛选或解析集合操作的脚本，需同时识别新记录中的 `dataset.collection.create`、`dataset.collection.rename`、`dataset.collection.move`、`dataset.collection.enable` 和 `dataset.collection.disable`。
- **集合删除接口**：定位参数统一为请求体中的 `id`、`collectionIds` 或 `datasetId + apiFileIds`，三种方式不可混用。旧版 `query.id` 继续兼容但已弃用，新接入应使用请求体。
- **语音识别用量**：已有自建语音识别接入需核对上游用量返回；按时长计费读取 `usage.seconds`，缺失或无效值记为 `0`，不再用客户端录音时长或识别文本估算用量。

- **工作流 CLI 脚本**：从源码使用 `@fastgpt/workflow-cli` 的脚本需切换到 `@fastgpt/cli`，将原构建命令的 `fastgpt-workflow` 替换为 `fastgpt workflow-build`。原先离线初始化的脚本需加 `--offline`；解析 JSON 输出的脚本需适配 `fastgpt-cli-result/v1`，成功结果改从 `data` 读取。
- **插件安装接口**：调用系统插件安装接口的脚本需处理全部失败时的 HTTP `500`。团队插件批量安装部分成功时返回 HTTP `200`，失败项改从 `data.failed` 读取，全部失败时从 `message` 读取错误说明。

## ⚙️ 优化

1. **[工作流与 Agent]** 修复多个子应用或工作流工具调用同一目标时，内部节点记忆互相覆盖的问题。按完整调用路径隔离内容提取、问题分类与 Pi Agent 状态，覆盖克隆应用共享后代工具、递归进入根应用等场景。
2. **[工作流与 Agent]** 修复 Agent、工具调用及嵌套子流程的记忆未完整回传、未执行分支的历史记忆丢失，以及并发子流程用旧状态覆盖其他节点新状态的问题；仅合并子流程本次更新，保留其他有效记忆。
3. **[工作流与 Agent]** 修复循环、并行运行中的记忆传递与失败隔离问题。循环在成功迭代间传递记忆，交互暂停保留检查点，失败迭代不提交；并行任务仅合并成功结果，失败尝试不影响重试，并按输入顺序合并，同一记忆键以靠后的成功任务为准。
4. **[工作流与 Agent]** 统一 Agent 表单与工作流节点的工具、技能和知识库卡片及状态校验，运行、发布和单节点调试使用相同规则；失效、下线或未配置资源会明确提示，异步选择与保存保留已有配置。
5. **[工作流与 Agent]** 商业版工作流 Builder 预览新增标题、简短概述和待确认状态，恢复待确认方案时定位到卡片顶部，后续渲染保留阅读位置；确认、修改与取消仍使用统一交互入口。
6. **[工作流与 Agent]** 单选、多选配置的选项上限由 `50` 提高至 `200`，用户选择节点的手动选项也限制为最多 `200` 项；单项文本输入最长 `100` 个 UTF-16 码元。
7. **[工作流与 Agent]** 统一应用、工作流和工具编辑中的按钮及模型选择器尺寸，调整帮助图标与文字的对齐，让操作区更一致。

9. **[知识库与文件]** 商业版简易应用、ChatAgent 与工作流 Agent 的标签过滤移入搜索参数的「搜索过滤」页签，并补充独立开关；手动输入模式关闭时保留条件，重新开启可继续编辑，参数提示按开关状态显示是否启用；知识库或过滤条件使用变量引用时保留配置，避免误删无法在编辑期确认的标签。
