## Upgrade Guide

### 1. Update Image Tags

- Update the `fastgpt-app` (FastGPT main service) image tag to `v4.14.18`.
- Update the `fastgpt-pro` (FastGPT Commercial Edition) image tag to `v4.14.18`.

## 🚀 New Features

1. Administrators can now disable the Personal WeChat publishing channel.

## 🐛 Bug Fixes

1. Fixed file type filtering and uploads for some `Workflow tools` and `User Form nodes`.
2. Fixed an incorrect stream-resume order when rapidly switching between unfinished chats.
