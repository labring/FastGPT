## 升级指南

### 镜像更新

- AIproxy: v0.7.5

### 升级脚本

本次升级无新增系统升级脚本，更新镜像并重启服务即可。

历史任务「回填应用资源快照」（`20260916_backfill_app_resource_snapshots`）新增前置依赖「迁移应用模型引用」（`20260903_backfill_app_model_references`）。若尚未完成这些历史任务，需先完成模型引用迁移，再执行资源快照回填，确保快照中的模型 ID 完整。

### 配置与接口兼容说明

- Agent 沙盒活跃实例总上限改用 `AGENT_SANDBOX_MAX`，默认 100，应用会话与技能编辑共用额度；未配置新变量时兼容读取旧变量 `AGENT_SANDBOX_MAX_EDIT_DEBUG`。可通过 `AGENT_SANDBOX_MAX_PER_TEAM` 设置单团队上限，默认不限制。管理台系统配置 `agentSandboxMax`、`agentSandboxMaxPerTeam` 优先于环境变量。
- 通用分页接口的 `pageSize` 上限统一为 500，部分业务接口仍有更小的限制；自定义 API 调用需遵守对应接口上限。

## 🚀 新增内容

1. Markdown 组件支持有限 HTML 渲染，同时优化各个组件的交互。
2. 创建应用、工具及知识库文件夹时支持选择是否继承父级权限。
3. 支持团队成员配置专属 AI 模型与渠道，完善多租户/成员级模型资源隔离与鉴权，并深度集成 AI Proxy。
4. 支持配置 Agent 沙盒活跃实例的系统总上限与单团队上限。
5. 应用对话支持按成员、应用和会话缓存输入草稿，切换会话或刷新页面后可恢复文字与已上传成功的附件引用。草稿仅保存在当前浏览器标签页，最多保留 10 份，自最后一次编辑起保留 1 小时，消息发送被正式受理后清除。

## ⚙️ 优化

1. 优化应用、技能、知识库及工具卡片的统一内边距与间距排版，提升视觉一致性。
2. 技能管理控制台补充关联应用标签展示与权限元数据对齐。
3. 模型请求被用户取消或探活流程中断时，日志级别调整为警告，避免计入模型服务错误；使用个人 OpenAI Key 时不再将此类中断误报为 Key 错误。
4. 系统升级任务的前置依赖未完成时，提示需先完成的具体任务名称，并按当前界面语言展示，便于按顺序执行或重试。
5. 团队成员管理中的「用户名」标签调整为「成员名」，明确其与登录账号的区别。
6. 优化工作流外部文件链接类型识别：无文件名或后缀的链接支持通过响应头与有限内容探测识别文件类型，统一 AI 对话、Agent、工具调用和文档读取的分类结果，并复用识别出的文件名进行文档解析。
7. 优化 API 文件库同步：先完成远端目录树拉取和结构差量校验，再批量补建目录、更新名称与父级，保持权限继承一致；远端请求因限流、网络或服务异常失败时中止本轮同步，避免将请求失败误判为文件删除。
8. 系统初始化接口按登录状态过滤公开配置，模型渠道元数据与沙盒连接信息改为按需获取；登录、退出或切换账号后刷新配置，避免复用旧会话缓存。
9. 统一通用分页参数校验，模型渠道调用日志支持每页最多 500 条。
10. 超过 30 天的重要通知不再触发重要提示。
11. 统一默认模型与辅助模型的回退规则，仅从当前成员有权使用的系统模型中选择；显式模型的权限错误不再触发默认模型回退，避免误用团队私有模型或绕过权限校验。

## 🐛 修复

1. 修复 SeekDB 容器重启或重建时数据丢失的问题。
2. 修复定价页面计费周期开关（月付/年付）选中状态背景色异常的问题。
3. 修复 MCP 工具输入 Schema 存在递归循环引用（如 `{ $ref: '#' }`）时导致 JSON 序列化报错的问题。
4. 修复 `InvokeProcessor` session getter 自递归导致调用栈溢出（Maximum call stack size exceeded）报错的问题。
5. 修复批量创建 Agent 团队成员时因无序并发导致插入异常的问题。
6. 修复 NextAPI 代理 Pro API 流式或无 Content-Type 响应（如微信登录回调）时，因未等待流结束而追加默认 JSON 包裹导致响应损坏的问题。
7. 修复复制 Agent、转换新建应用等入口可绕过创建上限的问题，并统一 Agent 创建额度、License 上限与账号资源用量的统计口径。
8. 修复 Agent 调用系统工具时使用应用所有者身份生成调用凭证的问题，改为使用实际运行成员身份，确保工具获取的用户信息正确。
9. 修复文件上传大小与数量限制在前后端口径不一致的问题，统一按团队覆盖值、套餐、系统配置和默认值依次取值，并将历史 `0` 值视为未配置。
10. 修复工作流判断器（`If/Else`）数组值与数字、布尔等非字符串引用变量比较时，「包含/不包含」结果错误的问题，统一按文本比较基础类型值。
11. 修复模板或备份导入的 CSV 数据在重解析时被当作普通文档处理的问题，保留逐行问答、自定义索引与元数据结构。
12. 修复知识库导出 CSV 时将系统自动生成的索引计入自定义索引列的问题，避免多余列及重新导入后产生重复索引。
13. 修复工作流模型引用识别不一致的问题，统一处理重复模型输入、旧版模型名称与模型 ID，避免将外部工具的同名参数误识别为系统模型配置。

## 🛠️ 代码优化

1. SSO 后端连接地址从 `feConfigs.sso.url` 调整至 `systemEnv.sso.url`，加载配置时兼容旧字段；商业版仍通过 `EXTERNAL_USER_SYSTEM_BASE_URL` 配置，无需手动迁移。
2. 使用无效或已删除的 MCP 应用访问 Key 时返回 HTTP 500 的问题，改为返回携带原请求 ID 的 JSON-RPC 错误，并将日志级别调整为警告。
3. 拆分应用资源提取、保存与发布授权、工作流运行时加载及前端校验职责；资源在实际执行节点按需加载，命中版本快照时复用应用授权，未命中时按实际运行成员校验权限。
