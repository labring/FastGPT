## 🚀 新增内容

1. **Markdown 受控 HTML 渲染与富交互组件支持**：
   - 完整支持大语言模型输出的常见 HTML 排版与富交互标签，包括折叠块（`<details>`、`<summary>`，兼容模型推理思考过程及 `data-think` 属性）、文本高亮（`<mark>`）、快捷键样式（`<kbd>`）、上下标（`<sub>`、`<sup>`）、自定义字体颜色与字号（`<font>`）、进度条（`<progress>`）、度量计（`<meter>`）、插图说明（`<figure>`、`<figcaption>`）以及受限表单预览控件（`<input disabled>`、`<textarea disabled>`）。
   - 建立 AST 级严格安全白名单过滤机制（基于 `rehype-sanitize` 与定制白名单 Schema），严格剥离 `<script>`、`<style>`、所有 `on*` 事件以及 `javascript:` / `data:` 伪协议，彻底防御同源 XSS 攻击。
2. **多媒体（视频/音频）原生流式加载与跨源播放**：
   - 彻底废弃前端 `fetch` 转 Blob 的加载方案，解决因外部媒体源未配置 CORS 响应头导致的播放被拦截报错，以及下载大文件导致前端内存暴涨或页面崩溃的问题。
   - 回归 HTML 原生 `<video>`、`<audio>` 与 `<source>` 标签机制，支持 HTTP Range 分段流式缓冲、边下边播与进度条自由拖动，并支持多媒体源解析与多源回退展示。
3. **Markdown 表格与代码块操作体验升级**：
   - 表格右上角新增悬浮操作栏，支持「一键复制为 Markdown 表格」与「下载为本地 CSV 文件」；针对合并单元格（`rowspan` / `colspan`）采用值复制网格解析，确保导出的 CSV 与 Markdown 结构绝对对齐、无行/列串位；优化超长表格横向平滑滚动，防止撑破对话框。
   - 代码块右上角新增「自动换行（Word Wrap）」切换开关，支持在单行超长代码自动换行与横向平滑滚动之间自由切换；规范化展示代码语言名称（如 TypeScript、Python 等）。
4. **Mermaid 流程图与 ECharts 图表流式与错误体验优化**：
   - 流式生成静默骨架屏：在大模型打字流式输出过程中，对未闭合、尚未就绪的 JSON 或 Mermaid 代码块采用静默骨架屏占位，消除流式过程中的红框报错、组件尺寸抖动与频繁重绘。
   - 统一代码块错误卡片（`CodeBlockErrorCard`）：当大模型生成结束但配置或语法仍存在异常时，展示风格统一的优雅错误提示卡片，并提供「复制代码」按钮便于排查与重新提问。

## ⚙️ 优化

1. **Markdown 渲染架构模块化重构**：将原单文件内联的 Markdown 实现解耦拆分为 `components/`（受控渲染组件）、`stream/`（流式增量切块、动画与子树缓存）、`utils/`（安全白名单与 Unified 插件流水线）和 `type.ts`，主入口代码量收敛至 300 行以内，显著提升渲染性能与代码可维护性。
2. **依赖版本安全升级**：
   - 升级 `@modelcontextprotocol/sdk` 从 1.26.0 至 1.32.1（#7939）。
   - 升级 `katex` 数学公式渲染库从 0.16.22 至 0.18.2（#7935）。
   - 升级文档站点 Next.js 从 15.5.24 至 15.5.27（#7936）。

## 🐛 修复

1. 修复 ECharts 代码块在 JSON 配置尚未闭合时提前触发解析导致报错的问题。
2. 修复 ECharts 骨架屏加载动画未能拉满卡片容器导致高度跳闪的问题。
3. 修复 Mermaid 复杂图表在流式结束后因最终渲染失败却局部成功而丢失错误卡片展示的问题。
4. 修复 ECharts 内部因非法配置（如 `legend: true` 等）抛出未捕获运行时异常、击穿导致前端应用崩溃并触发 Dev Overlay 的问题。
