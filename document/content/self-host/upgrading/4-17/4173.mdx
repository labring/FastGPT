## 升级指南

### 镜像更新

- AIproxy: v0.7.5

### 升级脚本

本次升级无新增系统升级脚本，更新镜像并重启服务即可。

## 🚀 新增内容

1. Markdown 组件支持有限 HTML 渲染，同时优化各个组件的交互。
2. 知识库文件夹创建时候支持选择是否默认继承
3. 支持工作空间成员配置专属 AI 模型与渠道，完善多租户/成员级模型资源隔离与鉴权，并深度集成 AI Proxy。

## ⚙️ 优化

1. 优化应用、技能、知识库及工具卡片的统一内边距与间距排版，提升视觉一致性。
2. 技能管理控制台补充关联应用标签展示与权限元数据对齐。

## 🐛 修复

1. 修复 SeekDB 容器重启或重建时数据丢失的问题。
2. 修复定价页面计费周期开关（月付/年付）选中状态背景色异常的问题。
3. 修复 MCP 工具输入 Schema 存在递归循环引用（如 `{ $ref: '#' }`）时导致 JSON 序列化报错的问题。
4. 修复 `InvokeProcessor` session getter 自递归导致调用栈溢出（Maximum call stack size exceeded）报错的问题。
5. 修复批量创建 Agent 团队成员时因无序并发导致插入异常的问题。
