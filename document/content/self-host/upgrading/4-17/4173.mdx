## 升级指南

### 镜像更新

- AIproxy: v0.7.5
- 代码运行沙盒（`fastgpt-code-sandbox`）：v4.17.0，修正原 v4.17.2 标签无法拉取的问题。

### 升级脚本

系统先完成启动必需任务及其完整前置依赖链，各 App 节点重载模型后才启动业务。启动链失败时 App 保持未就绪，需通过日志排障，修复后重启持有任务租约的 App 节点。

本版本新增以下后台自动升级任务，启动链完成后独立执行，共享集群最多 3 个并发名额。任务失败不会阻塞无依赖的其他后台任务，修复数据后可从管理页重试：

- 「回填沙箱实例团队归属」（`20261009_backfill_agent_sandbox_team_id`）：随沙盒配额功能新增，根据应用或技能来源，为历史 Agent 沙盒实例补齐团队归属；来源已删除的孤儿记录跳过并计数。
- 「回填目录祖先路径」（`20261022_backfill_folder_ancestor_ids`）：根据父级关系重建应用、工具和知识库文件夹的祖先路径，并清理非文件夹资源上的残留路径字段。历史文件夹直接挂在不同类型目录树下时，将其移到所属团队顶层，保留同树子级关系，并同步清理旧父级的继承权限；更高层祖先跨树时仅截断越界路径。父级缺失、跨团队、成环等其他异常仍记录为失败项，需修复后重试。
- 「迁移系统模型价格至百万单位」（`20261025_token_prices_per_million`）：将历史系统模型单价和阶梯边界换算后写入 `pricing`，保留旧根级价格原值，跳过已有合法 `pricing` 的模型；团队模型不参与迁移。

### 配置与接口兼容说明

- Agent 沙盒活跃实例总上限通过 `AGENT_SANDBOX_MAX` 配置，默认 100，应用会话与技能编辑共用额度。可通过 `AGENT_SANDBOX_MAX_PER_TEAM` 设置单团队上限，默认不限制。商业版可通过管理台系统配置这两个参数，并且优先级高于环境变量。
- 通用分页接口的 `pageSize` 超过 500 时自动按 500 处理，不再因超出该上限报错；部分业务接口仍保留更小的限制。支持按 `offset` 或 `pageNum` 定位，同时传入时优先使用 `offset`，包括 `offset=0`；非法偏移量不会回退为页码查询。
- OpenSandbox 新增 `AGENT_SANDBOX_CPU_OVERCOMMIT_FACTOR` 与 `AGENT_SANDBOX_MEMORY_OVERCOMMIT_FACTOR`，默认均为 1，取值须不小于 1。仅在 Kubernetes 运行态且 OpenSandbox Server 不低于 v0.2.1 时生效，按倍率降低资源预留，资源上限保持不变。修改后仅对后续新建或重建的沙盒生效，连接或恢复已有沙盒不会重新应用配置。
- 知识库批量导出接口 `/api/core/dataset/exportAll` 改为仅导出单个知识库，不再支持按目录整体导出；开启文件级权限时仅导出当前成员可读的文件，需适配分别请求各知识库。
- 商业版管理台新增「向量检索最大并发数」（`systemEnv.vectorRecallConcurrency`），取值为 0–1000 的整数，默认 0 表示不限制。大于 0 时，所有服务实例、所有向量库的召回共享该并发上限；开源版不启用此限制，无对应环境变量。
- 模型价格统一放入 `pricing`：LLM 使用 `pricing.tiers`，其他模型使用 `pricing.unitPrice`。Token 单价及 LLM 阶梯的 `maxInputTokens` 上限均按 M Tokens（百万 Tokens）填写，TTS 按每百万字符计价，STT 仍按每 60 秒计价；单价最多保留两位小数。迁移时 Token/TTS 旧单价乘以 1000，LLM 旧阶梯上限除以 1000，STT 旧单价保持不变。
- 新版接口和运行期不再读取旧根级计价字段，仅系统模型计费，团队模型免费。价格迁移在后台执行，尚未迁入 `pricing` 的系统模型暂按免费处理；混合版本运行时，旧节点仍使用旧价格，新版保存价格不会回写旧字段。升级后请确认价格迁移成功并核对系统模型价格。
- 修改知识库基本信息、模型配置及文件名称、标签、禁用状态等自身属性时，权限由可编辑（`write`）收紧为可管理（`manage`）；内容操作继续使用原有编辑权限。文件移动请求同时携带属性修改时，也需具有该文件的管理权限。
- 应用市场默认地址（`MARKETPLACE_URL`）更新为 `https://v3.marketplace.fastgpt.cn`；显式配置的自定义地址继续使用原值。
- 移除 `DEFAULT_ROOT_PSW` 环境变量，服务启动不再覆盖已有 root 密码。新建 root 的初始密码为 `123456`，登录后需设置新密码完成激活；历史 root 未保存 `status` 时也会进入激活流程，已有密码保留。日常改密改为在账号信息页操作，忘记密码时使用 root 密码重置脚本，并显式传入新密码。
- 工作流画布统一执行[编排规则校验](/guide/build/workflow/rules)，补充了：禁止纯串行回环、跨工具流程连线及多个调用节点共用同一工具入口，允许经有效条件出口控制的回流。打开旧工作流会保留已有连线，草稿仍可保存，但调试和发布前需修正不符合规则的连线。
- 被识别为用户配置错误的 API 请求统一返回 HTTP 400，并保留面向用户的错误提示；接入方需按失败响应处理。
- 新增 `AUXILIARY_GENERATION_SHOW_RUN_DETAIL` 环境变量，默认 `false`，控制技能、Agent 和工作流辅助生成的运行详情入口是否展示。

## 🚀 新增内容

1. 商业版新增[工作流辅助生成](/guide/build/workflow/assisted-generation)，支持通过自然语言创建或修改工作流。确认流程方案后，由同一 Agent 连续搭建、校验和修复，再交付候选版本；中断后可基于已保存的对话、计划和任务状态继续。方案或画布基线实质变化时重新确认；沙盒丢失时只能基于已保存上下文重建。候选版本需手动应用到画布并自动排版，应用后仍需检查、调试并手动保存和发布。使用时需具有应用编辑权限，并由管理员启用辅助生成与虚拟机（沙盒）能力。
2. Markdown 组件支持有限 HTML 渲染，同时优化各个组件的交互。
3. 应用对话支持按成员、应用和会话缓存输入草稿，切换会话或刷新页面后可恢复文字与已上传成功的附件引用。草稿仅保存在当前浏览器标签页，最多保留 10 份，自最后一次编辑起保留 1 小时，消息发送被正式受理后清除。
4. 创建应用、工具及知识库文件夹时支持选择是否继承父级权限。
5. 支持团队成员配置专属 AI 模型与渠道，完善多租户/成员级模型资源隔离与鉴权，并深度集成 AI Proxy。
6. 支持配置 Agent 沙盒活跃实例的系统总上限与单团队上限。
7. MCP 应用工具调用与外部渠道消息统一接入团队对话 QPM（每分钟请求数）限制，超限时返回具体额度与重试等待时间；外部渠道消息在去重后计数，避免平台重试重复消耗额度。
8. 工作流用户选择节点及表单输入中的单选、多选字段支持通过变量引用动态生成选项；动态选项为空时返回明确错误。
9. 系统插件支持名称、简介、工具集子工具、输入输出参数、密钥 Schema 及 README 的多语言展示；已有工作流节点和 Agent 固定工具保留添加时的文案语言快照。
10. OpenSandbox Kubernetes 运行态支持独立设置 CPU 与内存超卖倍率，在保持资源上限的同时降低调度预留。
11. 团队审计日志新增知识库及文件级失败训练任务批量重试、单任务重试、训练记录删除，以及切换索引模型重建索引的操作记录，支持按事件类型筛选；索引重建日志同时保留模型名称与稳定 ID，便于追溯。
12. 商业版管理台用户列表新增「全部、活跃、待激活、禁用、注销」状态筛选，默认查询活跃用户，可与用户名搜索组合使用；「注销」按当前及历史匿名用户名格式识别，仅用于筛选与展示，不改变账号实际状态。
13. 完善应用、工具、技能和知识库的目录导航，支持沿文件夹路径访问被授权的子资源；仅有子资源权限时，父目录作为导航入口展示，不额外授予父目录管理权限。
14. 团队审计日志新增应用、技能、知识库及文件恢复权限继承的操作记录，保留资源路径并支持按事件类型筛选。
15. 团队模型管理新增失效模型引用批量替换。团队所有者可分别选择语言、语音播放和重排模型，替换团队知识库、应用及历史版本中的失效静态引用，支持自定义模型选择器并展示替换、跳过、冲突和失败统计；不处理空值或动态变量引用，也不替换索引模型。
16. 工作流密码输入、工具密钥及 HTTP/MCP 鉴权请求头支持变量引用，可在运行时使用上游节点或应用变量提供的凭据。
17. 新增账号待激活状态与首次设置密码流程，root 支持在账号信息页修改密码；开源版通过旧密码验证，商业版沿用身份验证改密流程。改密或激活后保留当前登录会话并清理其他会话。

## ⚙️ 优化

1. 优化工作流外部文件链接类型识别：无文件名或后缀的链接支持通过响应头与有限内容探测识别文件类型，统一 AI 对话、Agent、工具调用和文档读取的分类结果，并复用识别出的文件名进行文档解析。
2. 优化 API 文件库同步：先完成远端目录树拉取和结构差量校验，再批量补建目录、更新名称与父级，保持权限继承一致；远端请求因限流、网络或服务异常失败时中止本轮同步，避免将请求失败误判为文件删除。
3. 模型请求日志与请求记录统一清理图片、音频等 base64 内容，并保留错误名称、消息与原因；面向团队成员的请求记录不保存服务端调用栈，个人 OpenAI Key 的空响应提示也不再附带完整请求内容。
4. 优化模型原生工具调用流的兼容处理，修复并行调用参数混淆、参数先于名称到达或名称重复下发导致的解析异常，并兼容工具名的 `functions.` 前缀与空参数。模型以工具调用状态结束但未返回有效工具时，明确返回错误，避免误判为正常结束。
5. 系统初始化接口按登录状态过滤公开配置，模型渠道元数据与沙盒连接信息改为按需获取；登录、退出或切换账号后刷新配置，避免复用旧会话缓存。
6. 优化应用、技能、知识库及工具卡片的统一内边距与间距排版，简介截断时可悬停查看完整内容；修复 MCP 应用名称过长时撑宽选择器的问题。
7. 技能管理控制台补充关联应用标签展示与权限元数据对齐。
8. 模型请求被用户取消或探活流程中断时，日志级别调整为警告，避免计入模型服务错误；使用个人 OpenAI Key 时不再将此类中断误报为 Key 错误。
9. 系统升级任务的前置依赖未完成时，提示需先完成的具体任务名称，并按当前界面语言展示，便于按顺序执行或重试。
10. 团队成员管理中的「用户名」标签调整为「成员名」，明确其与登录账号的区别；强制填写成员名时清空默认名称，避免直接提交占位值。
11. 统一通用分页参数校验，模型渠道调用日志支持每页最多 500 条。
12. 团队对话限流在配置读取或 Redis 服务运行异常时记录日志并跳过检查，避免限流服务故障阻断对话。
13. MCP 工具调用失败时在响应的文本内容中返回错误详情，便于客户端展示限流等具体原因。
14. 知识库列表接口 `listV2` 支持通过 `withFileCount` 按需返回 `fileCount`，统计库内所有层级的非目录集合数量，文件夹项不返回该字段。
15. 对话页支持通过 `/chat?pane=aa&tab=ta` 直接打开团队应用，切换页签时同步更新 URL，刷新或分享后保持当前页签。
16. 统一工作流节点尺寸与画布布局，问题分类节点的默认分类文案随当前界面语言展示。
17. 优化 Mermaid 流式渲染及流程图预览的缩放、拖拽与触控交互。
18. 工作流引用已删除或未包含在应用资源快照中的知识库时，将预期的资源缺失日志调整为警告，减少无效错误告警。
19. Mermaid 图包含换行标签时，自动适配。
20. 应用提示词编辑器补充输入指引及系统变量与应用自定义变量选择器。
21. 简易应用与 Agent 的知识库标签过滤移入搜索参数弹窗，统一条件编辑、变量选择与启用状态概览；切换知识库时自动清除无效自定义标签条件，工作流标签过滤在手动输入关闭时保留已配置条件。
22. 简化对话加载动画与沙盒状态文案，优化思考过程、工具及技能详情的折叠、滚动与标题吸顶交互；模型名称溢出时支持悬停查看完整内容。
23. 工作流辅助生成应用候选版本时，未配置凭据的工具默认关联可用系统密钥，无系统密钥的工具保持待激活状态。
24. 优化 API 文件库服务地址校验：缺少协议时兼容历史裸域名配置并默认补全 `https://`，表单补充完整 HTTP(S) 地址校验提示。
25. HTTP 请求节点和 HTTP 工具收到非 2xx 响应时，将响应正文一并写入错误消息，便于排查。
26. 应用、技能和知识库列表新增按资源 ID 局部刷新。修改协作者、转让所有者或恢复权限继承后，更新对应卡片并保留已加载分页与滚动位置，减少重复加载。
27. Agent 知识库检索日志补充重排前候选快照，与知识库搜索节点统一使用 `retrievalResults`。仅在实际启用重排且 `RETRIEVAL_RESULTS_LIMIT > 0` 时记录，用于对比召回与重排结果，默认不记录。
28. 外部 MCP 服务返回 HTTP 429 时不再自动回退到 SSE，保留原限流错误，避免重复连接请求。

## 🐛 修复

1. 修复 SeekDB 容器重启或重建时数据丢失的问题。
2. 修复定价页面计费周期开关（月付/年付）选中状态背景色异常的问题。
3. 修复 MCP 工具输入 Schema 存在递归循环引用（如 `{ $ref: '#' }`）时导致 JSON 序列化报错的问题。
4. 修复 `InvokeProcessor` session getter 自递归导致调用栈溢出（Maximum call stack size exceeded）报错的问题。
5. 修复批量创建 Agent 团队成员时因无序并发导致插入异常的问题。
6. 修复 NextAPI 代理 Pro API 流式或无 Content-Type 响应（如微信登录回调）时，因未等待流结束而追加默认 JSON 包裹导致响应损坏的问题。
7. 修复复制 Agent、转换新建应用等入口可绕过创建上限的问题，并统一 Agent 创建额度、License 上限与账号资源用量的统计口径。
8. 修复 Agent 调用系统工具时使用应用所有者身份生成调用凭证的问题，改为使用实际运行成员身份，确保工具获取的用户信息正确。
9. 修复文件上传大小与数量限制在前后端口径不一致的问题，统一按团队覆盖值、套餐、系统配置和默认值依次取值，并将历史 `0` 值视为未配置。
10. 修复工作流判断器（`If/Else`）数组值与数字、布尔等非字符串引用变量比较时，「包含/不包含」结果错误的问题，统一按文本比较基础类型值。
11. 修复模板或备份导入的 CSV 数据在重解析时被当作普通文档处理的问题，保留逐行问答、自定义索引与元数据结构。
12. 修复知识库导出 CSV 时将系统自动生成的索引计入自定义索引列的问题，避免多余列及重新导入后产生重复索引。
13. 修复工作流模型引用识别不一致的问题，统一处理重复模型输入、旧版模型名称与模型 ID，并覆盖自定义模型选择器，避免将外部工具的同名参数误识别为系统模型配置。
14. 修复管理员编辑套餐时将未填写的可选配额转为 `0` 的问题，留空时沿用套餐标准值，显式填写 `0` 时仍保留该值。
15. 修复工作流判断器正则条件错误剥离单侧或转义斜杠的问题，仅移除成对的 `/.../` 包装；手动输入和引用变量均保留正则语义，非法表达式按错误处理。
16. 修复 Agent 模型请求出错时遗漏本轮 Token 与积分消耗统计的问题，错误返回前仍累计已产生的消耗。
17. 修复 PowerPoint（PPTX）文档解析时演讲者备注顺序错乱的问题，严格按照关联关系将备注排在所属幻灯片之后。
18. 修复 Excel（XLSX）文档解析时默认系统日期与时间格式被转换为不带世纪的紧凑格式导致顺序与年代无法区分的问题，统一重写为规范的 ISO 日期时间格式。

## 🛠️ 代码优化

1. SSO 后端连接地址从 `feConfigs.sso.url` 调整至 `systemEnv.sso.url`，加载配置时兼容旧字段；商业版仍通过 `EXTERNAL_USER_SYSTEM_BASE_URL` 配置，无需手动迁移。
2. 使用无效或已删除的 MCP 应用访问 Key 时返回 HTTP 500 的问题，改为返回携带原请求 ID 的 JSON-RPC 错误，并将日志级别调整为警告。
3. 拆分应用资源提取、保存与发布授权、工作流运行时加载及前端校验职责；资源在实际执行节点按需加载，命中版本快照时复用应用授权，未命中时按实际运行成员校验权限。
4. 抽取共享 `workflow-core` 与 `workflow-cli`，统一节点、引用、条件分支、系统配置及语义校验，供画布与 AI 工作流构建复用。
5. 拆分技能调试执行逻辑与 HTTP 适配层，复用权限、工作流调度、消耗统计及失败收尾流程。
6. 补充企业微信 WebSocket 发布渠道的基础数据模型，包括机器人凭据、配置版本、连接状态、Bot ID 唯一约束及聊天和计费来源映射。
7. 工作流校验诊断码统一为共享枚举，供画布、CLI 与辅助生成复用。
8. 审计日志底层支持 `system` 作用域，无成员身份的系统事件可单独记录，成员事件仍要求提供成员 ID。
9. 统一 Agent Ask 与工作流辅助生成预览的结构化回答，问题与回答随独立用户消息保存，共用模型输入转换与对话持久化逻辑。
10. 工作流辅助生成的沙盒节点模板按内容缓存，减少多轮对话中的重复写入，模板文件被清理后自动补写。
11. 应用、文档、代码运行沙盒、MCP Server 等镜像的 Node.js 基础版本升级至 24.22.1，并更新 Hono 与 Vite 依赖。
12. 知识库解析任务在执行期间积分耗尽时反复报错的问题，识别额度不足并跳过本次处理，由下一轮领取任务时的团队余额检查统一暂停。
13. 修复网站知识库同步因模型配置错误未及时停止爬取，以及爬取未完成时误删历史页面的问题；因额度不足或模型配置错误提前停止、达到页数上限导致截断、页面抓取失败或无法确认爬取完成状态时，均跳过过期页面清理。任务结束日志补充完成状态、待处理及失败页数，便于排查同步异常。
14. 文件加载任务遇到预期的 DNS、网络连接或用户业务异常时，日志级别调整为警告，仍向调用方返回失败；配置占位域名及未知异常保留错误级别，减少无效告警。
15. 更新 Multer 至 2.5.0、Nodemailer 至 10.1.4、Undici 至 7.30.1、Zod 至 4.6.6，并更新 qs、MCP SDK、KaTeX 与文档站 Next.js 依赖。
16. 新增请求级 profile 性能采集，仅携带 `x-fastgpt-profile: 1` 的请求启用。业务通过 `profileStage({ event, params }, fn)` 追加阶段耗时和参数摘要，统一汇总请求耗时、Mongo 操作及进程资源指标，并支持上报 OTel 指标。
17. 新增 `UserConfigError` 用户配置错误分类，覆盖个人 OpenAI Key、HTTP 请求和外部 MCP 服务等失败场景。此类错误保留本地 info 日志并跳过 OTel 日志导出，工作流节点指标使用 `user_error` 状态，减少系统故障告警噪声。
18. 分离工作流错误分支输出、原始异常与展示详情，统一循环、并行和子工作流的错误传递与统计；运行详情落库后仍保留本次节点的观测状态，恢复循环时避免历史错误污染本轮结果。
