## 🚀 New Features

1. **Controlled HTML rendering and rich interactive components in Markdown**:
   - Added full support for common HTML typography and rich interactive tags generated by LLMs, including collapsible blocks (`<details>`, `<summary>`, supporting model reasoning processes and the `data-think` attribute), text highlights (`<mark>`), keyboard key styles (`<kbd>`), subscript and superscript (`<sub>`, `<sup>`), custom font colors and sizes (`<font>`), progress bars (`<progress>`), meters (`<meter>`), figure captions (`<figure>`, `<figcaption>`), and read-only form preview controls (`<input disabled>`, `<textarea disabled>`).
   - Implemented an AST-level strict security whitelist mechanism based on `rehype-sanitize` and custom schemas, stripping `<script>`, `<style>`, all `on*` event handlers, and `javascript:` / `data:` pseudo-protocols to defend against same-origin XSS attacks.
2. **Native streaming and cross-origin multimedia (video/audio) playback**:
   - Replaced frontend `fetch`-to-Blob media loading, resolving CORS blocking errors caused by third-party media sources without permissive headers and preventing browser crashes from high memory consumption when downloading large media files.
   - Restored native HTML `<video>`, `<audio>`, and `<source>` elements to support HTTP Range streaming chunk buffering, progressive playback, scrubbing, and multiple source fallback handling.
3. **Enhanced Markdown table and code block interactions**:
   - Added a floating toolbar in table headers supporting "Copy as Markdown" and "Download as CSV"; resolved merged cells (`rowspan` / `colspan`) using value-replicated grid normalization to ensure exported CSV and Markdown structures align without column or row drift; optimized smooth horizontal scrolling for oversized tables to protect chat layouts.
   - Added a word wrap toggle button to code blocks, allowing seamless switching between automatic line wrapping and horizontal scrolling for long code lines; standardized display labels for programming languages (e.g., TypeScript, Python).
4. **Optimized streaming and error states for Mermaid diagrams and ECharts charts**:
   - Silent skeleton loading during streaming: Rendered quiet skeleton placeholders while LLMs stream incomplete JSON or Mermaid code blocks, eliminating red error boxes, component resizing jitters, and frequent repainting during typing.
   - Unified code block error card (`CodeBlockErrorCard`): Reusable error card component displaying error descriptions with a "Copy code" action when generation finishes but configuration or syntax remains invalid.

## ⚙️ Optimizations

1. **Modular Markdown rendering architecture**: Decoupled the single-file Markdown implementation into dedicated directories: `components/` (controlled rendering components), `stream/` (incremental chunking, typewriter animation, and subtree caching), `utils/` (security schemas and Unified plugin pipeline), and `type.ts`, keeping the main entry point under 300 lines to improve rendering performance and maintainability.
2. **Dependency security and stability upgrades**:
   - Upgraded `@modelcontextprotocol/sdk` from 1.26.0 to 1.32.1 (#7939).
   - Upgraded `katex` from 0.16.22 to 0.18.2 (#7935).
   - Upgraded Next.js in `/document` from 15.5.24 to 15.5.27 (#7936).

## 🐛 Bug Fixes

1. Fixed premature parsing errors in ECharts code blocks when JSON configuration was not yet closed during streaming.
2. Fixed height flickering caused by ECharts loading skeleton animations not filling the entire card container.
3. Fixed missing error cards in complex Mermaid diagrams when final rendering failed despite partial parse successes.
4. Fixed uncaught runtime exceptions thrown by ECharts when invalid configurations (e.g., `legend: true`) crashed the frontend and triggered the development overlay.
