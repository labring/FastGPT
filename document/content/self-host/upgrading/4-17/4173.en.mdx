## Upgrade guide

### Configuration changes

- `AGENT_SANDBOX_MAX` now sets the total number of active Agent sandbox instances, with a default of 100 shared by App sessions and Skill editing. `AGENT_SANDBOX_MAX_EDIT_DEBUG` is no longer used. The new `AGENT_SANDBOX_MAX_PER_TEAM` sets a per-team limit and is unlimited by default. Commercial edition admin settings take precedence over environment variables.
- OpenSandbox adds `AGENT_SANDBOX_CPU_OVERCOMMIT_FACTOR` and `AGENT_SANDBOX_MEMORY_OVERCOMMIT_FACTOR`. Both default to 1 and must be at least 1. They apply only to the Kubernetes runtime with OpenSandbox Server v0.2.1 or later, reducing resource requests while keeping limits unchanged. Changes affect only new or recreated sandboxes.
- The Commercial edition admin console adds a maximum vector retrieval concurrency setting (`systemEnv.vectorRecallConcurrency`), accepting 0–1000. The default, 0, means unlimited. A positive value sets a shared recall limit across all service instances and vector databases. This limit does not apply to the Open-source edition and has no corresponding environment variable.
- Added `AUXILIARY_GENERATION_SHOW_RUN_DETAIL`, which defaults to `false` and controls whether run detail entry points appear for Skill, Agent, and Workflow assisted generation.
- The default marketplace URL (`MARKETPLACE_URL`) is now `https://v3.marketplace.fastgpt.cn`. Explicitly configured custom URLs keep their existing value.
- The SSO backend URL moves from `feConfigs.sso.url` to `systemEnv.sso.url`, with support for reading the old field. The Commercial edition continues using `EXTERNAL_USER_SYSTEM_BASE_URL`; no manual migration is required.

### Upgrade scripts

The system completes startup migrations and their dependencies before each App instance reloads its models and starts business services. These 3 new tasks then run automatically in the background, sharing up to 3 concurrent slots across the cluster. Failures do not block unrelated tasks. Review results in the admin console, repair failed data, and retry.

- **Backfill sandbox instance team ownership** (`20261009_backfill_agent_sandbox_team_id`): Resolves historical instances to their source App or Skill and fills in team ownership for quota tracking. Orphaned instances whose source has been deleted are skipped and counted.
- **Backfill folder ancestor paths** (`20261022_backfill_folder_ancestor_ids`): Rebuilds App, Tool, and Dataset folder paths and removes stale fields from resources that are not folders. Folders directly attached to another type of folder tree move to the team's root, with permissions inherited from the old parent removed. Cross-tree paths farther up the ancestry are truncated at the boundary. Missing parents, cross-team links, and cycles remain failed records to repair and retry.
- **Migrate system model prices to million units** (`20261025_token_prices_per_million`): Converts historical system model prices into `pricing`, preserves the original fields, and skips models with valid existing `pricing`. Team models are excluded.

### Compatibility notes

- **Root activation and passwords:** Removed `DEFAULT_ROOT_PSW`; startup no longer overwrites existing root passwords. A new root account starts with `123456` and must set a new password at first login. Historical root accounts without `status` must sign in with their existing password and complete activation. Change passwords on the account information page. If the password is lost, use the root password reset script and explicitly provide a new one.
- **Model pricing units:** LLMs use `pricing.tiers`; other models use `pricing.unitPrice`. Token prices and tier `maxInputTokens` limits now use million Tokens. TTS prices are per million characters; STT remains per 60 seconds. Prices support up to two decimal places. After upgrading, confirm that the background migration succeeded and review system model prices. System models without `pricing` are temporarily free; team models are free.
- **Workflow validation:** The canvas, debugging, and assisted generation share [orchestration rules](/en/guide/build/workflow/rules). Unconditional serial cycles, connections across Tool workflows, and Tool entries shared by multiple callers are rejected. Feedback through valid conditional outputs is allowed. Tool workflows can read upstream data available to their caller, but cannot access the caller Node's own outputs before they exist. Existing connections are preserved, and drafts can still be saved, but invalid connections must be corrected before debugging or publishing.
- **Dataset management permissions:** Updating Dataset information or model settings, or a file's name, tags, disabled state, and similar metadata, requires Manage (`manage`) permission. Content operations keep their existing Edit requirements. Moving a file while also changing its metadata requires Manage permission on that file.
- **Dataset export:** `/api/core/dataset/exportAll` supports only one Dataset at a time. Export folders by requesting each Dataset separately. When file-level permissions are enabled, only files readable by the current member are exported.
- **Pagination and error responses:** Shared pagination caps `pageSize` values above 500 at 500; some endpoints retain smaller limits. When both `offset` and `pageNum` are supplied, `offset` takes precedence, including `offset=0`. Invalid offsets do not fall back to page-based queries. API requests classified as user configuration errors return HTTP 400 and must be handled as failed requests.

## 🚀 New features

1. **[Workflows and Agents]** The Commercial edition adds [Workflow assisted generation](/en/guide/build/workflow/assisted-generation). After you confirm a natural-language plan, one Agent builds, validates, and repairs the Workflow before delivering a candidate version. Interrupted tasks can continue from saved chats, plans, and task state. Apply the candidate manually, then review, debug, save, and publish it. App Edit permission and enabled assisted generation and sandbox features are required.
2. **[Workflows and Agents]** User selection Nodes and single-select or multi-select form fields support options supplied by variables, with a clear error when the dynamic options are empty.
3. **[Workflows and Agents]** Password inputs, Tool secrets, and HTTP/MCP authentication headers can use variables supplied by upstream Nodes or App variables at runtime.
4. **[Models and billing]** Team members can configure dedicated AI models and providers, with resource isolation, authorization, and AI Proxy integration. Team owners can bulk-replace invalid language, speech playback, and rerank model assignments across Datasets, Apps, and historical versions, with processing statistics. Empty values, dynamic assignments, and embedding models are excluded.
5. **[Teams and permissions]** Added pending activation and first-time password setup. Root accounts can change passwords on the account information page. Activation or password changes retain the current session and clear other sessions. The Commercial edition admin console can filter users by all, active, pending activation, disabled, and canceled states.
6. **[Teams and permissions]** New App, Tool, and Dataset folders can optionally inherit permissions. Resource navigation supports access to authorized children through parent folder paths; parents appear as navigation entries without granting additional Manage permission.
7. **[Teams and permissions]** Team audit logs now cover retries and deletion of Dataset processing tasks, embedding model changes, and restored permission inheritance. Records preserve resource paths and model identifiers and can be filtered by event type.
8. **[Chat experience]** Recover input drafts and successfully uploaded attachment references, isolated by member, App, and session. The current browser tab stores up to 10 drafts for 1 hour after the last edit and clears them once sending is accepted.
9. **[Chat experience]** Markdown supports limited HTML rendering, with improved rich content component interactions.
10. **[Tools and channels]** System Plugin names, descriptions, child Tools, parameters, secret Schemas, and READMEs support multiple languages. Existing Workflow Nodes and Agent fixed Tools retain the language snapshot from when they were added.
11. **[Tools and channels]** MCP and external channels share the team's chat QPM limit. Limit responses include the quota and wait time; external channel messages are counted after deduplication. Dependency failures are logged and do not block chats.
12. **[System and operations]** Agent sandboxes support global and per-team quotas. The OpenSandbox Kubernetes runtime supports independent CPU and memory overcommit factors to control active instance counts and resource requests.
13. **[System and operations]** Added performance profiling enabled by the request header `x-fastgpt-profile: 1`, collecting stage timings, Mongo operations, and process metrics with optional OTel reporting.
14. **[Datasets and files]** Added an [OXR self-hosting guide](/en/self-host/custom-models/oxr), with custom PDF parser configuration and source filename tracing to help deploy and diagnose parsing services.

## ⚙️ Improvements

1. **[Workflows and Agents]** Assisted generation prepares sandboxes on demand and requests confirmation again when the plan or canvas baseline changes materially. Lost sandboxes can be rebuilt from saved context. Applying a candidate prefers an available system secret; Tools without one remain pending activation.
2. **[Workflows and Agents]** Improved native model Tool call streams to handle mixed parallel arguments, repeated or delayed names, the `functions.` prefix, and empty arguments. A Tool call completion without any valid Tool now returns an explicit error.
3. **[Workflows and Agents]** Standardized Node dimensions and canvas layout, localized default question classification labels, and added prompt editor guidance and selectors for system and custom variables.
4. **[Datasets and files]** API Dataset synchronization fetches and validates the directory tree before applying hierarchy, name, and permission inheritance changes in batches. Remote request failures stop synchronization to prevent accidental deletion. Legacy bare hostnames are accepted with `https://` added by default.
5. **[Datasets and files]** When synonym support is enabled, search results and citations can include matched standard-term mappings. Reranking considers both original and synonym-normalized text, retaining higher scores without rewriting source text. Disabled synonym support preserves existing behavior.
6. **[Datasets and files]** Unified file URL detection across AI chat, Agents, Tools, and document reading. Extensionless URLs can be detected from response headers and limited content inspection, with filenames and detection results reused within a request.
7. **[Datasets and files]** Unified tag filters across simple Apps, Agents, and Workflows, improving variable selection, enabled-state summaries, and modal scrolling. Switching Datasets clears invalid custom tag conditions; disabling manual input preserves configured conditions.
8. **[Datasets and files]** `listV2` can use `withFileCount` to return file counts across all folder levels on demand. Apps, Skills, and Datasets support refresh by ID, retaining pagination and scroll position after permission changes. Invalid non-array list responses preserve existing data and end loading.
9. **[Datasets and files]** Agent retrieval logs can include pre-rerank candidate snapshots, using the same `retrievalResults` structure as Dataset search Nodes. Snapshots are recorded only when reranking is actually used and `RETRIEVAL_RESULTS_LIMIT > 0`; recording is disabled by default.
10. **[Chat experience]** Retry and edit actions trim local history after deletion succeeds, reducing additional history requests. Incomplete history windows still refresh, and stale pagination responses started before trimming are discarded.
11. **[Chat experience]** Improved Mermaid streaming, line-break labels, zooming, dragging, and touch previews.
12. **[Chat experience]** Simplified loading animations and sandbox status messages, and improved collapsing, scrolling, and sticky titles for reasoning, Tool, and Skill details. Long error titles, running Node names, and model names are truncated, with their full text available on hover.
13. **[Chat experience]** `/chat?pane=aa&tab=ta` opens the team Apps tab directly and retains the selection after refresh.
14. **[Chat experience]** Standardized resource card spacing and added hover text for truncated descriptions.
15. **[Tools and channels]** MCP failures and HTTP non-2xx responses retain clear error details for diagnosing limits and service failures. MCP HTTP 429 responses no longer trigger an automatic SSE fallback, avoiding duplicate connection attempts.
16. **[Teams and permissions]** Initialization returns public configuration according to login status, fetches model provider and sandbox connection details on demand, and refreshes caches when accounts change. Member names are distinguished from login usernames, required-name forms clear default placeholders, and the Skill console includes linked App labels.
17. **[System and operations]** System upgrade tasks identify their prerequisites in the current language, helping users run or retry them in dependency order.
18. **[System and operations]** Model request, request record, and file loading logs remove base64 content and unnecessary stack traces. Cancellation, interrupted probes, and expected network or user configuration failures use lower log levels to reduce unnecessary alerts.

## 🐛 Fixes

1. **[System and operations]** Fixed SeekDB data loss after container restarts or recreation.
2. **[System and operations]** Fixed NextAPI wrapping Pro API streams or responses without Content-Type in default JSON. The proxy waits for streaming to finish and preserves original responses such as WeChat callbacks.
3. **[System and operations]** Fixed recursive access in the `InvokeProcessor` session getter causing a stack overflow.
4. **[Teams and permissions]** App test chats and Workflow debugging require Edit permission before running supplied Node definitions. Agents call system Tools as the actual running member, and reissued login sessions preserve root identity.
5. **[Teams and permissions]** Fixed repeated file-level permission activation clearing independent grants, incorrect inheritance of parent folder ownership, and folder permissions failing to reach internal files. Independent permission branches are preserved, and descendant updates respect each Dataset's file-level permission setting.
6. **[Teams and permissions]** Fixed copying or converting Agents bypassing creation limits, and aligned License, creation quota, and account resource usage counts.
7. **[Teams and permissions]** Fixed transaction and concurrency issues during bulk member creation and personal team creation at multi-team login, preventing duplicate creation and permission read failures.
8. **[Teams and permissions]** Fixed empty parent IDs causing BSON conversion or permission update failures when moving resources to the root, and restored dragging Skill cards into folders. Dragging is disabled during bulk selection to avoid conflicts.
9. **[Teams and permissions]** Fixed incorrect or duplicated department paths for Commercial edition members. Restore actions appear only for disabled members in synchronized teams.
10. **[Datasets and files]** Fixed team isolation in PG and OpenGauss vector retrieval, and prevented Commercial edition image parsing and index loading from using internal image paths belonging to other Datasets.
11. **[Datasets and files]** Fixed website synchronization deleting historical pages after incomplete or truncated crawls. Cleanup is skipped when insufficient points, model configuration errors, page limits, or page failures prevent completion, and the outcome is logged.
12. **[Datasets and files]** Fixed reparsing imported CSVs losing row-based Q&A, custom indexes, and metadata. Exports no longer count system indexes as custom indexes and include only readable content when file-level permissions are enabled.
13. **[Datasets and files]** Fixed multi-Dataset search excluding an entire Dataset when it lacks a requested tag. Negative and empty-value conditions now follow missing-tag semantics.
14. **[Datasets and files]** Fixed PPTX notes appearing after the wrong slide and XLSX system date formats losing century information. Doc2x tables escape cell pipe characters while preserving LaTeX semantics.
15. **[Datasets and files]** Fixed argument expansion overflows in large CSV, OFD, and PDF processing, and oversized Markdown table headers aborting an entire document import.
16. **[Datasets and files]** Fixed type and encoding detection for file URLs with query parameters, SVG XML declarations, and UTF-16 text. Upload size and count limits are consistent between client and server; canceling an S3 multipart upload stops the request and avoids spurious errors.
17. **[Datasets and files]** External PDF parser errors for encrypted or corrupted files now prompt users to decrypt or upload again.
18. **[Datasets and files]** File download and log export failures extract clear error messages instead of showing full JSON responses or duplicate alerts.
19. **[Datasets and files]** Fixed parsing tasks repeatedly failing after points run out. A subsequent team balance check pauses processing.
20. **[Workflows and Agents]** Fixed uncaught child Workflow or Workflow Tool errors failing to reach the parent Node, and failed MCP, HTTP, or system Tools run directly on the canvas missing chat error cards. Caught errors are not promoted; model Tool errors remain available for the model to handle.
21. **[Workflows and Agents]** Fixed forms with an empty description reporting a duplicate dataId on submission. Historical `null` values and incomplete interaction records are tolerated while valid continuation data is retained.
22. **[Workflows and Agents]** Fixed rerun Nodes retaining stale outputs. Outputs omitted by the current run are cleared, preventing loops or resumed interactions from reading old values. Required output defaults are filled only after successful runs.
23. **[Workflows and Agents]** Fixed containment checks against arrays and numeric or Boolean variables, and preserved paired slash delimiters and escapes in regular expressions. Invalid regular expressions are handled as errors.
24. **[Workflows and Agents]** Fixed inconsistent model assignment detection and replacement. Legacy names, model IDs, repeated inputs, and custom selectors are supported without mistaking similarly named business parameters for model settings.
25. **[Workflows and Agents]** Fixed code assistant input/output names differing from actual parameter keys and uploaded files being unavailable to parsing Nodes in single-step debugging. Existing output identifiers and variable connections are preserved.
26. **[Workflows and Agents]** Fixed variable deletion controls, dropdowns during dragging, and first-time guidance around side panels. Opening a panel ends the guide and prevents stale overlays from blocking the canvas.
27. **[Tools and channels]** Fixed recursive MCP Schemas breaking response serialization. Invalid external JSON-RPC responses show clear format errors.
28. **[Tools and channels]** Fixed requests waiting indefinitely for unknown MCP SSE sessions, which now return HTTP 404. Invalid App access keys return protocol errors carrying the request ID.
29. **[Tools and channels]** Fixed model Tool arguments being filtered or blocked by validation and Tool results being truncated again in history and SSE. Original arguments and the complete results consumed by the model are preserved, with configured fixed parameters taking precedence.
30. **[Tools and channels]** Fixed Lark session identifiers when no thread ID is supplied. Messages without a thread use the group chat identifier.
31. **[Tools and channels]** Tool version selectors show actual version numbers, and long MCP names no longer widen the selector.
32. **[Tools and channels]** Fixed required ObjectId parameters and minimal request examples in OpenAPI, preventing callers from treating required inputs as optional.
33. **[Chat experience]** Fixed incomplete resume cleanup after stream completion, cancellation, or errors, controllers interfering across sessions, and repeated cross-tab writes to local storage.
34. **[Chat experience]** Fixed concurrent chat title generation issuing duplicate requests or overwriting results. Manual titles are preserved, and an unset `customTitle` remains unset.
35. **[Chat experience]** Fixed copied tables retaining CSV escape quotes and different line endings causing incorrect rows after copying or exporting.
36. **[Chat experience]** Fixed text previews splitting emoji surrogate pairs and producing garbled characters.
37. **[Chat experience]** Fixed out-of-range time input advancing the date. Hours, minutes, and seconds are clamped on blur, and date changes preserve time edits.
38. **[Chat experience]** Fixed file size rounding displaying values such as `1024 KB` instead of the next unit.
39. **[Models and billing]** Fixed Agent request failures omitting incurred Tokens and points, missing historical reasoning Tokens in estimates, and `maxInputTokens=0` being treated as unlimited.
40. **[Models and billing]** Fixed invoice selections being lost or shifted after list refresh. Commercial edition invoicing supports bank orders and validates every order's ownership, amount, and invoice state to prevent duplicate requests.
41. **[Models and billing]** Fixed empty plan quotas becoming 0 during editing. Empty inputs use the standard plan value, while an explicit 0 is retained.
42. **[Models and billing]** Fixed the selected background for monthly and annual billing options on the pricing page.

## 🛠️ Code improvements

1. **[Workflows and Agents]** Extracted shared `workflow-core` and `workflow-cli` packages for Nodes, variables, conditional branches, and validation diagnostics. Resource authorization, snapshot loading, and runtime execution have separate responsibilities, reducing duplicate validation.
2. **[Workflows and Agents]** Unified structured replies and persistence for Agent Ask and assisted generation previews, separated Skill debugging logic from its HTTP adapter, and cached assisted generation Node templates to reduce repeated writes.
3. **[Tools and channels]** Added WeCom WebSocket publishing channel data models, credential configuration, and connection state management.

User configuration errors retain local diagnostics and skip OTel log export to distinguish them from system failures. Also fixed tracing state not being shared across Next.js module instances.
5. **[System and operations]** Updated runtime images to Node.js 24.22.1 and refreshed Hono, Vite, Multer, Nodemailer, Undici, Zod, MCP SDK, KaTeX, and other dependencies. Updated the OpenSandbox SDK and deployment components and removed unused Deep RAG paths and admin dependencies.
