## Upgrade guide

### Configuration

This update requires no new environment variables or app upgrade scripts.

## 🐛 Fixes

1. Fixed login restore, API calls, and workflow loading failing validation when a user's language preference, an API language parameter, or a workflow node's plugin language used a language this version doesn't recognize (for example, a language added in a newer version or data left behind after a rollback). Unrecognized languages now fall back to English, and unrecognized languages in a plugin's per-language README URLs no longer cause validation errors.
