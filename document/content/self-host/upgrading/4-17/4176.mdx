## 升级指南

### 配置说明

使用 `HTTP_PROXY` / `HTTPS_PROXY` 访问 MCP 服务时，FastGPT 所在容器必须能通过本地 DNS 解析目标域名，代理必须支持向目标端口建立 CONNECT 隧道，包含明文 HTTP 的 80 端口或自定义端口。

需要直连的受控主机可通过 `NO_PROXY` 配置；直连请求仍执行 DNS 地址固定和 SSRF 校验。本次更新无需新增环境变量或执行应用升级脚本。

识别企业微信 SSO 类型需要同时更新 FastGPT、FastGPT Pro 和 FastGPT SSO。旧版或自建 SSO 服务无法返回类型时，沿用原有跳转规则。

## 🐛 修复

1. 修复配置环境代理时 MCP 服务无法连接的问题，固定代理隧道连接的已校验 IP，防止代理侧重新解析域名绕过 SSRF 防护，并完善连接超时、取消与资源清理。
2. 修复插件重新运行后清空输入时，部分字段仍保留上一次的值或无法恢复默认值的问题。
3. 修复企业微信客户端误将非企业微信 SSO 选为自动登录渠道的问题，同时恢复全局 `sso.autoLogin` 在企业微信客户端中的行为。
4. 修复 API 知识库同步部分目录时，如果接入方不支持查询目录详情，已导入的目录或文件可能被误删的问题。
