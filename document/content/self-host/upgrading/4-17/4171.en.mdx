## 📦 Upgrade Guide

### Image updates

- Update the AI Proxy image tag to `v0.7.3`

### Admin entry changes

The commercial edition's admin interface is now part of the main FastGPT app. After signing in as root, use the Admin entry to access system settings, operations management, and License activation and renewal. System settings are under `/admin/settings/*`; system tools and models are at `/admin/resources/tool` and `/admin/resources/model`. Legacy routes have been removed.

The FastGPT Pro service is still required. If you use custom health checks for Pro, update the probe path to `/api/health`.

### Upgrade scripts

This upgrade includes the following automated scripts:

1. Backfill App resource permission snapshots, clean legacy V1 apps and version data, and validate published App versions. The migration task does not block startup; its progress and failed records are available in system upgrade tasks.
2. Enable reasoning mapping for compatible channels: enable `map_reasoning_to_reasoning_content: true` response-field conversion for existing AIProxy OpenAI channels while preserving their other configuration. This resolves reasoning-field differences for reasoning models such as DeepSeek-R1. Channels that already have this setting enabled are not updated again, and the migration task does not block startup.
3. Upgrade Dataset tag data: migrate legacy Collection tags to typed tags and clean duplicate tag definitions. The migration task does not block startup.

## Compatibility notes

The commercial edition no longer requires the Pro service to be started separately. Its configuration has moved to the FastGPT client.

## 🚀 New Features

1. Published App versions now include resource permission snapshots and runtime authorization. Static resources are checked against the snapshot captured at publishing time, while dynamic resources are checked against the current runtime user. This fixes permission calculations for collaboratively developed Apps with distributed runtime permissions.
2. Added Dataset tag management and filtering with typed tag values, Collection tag maintenance, and tag conditions for Dataset searches in Workflows and Agent V2.
3. Password changes now support third-party authentication, with a unified authorization, verification, and password-update flow.
4. Agent V2 Dataset search now supports Dataset citations, so chats can display the citations returned by the current search.
5. Apps now include a Token usage dashboard, and usage records also show Token consumption.
6. App, Agent, Skill, Tool, and Dataset lists now support batch selection, moving, and deletion, with available actions restricted by management permissions.
7. Admin features are now integrated into the main app, with menus and feature status based on License permissions.
8. File-reading Node debugging now supports local file uploads and file URLs, and prevents execution while uploads are pending or files have errors.
9. Added collection-level permission for Datasets: assign collaborators to individual files or folders, with inherited and independent states, inheritance restoration, and ownership transfer. The switch is off by default, so existing Datasets keep their behavior; once enabled, lists, details, and retrieval results are authorized file by file, and disabling clears all file permission configurations. See [Collection-level Permission](../../../guide/dataset/collection_permission).
10. Added system model health probing and monitoring. Administrators can enable scheduled health probes, view a 48-hour status chart, and configure an alert Webhook and Token to receive notifications when model status changes. See [System Model Configuration and Monitoring](../../config/model/intro).
11. Added first-login onboarding and action orchestration. First login can require missing team member display names to be completed, automatically prompt users to handle pending team invitations, and orchestrate follow-up dialogs such as system announcements and enterprise verification.
12. Administrators can now update a system model's identifier (`model`) directly using its stable `modelId`, with associated channel model mappings and model lists updated automatically.
13. Added OFD file parsing support.
14. Added integration guide and examples for TokenDance AI API gateway.
15. Added an SSO password policy. Administrators can prevent SSO namespace accounts from using or changing platform passwords, and the login page now shows only the available authentication methods.
16. Personal workflow tools now support tracking the latest published version, eliminating the need to manually reselect tool versions after updating an App.
17. Added `off` input type for workflow node inputs: intended for third-party interface parameter passing, not rendered in the UI while preserving parameter schema, default values, and validation, and excluded from Agent auto-generated parameters.
18. Supported string tag type in workflow dataset search tag filters: supports structured text conditions and reference variables, executing corresponding match operations at the retrieval layer.
19. Added the "Basic Features - Model Management" category and endpoints to the OpenAPI documentation (public model list, member available model catalog, and batch model summaries), supporting model queries via API Key.

## ⚙️ Improvements

1. Updated the Dataset Collection batch action bar, tag spacing, and tag management empty state.
2. App log user filters now load only after the filter is opened, with server-side search and pagination instead of a fixed 100-user limit.
3. Dataset search Nodes can now record candidates before reranking to help compare retrieval and reranking results. Set the recording limit with `RETRIEVAL_RESULTS_LIMIT`; recording is disabled by default.
4. Beta models now appear at the end of the model selector.
5. Fixed the default Dataset image model being automatically restored after clearing it. The image model can now remain unconfigured.
6. Redesigned admin system configuration forms with improved navigation and category layouts.
7. Supported unlimited expiration time for commercial License activation, improving display and validation for non-expiring licenses.
8. Improved large-number formatting in Chinese locales, including localized ten-thousand and hundred-million units.
9. Tables now enable horizontal scrolling by default and remove redundant side padding, improving browsing on narrow screens.
10. Fixed Workflow array variables receiving a single object JSON string being parsed as a plain object rather than an array, automatically wrapping it into a single-element array to prevent errors in loop and parallel nodes.
11. Sorted template model list by model provider order when adding models from templates, keeping model lists organized and consistent.
12. Optimized chat title generation rules: initial chat rounds that only upload files or trigger auto-execution now assign localized fixed titles (such as "Upload File" or "Auto Execute"), which are automatically overwritten once subsequent text queries are sent; custom titles (`customTitle`) retain the highest priority and will not be overwritten; unified title fallback and display consistency across chat history, logs, and exports; and prevented empty values or placeholders from being persisted as chat titles.

## 🐛 Fixes

1. Tool calls now isolate Workflow Tool runtime state and restore interactive Node memory, preventing concurrent calls from interfering with one another or losing interactive results.
2. Fixed invoice-header forms overwriting existing input during data loading and failing to validate required fields consistently.
3. Hid the custom-title action for temporary chats that have not been saved to history, since their title changes cannot be persisted.
4. Fixed FastGPT Pro license verification after login and added authentication checks to billing endpoints.
5. Fixed MongoDB transaction errors caused by concurrently writing human and AI chat items in the same chat round.
6. Fixed HTML images in parsed documents failing to preview, and converted S3 object keys inside HTML tags to preview URLs.
7. Fixed text cleanup removing `]]` from content and failing to remove all consecutive whitespace between Chinese characters.
8. Fixed selecting, copying, and pasting Variable and Skill tags in the prompt editor.
9. Fixed JSON extraction including trailing explanations containing brackets after a model-generated JSON value.
10. Fixed soft line breaks in PowerPoint paragraphs being dropped and causing adjacent text to be joined.
11. Fixed Markdown table corruption when a cell contains a backslash and when an HTML table has no explicit header row.
12. Tool execution failures are no longer shown as ordinary chat errors in the bottom error card or counted in the Node response summary.
13. Fixed App chat tests failing to validate model availability before sending the request; specific model configuration errors are now shown first.
14. Fixed FastGPT Pro Lark publishing channels failing to return the challenge during event-subscription URL verification when an Encrypt Key is configured.
15. Fixed Tool inputs incorrectly switching to a JSON editor in manual input mode. They now use the input control declared by the Node.
16. Fixed MongoDB change streams failing to recover after termination by adding automatic reconnection and configuration reloads.
17. Fixed MongoDB transaction errors caused by concurrent system configuration updates.
18. Fixed inactive or non-reasoning model Nodes incorrectly displaying empty reasoning output cards in Workflows.
19. Fixed HTML table to Markdown conversion failing to recognize `<th>` cells, which caused standard HTML tables to lose header names.
20. Fixed streaming Node responses being unexpectedly interrupted when child Workflow details were not published.
21. Fixed popup blockers on iOS Safari preventing source files from opening after asynchronous fetching.
22. Fixed collaborator role assignment failing to honor group and organization administrator rights.
23. Fixed runtime edge statuses being incorrectly reset to waiting during single-node workflow debugging, which caused the debug endpoint to return immediately while the frontend remained in a running state.
24. Fixed Dataset chunking truncating Markdown image URLs that contain parentheses, which could attach embeddings or descriptions to the wrong image source.
25. Fixed upload validation for empty files and Office lock files, and unified content validation for Dataset image uploads.
26. Fixed DNS-rebinding SSRF risks in MCP and narrowed resolved address-family checks.
27. Removed remote-image HEAD pre-validation that could let malicious addresses block requests or cause denial of service.
28. Fixed chat log views incorrectly showing the “Content generated by AI” notice.
29. Fixed required-property detection when a JSON Schema property uses a boolean `required` value.
30. Fixed same-origin OpenAPI Scalar test requests being misclassified, which caused CSRF validation to fail.
31. Fixed outlink delete-permission checks and frontend feedback, and removed outlinks and quick references immediately when an App is deleted.
32. Fixed long whole numbers from spreadsheets being converted to scientific notation or losing precision.
33. Fixed strict enum inputs ignoring JSON Schema `default` and always selecting the first enum value.
34. Fixed Workflow and Agent execution dropping intermediate ToolCall assistant messages and corrupting response order during streaming and persistence, ensuring complete tool transcripts and node response logs.
35. Fixed interactive state loss when resuming paused child workflows and interactive tools, correctly passing current query and user input context upon resumption.
36. Sanitized link `href` targets in Markdown rendering to prevent stored click-XSS vulnerabilities from dangerous URL protocols such as `javascript:`.
37. Fixed Dataset retrieval result fusion (RRF) mutating the input search result score objects in place, ensuring candidate scores recorded prior to reranking retain their original values.
38. Fixed the concurrent task runner `batchRun` continuing to pull remaining tasks across other concurrency slots after a task failure, immediately stopping new task pickup on error.
39. Fixed deployer-configured internal endpoints (such as chat log push, DingTalk token fetching, third-party API dataset sync, and custom PDF parsing) being incorrectly blocked when `CHECK_INTERNAL_IP=true` is enabled.
40. Fixed app resource backfill migration errors caused by legacy V1 apps and invalid non-ObjectId resource references, and cascade-cleaned legacy V1 apps along with their versions, chats, and outlinks during migration.
41. Fixed an issue where the search highlight component (`HighlightText`) crashed the page when searching terms containing special regex characters such as parentheses, brackets, or `c++`.
42. Fixed an issue where web page link import for datasets did not resolve relative image and hyperlink paths (e.g. `./`, `../`) against the page URL, causing images and links to fail.
43. Fixed an issue where merging multiple system messages in chat history reversed their order when using the OpenAI-compatible API, ensuring original relative order is preserved.
44. Fixed safe link validation in Markdown rendering incorrectly rejecting valid URLs with non-UTF-8 percent-encoding in query parameters, causing them to render as unclickable plain text and images to not display.
45. Fixed base64 images embedded inside HTML `<img>` tags in parsed documents (such as docx/xlsx HTML tables) not being uploaded to storage and leaking into text chunks as massive base64 strings.
46. Fixed Workflow condition node (`If/Else`) throwing a TypeError (`trim is not a function`) when using "starts with" or "ends with" conditions on non-string inputs.
47. Fixed some Dataset file ingestion endpoints not binding client-supplied S3 object keys to the already-authorized resource.

## 🛠️ Code Improvements

1. The model test endpoint can now be called without configuring a channel.
2. Added APIs for pinning Apps and folders, with opt-in pinned-first sorting in list endpoints.
3. Dataset APIs now support external document parsing options for retaining headers and footers, appendices, image recognition results, and chart analysis results. These options apply only when an external parsing service is enabled.
4. Refactored scheduled timer tasks and distributed locking with `checkTimerLock`, consolidating model status probing in the service layer to prevent concurrent probes across nodes.
5. Optimized sensitive data encryption/decryption performance by caching derived scrypt keys and eliminating blocking CPU queries; switched main application Dockerfile base image to debian-slim.
