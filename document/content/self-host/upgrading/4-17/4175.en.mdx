## 🐛 Fixes

1. Fixed an issue where replies in home chats or apps with read-only access remained marked as unread after non-root users read them.
2. Fixed incorrect permission checks when creating HTTP tools in tool folders.
3. Fixed missing permission checks when moving apps, Datasets, Skills, and Collections from the root directory.
4. Fixed workflow detail pages failing to load when an end node in a loop or parallel execution has an invalid reference, and aggregate output types failing to reset.
