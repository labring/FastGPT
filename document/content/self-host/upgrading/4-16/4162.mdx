## 📦 升级指南

### 1. 迁移资源权限数据

本版本将 App、Dataset 和 Agent Skill 的资源权限补齐为完整有效 ACL。升级后请先执行 dry-run；dry-run 不会写入权限数据，默认只处理所有团队，也可以通过 `teamId` 指定单个团队。

```bash
curl -X POST 'https://你的域名/api/admin/4162/initPermission' \
  -H 'Content-Type: application/json' \
  -H 'rootkey: 你的ROOT_KEY' \
  -d '{"dryRun":true,"batchSize":100}'
```

确认返回的 `errors` 为空或已完成异常资源处理后，执行正式迁移：

```bash
curl -X POST 'https://你的域名/api/admin/4162/initPermission' \
  -H 'Content-Type: application/json' \
  -H 'rootkey: 你的ROOT_KEY' \
  -d '{"dryRun":false,"batchSize":100}'
```

`batchSize` 可设置为 `1` 到 `1000`，默认值为 `100`，用于限制每批读取、计算和写入的目标资源数量；父级资源链会按需读取。返回结果中的 `resourceCount` 是扫描资源数，`updatedResourceCount` 是需要写入的资源数，`skippedResourceCount` 是因父级缺失或树结构异常而跳过的目标资源数，`errors` 包含异常详情。迁移保留资源自身的 owner 和子级权限，继承开关缺失的历史资源按启用继承处理。

正式迁移可安全重复执行；完成后再次执行 dry-run，确认 `updatedResourceCount` 和 `errors` 均为 `0`。存在 `errors` 时应先根据资源类型、资源 ID 和父级 ID 修复数据，再重试正式迁移。

3. 支持账号注销。

## ⚙️ 优化

1. 优化账号页整体 UI 和移动端适配。
2. 管理员页和模型提供商路由。
3. S3 分块上传网络抖动优化。
4. 文件上传错误提示统一文案。
5. 优化技能保存时，结构化提取 name 和 description，允许空 description。
6. 连续工具调用异常检查，提高判断精确性，不再只判断调用次数和工具数量，改成判断相同工具且相同参数，连续调用超过 5 次，认为是模型幻觉异常。
