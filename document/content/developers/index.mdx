## 开发者集成全景

FastGPT 面向业务系统与开发者提供完整的开放能力矩阵：

![通过可信后端集成 FastGPT](/imgs/diagrams/integration-overview.zh-CN.light.svg)

API Key 保存在可信服务端。身份代理按需启用，要求接口支持并建立同团队成员的可信身份映射。MCP 客户端通过单独配置的 MCP 服务及其认证方式接入。

## 凭证体系与鉴权方式

各接口分别声明接受的凭证类型，接入前按生成契约确认鉴权要求。

| 凭证类型 | 传输位置 | 权限作用域 | 适用场景 |
|---|---|---|---|
| **团队 API Key** | `Authorization: Bearer <apiKey>` | 绑定创建成员在所属团队中的可用资源权限 | 业务系统对接、自动化任务、模型调用 |
| **用户登录会话** | Cookie `fastgpt_token` 或 `token` 头 | 当前成员的资源权限，受接口授权与会话校验约束 | 前端界面通信、同源管理接口 |
| **Root 管理密钥** | 请求头 `rootkey: <ROOT_KEY>` | 明确启用 Root 鉴权的管理接口，具体资源约束由接口决定 | 跨团队运维、模型探测与自动化迁移任务 |

## 核心集成任务

1. [API 极速入门](/zh-CN/openapi/intro)：获取团队 API Key，执行首次端到端请求，使用 OpenAI 官方 SDK 接入。
2. [身份代理机制](/zh-CN/openapi/identity-proxy)：可信服务端通过 `authProxy` 代表真实用户发起调用，实现细粒度权限控制与操作审计。
3. [应用与工作流集成](/zh-CN/openapi/app)：调用已发布的对话 Agent、Agent V2 与可视化工作流应用，动态注入全局变量。
4. [会话与 17 类流式事件](/zh-CN/openapi/chat)：管理持久化 `chatId`，深度解析回答、思考、节点状态、计划与交互挂起事件帧。
5. [知识库全生命周期集成](/zh-CN/openapi/dataset)：通过 API 创建集合、异步推送文档到训练队列、检索测试与命中调优。

## 机器可读 OpenAPI 契约

FastGPT 每个部署实例均在本地动态生成最新的 OpenAPI 3.1 规范文档：

- **System OpenAPI（API Key 开放接口）**：访问 `/apidoc/systemopenapi`（页面）或 `/api/apidoc/systemopenapi.json`（JSON 契约）。
- **Dev API（完整开发接口）**：访问 `/apidoc/devapi`（页面）或 `/api/apidoc/devapi.json`（JSON 契约）。

维护历史已有集成时，参考 [历史 API 参数与迁移](/zh-CN/openapi/legacy)。
