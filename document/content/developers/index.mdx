先建立一次成功调用，再接入业务系统。需要目标团队的凭证及对应资源权限。

1. [API 入门](/zh-CN/openapi/intro)：地址、密钥、应用选择和首次请求。
2. [应用集成](/zh-CN/openapi/app)：调用已发布的应用与工作流工具。
3. [会话与流式响应](/zh-CN/openapi/chat)：会话标识、流式事件和错误处理。
4. [知识库集成](/zh-CN/openapi/dataset)：导入、处理状态与检索。
5. [身份代理](/zh-CN/openapi/identity-proxy)：可信服务端代表团队成员执行。

当前生成的 System OpenAPI 提供明确开放给 API Key 的接口契约；Dev API 提供内部开发接口。打开自己的 FastGPT 地址下 `/apidoc/systemopenapi` 或 `/apidoc/devapi`，按部署版本核对参数。云服务链接见 [API 入门](/zh-CN/openapi/intro)。
