Establish one successful call before integrating a business system. You need credentials for the target team and permission to access its resources.

1. [API getting started](/en/openapi/intro): address, key, application selection, and a first request.
2. [Application integration](/en/openapi/app): call published applications and workflow tools.
3. [Conversations and streaming](/en/openapi/chat): conversation identity, stream events, and errors.
4. [Knowledge-base integration](/en/openapi/dataset): ingestion, processing status, and retrieval.
5. [Identity proxy](/en/openapi/identity-proxy): execute as a team member through a trusted server.

Generated System OpenAPI documents contracts explicitly accessible with API keys. Dev API covers internal development interfaces. Open `/apidoc/systemopenapi` or `/apidoc/devapi` on your FastGPT host and check the contract for that deployment. Cloud links are in [API getting started](/en/openapi/intro).
