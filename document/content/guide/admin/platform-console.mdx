在私有化部署（商业版）环境中，使用 `root` 管理员账号登录后可访问**平台运营后台**（`/admin/*`），对全局租户、系统资源、模型路由、商业计费与系统迁移任务进行集中治理。

## 一、平台概览与租户治理

| 模块名称 | 路由地址 | 核心管理职责 |
| --- | --- | --- |
| **全局数据看板** | `/admin/dashboard` | 查看全平台注册用户趋势、活跃团队数、新增应用与知识库总量、全局对话轮次与积分消耗时序图 |
| **用户管理** | `/admin/users` | 检索全平台用户账号、新建/禁用用户、重置用户登录密码、查看用户所属团队与登录状态 |
| **团队管理** | `/admin/teams` | 管理所有租户团队、修改团队套餐配额、转移团队拥有者、配置团队专属成员或资源上限 |
| **全局应用监管** | `/admin/apps` | 跨团队检索全平台创建的应用（对话 Agent、Agent V2、工作流、工具），排查异常应用或转移所有者 |
| **全局知识库监管** | `/admin/datasets` | 跨团队查看知识库容量、集合数量，并监控全平台向量化与 QA 抽取训练队列堆积情况 |

## 二、系统资源与模型渠道中心（`/admin/resources/*`）

### 1. 系统模型与 AIProxy 渠道管理（`/admin/resources/model`）

通过 5 个子视图统一管理全平台模型底座（详细配置流程见 [模型配置说明](/zh-CN/self-host/config/model/intro)）：

- **模型配置（`modelTab=config`）**：从内置预设启用或自定义添加语言模型、向量模型、重排模型、语音合成（TTS）与语音识别（STT）模型，设置上下文窗口、功能标签与千 Token 积分单价。
- **模型渠道（`modelTab=channel`）**：配置对接各模型供应商的 API 端点、密钥列表、模型映射表与渠道优先级权重。
- **渠道调用日志（`modelTab=channel_log`）**：按请求 ID、渠道名称、模型名称或状态码检索底层模型调用耗时与报错详情。
- **提供商监控与测试（`modelTab=account_model` / `status`）**：批量发起渠道连通性测试，配置定时健康探测间隔与异常告警 Webhook。

### 2. 系统工具与模板市场管理

| 资源模块 | 路由地址 | 核心操作 |
| --- | --- | --- |
| **系统工具库** | `/admin/resources/tool` | 在线上传 `.pkg` 插件包、管理官方与自定义系统工具标签、配置平台级工具默认密钥、启用/停用工具或设置工具调用单价 |
| **应用模板市场** | `/admin/resources/app_template` | 维护工作台“模板市场”中的分类标签与推荐应用模板，支持将优秀工作流或 Agent 上架为全平台公共模板 |

## 三、商业化计费、通知与合规审计

| 模块名称 | 路由地址 | 核心管理职责 |
| --- | --- | --- |
| **套餐与资源包配置** | `/admin/plans` | 自定义平台标准订阅套餐档位（免费版/团队版/企业版）的价格、周期与配额，配置额外积分包与索引包 |
| **支付订单与优惠券** | `/admin/pays` | 查看全平台充值与订阅支付流水，生成批量兑换码或折扣优惠券 |
| **发票审批管理** | `/admin/invoice` | 审核各团队提交的开票申请，核对增值税发票抬头并上传已开具的电子发票文件 |
| **系统公告与通知** | `/admin/inform` | 发布全站顶部横幅公告，或向指定团队/用户发送站内系统通知与邮件提醒 |
| **平台审计日志** | `/admin/audit` | 检索全平台管理与关键业务操作审计记录，支持按操作人、团队、事件类型与时间区间溯源 |
| **商业授权（License）** | `/admin/license` | 查看当前实例 ID（Instance ID）、上传或更新商业版 License 密钥，并核对授权到期时间与功能模块边界 |

## 四、全局系统设置与平滑升级迁移

### 1. 系统参数设置（`/admin/settings/*`）

- **基础设置（`/admin/settings/basic`）**：配置站点名称、Logo、备案信息、帮助文档链接与版权声明。
- **功能开关（`/admin/settings/feature`）**：控制团队模型开关（`enable_team_model`）、用户注册方式、同步任务开关等全局特性。
- **模型默认设置（`/admin/settings/model`）**：指定平台默认的对话模型、向量模型、文本理解模型与 PDF 解析服务（如 MinerU / Marker / Doc2x）。
- **支付渠道（`/admin/settings/pay`）**：配置微信支付、支付宝或 Stripe 商户凭证。
- **第三方与用户登录（`/admin/settings/thirdParty` / `user`）**：配置短信/邮件验证码网关、OAuth2 / OIDC / SAML 单点登录与企业通讯录同步参数（详见 [SSO 与外部成员同步](/zh-CN/guide/admin/sso) 与 [团队模式说明](/zh-CN/guide/admin/teamMode)）。

### 2. 系统升级与数据自动迁移（`/admin/migration`）

当私有化实例跨版本升级镜像后，可在 **`/admin/migration`** 页面查看当前版本注册的自动系统迁移脚本（System Migration）：

1. 检查各迁移任务的执行状态（待执行、运行中、已完成、失败）、实时处理进度与断点检查点（Checkpoint）。
2. 对支持在线重跑或阻塞升级的迁移任务，可在确认数据库备份就绪后手动触发或恢复执行，并结合容器日志核对完成结果。标准升级步骤见 [版本升级说明](/zh-CN/self-host/upgrading/upgrade-instruction)。
