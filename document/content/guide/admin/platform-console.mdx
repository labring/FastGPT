在私有化部署环境中，使用 `root` 管理员账号登录后点击左侧导航栏底部的**管理员**即可进入平台运营后台：

- **开源社区版（未激活商业版 License）**：左侧导航栏平铺展示 **系统模型**、**系统工具**、**版本升级** 与 **License 管理** 4 个管理页面。
- **商业版（已激活商业版 License）**：按左侧九大一级菜单对全局租户、系统资源、模型路由、商业计费与系统迁移任务进行集中治理；其中 **用户管理 → 套餐管理 / 支付记录 / 开票管理** 以及 **系统配置 → 套餐 & 充值** 需商业版 License 包含支付能力后显示。

## 一、数据面板、通知管理与用户/资源治理

| 导航入口 | 核心管理职责 |
| --- | --- |
| **数据面板** | 查看全平台注册用户趋势、活跃团队数、新增应用与知识库总量、全局对话轮次与积分消耗时序图 |
| **通知管理** | 发布全站顶部横幅公告，或向指定团队/用户发送站内系统通知与邮件提醒 |
| **用户管理 → 用户信息** | 按状态（全部、活跃、禁用、注销）与用户名组合检索账号，新建/禁用用户、重置密码、查看所属团队 |
| **用户管理 → 团队管理** | 管理所有租户团队、转移团队拥有者、查看团队成员构成 |
| **用户管理 → 套餐管理** | 查看与调整各团队当前生效的套餐等级、到期时间及附加配额 |
| **用户管理 → 支付记录** | 查看全平台充值与订阅支付订单流水及优惠券使用记录 |
| **用户管理 → 开票管理** | 审核各团队提交的开票申请，核对增值税发票抬头并上传已开具的电子发票文件 |
| **用户资源 → 应用管理** | 跨团队检索全平台创建的应用（对话 Agent、工作流、工具），排查异常应用或转移所有者 |
| **用户资源 → 知识库管理** | 跨团队查看知识库容量、集合数量，并监控全平台向量化与问答对提取训练队列情况 |

## 二、系统资源（系统模型、系统工具与应用模板）

### 1. 系统资源 → 系统模型

通过 5 个标签页统一管理全平台模型底座（详细配置流程见 [模型配置说明](/zh-CN/self-host/config/model/intro)）：

- **模型配置**：浏览与管理语言模型、向量模型、重排模型、语音合成（TTS）与语音识别（STT）模型预设与实例，配置上下文窗口、功能标签、平台默认模型与 `pricing` 计费标准。
- **模型渠道**：配置对接各模型供应商的 API 端点、密钥列表、模型映射表与渠道优先级权重。
- **调用日志**：按请求 ID、渠道名称、模型名称或状态码检索底层模型调用耗时与报错详情。
- **监控**：查看模型渠道调用成功率、吞吐与延迟监控指标。
- **模型探测**：批量发起渠道连通性探测，配置定时健康探测与异常告警。

### 2. 系统工具与应用模板

| 导航入口 | 核心操作 |
| --- | --- |
| **系统资源 → 系统工具** | 在线上传 `.pkg` 插件包、管理官方与自定义系统工具标签、配置平台级工具默认密钥、启用/停用工具或设置工具调用单价；详见[配置系统工具](/zh-CN/guide/build/tools/system-plugins/upload_system_tool) |
| **系统资源 → 应用模板** | 维护工作台**模板市场**中的分类标签与推荐应用模板，支持将优秀工作流或 Agent 上架为全平台公共模板 |

## 三、系统配置、版本升级、审计日志与 License 管理

### 1. 系统配置

- **系统配置 → 基础配置**：配置站点名称、Logo、备案信息、文档链接、**向量检索最大并发数**（`systemEnv.vectorRecallConcurrency`，取值 `0–1000`，默认 `0` 表示无限制）以及 **PDF 解析配置**（按优先级依次为：自定义 PDF 解析地址（第一优先级）、解析密钥（Doc2x）、合合信息 Textin（第三优先级））。
- **系统配置 → 功能清单**：控制团队模型开关（`enable_team_model`）、允许团队上传插件（`enable_team_plugin_upload`）及后台同步开关。
- **系统配置 → 安全配置**：配置节点忽略 HTTPS 证书校验、模型安全审查（百度内容安全 ID/Secret、自定义安全校验 URL）以及文件 URL 白名单。
- **系统配置 → 第三方提供商**：配置自定义工作流全局变量（供工作流节点复用的外部提供商凭证变量）。
- **系统配置 → 用户配置**：配置团队模式、自定义用户系统配置（只读展示 SSO 服务地址，配置 SSO 登录按钮标题、图标与自动跳转）、邮箱与阿里云短信网关，以及微信服务号、企业微信、GitHub、Google、Microsoft 快捷登录（详见 [SSO 与外部成员同步](/zh-CN/guide/admin/sso) 与 [团队模式说明](/zh-CN/guide/admin/teamMode)）。
- **系统配置 → 套餐 & 充值**：自定义平台标准订阅套餐四档（`Free` 免费版、`Basic` 基础版、`Advanced` 高级版、`Custom` 定制版；同时兼容 `Experience` / `Team` / `Enterprise` 旧版套餐展示）的价格、周期与配额，配置额外积分包、索引包与支付渠道凭证。

### 2. 版本升级、审计日志与 License 管理

| 导航入口 | 核心管理职责 |
| --- | --- |
| **版本升级** | 查看当前版本注册的自动系统迁移任务（System Migration）状态、实时处理进度与断点检查点（Checkpoint），在确认数据库备份就绪后手动触发或恢复执行；详见[版本升级说明](/zh-CN/self-host/upgrading/upgrade-instruction) |
| **审计日志** | 检索全平台管理与关键业务操作审计记录，支持按操作人、团队、事件类型与时间区间溯源 |
| **License 管理** | 查看租户名称、资源额度、授权能力与有效期，激活或变更商业版 License 密钥 |
