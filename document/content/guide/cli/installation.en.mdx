FastGPT CLI is built on Node.js and supports macOS, Linux, and Windows (WSL2 / PowerShell).

---

## Prerequisites

- **Node.js**: Version `>= 20.x` (Node.js 22 LTS or newer is recommended)
- **Package Manager**: `npm`, `pnpm`, or `yarn`

Check your current Node.js version before installing:

```bash
node -v
```

If your Node.js version is below `v20.0.0`, please update Node.js via the [official website](https://nodejs.org/) or using `nvm` / `fnm`.

---

## Method 1: Global Installation via npm (Manual)

Run the following command to install `@fastgpt/cli` globally:

```bash
npm install -g @fastgpt/cli
```

You can also use alternative package managers:

```bash
# Using pnpm
pnpm add -g @fastgpt/cli

# Using yarn
yarn global add @fastgpt/cli
```

Verify that the CLI is ready:

```bash
fastgpt --version
```

The terminal will print the installed CLI version (e.g., `0.1.0-alpha.1`).

## Method 2: AI Agent One-Click Setup Prompt (Recommended for Agents)

If you are using an AI coding assistant (such as **Claude Code**, **Codex**, **Cursor**, or **Windsurf**), you can copy and paste the prompt below directly into your Agent's conversation. The Agent will check your environment, install the package, run diagnostics, and guide you through configuration automatically.

```markdown
Please help me install and set up the official FastGPT CLI (@fastgpt/cli) in this environment:

1. **Environment Check**: Verify that Node.js version is >= 20.x; notify me to upgrade if not met.
2. **Global Install**: Run `npm install -g @fastgpt/cli` (or use pnpm/yarn according to this environment).
3. **Verify Version**: Run `fastgpt --version` to ensure the binary is accessible in system PATH.
4. **Run Diagnostics**: Run `fastgpt doctor --format json` to check runtime health, keychain status, and config integrity.
5. **Guided Setup**: Ask for my FastGPT server URL (defaulting to cloud `https://cloud.fastgpt.cn/api`, or a self-hosted instance) and login method (account credentials or API Key), then help me run `fastgpt login` to complete setup.
```

Once the Agent finishes execution, you can manage datasets, test knowledge recall, and automate FastGPT tasks via terminal commands or by asking your Agent.

## Health Check and Diagnostics (fastgpt doctor)

After installation, it is recommended to run the built-in diagnostic command:

```bash
fastgpt doctor
```

This command runs 5 diagnostic health checks:

1. **Node.js Runtime**: Validates Node.js engine compatibility (>= 20.x).
2. **Configuration File**: Validates `config.json` existence, JSON schema correctness, and directory permissions (`0700`).
3. **Secret Store Backend**: Detects whether system keychains (macOS Keychain / Linux Secret Service) or secure file storage (`0600`) are active.
4. **Server Connectivity**: Verifies server reachability and TLS certificate validity.
5. **Authentication Status**: Inspects current profile credential validity, expiration timestamps, and team permissions.

For CI pipelines or AI Agents, use `--format json` for programmable inspection:

```bash
fastgpt doctor --format json
```
