FastGPT CLI provides full lifecycle management capabilities for FastGPT's core asset: **Datasets (Knowledge Bases)**. Whether for routine maintenance, DevOps bulk provisioning, or AI Agent automation, you can manage datasets efficiently directly from your terminal.

---

## Dataset Commands Overview

| Command                              | Risk Level    | Description                                                        |
| ------------------------------------ | ------------- | ------------------------------------------------------------------ |
| `fastgpt dataset list`               | `read`        | List accessible datasets with pagination, filtering, and search    |
| `fastgpt dataset get <id>`           | `read`        | View dataset details, vector/agent model bindings, and collections |
| `fastgpt dataset create`             | `write`       | Create a new dataset or folder with `--dry-run` parameter preview  |
| `fastgpt dataset update <id>`        | `write`       | Update dataset properties or move between folders and root         |
| `fastgpt dataset delete <id>`        | `destructive` | Permanently delete a dataset with safety confirmation and dry-run  |
| `fastgpt dataset search <id> <text>` | `read`        | Test recall quality across embedding, full-text, and rerank models |

## 1. List and Filter (dataset list)

### Common Examples

```bash
# List root datasets
fastgpt dataset list

# Search by keyword in name and description
fastgpt dataset list --search "Technical Guide"

# Filter datasets inside a specific parent folder
fastgpt dataset list --parent-id "68ad85a7463006c963799a05"

# Filter by type: dataset, folder, or websiteDataset
fastgpt dataset list --type folder

# Custom pagination (default: 20 per page)
fastgpt dataset list --page 2 --page-size 50
```

### JSON Mode for Agent / CI Automation

```bash
fastgpt dataset list --format json
```

The returned JSON envelope includes standardized pagination metadata in the `meta` field:

```json
{
  "ok": true,
  "data": {
    "list": [
      {
        "_id": "68ad85a7463006c963799a05",
        "name": "Engineering Standards",
        "type": "dataset",
        "vectorModel": { "model": "text-embedding-3-small" }
      }
    ]
  },
  "meta": {
    "total": 1,
    "page": 1,
    "pageSize": 20,
    "hasMore": false,
    "count": 1
  }
}
```

## 2. Inspect Dataset Details (dataset get)

Query using either a positional argument or the `--id` flag:

```bash
# Using positional argument
fastgpt dataset get 68ad85a7463006c963799a05

# Using --id flag (convenient for scripts and agents)
fastgpt dataset get --id 68ad85a7463006c963799a05
```

The output displays full metadata, associated vector and QA model IDs, application reference counts, and your access permissions.

## 3. Create a Dataset (dataset create)

### Create Standard Dataset

```bash
fastgpt dataset create --name "HR Employee Handbook" --intro "Onboarding policies"
```

If `--name` is omitted in an interactive TTY, the CLI will prompt you to enter one.

### Specify Models and Parent Folder

```bash
fastgpt dataset create \
  --name "API Reference" \
  --vector-model "text-embedding-3-small" \
  --parent-id "68ad85a7463006c963799a05"
```

### Preview Request with `--dry-run`

Before running in automation, use `--dry-run` to preview the validated payload. Parameters are verified locally against shared OpenAPI schemas, and **no HTTP request is sent to the server**:

```bash
fastgpt dataset create --name "Test Lib" --dry-run --format json
```

```json
{
  "ok": true,
  "changed": false,
  "data": {
    "dryRun": true,
    "risk": "write",
    "operation": "dataset create",
    "preview": {
      "method": "POST",
      "path": "/core/dataset/create",
      "payload": {
        "name": "Test Lib",
        "type": "dataset",
        "parentId": null,
        "intro": ""
      }
    }
  }
}
```

## 4. Update Dataset (dataset update)

Update name, intro, agent model, or folder hierarchy:

```bash
# Update name and description
fastgpt dataset update 68ad85a7463006c963799a05 --name "New Title" --intro "Updated intro"

# Move to a subfolder
fastgpt dataset update 68ad85a7463006c963799a05 --parent-id "68ad85a7463006c963799a06"

# Move back to root directory (pass null)
fastgpt dataset update 68ad85a7463006c963799a05 --parent-id null
```

## 5. Delete Dataset (dataset delete)

<Alert icon="⚠️" context="error">
  **Destructive Operation**: Deleting a dataset permanently removes all its collections and data
  chunks. This action cannot be undone.
</Alert>

### Interactive Deletion (TTY)

Running the command in an interactive terminal will prompt for confirmation:

```bash
fastgpt dataset delete 68ad85a7463006c963799a05
# ? Are you sure you want to permanently delete dataset "68ad85a7463006c963799a05"? (y/N)
```

### Non-Interactive & Agent Automation (`--yes` Guard)

In CI environments or with `--format json`, explicit confirmation via `--yes` is required. Calls missing `--yes` are aborted with exit code `2`:

```bash
fastgpt dataset delete 68ad85a7463006c963799a05 --yes --format json
```

### Safe Preview with `--dry-run`

Preview the deletion without prompting or deleting:

```bash
fastgpt dataset delete 68ad85a7463006c963799a05 --dry-run
```

## 6. Test Knowledge Recall (dataset search)

Test recall quality and evaluate embedding and reranking scores directly from your terminal:

```bash
# Basic search test
fastgpt dataset search 68ad85a7463006c963799a05 "What is FastGPT?"

# Advanced hybrid search with similarity threshold and reranking
fastgpt dataset search 68ad85a7463006c963799a05 \
  --text "API authentication flow" \
  --similarity 0.6 \
  --mode mixedRecall \
  --rerank
```

### Search Options

- `--text <query>`: Search question or prompt.
- `--mode <mode>`: Search mode: `embedding`, `fullTextRecall`, or `mixedRecall` (default).
- `--similarity <score>`: Minimum similarity score threshold (`0.0 ~ 1.0`).
- `--limit <tokens>`: Maximum recall token budget (default 5000).
- `--rerank` / `--no-rerank`: Enable or disable the ReRank scoring model.

The result outputs duration, retrieved chunk content, scores, and source file metadata.
