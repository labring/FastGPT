FastGPT CLI 提供了对 FastGPT 核心资产——**知识库（Dataset）** 的完整生命周期管理能力。无论是日常维护、DevOps 批量初始化，还是 AI Agent 自动化构建，都能在终端中高效执行。

---

## 知识库命令总览

| 命令                                 | 风险等级      | 说明                                                      |
| ------------------------------------ | ------------- | --------------------------------------------------------- |
| `fastgpt dataset list`               | `read`        | 分页列出有权访问的知识库，支持名称与简介模糊搜索          |
| `fastgpt dataset get <id>`           | `read`        | 查看知识库详情、绑定的向量/文本模型以及文件数统计         |
| `fastgpt dataset create`             | `write`       | 创建新知识库或文件夹，支持设置嵌入模型与 `--dry-run` 预览 |
| `fastgpt dataset update <id>`        | `write`       | 修改知识库属性，支持移动到子目录或移回根目录              |
| `fastgpt dataset delete <id>`        | `destructive` | 永久删除知识库及下属集合与数据切片，具备安全确认与预览    |
| `fastgpt dataset search <id> <text>` | `read`        | 执行检索测试，验证向量召回、全文召回与重排模型效果        |

## 1. 列表与筛选（dataset list）

### 常用查询示例

```bash
# 列出根目录知识库
fastgpt dataset list

# 按关键词模糊搜索名称与简介
fastgpt dataset list --search "技术规范"

# 筛选指定父级文件夹内的知识库
fastgpt dataset list --parent-id "68ad85a7463006c963799a05"

# 仅筛选文件夹类型（可选 dataset、folder、websiteDataset）
fastgpt dataset list --type folder

# 指定分页参数（默认每页 20 条）
fastgpt dataset list --page 2 --page-size 50
```

### JSON 模式输出（供 Agent / CI 消费）

```bash
fastgpt dataset list --format json
```

输出的 JSON 信封中，`meta` 字段将严格返回标准分页元数据：

```json
{
  "ok": true,
  "data": {
    "list": [
      {
        "_id": "68ad85a7463006c963799a05",
        "name": "产品研发规范",
        "type": "dataset",
        "vectorModel": { "model": "text-embedding-3-small" }
      }
    ]
  },
  "meta": {
    "total": 1,
    "page": 1,
    "pageSize": 20,
    "hasMore": false,
    "count": 1
  }
}
```

## 2. 查看知识库详情（dataset get）

支持通过位置参数或 `--id` 标志查询：

```bash
# 通过位置参数查询
fastgpt dataset get 68ad85a7463006c963799a05

# 通过 --id 标志查询（便于脚本组装）
fastgpt dataset get --id 68ad85a7463006c963799a05
```

输出内容包含知识库的完整元数据、关联的向量检索模型、文本理解模型、应用引用数量以及当前用户的读写权限。

## 3. 创建知识库（dataset create）

### 创建标准知识库

```bash
fastgpt dataset create --name "HR 员工手册" --intro "包含入职指引与考勤制度"
```

如果在交互式终端中未提供 `--name`，CLI 将友好提示输入名称。

### 指定向量模型与目录

```bash
fastgpt dataset create \
  --name "API 参考指南" \
  --vector-model "text-embedding-3-small" \
  --parent-id "68ad85a7463006c963799a05"
```

### 预览操作参数（--dry-run）

在自动化脚本或 CI 创建前，建议使用 `--dry-run` 预览请求体。该命令将在本地通过共享 OpenAPI Schema 完成参数强校验，输出请求路径与格式化载荷，且**绝不向服务端发起真实写入**：

```bash
fastgpt dataset create --name "测试库" --dry-run --format json
```

```json
{
  "ok": true,
  "changed": false,
  "data": {
    "dryRun": true,
    "risk": "write",
    "operation": "dataset create",
    "preview": {
      "method": "POST",
      "path": "/core/dataset/create",
      "payload": {
        "name": "测试库",
        "type": "dataset",
        "parentId": null,
        "intro": ""
      }
    }
  }
}
```

## 4. 更新知识库（dataset update）

支持更新名称、简介、Agent 模型以及移动层级：

```bash
# 修改名称与简介
fastgpt dataset update 68ad85a7463006c963799a05 --name "新名称" --intro "最新简介"

# 移动到指定文件夹
fastgpt dataset update 68ad85a7463006c963799a05 --parent-id "68ad85a7463006c963799a06"

# 将知识库移回根目录（传入 null 或空值）
fastgpt dataset update 68ad85a7463006c963799a05 --parent-id null
```

同样支持结合 `--dry-run` 进行变更预检。

## 5. 删除知识库（dataset delete）

<Alert icon="⚠️" context="error">
  **破坏性操作（destructive）**：删除知识库将永久清理其包含的所有集合（Collection）以及切片数据（Chunks），无法撤销。
</Alert>

### 交互式删除（TTY 终端）

直接执行删除命令时，CLI 会弹出确认提示：

```bash
fastgpt dataset delete 68ad85a7463006c963799a05
# ? Are you sure you want to permanently delete dataset "68ad85a7463006c963799a05"? (y/N)
```

### 非交互式与 Agent 自动化模式（--yes 强制护栏）

在 CI 自动化流水线或使用 `--format json` 时，为了防止误操作，CLI 强制要求传入 `--yes`。如果未传入，命令将被安全拦截并以退出码 `2` 终止：

```bash
# CI 或 Agent 自动化删除
fastgpt dataset delete 68ad85a7463006c963799a05 --yes --format json
```

### 删除预检预览（--dry-run）

无需确认提示即可安全预检删除请求：

```bash
fastgpt dataset delete 68ad85a7463006c963799a05 --dry-run
```

## 6. 召回效果检索测试（dataset search）

无需打开 Web 界面，即可在终端中快速测试知识库的检索召回质量，评估向量与重排效果：

```bash
# 基础检索测试
fastgpt dataset search 68ad85a7463006c963799a05 "什么是 FastGPT？"

# 进阶检索：设置相似度阈值并启用混合召回
fastgpt dataset search 68ad85a7463006c963799a05 \
  --text "API 认证流程" \
  --similarity 0.6 \
  --mode mixedRecall \
  --rerank
```

### 检索参数说明

- `--text <query>`：检索测试问题文本。
- `--mode <mode>`：召回模式，支持 `embedding`（纯向量召回）、`fullTextRecall`（纯全文召回）和 `mixedRecall`（混合召回，默认）。
- `--similarity <score>`：相似度最低分数阈值（`0.0 ~ 1.0`）。
- `--limit <tokens>`：召回内容的最大 token 预算（默认 5000）。
- `--rerank` / `--no-rerank`：显式开启或关闭 ReRank 重排模型打分。

测试结果将打印检索耗时、命中的数据块列表、匹配得分以及所属文件来源，便于在流水线中自动化校验检索指标。
