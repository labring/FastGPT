FastGPT CLI（`fastgpt`）是 FastGPT 官方推出的命令行工具，旨在为开发者、DevOps 工程师以及 AI 编程助手（如 Claude Code、Codex、Cursor、Windsurf 等）提供稳定、安全且高效的终端交互与自动化管理能力。

借助 FastGPT CLI，你无需打开浏览器即可在终端中完成身份认证、多团队环境切换、知识库增删改查、召回效果测试、配置自检诊断等核心操作。

---

## 核心设计特性

<Alert icon="⚡" context="success">
  FastGPT CLI 严格遵循「本地首选、安全优先、Agent 友好」的现代 CLI 架构，同时支持人类终端交互与 AI
  智能体可编程调用。
</Alert>

### 1. 终端与 Agent 双模友好

- **人类友好**：在交互式 TTY 终端下，提供彩色的层次化输出、输入引导与二次确认保护，支持 `fastgpt doctor` 一键诊断环境。
- **Agent / CI 友好**：非 TTY 环境或显式传入 `--format json` 时，自动输出确定性的结构化 JSON 信封；所有非结果输出（如调试日志、进度信息、安全警告）严格走 `stderr`，确保 `stdout` 纯净，便于管道处理与程序化解析。

### 2. 本地安全与敏感信息保护

- **系统级密钥环**：优先使用 macOS Keychain 与 Linux Secret Service 存储登录凭据；在容器或无桌面环境中自动平滑降级为 `0600` 权限的受保护文件存储。
- **自动脱敏与防泄漏**：CLI 内部所有错误堆栈、HTTP 日志以及命令信封中的凭据参数均经过深度脱敏；强制拦截跨源 3xx 重定向，防止认证凭据外泄至不可信服务。
- **破坏性操作防护**：删除等高风险操作在交互终端下强制二次确认；在非交互或脚本自动化模式下必须显式传入 `--yes`，且全面支持 `--dry-run` 零副作用请求预览。

### 3. 与 Web 端统一的滑动会话续期

- 登录会话具备 7 天有效期。
- 每次在终端发起有效操作，服务端自动执行 24 小时防抖的滑动续期（Sliding Session Renewal），使活跃开发者的会话持续保持有效，彻底告别频繁重新登录。

## 命令结构一览

FastGPT CLI 采用领域驱动（DDD）风格组织命令空间：

| 一级命令域         | 说明                                   | 典型命令                                         |
| ------------------ | -------------------------------------- | ------------------------------------------------ |
| `auth`             | 账号认证、多环境 Profile、团队空间切换 | `fastgpt auth status`、`fastgpt auth switch`     |
| `login` / `logout` | 登录与注销便捷入口                     | `fastgpt login`、`fastgpt logout`                |
| `whoami`           | 快速查看当前登录身份、团队与权限       | `fastgpt whoami`                                 |
| `dataset`          | 知识库全生命周期管理与召回测试         | `fastgpt dataset list`、`fastgpt dataset search` |
| `config`           | 客户端本地配置查看与修改               | `fastgpt config get`、`fastgpt config set`       |
| `doctor`           | 运行时、配置文件、服务端连通性体检     | `fastgpt doctor`                                 |
