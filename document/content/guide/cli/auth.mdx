FastGPT CLI 支持企业级多租户、多环境与多凭据形态管理。你可以同时保存开发环境、测试环境与生产环境的连接配置，并在不同的团队空间之间自由切换。

---

## 凭据类型与支持范围

FastGPT CLI 支持以下两类主要凭据：

| 凭据类型                                 | 适用场景                           | 权限范围                                  | 会话有效期                       |
| ---------------------------------------- | ---------------------------------- | ----------------------------------------- | -------------------------------- |
| **Session Token**（账号密码登录）        | 本地开发、日常交互、多团队切换     | 拥有当前账号在目标团队的所有权限          | 7 天滑动续期（使用时自动顺延）   |
| **Personal API Key**（个人通用 API Key） | CI/CD 流水线、自动化脚本、AI Agent | 具备当前账号所有权范围内全部 OpenAPI 能力 | 根据控制台设置长期有效或设定期限 |

<Alert icon="🔒" context="warning">
  **注意**：在 FastGPT 中，针对单个应用创建的 **App-scoped API Key**（应用专属
  Key）仅能用于该应用的对话与调用，不能用于知识库全局管理。CLI 在执行 `dataset`
  等管理命令时会自动进行凭据门禁检查，避免误用受限 Key。
</Alert>

## 登录与初始化

### 1. 交互式账号密码登录（推荐）

在终端中执行以下命令，根据提示输入服务端地址、用户名和密码：

```bash
fastgpt login
```

执行流程：

1. 提示输入 FastGPT 服务端地址（默认官方云平台 `https://cloud.fastgpt.cn/api`，私有化部署用户请输入你的实例 API 地址，例如 `https://fastgpt.mycompany.com/api`）。
2. 输入用户名/手机号/邮箱及密码。
3. 登录成功后，凭据将自动存入系统安全密钥环（macOS Keychain 或 Linux Secret Service）。

### 2. 使用 API Key 快速登录（无交互式）

如果你更倾向于使用在 FastGPT Web 控制台「账号 - API 秘钥」中生成的个人通用 API Key，可以直接指定：

```bash
fastgpt login --api-key "fastgpt-personal-xxxxxx" --base-url "https://cloud.fastgpt.cn/api"
```

### 3. 指定环境名称（Profile）

使用 `--profile <name>` 可以为不同的实例或账号创建独立的配置 Profile（默认为 `default`）：

```bash
# 登录本地自建环境
fastgpt login --profile local --base-url "http://localhost:3000/api"

# 登录公司生产环境
fastgpt login --profile prod --base-url "https://ai.company.com/api"
```

## 查看身份与会话信息

### 1. 查看当前用户信息（fastgpt whoami）

```bash
fastgpt whoami
```

终端将清晰展示当前用户的账户详情，包括：

- 用户 ID 与用户名
- 是否为系统管理员（Root）
- 当前生效的团队空间（Team ID、团队名称、成员权限）
- 会话有效期与下一次自动顺延时间

在脚本中使用时，可添加 `--format json` 输出标准 JSON：

```bash
fastgpt whoami --format json
```

### 2. 查看当前 Profile 状态（fastgpt auth status）

```bash
fastgpt auth status
```

展示当前激活的 Profile 名称、Base URL、认证模式（Token 或 API Key）以及底层存储后端（Keychain 或 File）。

## 滑动会话无感续期（Sliding Session）

FastGPT 的登录会话采用 **24 小时防抖的滑动续期机制**：

1. **基础寿命**：每次成功登录，会话有效时长为 7 天。
2. **自动顺延**：当你在终端执行任何需要认证的命令时，若距离上次续期已超过 24 小时，服务端将自动将 Redis 中的会话过期时间顺延 7 天，并通过响应头回传最新的到期时间戳。
3. **静默刷新**：CLI 客户端捕获到续期响应后，会在本地安全更新会话过期时间，无需你重新执行 `fastgpt login`。

## 多 Profile 与团队空间管理

### 1. 列出所有环境配置

```bash
fastgpt auth list
```

展示本地保存的所有 Profile 清单，以及当前正在使用的环境标识（`*`）。

### 2. 切换当前生效 Profile

```bash
fastgpt auth switch prod
```

切换后，后续所有命令都将默认作用于 `prod` 环境。也可以通过临时参数全局覆盖：

```bash
fastgpt dataset list --profile local
```

### 3. 切换当前账号的团队空间

如果你的账号加入了多个团队，可以使用 `auth switch-team` 在团队之间无缝切换：

```bash
fastgpt auth switch-team 68ad85a7463006c963799a05
```

CLI 将向服务端请求签发对应团队的活跃凭据，并自动更新本地 Profile，之后的操作将立即作用于新团队的数据与资源。

### 4. 注销登录

```bash
# 注销当前 Profile
fastgpt logout

# 注销指定 Profile
fastgpt auth logout local
```

注销后，CLI 会安全清除对应 Profile 在系统 Keychain 或本地凭据文件中的记录。
