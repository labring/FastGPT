本教程引导你在可视化画布上搭建一个具备条件分支与模型调用的多节点工作流，掌握工作流引擎的核心编排机制。

## 学习目标与前置条件

完成本教程后，你将理解工作流画布的执行连线与数据流转原理，学会通过节点组合实现“用户输入 → 文本提取 → AI 对话生成 → 指定回复”的完整处理链条。

在开始前，确认满足以下条件：
- 拥有当前团队的应用创建权限。
- 当前团队已配置可用的对话模型。
- 熟悉基本的工作区界面操作。

## 第一步：新建空白工作流

1. 登录 FastGPT 控制台，进入“应用”页面。
2. 点击右上角“创建应用”，在应用类型中选择“工作流”。
3. 名称填写为 `智能文本摘要工作流`，点击“创建”。
4. 画布初始状态包含一个“流程开始”节点，代表整个工作流的触发入口。

![工作流初始画布与流程开始节点](/imgs/optimized/current/workflow-start-chat.png.webp)

## 第二步：添加 AI 对话节点并建立连接

1. 在画布左侧或空白处右键打开节点菜单，选择“核心节点 → AI 对话”。
2. 将“AI 对话”节点拖入画布中央。
3. **建立执行连线**：从“流程开始”节点的右侧连接桩拖出连线，连接至“AI 对话”节点的左侧连接桩。执行连线决定了节点的执行先后顺序。
4. **配置节点参数**：
   - 模型选择：挑选可用的对话模型。
   - 系统提示词：输入 `请将输入文本提炼为 3 条核心要点，保留关键人名、时间与具体数据。`。
   - 用户问题输入：点击输入框右侧的变量引用图标，选择绑定至“流程开始”节点的“用户问题”。数据引用连接保证了上游文本向下游节点的稳定传递。

![执行连线与用户输入引用配置](/imgs/optimized/current/workflow-config.png.webp)

## 第三步：添加文本回复节点呈现结果

1. 在节点菜单中选择并添加“指定回复”节点。
2. 将“AI 对话”节点的执行输出连接至“指定回复”节点的执行输入。
3. 在“指定回复”的内容输入框中，输入前置提示语，并点击变量引用插入“AI 对话”节点的“模型生成内容”。
4. 关闭“AI 对话”节点自身的直接输出开关，由“指定回复”节点统一定制最终展示格式。

## 第四步：工作区端到端调试

在右侧预览调试面板中输入测试文本：

```text
FastGPT 团队定于本周五上午 10:00 在 3 号会议室举行架构评审会议，全程预计耗时 2 小时。请所有参会人员提前准备好手提电脑与技术文档。
```

点击发送后，实时观察画布与调试面板：
1. 画布上各节点依次亮起运行指示，显示当前执行进度。
2. 调试面板返回包含周五、10:00、3 号会议室、2 小时等具体要素的三点清晰摘要。
3. 打开调试面板中的“执行详情”，可以查看每个节点的输入参数、输出参数、执行状态及单步耗时（ms）。

![摘要工作流返回三条结构化核心信息](/imgs/optimized/current/workflow-answer.png.webp)

## 第五步：保存并发布正式版本

1. 确认输出效果无误后，点击右上角的“发布”按钮。
2. 输入版本描述（例如 `v1.0.0: 完成基础摘要工作流`），确认发布。
3. 新版本立即接管外部访问入口，草稿编辑变动在下一次发布前保留在工作台中。

## 编排排障指南

| 常见问题 | 排查步骤 |
| --- | --- |
| 节点处于等待状态未执行 | 检查上游节点至该节点的执行连线连接状态，确认所有前置依赖均已触发 |
| 下游模型接收内容为空 | 检查变量引用配置，确认正确绑定了上游节点的输出字段 |
| 画布未产生对话回复 | 检查工作流中是否包含可输出内容的节点（如 AI 对话节点的输出开关或指定回复节点） |
| 变量更新未生效 | 确认变量写入节点的执行时序位于下游读取节点之前 |
