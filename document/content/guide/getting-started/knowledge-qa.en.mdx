This guide provides a standardized recipe for building high-precision knowledge-base Q&A applications that deliver dependable answers with explicit citations.

## Scenario and Prerequisites

This guide addresses a core problem: transforming structured or unstructured policy documentation into an operational Q&A system that adheres strictly to source facts and exposes verifiable citations.

Before starting, confirm the following prerequisites:
- Permissions to create datasets, manage applications, and publish channels in your active team.
- An available embedding model and chat model configured in the environment (refer to [Model Configuration](/en/self-host/config/model/intro)).
- A clean UTF-8 text document prepared locally, such as `travel-policy.txt` containing:

```text
FastGPT Example Travel Policy
1. Submission deadline: Employees must submit expense reports within 15 calendar days after returning from a business trip.
2. Mandatory receipts: Every claim must attach an official tax invoice and an approved travel request form.
3. Finance review SLA: The finance department completes review and disbursement within 5 business days after receiving complete valid receipts.
```

![Create travel policy knowledge base and choose available model](/imgs/optimized/current/knowledge-create.png.webp)

## Step 1: Create a Knowledge Base and Configure Chunking

1. Open the "Knowledge Base" console, click "New", name it `Corporate Travel Policy`, and select your team's embedding model.
2. Open the knowledge base, click "New / Import → Text Dataset → Local Files", and upload `travel-policy.txt`.
3. **Chunking Strategy**:
   - For policy clauses, start with the default chunking parameters and inspect complete clauses in the preview before adjusting boundaries.
   - For structured Q&A catalogs: Use QA segmentation to automatically derive query-answer pairs for higher semantic matching.
4. In the preview view, click the file on the left to confirm that time limits and documentation requirements remain grouped in single chunks. Click "Start Import".

![Previewing text chunks preserves core factual context](/imgs/optimized/current/knowledge-preview.png.webp)

## Step 2: Validate Search Recall and Reranking

Before connecting the knowledge base to an application, verify retrieval quality using standalone search testing:
1. Navigate to the "Search Test" tab at the top of the knowledge base.
2. In the query box, enter a representative question: "Within how many days must an employee file expenses after returning?".
3. Inspect returned chunks and their similarity scores.
4. Verify that the top candidate chunk contains `15 calendar days`. If a reranker is active, confirm that high-relevance chunks rank highest after the second-pass scoring.

![Search test hits original text containing 15 calendar days deadline](/imgs/optimized/current/knowledge-search.png.webp)

## Step 3: Create a Chat Agent with Grounding Prompts

1. Navigate to "Applications", create a new application, choose "Chat Agent", and name it `Travel Policy Assistant`.
2. Pick an active chat model.
3. In the "Knowledge Base" configuration section, attach the validated `Corporate Travel Policy`.
4. Compose a system prompt enforcing strict factual adherence:

```text
You are a corporate travel policy assistant.
Answer user questions strictly using the retrieved reference text.

Operational rules:
1. State deadlines, processes, and mandatory documentation as explicitly recorded in the policy.
2. Append source citations at the end of each answer.
3. For information not recorded in the references, state that the current policy contains no record and direct the user to HR or Finance.
```

![Choose Chat Agent and fill out application details](/imgs/optimized/current/app-create.png.webp)

## Step 4: Test in Workspace and Verify Edge Cases

Run two distinct tests in the right-hand testing drawer:
1. **Factual Recall Test**: Ask "What receipts are required for reimbursement?". Confirm that the assistant lists invoices and approved request forms with accurate citations.
2. **Boundary Test**: Ask "What is the daily hotel lodging allowance?". Confirm that the model states the policy lacks records on lodging rates, preventing hallucinated numbers.

![Testing chat returns deadline, receipts, and source references](/imgs/optimized/current/knowledge-answer.png.webp)

## Step 5: Configure Citation Visibility and Publish

1. Click "Save" in the workspace header and publish a production release.
2. Open the "Publishing Channels" tab and add a "Public Share Link".
3. Toggle on "Show Source Citations". This lets end users click citation pills at the bottom of answers to inspect original source chunks.
4. Copy the URL and test the experience in an external browser tab.

![Published share window returns 15 calendar days deadline and required documents](/imgs/optimized/current/knowledge-published.png.webp)

## Acceptance Checklist

- [ ] Knowledge base collection status is ready and vector indexing is active.
- [ ] Standalone search tests recall target chunks with high confidence scores.
- [ ] The assistant answers grounded facts reliably and explicitly marks unrecorded questions.
- [ ] Public share links display expandable citation pills that reveal source material.
