FastGPT CLI (`fastgpt`) is the official command-line tool for FastGPT. It gives developers, DevOps engineers, and AI coding assistants such as **Codex**, **Claude Code**, **Cursor**, and **Windsurf** reliable, secure, and programmable access to FastGPT resources.

Use the terminal directly or work with an AI Agent to authenticate, switch teams, manage Datasets, test retrieval, and manage App conversations without opening a browser.

## ⚡ Developer quick start: Three steps

To set up the CLI yourself, follow these three steps:

### 1. Install the CLI

With Node.js `>= 20.12.0` installed, run:

```bash
npm install -g @fastgpt/cli@beta
# Or use pnpm: pnpm add -g @fastgpt/cli@beta

# Verify installation
fastgpt --version
```

### 2. Sign in

Run the login command to authenticate:

```bash
# Option A: Sign in interactively (cloud or self-hosted)
fastgpt login
# For self-hosted instances: fastgpt login --base-url https://your-domain.com/api

# Option B: API Key login via stdin (Recommended for CI / container / Agent environments)
printf '%s' "$FASTGPT_API_KEY" | fastgpt login --api-key-stdin

# Option C: Username and password via stdin
printf '%s' "$FASTGPT_PASSWORD" | fastgpt login --username <USERNAME> --password-stdin
```

After signing in, check your current identity and team at any time:

```bash
fastgpt whoami
```

> **Credential storage and session expiration**:
> Credentials are stored in your system keychain (macOS Keychain / Linux Secret Service) when available. Sessions expire 7 days after creation. Run `fastgpt login` to sign in again after expiration.

### 3. Run diagnostics (Doctor)

Check your local environment, configuration file permissions, and connection to the server:

```bash
fastgpt doctor
```

## Core capabilities

FastGPT CLI uses domain-driven design (DDD) and a concise command structure:

| Category               | Example commands                                                                                                                                             | Description                                                                                                                                  |
| :--------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **Identity and teams** | `fastgpt whoami`<br/>`fastgpt auth switch-team --team-id <id>`                                                                                               | View the current user and team, or switch teams                                                                                              |
| **Dataset search**     | `fastgpt dataset list`<br/>`fastgpt dataset search <id1,id2> "query"`                                                                                        | List Datasets with pagination, or search one or more Datasets; returns the top 20 results by default                                         |
| **Dataset management** | `fastgpt dataset create --name "Docs"`<br/>`fastgpt dataset collection create-file <id> ./doc.pdf`<br/>`fastgpt dataset data list <collectionId>`            | System OpenAPI dataset CRUD, file/text/link collection imports, and chunk management                                                         |
| **Configuration**      | `fastgpt config list`<br/>`fastgpt commands --compact --format json`                                                                                         | View local client configuration, or discover compact machine-readable command schemas                                                        |
| **App conversations**  | `fastgpt chat run --appId <id> --text "Hello"`<br/>`fastgpt chat init --appId <id> --chatId <chatId>`<br/>`fastgpt chat stop --appId <id> --chatId <chatId>` | Run an App and get a JSON response, read its configuration and status, or send a stop signal                                                 |
| **App chat history**   | `fastgpt chat history list --appId <id>`<br/>`fastgpt chat record list --appId <id> --chatId <chatId>`                                                       | List, update, and soft-delete App conversations, check status in batches, mark conversations as read, and read messages and response details |

App chat commands use OpenAPI endpoints only. App API Keys can omit `--appId`; personal API Keys and user sessions must specify an App. Use `--file <path>` or `--stdin` with `chat run` to load a JSON request. All write operations support `--dry-run`.

`chat record list` fetches the latest page by default and returns messages in chronological order. Each command fetches one page. Pass `meta.prevCursor` as `--prevId` to fetch older rounds, or `meta.nextCursor` as `--nextId` to fetch newer rounds. `--initialId` loads rounds around the AI reply with the specified `dataId`. Use only one of these three ID flags. The server determines the anchor role from the pagination direction. `--pageSize` is a target message count; the server may return extra messages to keep round boundaries intact.

The API returns `prevCursor` and `nextCursor`, which the CLI copies unchanged into `meta`. A cursor is `null` when there is no next page in that direction.

Use `dataId` for message operations such as reading response details. A message's `id` is a deprecated compatibility alias.

`chat run` has a default HTTP timeout of 300000 milliseconds, configurable with `--timeoutMs`. A timeout does not stop the App, and failed generation requests are not retried automatically. `chat stop` returns as soon as the stop signal is written, without waiting for background cleanup. Use each command's `--help` for its full parameter list.

## Automation and scripting guidelines

- **Agent & Automation Pipelines**: Pass `--format json` to get structured JSON envelopes (logs route to `stderr`, keeping `stdout` clean).
- **Low-Token Discovery & Chaining**: Use `commands --compact` and `--command "<cmd>"` to discover schemas on demand; pass `--fields _id,name` to trim list payloads, or `--pick data.datasetId --raw` to extract scalar IDs directly into shell variables.
- **Destructive Operation Safety**: Write/delete actions support `--dry-run` validation previews; non-interactive scripts and CI pipelines mandate `--yes` for destructive execution.
