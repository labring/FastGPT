本教程引导你构建一个具备自主规划与工具调用能力的对话 Agent V2，完成从知识检索到结构化清单输出的端到端任务。

## 学习目标与前置条件

完成本教程后，你将掌握对话 Agent V2 的核心工作原理，学会在系统中挂载工具与知识库，并通过执行详情分析模型的思考与调用链路。

在开始前，确认满足以下条件：
- 拥有当前团队的应用创建权限与知识库读取权限。
- 当前环境已配置支持 Function Calling（工具调用）的对话模型。
- 已完成[快速上手教程](/zh-CN/guide/getting-started/quick-start)，团队中存在包含差旅规则的 `企业差旅制度` 知识库。

## 第一步：新建对话 Agent V2

1. 登录 FastGPT 控制台，进入“应用”页面。
2. 点击右上角“创建应用”。
3. 在类型列表中选择“对话 Agent V2”，应用名称填写为 `报销审核 Agent`，点击“创建”。
4. 进入应用编排界面，在模型选择区挑选支持工具调用的模型。

![创建 Agent 时选择对话 Agent V2 类型](/imgs/current/app-types.png)

## 第二步：编写结构化系统指令

在系统提示词区域输入明确的任务指令，规定 Agent 的决策流程与输出规范：

```text
你是一个严谨的企业差旅报销审核助手。
在回答用户的报销咨询前，必须先调用知识库检索相关的差旅制度。

回答格式要求：
1. 提交时限：明确说明返程后提交申请的天数要求。
2. 必备凭证：逐项列举必须上传的发票与单据。
3. 审核流程：说明财务部门的处理时限。
4. 补充说明：列出制度中未明确但需要用户留意的细节。

保持陈述客观明确，直接引用制度中的明确事实。
```

## 第三步：挂载知识库与外部工具

1. 在应用配置面板的“知识库”区域，点击“添加”，选择此前创建的 `企业差旅制度`。
2. 在“工具”配置区域，点击“添加工具”。系统内置了网络搜索、代码运行和数据处理等工具。选择挂载知识库检索工具。
3. 保持单次运行工具调用次数上限的默认设置，为多轮推理提供充足预算。

![挂载工具与知识库](/imgs/current/agent-prompt-reference.png)

## 第四步：交互调试与执行链路分析

在右侧调试区域输入测试提问：

```text
我刚结束出差回公司，请帮我梳理报销需要注意的时间点和必备材料。
```

点击发送后，观察调试面板的执行过程：
1. **思考过程**：Agent 接收问题后，根据指令主动决策先调用知识库检索工具。
2. **工具调用**：Agent 自动提取关键词 `出差 报销 时限 材料` 传入知识库检索接口。
3. **观察结果**：检索工具返回差旅制度分块（包含 15 个自然日、发票及已审批差旅申请单）。
4. **生成回答**：Agent 结合返回的制度事实，按照预设的四个结构化要点组织答案并附带引用来源。

展开右侧对话框中的“执行详情”，逐层检查工具入参、输出内容与各步骤耗时。

![报销检查助手引用差旅制度返回结构化清单](/imgs/current/agent-answer.png)

## 第五步：保存并发布正式版本

1. 确认调试效果符合预期后，点击工作区右上角的“发布”按钮。
2. 填写版本更新说明（例如 `v1.0.0: 首个差旅审核 Agent`），点击“确认发布”。
3. 此时系统将正式版本指针指向当前配置，线上访问渠道立即生效该版本。

## 常见排查点

| 异常现象 | 核心排查方向 |
| --- | --- |
| 模型未调用工具直接回复 | 检查所选模型是否支持 Function Calling；强化提示词中的前置检索指令 |
| 检索结果为空 | 检查知识库向量索引就绪状态；核实关联知识库权限 |
| 工具调用超时报错 | 检查辅助网络或模型服务连接状态；检查执行日志中的错误堆栈 |
