本教程引导你构建一个具备自主规划与工具调用能力的对话 Agent V2，完成从知识检索到结构化清单输出的端到端任务。

## 学习目标与前置条件

完成本教程后，你将掌握对话 Agent V2 的核心工作原理，学会在系统中挂载工具与知识库，并通过执行详情分析模型的思考与调用链路。

在开始前，确认满足以下条件：
- 拥有当前团队的应用创建权限与知识库读取权限。
- 当前环境已配置可用的对话模型（云服务预设的对话模型默认均支持工具调用；私有化部署环境可在“AI 配置”弹窗中选择模型，确认模型信息表“工具调用”一列显示“支持”）。
- 已完成[快速上手教程](/zh-CN/guide/getting-started/quick-start)，团队中存在包含差旅规则的 `差旅制度` 知识库。

## 第一步：新建对话 Agent V2

1. 登录 FastGPT，点击左侧导航栏的“工作台”。
2. 首次使用时点击页面中央的“创建你的第一个 Agent”（若工作台已有应用，点击列表首个“新建”卡片），进入“创建 Agent”页面。
3. 在“Agent 类型”列表中选择“对话 Agent V2”，在“图标 & 名称”中填写 `报销检查助手`，点击“创建”。
4. 进入“应用配置”界面，在“AI 配置 → AI 模型”中保留默认模型（如 `qwen3.8-flash`），或从下拉列表中选择通义千问（`Qwen-plus`、`qwen3.6-plus`）、深度求索（DeepSeek）、豆包、ChatGLM 等主流对话模型（云服务预设模型均已支持工具调用）。

![创建 Agent 时选择对话 Agent V2 类型](/imgs/optimized/current/app-types.png.webp)

## 第二步：编写结构化系统指令

在“AI 配置 → 提示词”输入框中填写明确的任务指令，规定 Agent 的检索动作与输出格式（与下方运行截图一致，也可使用同等语义的中文提示词）：

```text
Retrieve the travel policy before answering. Return exactly four short bullet points: submission deadline, required documents, Finance review time, and missing policy information. Use only explicit policy facts. Do not calculate dates or introduce additional requirements.
```

中文等效提示词参考：

```text
回答前请先检索差旅制度，并固定输出四个简短要点：提交期限、必需材料、财务审核时间、制度缺失信息。仅使用制度中的明确事实，禁止推算日期或补充额外要求。
```

## 第三步：关联知识库与引用工具

1. 在“应用配置”面板底部的“知识库”区域，点击右侧的“+ 选择”，勾选此前创建的 `差旅制度` 知识库并确认。关联知识库后，对话 Agent V2 会自动启用知识库检索能力。
2. 如需扩展其他外部工具或技能，可在“关联技能”或“工具”区域点击右侧的“+ 选择”，按需挂载团队技能或系统工具。
3. 在“提示词”输入框中输入 `@` 可呼出能力引用菜单（如下图所示），支持从“系统工具”、“我的工具”、“我的 agents”或“关联技能”中直接点选“知识库检索”、“虚拟机”、“文件解析”或“秘塔搜索工具集”等能力，在提示词中明确指定调用项。

![挂载工具与知识库](/imgs/optimized/current/agent-prompt-reference.png.webp)

## 第四步：交互调试与执行链路分析

在右侧“调试预览”面板底部的输入框中输入测试提问：

```text
请检查我的报销准备情况：提交期限、必需材料、财务审核时间以及制度缺失的信息。
```

点击发送后，观察“调试预览”面板的执行过程：
1. **思考过程**：Agent 接收问题后，根据指令主动决策先调用知识库检索工具。
2. **工具调用**：Agent 自动生成检索查询词并调用知识库检索。
3. **观察结果**：检索返回 `travel-policy.txt` 中的差旅制度分块（包含 15 个自然日、发票、已审批出差申请单及 5 个工作日审核时限）。
4. **生成回答**：Agent 按照提交期限、必需材料、财务审核时间、制度缺失信息四个要点输出结构化清单，并在下方展示“共 1 条引用”。

点击回答上方的“已处理”或回答下方的“运行详情”，可逐层检查工具入参、检索返回内容与单步耗时。

![报销检查助手引用差旅制度返回结构化清单](/imgs/optimized/current/agent-answer.png.webp)

## 第五步：保存并发布正式版本

1. 确认调试效果符合预期后，点击右上角的“保存”按钮，在下拉菜单中选择“保存并发布”。
2. 在“保存并发布”弹窗中填写版本名称（例如 `报销检查助手 v1`），点击“确认”。
3. 此时系统将正式版本指针指向当前配置，线上访问渠道立即生效该版本。

## 常见排查点

| 异常现象 | 核心排查方向 |
| --- | --- |
| 模型未调用工具直接回复 | 检查所选模型是否支持 Function Calling；强化提示词中的前置检索指令 |
| 检索结果为空 | 检查知识库向量索引就绪状态；核实关联知识库权限 |
| 工具调用超时报错 | 检查辅助网络或模型服务连接状态；检查执行日志中的错误堆栈 |
