This tutorial guides first-time builders through creating a grounded knowledge-base Q&A assistant in 5 minutes and generating an externally accessible share link.

## Learning Goals and Preparation

By completing this tutorial, you will build an online assistant capable of answering corporate travel expense policies accurately, mastering the end-to-end workflow of "import knowledge base → attach to Agent → test in workspace → publish to production".

Before starting, prepare the following resources:
- Resource creation permissions in your current workspace team.
- Configured chat models and embedding models (SaaS accounts include default models; for self-hosted instances, refer to [Model Configuration](/en/self-host/config/model/intro)).
- Save the following sample text locally as a UTF-8 encoded file named `travel-policy.txt`:

```text
FastGPT Example Travel Policy
1. Submission deadline: Employees must submit expense reports within 15 calendar days after returning from a business trip.
2. Mandatory receipts: Every claim must attach an official tax invoice and an approved travel request form.
3. Finance review SLA: The finance department completes review and disbursement within 5 business days after receiving complete valid receipts.
```

## Step 1: Create a Knowledge Base and Import Sample Data

1. Log in to the FastGPT console, navigate to "Knowledge Base", and click "New" in the upper right corner.
2. Set the knowledge base name to `Corporate Travel Policy`, select the recommended embedding model, and confirm.
3. Open the newly created knowledge base, click "New / Import → Text Dataset → Local Files", and upload your `travel-policy.txt` file.
4. Keep the default chunking strategy on the data parsing screen, then click "Next".
5. In the data preview screen, verify that the submission deadlines and receipt requirements remain intact within the chunks, then click "Start Import".
6. Wait until the index status displays "Ready".

![Create travel policy knowledge base and choose available model](/imgs/current/knowledge-create.png)

## Step 2: Create a Chat Agent and Attach the Knowledge Base

1. Click "Application" in the navigation bar, then click "Create Application" in the upper right corner.
2. Select "Chat Agent" as the application type, enter `Travel Assistant` as the name, and click "Create".
3. In the application settings panel, pick an available chat model.
4. In the "Knowledge Base" section, click add and select the `Corporate Travel Policy` knowledge base created earlier.
5. In the system prompt area, enter the operational instructions:

```text
You are a corporate travel expense assistant. Answer questions based on the referenced travel policy.
State explicit deadlines and required documents clearly with references.
When a requested item is not mentioned in the policy, state that the current documentation contains no record.
```

## Step 3: Test Responses in Workspace

In the right-hand testing chat drawer, submit a test query:

```text
How many days do I have to submit my travel expenses after returning? What documents are required?
```

Inspect the response. The assistant clearly identifies the "15 calendar days" deadline, lists invoices and approved request forms, and provides citations linked to the original knowledge chunk.

![Knowledge Q&A assistant answers query with grounded citations](/imgs/current/knowledge-answer.png)

## Step 4: Publish a Public Share Link

1. Click the "Publish" button in the top right corner to freeze the active version.
2. Open the "Publishing Channels" tab at the top and select "Public Share Link".
3. Enable the share link and copy the generated URL.
4. Open the link in a separate browser tab to verify the standalone user experience.

![Publish share link for end users](/imgs/current/app-publish.png)
