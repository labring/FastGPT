---
title: 核心概念
description: 理解应用、知识对象、工具、Skill、发布与权限的关系。
---

| 对象 | 职责与关系 |
| --- | --- |
| 应用 | 通过对话 Agent、对话 Agent V2 或工作流创建面向用户的体验 |
| Agent 节点 | 工作流中负责自主规划与工具调用的步骤 |
| 知识库 | 管理供检索使用的资料，包含集合 |
| 集合 | 内容集合保存数据块；文件夹集合组织其他集合 |
| 数据块与检索索引 | 数据块保存可维护的知识内容；索引提供可搜索的表示 |
| 工具 | 输入输出明确的可调用操作，工具集将相关操作归组 |
| 工作流工具 | 可独立运行，也可被其他应用调用的流程 |
| Skill | 将一组或多组指令与支持文件统一管理、版本化并发布的资源 |
| MCP 工具 / MCP 服务 | 前者把外部能力接入 FastGPT；后者把 FastGPT 能力提供给外部客户端 |
| 发布版本 / 发布渠道 | 前者确定运行配置；后者确定用户或系统的访问方式 |

团队角色决定团队层面的管理能力；资源协作者权限决定具体应用、知识库等资源的操作范围；平台 root 管理部署级配置。版本、授权、套餐、配置、权限和模型能力分别影响功能可用性。
