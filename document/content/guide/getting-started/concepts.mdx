FastGPT 构建于清晰的领域模型之上。理解应用、知识资产、扩展工具与运行权限之间的协作关系，有助于构建稳定可维护的企业级 AI 系统。

## 系统全景拓扑

FastGPT 将各类实体划分为配置态、运行态与持久化存储层：

| 层次 | 核心职责 | 包含实体 |
| --- | --- | --- |
| 配置态 | 供开发者编排与维护的业务逻辑资产 | 应用草稿、知识库集合、技能代码包、工具参数、环境变量 |
| 运行态 | 承载用户请求执行与状态流转的调度引擎 | 会话轮次、执行快照、沙箱环境、MCP 连接、任务队列 |
| 存储层 | 提供数据持久化与高维检索能力的基础设施 | MongoDB 业务库、向量数据库、全文索引引擎、S3 对象存储、Redis 缓存与消息队列 |

## 应用实体体系

在 FastGPT 中，**应用（Application）** 是面向最终用户或外部系统交付体验的完整逻辑单元。

### 应用形态分类

- **对话 Agent（Chat Agent）**：围绕单一对话模型构建的线性问答助手，依托系统指令、上下文记忆与关联知识库直接响应用户提问。
- **对话 Agent V2（Chat Agent V2）**：具备动态规划与自主工具调用能力的高阶智能体，基于 ReAct 循环评估任务目标、选择工具集并完成复杂推理。
- **工作流（Workflow）**：在可视化画布上通过节点与有向连线编排的确定性处理管道，掌控数据转换、条件分支与批处理逻辑。

### 版本生命周期与快照

- **草稿版本**：开发者在工作台进行编辑、测试的即时配置。系统支持自动保存与手动保存草稿记录。
- **发布版本（Published Version）**：经过测试验证并明确发布的配置基线。发布操作同时更新应用的“正式版本指针”，并将所引用的模型、知识库与工具生成一份只读的**资源授权快照**。
- **发布渠道（Publishing Channel）**：对外暴露应用能力的访问通路，包括免登录分享链接、嵌入式聊天挂件、OpenAPI 密钥与 MCP 服务入口。

## 知识资产体系

**知识库（Knowledge Base）** 是经由统一处理链路结构化组织的信息资产库，为应用提供检索增强生成（RAG）的事实依据。

### 三层资产拓扑

1. **知识库**：顶层管理单元，定义了全局适用的向量模型、全文检索策略与团队协作权限。
2. **集合（Collection）**：知识库内部的组织单元。**内容集合**负责承载具体文件、网页或数据表；**目录集合**负责组织与嵌套其他子集合。
3. **数据块（Data Chunk）**：经由切分与格式化后独立维护的最小知识单元。每个数据块关联一个或多个检索索引。

### 双引擎索引机制

知识库支持向量检索与全文检索双重索引：
- **向量索引（Embedding Index）**：通过向量模型提取语义特征，擅长处理同义表达与意图匹配。
- **全文索引（Full-Text Index）**：基于分词与 BM25 算法进行精确词项匹配，保障专有名词与编号的高精度召回。
- **重排器（Rerank）**：多路召回后对候选数据块进行统一相关性二次打分，输出最贴近问题的精选上下文。

## 扩展能力与工具生态

FastGPT 通过模块化机制连接外部系统与代码能力：

- **工具（Tool）**：输入与输出契约明确的单一可调用函数。相关操作由**工具集（Tool Set）**进行连接配置与统一鉴权。
- **工作流工具（Workflow Tool）**：带有明确入参和出参定义的完整工作流，既支持在画布中独立触发，也支持挂载至 Agent 成为子任务执行单元。
- **技能（Skill）**：包含指令、模板与支持文件的独立版本化能力包，在代码执行沙箱中加载并向 Agent 提供专项执行能力。
- **MCP 工具（MCP Tool）**：通过 Model Context Protocol 协议由外部服务向 FastGPT 暴露的扩展能力。
- **MCP 服务（MCP Service）**：FastGPT 将自身的应用与知识库作为工具端点，向外部客户端暴露的协议服务。

## 权限与安全上下文

系统在组织与资源两个维度实行严格的访问控制：

- **团队管理（Team Management）**：划分租户隔离边界。团队成员分配拥有者、管理员或普通成员角色。
- **资源协作者权限（ACL）**：细粒度控制特定应用、知识库的权限等级，划分为查看、编辑和管理权限。
- **平台运营管理（Platform Administration）**：由平台 Root 管理员维护全局模型目录、租户额度配额与基础设施状态。
- **身份代理（Identity Proxy）**：外部集成或发布渠道代表团队内指定活跃成员发起请求的授权模式，根据该成员的个人权限解析会话数据。
