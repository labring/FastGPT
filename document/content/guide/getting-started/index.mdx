## 面向不同角色的专用入口

- [开发者入口](/zh-CN/developers)：完成 API 集成，或进入[插件开发专题](/zh-CN/plugin/intro)学习工具、模型预设、调试与发布。
- [部署与运维入口](/zh-CN/self-host)：选择 Docker 或 Sealos 安装方案、配置向量库与模型、掌握系统监控与版本升级。
- [知识库全生命周期](/zh-CN/guide/dataset/lifecycle)：深入学习数据切片、索引维护、增量同步与标签管理。
- [扩展与工具生态](/zh-CN/guide/build/tools/overview)：学习接入 HTTP 工具、系统插件、代码沙箱与 MCP 协议服务。
