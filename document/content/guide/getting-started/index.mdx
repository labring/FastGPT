FastGPT 将模型、知识库、工具和可视化工作流连接成可供用户访问的 AI 应用。

## 从一次成功的问答开始

[**创建首个知识库问答 →**](/zh-CN/guide/getting-started/knowledge-qa)

准备一份简短资料，导入知识库，关联对话 Agent，测试答案并发布修改。教程提供可直接复制的示例资料和验收问题。

<Cards>
  <Card title="选择应用类型" href="/zh-CN/guide/getting-started/application-types">按任务选择对话 Agent、对话 Agent V2 或工作流。</Card>
  <Card title="创建首个工作流" href="/zh-CN/guide/getting-started/first-workflow">连接输入、模型与输出，观察一次完整执行。</Card>
  <Card title="创建首个 Agent 任务" href="/zh-CN/guide/getting-started/first-agent">让 Agent 根据问题检索资料并完成任务。</Card>
</Cards>
