本指南提供构建高准确度知识库问答应用的标准化实操方案，帮助你在业务中实现具备可靠引用来源的企业级问答助手。

## 目标场景与前置准备

本指南解决的核心问题：将结构化或非结构化规章文档转化为能够精准回答业务咨询、严格遵循原文事实并标注明确依据的问答系统。

开始前，确认满足以下条件：
- 拥有当前团队的知识库创建、应用管理与发布权限。
- 当前环境已配置可用的向量检索模型与对话模型（参考[模型配置](/zh-CN/self-host/config/model/intro)）。
- 本地准备一份格式规范的文本资料，例如保存如下内容的 UTF-8 文件 `travel-policy.txt`：

```text
FastGPT 示例企业差旅制度
1. 报销提交时限：员工必须在出差行程结束返程后的 15 个自然日内提交报销申请。
2. 必备报销凭证：每笔申请必须附带增值税普通发票或专用发票，以及已审批通过的差旅审批单。
3. 财务审核周期：财务部门在收齐全部合规凭据后的 5 个工作日内完成审核与款项发放。
```

![创建差旅制度知识库并选择当前环境可用的模型](/imgs/optimized/current/knowledge-create.png.webp)

## 步骤一：创建知识库与数据切分

1. 进入“知识库”控制台，点击“新建”，输入名称 `企业差旅制度`，选择当前团队配置的向量模型。
2. 进入知识库，点击“新建/导入 → 文本数据集 → 本地文件”，上传 `travel-policy.txt`。
3. **切片策略配置**：
   - 制度类条款文本：从默认分块参数开始，在预览中核对条款完整性，再调整切分边界。
   - 常见问答类文本：推荐选用 QA 问答拆分模式，系统会自动将文档转换为一问一答对以提高语义匹配率。
4. 在数据预览界面中点击左侧文件条目，核对关键时限与凭证要求是否完整保留在单个数据块内。确认无误后点击“开始导入”。

![导入前预览文本分块保持核心语义完整](/imgs/optimized/current/knowledge-preview.png.webp)

## 步骤二：验证检索召回与重排效果

在将知识库关联至应用前，通过独立的检索测试验证召回质量：
1. 点击知识库顶部的“搜索测试”标签页。
2. 在测试输入框中输入典型查询：“出差回来后必须在几天内完成报销？”。
3. 观察返回的数据块列表及其相似度得分。
4. 验证相似度最高的候选块包含 `15 个自然日`。若存在重排模型（Rerank），同时核对重排后的得分分布，确认高相关分块排在首位。

![搜索测试命中包含 15 个自然日报销期限的原文](/imgs/optimized/current/knowledge-search.png.webp)

## 步骤三：创建对话 Agent 并绑定提示词约束

1. 进入“应用”控制台，创建应用并选择“对话 Agent”，命名为 `差旅制度问答助手`。
2. 关联模型选择当前团队可用的对话模型。
3. 在“知识库”配置区，挂载刚才完成验证的 `企业差旅制度`。
4. 编写注重事实约束的系统提示词：

```text
你是一个专业的差旅报销制度问答助手。
请仅根据下方检索到的参考文档回答用户提问。

回答规则：
1. 直接陈述制度明确规定的时限、流程与必需凭证。
2. 答案末尾必须标注依据来源。
3. 对于参考文档中未记录的信息，直接回复“当前差旅制度中未收录相关规定”，提示用户联系人力资源或财务部门核实。
```

![选择对话 Agent 并填写差旅制度问答](/imgs/optimized/current/app-create.png.webp)

## 步骤四：工作区即时调试与极端情况验证

在右侧工作区调试面板中开展两类测试：
1. **基准事实测试**：输入“报销需要提供哪些材料？”，核对回答是否准确列出发票与已审批差旅申请单，并检查引用条目。
2. **知识外溢测试**：输入“员工差旅的酒店住宿补贴标准是多少？”，确认模型如实说明制度未记录相关标准，避免自由推演。

![调试回答给出期限、材料和资料引用](/imgs/optimized/current/knowledge-answer.png.webp)

## 步骤五：配置引用透明度与发布

1. 点击工作台右上角“保存”并确认发布正式版本。
2. 进入应用的“发布渠道”选项卡，添加“免登录分享链接”。
3. 在渠道配置中开启“显示引用片段”开关。用户在最终使用时，能够点击回答底部的引用标签展开查看知识库中的对应原文。
4. 复制分享链接并在外部浏览器中完成最终验证。

![发布后的分享窗口返回 15 个自然日期限与必需材料](/imgs/optimized/current/knowledge-published.png.webp)

## 质量验收清单

- [ ] 知识库集合构建成功，向量索引处于可用状态。
- [ ] 搜索测试能够稳定命中目标分块且置信度得分达标。
- [ ] 助手准确回复已有事实，对未收录内容做出明确说明。
- [ ] 外部发布链接能够正常展开引用片段并核对原文。
