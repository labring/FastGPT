## 案例二：知识库 + 对话 Agent—民法典问答助手

### 2.1 适用场景

知识库适合“回答必须基于资料”的场景，例如制度问答、产品手册问答、法律条文检索、客服知识支持等。没有知识库时，AI 主要依赖模型自身能力回答；接入知识库后，AI 会先检索你的资料，再基于检索结果组织答案。

本案例将《中华人民共和国民法典》导入知识库，并创建一个民法典问答助手。用户用自然语言提问时，助手需要优先引用民法典原文，减少凭空生成。

可以把知识库理解为给 AI 配置的“资料室”。模型本身具备通用知识，但不了解你的公司制度、产品细节、内部流程或指定法规版本；知识库把这些资料变成可检索内容，让 AI 在回答前先查资料，再组织答案。对于法律、制度、客服、售后等场景，这比单纯依赖模型记忆更可控。

### 2.2 准备内容

- 示例文件：[civil-code-lease.txt](/examples/civil-code-lease.txt)，摘录第三编合同、第十四章租赁合同的第725至728条。版本为2020年5月28日通过、2021年1月1日起施行的民法典，来源为[最高人民法院转载全文](https://www.court.gov.cn/zixun/xiangqing/233181.html)。本样本用于演示检索；正式使用时核对现行法律及相关解释。
- 一个可用的对话模型和向量模型。
- 一个用于测试的法律问题，例如“租房合同没到期，房东要卖房，我该怎么办？”。

### 2.3 配置步骤

1. **创建知识库**

   在左侧导航栏点击 **知识库**，点击右上角 **新建**，在下拉菜单中选择 **通用知识库**。知识库名称填写为 `民法典租赁条文`，选择当前团队可用的索引模型和文本理解模型，点击 **创建** 完成创建。

   ![创建通用知识库并选择索引模型与文本理解模型](/imgs/optimized/current/knowledge-create.png.webp)

2. **创建文本数据集**

   点击“新建/导入”，再选择“文本数据集”，用于导入本地文档。

3. **上传本地文件**

   选择“本地文件”后确认，点击上传区域，选择示例文件。实际使用时可以同时上传多个文件，本案例只上传一个文件作为演示。

4. **设置解析参数**

   进入参数设置页后，根据文件类型选择解析方式。

   常用配置建议：
   - **文件解析设置**：上传 PDF 时建议开启；普通 Word、Markdown、TXT 等文件可先使用默认配置。
   - **处理方式**：大多数场景选择分块存储，成本较低，检索速度也更快。
   - **分块处理参数**：控制分块方式（默认或自定义按段落、按长度、按指定分割符分块）与分块大小，快速测试时使用默认值即可。
   - **索引增强**：先保留当前界面默认值。根据实际检索效果再按需开启“将标题加入索引”“自动生成补充索引”或“图片自动索引”等选项，并核对所需模型与额度。

   这些参数会直接影响后续问答质量。分块过大时，检索结果可能包含太多无关内容，回答容易变得冗长；分块过小时，关键上下文可能被拆散，回答容易缺少依据。快速上手阶段可以先使用默认配置，正式接入企业制度、合同、产品手册时，再根据问答效果逐步调整。

5. **预览分块效果**

   到数据预览步骤后，检查分块是否完整、可读。如果分块过长或过短，再返回调整参数。

   预览分块时重点看三点：段落是否被异常截断，标题与正文是否保留在同一语义范围内，表格、条款或编号是否仍然可读。只要这里的知识片段质量不稳定，后续应用即使 Prompt 写得很好，也很难稳定给出准确答案。

   ![租赁条文样本的来源、版本与分块预览](/imgs/optimized/current/civil-code-preview.png.webp)

6. **等待知识库就绪**

   当数据状态变为“已就绪”后，知识库即可被应用引用。

7. **创建并关联对话 Agent**

   进入 **工作台 → Agents**，点击列表首个 **新建** 卡片（空列表时点击页面中央的 **创建你的第一个 Agent**），选择 **对话 Agent**，在名称框中填写 `民法典问答助手`，点击名称框右侧的 **创建**。创建完成后，在左侧 **知识库** 区域点击 **+ 选择**，关联刚刚创建的知识库。

   关联知识库后，应用的回答链路会从单纯对话变成“用户问题 → 知识库检索 → 模型总结回答”。这也是案例一和案例二的关键差异：案例一强调内容生成，案例二强调基于资料回答。

8. **配置问答 Prompt**

   民法典问答助手需要强调“基于知识库回答”和“引用原文”。在 **提示词** 输入框中填写与下方实测截图一致的规则：

   ```md
   基于知识库中《民法典》租赁条文回答。先给简短结论，再引用条号及关键原文，说明适用条件与例外。仅使用检索依据；资料不足时说明缺少的依据。最后提醒具体案件需结合合同与事实咨询专业律师。控制在300字内。
   ```

   法律问答类场景需要明确回答边界：提供基于检索资料的条文解释，并通过要求引用条号原文、说明资料缺口与添加咨询律师提醒，保证输出可追溯且符合知识问答规范。

9. **配置开场白**

   在配置页左侧展开 **对话开场白** 折叠区块，在开场白文本框中填写欢迎语：

   ```text
   你好！我是民法典问答助手 ⚖️

   我基于《中华人民共和国民法典》原文，帮你解答法律问题。

   ⚠️ 提示：我的回答仅供参考，具体法律问题建议咨询专业律师。
   ```

   接着在开场白文本框下方点击 **新增预设问题**，逐条录入以下示例问题：
   - `租房合同没到期，房东要卖房，我该怎么办？`
   - `网购商品收到后发现坏了，商家不给退，法律怎么规定？`
   - `楼上漏水把我家的天花板泡了，能索赔吗？`

   ![展开对话开场白区块配置欢迎语与预设问题（界面位置示意）](/imgs/optimized/current/welcome-config.png.webp)

10. **验证问答效果**

    提出一个民法典相关问题，检查回答是否包含简短结论、条号及关键原文、适用条件与例外，以及咨询专业律师提醒。

    验证时重点评估两项指标：法条格式的完整性，以及知识库引用的真实性。建议同时测试资料内问题、资料外问题和模糊问题：资料内问题应能引用原文，资料外问题应说明无法直接确认，模糊问题应主动提示需要补充事实。

### 样本验收

![民法典问答助手引用租赁条文回答售房问题](/imgs/optimized/current/civil-code-answer.png.webp)

输入“租房合同没到期，房东要卖房，我该怎么办？”。预期引用第725条说明所有权变动对租赁合同效力的影响，并按第726条说明优先购买权及例外；涉及通知与赔偿时核对第727、728条。资料外问题如“劳动合同试用期最长多久？”应说明当前租赁样本缺少依据。

### 2.4 业务价值

- **降低资料检索门槛**：把长篇法规、制度、手册转成自然语言问答入口，让业务人员不用先知道关键词或目录位置，也能快速找到相关内容。
- **提升回答可信度**：通过知识库检索和原文引用，让答案具备来源依据，减少模型凭经验编造或泛泛而谈的风险。
- **沉淀组织知识**：企业内部制度、产品 FAQ、售后 SOP、合同模板等资料可以持续进入知识库，形成可维护、可复用的知识资产。
- **适配高频支持场景**：法务、HR、行政、客服、交付团队都可以使用类似模式，把重复咨询转成自助问答，提高响应效率。
