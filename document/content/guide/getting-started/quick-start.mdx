本教程面向初次使用 FastGPT 的构建者，引导你在 5 分钟内完成一个具备依据的知识库问答助手，并生成对外可访问的分享链接。

## 学习目标与准备工作

完成本教程后，你将拥有一个能够准确回答企业差旅报销规则的在线助手，掌握“知识库导入 → Agent 关联 → 实时调试 → 发布生效”的完整工作流程。

在开始前，准备以下环境与素材：
- 拥有当前团队的资源创建权限。
- 团队内配置了可用的对话模型与向量模型（SaaS 版本默认已就绪；私有化部署参考[模型配置](/zh-CN/self-host/config/model/intro)）。
- 复制下方文本，保存为本地 UTF-8 编码的 `travel-policy.txt` 文件：

```text
FastGPT 示例企业差旅制度
1. 报销提交时限：员工必须在出差行程结束返程后的 15 个自然日内提交报销申请。
2. 必备报销凭证：每笔申请必须附带增值税普通发票或专用发票，以及已审批通过的差旅审批单。
3. 财务审核周期：财务部门在收齐全部合规凭据后的 5 个工作日内完成审核与款项发放。
```

## 第一步：创建知识库并导入示例数据

1. 登录 FastGPT，点击左侧导航栏的“知识库”，点击右上角“新建”，在下拉菜单中选择“通用知识库”。
2. 在“创建通用知识库”弹窗中，名称填写 `差旅制度`，保留默认的“索引模型”与“文本理解模型”，点击“创建”。
3. 进入新建的知识库，点击“新建/导入 → 文本数据集 → 本地文件”，在“选择文件”步骤上传保存好的 `travel-policy.txt`，等待上传进度达到 100% 后点击“下一步”。
4. 在“参数设置”步骤保留系统默认的数据处理方式设置，点击“下一步”。
5. 在“数据预览”步骤点击左侧文件列表中的 `travel-policy.txt`，在右侧“分块预览”中确认报销时限与凭证要求完整呈现在分块内，点击“下一步”。
6. 在“确认上传”步骤点击“开始上传”，等待数据集列表中的训练状态转为“已就绪”。

![创建差旅制度知识库并选择当前环境可用的模型](/imgs/optimized/current/knowledge-create.png.webp)

## 第二步：创建对话 Agent 并绑定知识库

1. 点击左侧导航栏的“工作台”。首次使用时点击页面中央的“创建你的第一个 Agent”（若工作台已有应用，点击列表首个“新建”卡片），进入“创建 Agent”页面。
2. 在“Agent 类型”中选择“对话 Agent”，在“图标 & 名称”中填写 `差旅制度问答`，点击“创建”。
3. 在“应用配置”面板的“AI 配置 → AI 模型”中，选择当前团队可用的对话模型（如截图中的 `qwen3.8-flash`）。
4. 在下方“知识库”区域点击右侧的“+ 选择”，勾选上一步创建的 `差旅制度` 知识库并确认。
5. 在“提示词”输入框中填写清晰的任务指令：

```text
你是一个专业的差旅报销助手。根据引用的差旅制度回答用户提问。
直接陈述规则明确的截止时间与必需文件，标明具体依据。
规则未提及的信息，直接说明当前制度暂无记录。
```

## 第三步：工作区即时调试

在右侧“调试预览”窗口底部的输入框中输入验证问题：

```text
出差回来后多久提交报销？需要准备哪些材料？
```

观察右侧回复。按中文示例文件操作时，AI 回复标出“15 个自然日内”提交，列出发票与已审批通过的差旅审批单，并在回答下方显示 `travel-policy.txt` 引用来源（下方截图基于英文版 `travel-policy.txt` 与英文提示词录制，回复显示为“15 个日历日内”与“已批准的出差申请单”）。

![知识问答助手引用差旅制度给出准确答案](/imgs/optimized/current/knowledge-answer.png.webp)

## 第四步：发布公开分享链接

1. 点击右上角的“保存”按钮，在下拉菜单中选择“保存并发布”；在“保存并发布”弹窗中填写版本名称（如 `差旅制度 v1`），点击“确认”。
2. 点击顶部的“发布渠道”标签页，在左侧渠道列表中选择“免登录窗口”。
3. 点击右上角的“创建新链接”，填写链接名称（可按需开启“查看引用片段”），点击“确认”，系统会自动复制生成的分享地址。
4. 在浏览器新标签页打开该链接，即可作为最终访客与问答助手进行独立对话。

![发布分享链接以便最终用户访问](/imgs/optimized/current/app-publish.png.webp)
