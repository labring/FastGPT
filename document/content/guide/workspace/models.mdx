---
title: 查看和选择团队可用模型
description: 根据任务能力、可用范围与计费信息选择模型，并定位配置入口。
---

进入“账号 → 模型服务”（`/account/model`），可查看当前团队可用的全部模型目录、筛选模型类型与供应商、核对阶梯计费标准，并在开启团队模型管理时配置专属渠道。

## 按任务选择

- 对话和摘要选择语言模型；工具调用、视觉和推理能力按模型标签及配置核对。
- 知识库索引选择向量模型；检索重排需要已配置的重排模型。
- 在应用中使用模型前确认当前成员可用范围与额度，先运行一个小样本。

| 模型分类 | 用途与挂载位置 | 关键核对属性 |
| --- | --- | --- |
| **语言模型（LLM）** | 对话 Agent、Agent V2、工作流 AI 对话/问题分类/内容提取/问题优化 | 最大上下文窗口、最大输出 Token、Function Calling 支持、视觉/音频多模态标签、推理（Reasoning）支持 |
| **向量模型（Embedding）** | 知识库新建时的向量索引构建与语义检索 | 向量维度、分块 Token 上限、单价（新建知识库后向量模型固定） |
| **重排模型（Rerank）** | 知识库检索二次相关性精排 | 上下文长度限制与每千 Token 计费点数 |
| **语音模型（STT / TTS）** | 对话语音输入转文字与回答语音合成播报 | 支持语种与音色列表 |

目录中的显示名称、模型实例标识和供应商模型名称具有各自用途。API 和配置文件按对应契约使用准确标识；价格和供应商支持情况以当前环境为准。

## 团队配置与平台配置

具有安装模型权限的成员可按当前界面提供的模板和渠道配置团队模型。平台系统模型管理由 root 执行。SaaS 账号可能只展示可用目录；自部署管理入口与配置见[模型配置方案](/zh-CN/self-host/config/model/intro)。

- **可用模型目录（`modelTab=active_model`）**：所有环境默认展示，支持按模型提供商（如 Qwen、DeepSeek、OpenAI、GLM、MiniMax 等）与模型类型组合筛选，悬停价格可查看输入/输出阶梯计费详情。
- **团队与平台模型管理（需开启 `feConfigs.enable_team_model` 或在自部署 `/admin/resources/model`）**：额外提供**模型配置**（`config`）、**模型渠道**（`channel`）、**调用日志**（`channel_log`）与**提供商健康监控**（`account_model`）标签页，用于配置 OneAPI / AIProxy 渠道优先级、测试连通性与 Webhook 告警。

模型在目录可见但请求失败时，检查应用所选实例、成员权限、渠道凭证、提供商服务状态和额度。更新配置后先测试，再验证关联应用。
