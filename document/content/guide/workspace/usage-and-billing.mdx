在“账号”中心，团队成员可以查看 AI 积分消耗并维护个人资料、通知与偏好设置；团队所有者与团队管理员可管理套餐与资源包，并在开启支付功能时通过**账号 → 账单与发票**查看订单与申请增值税发票。

## 一、使用详情与仪表盘

进入**账号 → 使用记录**，支持在**使用详情**与**仪表盘**两个标签页之间切换，并可点击右上角**套餐使用情况**查看当前套餐配额：

### 1. 使用详情

- **多维过滤**：按团队成员、使用来源（在线使用、API、免登录链接、数据训练、定时任务、飞书、公众号、分享链接、企业微信、微信个人号、钉钉、PDF 解析、MCP 调用、应用评测等）、具体项目名称及起止日期筛选。
- **账单字段**：逐笔展示操作时间、执行成员、触发来源、关联应用或知识库名称、消耗 AI 积分数量，并可展开查看底层模型输入/输出 Token 数与单价。
- **导出核对**：支持将筛选范围内的消费记录导出为 CSV 文件，用于部门内成本分摊与财务对账。

### 2. 仪表盘

- 支持按日期范围与团队成员筛选，汇总展示区间内的总消耗积分与按日总积分消耗趋势折线图。

## 二、套餐订阅与额外资源包

在**账号 → 个人信息**的团队套餐卡片或**账号 → 使用记录**右上角点击**套餐使用情况**（点击升级/续费可打开套餐订阅页），可查看当前团队生效的标准套餐等级及资源配额：

| 资源类别 | 包含内容 | 扩容与生效规则 |
| --- | --- | --- |
| **标准订阅套餐（月付 / 年付）** | 团队成员上限、应用数量上限、知识库容量（数据集组数）、每周期赠送 AI 积分、虚拟机沙箱与并发配额 | 升级套餐立即生效并按周期计费；具体档位额度以当前环境套餐页面公示为准 |
| **额外 AI 积分包** | 独立购买的补充 AI 算力积分 | AI 积分优先扣除最先过期的资源包，支持自定义购买份数与有效期 |
| **额外知识库索引包** | 独立扩容的知识库向量索引组数上限 | 用于大规模文档入库场景，在有效期内叠加至团队总索引容量 |

页面底部提供 **AI 积分计算标准** 检索表，支持按模型类型（语言模型、向量模型、重排模型、语音模型、PDF 增强解析）查询每百万 Token（M Tokens）折算的积分单价。

## 三、账单记录与发票管理

团队所有者与具备管理员权限的成员可进入**账号 → 账单与发票**（需环境已开启支付功能），通过三个子标签管理财务凭证：

1. **账单记录**：查看所有订阅订单与资源包充值记录、支付状态、实付金额与生效周期。
2. **账单发票**：查看已申请的发票记录与进度；点击右上角**开票**按钮，可勾选已完成支付的有效账单提交电子发票申请。
3. **默认抬头**：预先维护企业增值税普通发票或专用发票抬头（单位名称、纳税人识别号、开户行及账号、注册地址与电话、接收邮箱），供开票时一键复用。

## 四、个人资料、安全与偏好设置

| 页面入口 | 核心能力 |
| --- | --- |
| **账号 → 个人信息** | 修改头像、昵称、绑定手机/邮箱、修改密码、查看团队套餐使用情况、使用**兑换码**，以及执行**注销账号**流程 |
| **账号 → 团队管理** | 管理团队成员、部门组织、成员组与团队权限配置（商业版与云服务版显示） |
| **账号 → 使用记录** | 查看团队 AI 积分消耗明细、仪表盘趋势并导出 CSV（商业版与云服务版显示） |
| **账号 → 自定义域名** | 配置企业专属自定义访问域名（商业版与云服务版开启 `customDomain` 时显示） |
| **账号 → 模型提供商** | 查看团队可用模型目录、计费标准及团队模型渠道（商业版与云服务版显示） |
| **账号 → API 密钥** | 创建、编辑、配置额度/过期时间与撤销团队级 OpenAPI 密钥（仅对具备“创建 API 密钥”团队权限的成员显示）；详见[通过 API 访问应用](/zh-CN/guide/build/publish/openapi) |
| **账号 → 通知** | 配置绑定通知接收方式，接收配额预警、账单到期与系统通知（商业版与云服务版显示） |
| **账号 → 语言与时区** | 切换界面显示语言（简体中文 / 繁体中文 / English(US) / 한국어）与默认业务时区 |

下一步：管理团队组织架构见 [团队、成员组与权限](/zh-CN/guide/workspace/team/team_roles_permissions)，或查阅 [可用模型目录](/zh-CN/guide/workspace/models)。
