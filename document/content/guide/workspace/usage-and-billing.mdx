在“账号”中心，团队拥有者与成员可以查看 AI 积分消耗、管理套餐与资源包、申请增值税发票，并维护个人资料、通知与偏好设置。

## 一、用量看板与使用明细

进入“账号 → 使用记录”，支持在**使用明细**与**用量看板**两个视图之间切换：

### 1. 使用明细

- **多维过滤**：按团队成员、使用来源（在线调试、门户对话、分享链接、API 调用、知识库索引、自动评测、MCP 调用）、具体项目名称及起止日期筛选。
- **账单字段**：逐笔展示操作时间、执行成员、触发来源、关联应用或知识库名称、消耗 AI 积分数量，并可展开查看底层模型输入/输出 Token 数与单价。
- **导出核对**：支持将筛选范围内的消费记录导出为 CSV 文件，用于部门内成本分摊与财务对账。

### 2. 用量看板

- 按日或按月聚合展示团队总积分消耗趋势、各应用消耗排行、模型调用分布与知识库索引消耗占比，帮助识别高消耗工作流或异常高频调用。

## 二、套餐订阅与额外资源包

进入“套餐与计费”页面，查看当前团队生效的标准套餐等级及资源配额：

| 资源类别 | 包含内容 | 扩容与生效规则 |
| --- | --- | --- |
| **标准订阅套餐（月付 / 年付）** | 团队成员上限、应用数量上限、知识库容量（数据集组数）、每周期赠送 AI 积分、虚拟机沙箱与并发配额 | 升级套餐立即生效并按周期计费；具体档位额度以当前环境套餐页面公示为准 |
| **额外 AI 积分包** | 独立购买的补充 AI 算力积分 | 当套餐内赠送积分耗尽时自动顺延抵扣，支持自定义购买份数与有效期 |
| **额外知识库索引包** | 独立扩容的知识库向量索引组数上限 | 用于大规模文档入库场景，在有效期内叠加至团队总索引容量 |

页面底部提供 **AI 积分计算标准** 检索表，支持按模型类型（语言模型、向量模型、重排模型、语音模型、PDF 增强解析）查询每千 Token 折算的积分单价。

## 三、账单记录与发票管理

进入“账号 → 账单与发票”，通过三个子标签管理财务凭证：

1. **账单记录**：查看所有订阅订单与资源包充值记录、支付状态、实付金额与生效周期。
2. **申请开票**：勾选一笔或多笔已完成支付的有效账单，提交电子发票申请，并在列表中跟踪开票进度与下载 PDF 发票。
3. **发票抬头管理**：预先维护企业增值税普通发票或专用发票抬头（单位名称、纳税人识别号、开户行及账号、注册地址与电话、接收邮箱），供开票时一键复用。

## 四、个人资料、安全与偏好设置

| 页面入口 | 核心能力 |
| --- | --- |
| **账号 → 个人信息** | 修改头像、成员显示名、绑定手机/邮箱、重置登录密码、提交企业实名认证、兑换优惠码与查看优惠券列表 |
| **账号 → API 密钥** | 创建、编辑、配置额度/过期时间与撤销成员级 OpenAPI 密钥；详见[通过 API 访问应用](/zh-CN/guide/build/publish/openapi) |
| **账号 → 通知中心** | 查看团队邀请、配额预警、账单到期与系统升级通知 |
| **账号 → 偏好设置** | 切换界面显示语言（简体中文 / 繁体中文 / English / 日本語）与默认业务时区 |
| **账号 → 第三方账号** | 管理个人绑定的第三方登录或外部服务授权 |
| **账号 → 账号注销** | 核对账号下属团队与资产状态后执行安全注销流程 |

下一步：管理团队组织架构见 [团队、成员组与权限](/zh-CN/guide/workspace/team/team_roles_permissions)，或查阅 [可用模型目录](/zh-CN/guide/workspace/models)。
