## 账号与团队问题

### 登录后找不到此前创建的应用或知识库，如何排查？

请按以下三步核对当前登录状态：

1. **核对当前所在团队**：点击左侧导航栏**账号 → 团队管理**，检查页面左上角“团队管理”标题旁的团队切换下拉框是否处于目标协作团队。若此前是通过邀请链接加入他人团队，需切换至对应团队空间查看资源。
2. **核对登录方式是否一致**：微信扫码登录与手机号验证码登录若未在“账号 → 个人信息”中完成绑定，系统会将其识别为两个独立账号。
3. **核对所访问的区域站点**：云服务各区域站点的账号与数据相互独立（详见[云服务站点说明](/zh-CN/guide/version/cloud/intro#访问入口与区域站点)），请确认当前访问域名与注册时一致。

### 如何邀请同事协作同一应用或知识库？

在多成员协作套餐（基础版、高级版或定制版）下，进入**账号 → 团队管理 → 成员**点击右上角**邀请成员**创建邀请链接，将同事邀请至同一团队空间，随后在团队权限页或单个应用/知识库的**协作者**弹窗中分配读写或管理权限（详见[成员、部门、群组与权限](/zh-CN/guide/workspace/team/team_roles_permissions)）。

## 套餐订阅与计费问题

### AI 积分是如何计算和扣减的？

云服务内置的大语言模型对话、向量索引生成、重排（Rerank）以及 PDF 增强解析均按实际消耗量折算为 **AI 积分** 扣减：

- **模型调用**：按各模型的输入与输出 Token 数量（以每百万 Token，即 `M Tokens` 为计价基准）乘以对应倍率计算。
- **扣减顺序**：AI 积分优先扣除最先过期的资源包（含额外 AI 积分包与当前周期套餐积分）。可在**账号 → 使用记录**中按团队成员、使用来源、项目名称与时间范围查阅明细。

### 套餐升级、降级或购买额外资源包后何时生效？

- **购买额外资源包**：支付成功后立即生效，可与当前周期套餐额度叠加使用，有效期以资源包订单页标注为准。
- **套餐升级与降级**：新购套餐等级高于当前套餐时立即生效；若新购套餐等级低于当前套餐，则继续使用当前套餐至本周期结束后切换。
- **套餐到期与免费版清理规则**：套餐到期未续费时自动转为免费版配额；免费版团队若连续 30 天未登录，系统将自动清理该团队的所有知识库内容，请及时续费或导出备份数据。

### 如何申请开具增值税发票？

在中国站完成套餐订阅或资源包充值后，团队所有者或团队管理员可进入左侧导航栏**账号 → 账单与发票**，在**默认抬头**标签页维护企业增值税发票抬头与收件邮箱，并在**账单发票**标签页点击右上角**开票**勾选已完成支付的订单提交申请（详见[使用记录与账单发票](/zh-CN/guide/workspace/usage-and-billing)）。

## 模型接入与数据安全

### 是否支持接入自己的模型

FastGPT 云服务默认提供官方统一模型。当环境开启团队模型功能且成员在**账号 → 团队管理 → 权限**中具备**安装模型**权限时，可在**账号 → 模型提供商**中配置团队专属模型与渠道，使用自有 API Key 调用模型免收平台 AI 积分（详见[模型提供商](/zh-CN/guide/workspace/models)）。

### 云服务中上传的知识库文档和对话数据是否会被用于模型训练？

租户上传的知识库文件、结构化分块数据以及应用对话日志均按团队租户严格隔离存储，仅用于当前团队授权的应用检索与对话响应，平台承诺绝不将租户私有业务数据用于任何基础大模型的训练或对外共享。对数据物理驻留有严格内网合规要求的企业，可选用 [FastGPT 商业版](/zh-CN/guide/version/commercial) 进行私有化自部署。
