## 账号与团队问题

### 登录后找不到此前创建的应用或知识库，如何排查？

请按以下三步核对当前登录状态：
1. **核对当前所在团队**：点击左侧导航栏“账号 → 团队管理”，检查右上角或团队切换器是否处于目标协作团队。若此前是通过邀请链接加入他人团队，需切换至对应团队空间查看资源。
2. **核对登录方式是否一致**：微信扫码登录与手机号验证码登录若未在“账号 → 个人信息”中完成绑定，系统会将其识别为两个独立账号。
3. **核对所访问的区域站点**：云服务各区域站点的账号与数据相互独立（详见[云服务站点说明](/zh-CN/guide/version/cloud/intro#访问入口与区域站点)），请确认当前访问域名与注册时一致。

### 如何将个人账号下的应用或知识库共享给团队成员？

订阅团队套餐（标准版及以上）后，进入“账号 → 团队管理”创建邀请链接，将成员邀请至同一团队空间，随后在团队或单个应用/知识库的“协作者”弹窗中分配读写或管理权限（详见[团队与权限管理](/zh-CN/guide/workspace/team/team_roles_permissions)）。

## 套餐订阅与计费问题

### AI 积分是如何计算和扣减的？

云服务内置的大语言模型对话、向量索引生成、重排（Rerank）以及 PDF 增强解析均按实际消耗量折算为 **AI 积分** 扣减：
- **模型调用**：按各模型的输入与输出 Token 数量（以每百万 Token，即 `M Tokens` 为计价基准）乘以对应倍率计算。
- **扣减顺序**：系统优先扣减即将到期的额外积分资源包，再扣减当前周期套餐内包含的积分额度。可在“账号 → 用量记录”中按应用、操作类型与时间范围查阅明细。

### 套餐升级、降级或购买额外资源包后何时生效？

- **购买额外资源包**：支付成功后立即生效，可与当前周期套餐额度叠加使用，有效期以资源包订单页标注为准。
- **套餐升级**：补齐差价或按新周期结算后立即解锁更高等级的应用数量、知识库容量与并发上限。
- **套餐到期未续费**：账号自动转为免费版配额。超出免费版上限的存量应用与知识库数据仍会保留一定缓冲期，期间可随时续费恢复完整调用或导出备份数据。

### 如何申请开具增值税发票？

在中国站完成套餐订阅或资源包充值后，依次进入左侧导航栏“账号 → 账单与发票”：
1. 在“发票抬头”中填写企业名称、纳税人识别号及收件邮箱。
2. 在“可开票订单”列表中勾选对应订单，选择增值税普通发票或专用发票并提交申请。电子发票开具完成后将发送至预留邮箱，也可在发票列表中直接下载（详见[用量看板、账单发票与套餐资源包](/zh-CN/guide/workspace/usage-and-billing)）。

## 模型接入与数据安全

### 是否支持接入自己的模型

FastGPT 云服务默认提供官方统一模型。当账号所在团队具备团队模型管理权限时，可在**账号 → 模型提供商**中配置团队专属模型与渠道，使用自有 API Key 调用模型时不消耗平台 AI 积分（详见[查看和选择团队可用模型](/zh-CN/guide/workspace/models)）。

### 云服务中上传的知识库文档和对话数据是否会被用于模型训练？

租户上传的知识库文件、结构化分块数据以及应用对话日志均按团队租户严格隔离存储，仅用于当前团队授权的应用检索与对话响应，平台承诺绝不将租户私有业务数据用于任何基础大模型的训练或对外共享。对数据物理驻留有严格内网合规要求的企业，可选用 [FastGPT 商业版](/zh-CN/guide/version/commercial) 进行私有化自部署。
