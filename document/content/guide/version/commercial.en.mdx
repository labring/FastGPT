## Overview

FastGPT Commercial Edition is an enterprise-grade release built on top of the open-source Community Edition, adding multi-tenant governance, granular role-based access control, third-party dataset synchronization, application evaluation, and a platform administration console. To enable Commercial Edition capabilities, deploy the `fastgpt-pro` container image alongside your Community Edition instance and configure the internal service URL and license key.

## FAQ

### How is delivery handled?

Full deployment = Community Edition image + Commercial Edition image

Upon subscription, we provide the Commercial Edition container image and a corresponding License key required to start the service.

### How does custom development work?

A full deployment runs the open-source Community Edition service together with the Commercial Edition image. Your engineering team can customize and build the open-source Community Edition frontend and backend code while communicating with the standard Commercial Edition service interfaces. Teams maintaining custom code forks are responsible for merging upstream changes during future version upgrades.
