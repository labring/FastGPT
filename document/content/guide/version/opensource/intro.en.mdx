FastGPT Community Edition is the free version of FastGPT, designed for individual developers and small delivery teams. It includes all core FastGPT features: Agent building, workflows, and datasets. Please use it in compliance with the [FastGPT Open Source License](/en/guide/version/opensource/license).

## Community Edition vs. Commercial Edition

| Capability | FastGPT Community Edition (Open Source) | FastGPT Commercial Edition (Enterprise Self-Hosted / Cloud) |
| --- | --- | --- |
| **Core Orchestration** | Full support for Chat Agent, Chat Agent V2, Visual Workflow, System Tools, HTTP/MCP Tools, and Agent Skills | Full support for all core orchestration capabilities |
| **Knowledge Base & RAG** | Local file, URL, and CSV template import; semantic, full-text, and hybrid search with Rerank | Adds Feishu/Yuque/DingTalk/API external datasets, collection-level permissions, and scheduled web sync |
| **Multi-Tenancy & IAM** | Single-team workspace | Multi-team mode, department hierarchy, member groups, granular role matrices, and enterprise SSO |
| **Publishing & Governance** | Share links, OpenAPI, and MCP service publishing | Adds share link QPM/point quotas, expiration dates, external auth webhooks, and custom domains |
| **Platform Administration** | Configuration files and model setup | Full [Root Platform Administration Console (`/admin/*`)](/en/guide/admin/platform-console), audit logs, billing plans, and custom branding |
