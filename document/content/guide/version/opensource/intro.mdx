FastGPT 社区版是 FastGPT 的免费版本，适合于个人开发者或小型交付团队使用。包含了 FastGPT 所有核心功能：Agent 构建、工作流、知识库，请在遵守 [FastGPT 开源协议](/zh-CN/guide/version/opensource/license)的前提下使用。

## 社区版与商业版核心能力对比

| 能力维度 | FastGPT 社区版（开源） | FastGPT 商业版（企业私有化 / 云服务） |
| --- | --- | --- |
| **核心编排能力** | 完整包含对话 Agent、对话 Agent V2、可视化工作流、系统工具、HTTP/MCP 工具与 Agent Skill | 完整包含全部核心编排能力 |
| **知识库与混合检索** | 支持本地文件、网页链接、CSV 模板导入，支持语义、全文与混合检索 + Rerank 重排 | 额外支持飞书/语雀/钉钉/API 第三方知识库、集合级独立权限与定时同步 |
| **多租户与组织治理** | 单团队管理模式 | 支持多团队模式、部门架构树、群组、细粒度角色权限矩阵与企业 SSO 单点登录 |
| **发布与安全管控** | 支持免登录分享链接、OpenAPI 与 MCP 服务发布 | 额外支持分享链接 QPM/积分限额、过期时间、第三方身份鉴权钩子与自定义域名 |
| **平台运营后台** | 通过配置文件与基础后台管理模型 | 提供完整 [Root 平台运营后台（`/admin/*`）](/zh-CN/guide/admin/platform-console)、全局审计、套餐计费与品牌定制 |
