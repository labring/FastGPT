## Features

- Can be added multiple times
- Has external inputs
- Trigger-based execution
- Manual configuration

![Features — interface example](/imgs/current/text-join-result.png)

## Function

Applies fixed text processing to inputs. Insert variable references in the text editing area to produce a string for downstream nodes.

The screenshot adds `测试文本拼接：` before the input and `结束。` on the following line. The example below uses `Question: ` to demonstrate the same variable substitution.

## Use Cases

Provide custom-formatted text to any node, or preprocess system prompts for AI nodes.

## Configuration and output

Write fixed text and use the editor's variable selector to insert upstream outputs or global variables. Execution returns **Concatenation result** as a string for AI Chat, HTTP, or Specified Reply. Let the editor generate node references so they identify the intended source.

## Example: prefix the input

1. Connect Start → Text Concatenation → Specified Reply.
2. Enter `Question: ` in the concatenation text, then insert the start node's user question with the variable selector.
3. Reference **Concatenation result** in Specified Reply.
4. Debug with `Hello` and expect `Question: Hello`.

For empty values or unresolved placeholders, inspect variable keys, upstream execution order, and input values. This node combines text from a template. Use [Code Run](/en/guide/build/workflow/nodes/sandbox-v2) for arithmetic or structured transformations.
