---
title: Agent 节点
description: 在工作流中配置自主规划、知识检索、工具与 Skill。
---

Agent 节点把需要自主规划的任务放入工作流。节点模板标记版本为 4.17.0；当前部署需要提供该节点、支持工具调用的模型，以及所选资源的使用权限。

当前 SaaS 采集界面的“添加节点 → Agent”用于选择已有应用。独立 Agent 节点的显示取决于部署提供的节点列表；使用前确认能选择该节点。需要先体验自主任务与 Skill 时，可按[首个 Agent 任务](/zh-CN/guide/getting-started/first-agent)创建对话 Agent V2。

## 输入与配置

| 配置 | 用途 |
| --- | --- |
| 模型与提示词 | 选择模型，规定任务目标、输出要求和工具使用边界 |
| 用户问题 | 引用开始节点或上游节点提供的任务 |
| 文件链接 | 传入当前任务可访问的文件 |
| 工具 | 选择可调用操作，确认参数与权限 |
| 知识库 | 选择可检索资料及检索参数 |
| Skill 与虚拟机 | 关联已发布的 Skill；执行环境需要服务配置及相应可用额度 |
| 回复文本 | 控制结果是否直接展示在对话中 |

## 输出与连接

主要输出为字符串类型的 AI 回复内容；错误输出供错误处理路径使用。将该输出引用到后续文本、分支或回复节点。执行连线负责运行顺序，值引用负责传递内容。

## 示例：制度检查

把开始节点连接到 Agent 节点，用户问题引用开始节点输入，关联差旅制度知识库。提示词要求检索制度并列出报销材料及期限。输入“生成出差报销清单”，检查返回的材料、期限和检索依据。示例资料及预期结果见[首个 Agent 任务](/zh-CN/guide/getting-started/first-agent)。

需要确定顺序的步骤放入工作流连线；节点内部的工具选择受模型规划影响。工具写操作应具有明确权限与确认流程。故障时检查执行详情、模型工具能力、资源权限和虚拟机状态。
