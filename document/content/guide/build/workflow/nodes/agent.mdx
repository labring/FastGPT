---
title: Agent 节点
description: 在工作流中配置自主规划、知识检索、工具与 Skill。
---

Agent 节点（`agent`）将基于 ReAct 循环的自主规划能力嵌入确定性工作流画布，让工作流在保持外层严格路由与控制的同时，将局部开放式子任务委托给具备工具、知识库、虚拟机沙箱与 Skill 的智能体执行。

当前 SaaS 采集界面的“添加节点 → Agent”用于选择已有应用。独立 Agent 节点的显示取决于部署提供的节点列表；使用前确认能选择该节点。需要先体验自主任务与 Skill 时，可按[首个 Agent 任务](/zh-CN/guide/getting-started/first-agent)创建对话 Agent V2。

## 输入与配置

| 配置字段 | 内部 Key | 类型 | 用途与说明 |
| --- | --- | --- | --- |
| **AI 模型** | `model` | `String` | 选择支持工具调用的模型 |
| **提示词** | `systemPrompt` | `String` | 规定任务目标、输出格式与工具调用边界 |
| **用户问题** | `userChatInput` | `String` | 引用流程开始节点或上游节点生成的子任务指令 |
| **文件链接** | `fileUrlList` | `Array<string>` | 传入当前任务可访问的文档或图片 URL 列表 |
| **知识库** | `datasets` | `SelectDataset` | 绑定供 Agent 自主按需检索的知识库及检索参数 |
| **工具** | `selectedTools` | 工具列表 | 挂载系统工具、HTTP 工具、MCP 工具或工作流工具 |
| **Agent 技能与启用虚拟机** | `skills` / `useAgentSandbox` | Skill 列表 + `Boolean` | 挂载已发布的 [Agent Skill](/zh-CN/guide/build/skill/integration)，并在虚拟机沙箱中执行脚本与文件读写 |

## 输出与连接

| 输出端口 | 内部 Key | 数据类型 | 说明 |
| --- | --- | --- | --- |
| **AI 回复内容** | `answerText` | `String` | Agent 完成多轮思考与工具调用后生成的最终结论文本 |
| **错误信息** | `errorText` | `String` | 开启**报错捕获**后显示，当模型或沙箱执行失败时输出错误详情并触发异常分支 |

执行连线负责控制节点运行先后顺序，变量引用负责将 `answerText` 传递给下游判断器、文本拼接或指定回复节点。

## 示例：制度检查

1. 将**流程开始**节点连接到 **Agent 节点**，`用户问题` 引用开始节点的 `userChatInput`。
2. 在 Agent 节点中关联 `企业差旅制度` 知识库，提示词填写 `先检索差旅制度，再按提交期限、必备发票单据、财务审核周期三项输出核查清单。`。
3. 将 Agent 节点的 `AI 回复内容` 连接到下游结构化归档或指定回复节点。
4. 调试输入 `生成出差报销清单`，在运行详情中展开 Agent 节点的思考步骤，核对检索调用参数、返回的材料与期限依据。示例资料见[首个 Agent 任务](/zh-CN/guide/getting-started/first-agent)。

需要确定顺序的步骤放入工作流连线；节点内部的工具选择受模型规划影响。工具写操作应具有明确权限与确认流程。故障时检查执行详情、模型工具能力、资源权限和虚拟机状态。
