## Characteristics

- Can be added multiple times (keeps connections tidy in complex workflows)
- Has external input
- Has static configuration
- Trigger-based execution
- Core node

![](/imgs/flow-dataset1.png)

## Parameters

### Input - Linked Datasets

Select one or more Datasets using the **same embedding model** for vector search.

### Input - Search Parameters

[View parameter details](../../../dataset/dataset_engine.en.mdx#search-parameters)

### Output - Referenced Content

Outputs citations as an array with a possible length of 0. This means the output path will still run even when no results are found.
