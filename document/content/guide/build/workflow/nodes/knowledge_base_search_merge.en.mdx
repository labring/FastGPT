## What It Does

Merges search results from multiple Datasets into a single output, re-ranks them using RRF (Reciprocal Rank Fusion), and supports max token filtering.

## Usage

The AI Chat node can only accept one Dataset citation input. If you call multiple Datasets, you cannot directly cite all of them (as shown below).

![Multiple Dataset search results feeding a single AI Chat node](/imgs/knowledge_merge2.png)

Connect each Dataset search output to **Dataset search Merge**, then connect the merged citation output to the AI Chat node. Set the maximum token limit to control the amount of merged content.

![Merged Dataset citations connected to AI Chat](/imgs/knowledge_merge3.png)

## Example Use Cases

1. After question classification, search different Datasets per category, then feed the merged results to a single AI Chat node. This avoids adding a separate AI Chat node to each branch.
