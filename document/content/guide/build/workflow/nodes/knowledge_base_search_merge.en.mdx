## What It Does

Merges search results from multiple Datasets into a single output, re-ranks them using RRF (Reciprocal Rank Fusion), and supports max token filtering.

## Usage

AI Chat accepts a single citation list. Connect the outputs of multiple search nodes to **Dataset search Merge**, then pass the combined citations to AI Chat.

This verified example supplies two demonstration lists containing three entries, including one duplicate. The output contains two citations with RRF ranking scores:

## Example Use Cases

1. After question classification, search different Datasets per category, then feed the merged results to a single AI Chat node. This avoids adding a separate AI Chat node to each branch.
