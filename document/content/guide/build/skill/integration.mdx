## 前置条件

准备已发布的 Skill、资源使用权限、支持工具调用的模型和可用虚拟机服务。自部署需完成执行环境配置；SaaS 的授权、套餐与额度以当前账号界面为准。

## 如何在应用中绑定技能？

### 对话 Agent V2

进入应用编辑页，在左侧 **关联技能** 区域点击 **+ 选择**，勾选已经发布的技能并确认虚拟机配置。关联技能会自动启用所需虚拟机，并在关联期间保持虚拟机开启状态。设置清晰的任务指令，再保存并调试。

本例关联[开发教程](/zh-CN/guide/build/skill/development)中发布的“提取邮箱”技能（下方截图复用示例应用 `报销检查助手` 演示挂载效果）。在提示词中填写：

```text
当用户输入文本时，调用 extract-emails 技能的 Python 脚本提取所有邮箱地址，去重并按首次出现顺序逐行返回。
```

在右侧调试面板输入 `Contact alice@example.com and bob@example.org; CC alice@example.com`，预期得到 `alice@example.com`、`bob@example.org` 两个唯一邮箱。在已处理步骤中展开“虚拟机/执行命令”，核对脚本输入和返回结果。

### 在工作流中调用带技能的 Agent

在新建工作流中，先将技能绑定到如上创建的 **对话 Agent V2** 应用，随后在工作流画布左上角 **+** 节点面板切换到 **Agent** 标签页，添加该对话 Agent V2（应用调用节点）。对于已包含独立 **Agent 节点** 的存量旧工作流，可直接选中画布上的 Agent 节点，在节点内部的 **技能** 栏点击 **+ 选择** 关联已发布技能，并确认模型、用户问题和虚拟机配置。参考 [Agent 节点](/zh-CN/guide/build/workflow/nodes/agent)。

| 挂载载体 | 配置入口 | 虚拟机与运行范围 | 典型适用场景 |
| --- | --- | --- | --- |
| **对话 Agent V2** | 应用编辑页左侧 **关联技能** 区域 → 点击 **+ 选择** | 会话级沙箱（`sessions/<chatId>`），跨多轮对话保留工作区文件与已初始化的技能环境 | 开放式多轮表格分析、交互式报告生成、长周期代码与文件处理 |
| **工作流（应用调用 / 旧版 Agent 节点）** | 新流程：画布 **+** → **Agent** 标签页选择已绑定技能的对话 Agent V2；存量旧流程：选中 Agent 节点 → **技能** 栏点击 **+ 选择** | 随当前工作流会话拉起沙箱，接收上游节点传入的结构化变量与文件链接，输出执行文本供下游节点消费 | 在固定业务流水线中嵌入需要自主执行脚本或调用专属技能包能力的子步骤 |

## 智能体如何调用技能？

运行时将所选技能的发布内容准备到执行环境，Agent 根据任务与模型规划选择相关指令和工具。一个 Skill 资源可以包含一组或多组指令及支持文件，多个资源可以关联到同一 Agent。

用一个技能明确定义的输入进行调试，检查执行详情、虚拟机中的文件和最终结果。确认输出满足技能说明后，[发布应用修改](/zh-CN/guide/build/publish/versions)，并从新会话验证。

技能缺失时检查已发布版本与权限；环境启动或依赖安装失败时检查[初始化脚本](/zh-CN/guide/build/skill/initialization)与虚拟机日志。仅发布 Skill 和发布应用配置分别作用于各自资源，按修改对象完成发布。
