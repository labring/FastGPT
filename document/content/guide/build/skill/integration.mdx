## 前置条件

准备已发布的 Skill、资源使用权限、支持工具调用的模型和可用虚拟机服务。自部署需完成执行环境配置；SaaS 的授权、套餐与额度以当前账号界面为准。

## 如何在应用中绑定技能？

### 对话 Agent V2

进入应用编辑页，在“关联 Skill”中选择已经发布的技能，确认虚拟机配置。关联 Skill 会启用所需虚拟机；关联期间保留虚拟机能力。设置清晰的任务指令，再保存并调试。

本例关联[开发教程](/zh-CN/guide/build/skill/development)中发布的“提取邮箱”。提示词要求调用该 Skill 的 Python 脚本，输入 `Contact alice@example.com and bob@example.org; CC alice@example.com`。预期得到 `alice@example.com`、`bob@example.org` 两个唯一邮箱。在已处理步骤中展开“虚拟机/执行命令”，核对脚本输入和返回结果。

![已关联提取邮箱 Skill 的 Agent 返回去重邮箱](/imgs/current/skill-agent-result.png)

### 工作流 Agent 节点

进入工作流画布，添加或选中 Agent 节点，在节点的 Skill 配置中选择已发布技能，并确认模型、用户问题和虚拟机配置。把上游任务引用到节点输入，再检查节点输出。参考 [Agent 节点](/zh-CN/guide/build/workflow/nodes/agent)。

## 智能体如何调用技能？

运行时将所选技能的发布内容准备到执行环境，Agent 根据任务与模型规划选择相关指令和工具。一个 Skill 资源可以包含一组或多组指令及支持文件，多个资源可以关联到同一 Agent。

用一个技能明确定义的输入进行调试，检查执行详情、虚拟机中的文件和最终结果。确认输出满足技能说明后，[发布应用修改](/zh-CN/guide/build/publish/versions)，并从新会话验证。

技能缺失时检查已发布版本与权限；环境启动或依赖安装失败时检查[初始化脚本](/zh-CN/guide/build/skill/initialization)与虚拟机日志。仅发布 Skill 和发布应用配置分别作用于各自资源，按修改对象完成发布。
