title: Template Marketplace, App Folders, and Batch Management
description: Create applications from templates and organize team applications with folders, batch actions, JSON import/export, and inherited permissions.

As your team scales its Chat Agents, Agent V2 apps, and Workflows, use the Template Marketplace to start from proven patterns and manage assets through folders, batch operations, and JSON configuration portability.

## Create Applications from the Template Marketplace

1. Click **Template Marketplace** in the left sidebar, or browse recommended templates on the **Applications** page.
2. Filter templates by category (such as customer support, document analysis, content creation, or productivity) or search by keyword.
3. Click a template card to review its architecture and prerequisites, then click **Use Template** to create an application instance in your current directory.
4. Open the created application, bind your team's active models, knowledge bases, and tool credentials, and run a test in the debug preview pane.

## Filter Applications and Organize Folders

1. **Filter and sort**: Go to **Studio → Agent**, where the upper-left corner displays the **Agent** heading. Filter by App type (Chat Agent, Chat Agent V2, Workflow), search by name, or change the sort order; the upper-right toolbar provides **Batch Manage**, **+ Folder**, and **Import**.
2. **Create folders**: Click **+ Folder** in the upper-right corner, enter a name and description, and choose whether to follow parent folder permissions to organize Apps by department, project, or lifecycle stage.
3. **Permission inheritance and parent owner boundary**: Collaborator roles (Can Use, Can Edit, Can Manage) assigned to a folder are inherited by child folders and resources inside it; a parent folder's Owner inherits **Can Manage (`manage`)** permission on child resources while each child resource retains its own single Owner.
4. **Ancestor path navigation**: When a member has access only to a descendant application, tool, skill, or dataset inside a folder hierarchy, ancestor folders appear as read-only navigation entries (hiding folder metadata and management menus and disabling drag-and-drop), allowing the member to follow breadcrumbs into the authorized subtree and search within it. See [Team Roles and Permissions](/en/guide/workspace/team/team_roles_permissions).

## Batch Move and Batch Delete

1. Click **Batch Management** in the top-right corner of the application list to enter multi-select mode.
2. Select one or more applications or folders.
3. **Batch move**: Click **Move** and choose the destination folder or root directory. Moved resources inherit the destination folder's collaborator permissions.
4. **Batch delete**: Click **Delete**, verify the listed resources in the confirmation dialog, and enter the confirmation phrase to submit. Deleting an application removes its conversation history, evaluation tasks, and share links; export critical configurations beforehand.

## Import and Export JSON Configurations

Workflows and Chat Agents (Simple Mode) support portable JSON DSL files for cross-environment migration, backup, and sharing:

1. **Export configuration**: Open the target Workflow or Chat Agent (Simple Mode) editor, click the menu beside the App name card in the upper-left corner (the dropdown arrow menu in Workflows or the **...** menu in Chat Agents), and select **Export** to download or copy the `.json` definition (sensitive credentials are excluded).
2. **Import configuration**: In a target Workflow or Chat Agent (Simple Mode) editor, open the menu beside the App name in the upper-left corner, select **Import**, paste the JSON text or upload a `.json` file, and click **Confirm** to update the current draft. You can also click **Import** in the upper-right corner of the **Studio → Agent** list page to create a new App from JSON.
3. **Post-import checklist**: After importing a configuration across teams or environments, re-select valid team models, knowledge bases, and tools before publishing.
