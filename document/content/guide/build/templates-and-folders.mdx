随着团队内对话 Agent、Agent V2 与工作流数量的增长，可以通过模板市场复用成熟编排方案，并利用文件夹、批量管理与配置导入导出维护应用目录。

## 从模板市场创建应用

1. 在工作台左侧导航点击“模板市场”（`/dashboard/templateMarket`），或在“应用”列表空状态卡片中浏览推荐模板。
2. 按场景分类（如智能客服、文档分析、内容创作、办公提效）筛选，或在右上角搜索框按关键词检索。
3. 点击模板卡片查看流程说明、适用场景与前置要求；点击**使用模板**即可在当前目录直接创建应用实例。
4. 进入新建的应用后，将各模型节点、知识库引用和工具凭证替换为本团队的可用资源，并在调试预览面板验证运行结果。

## 应用列表筛选与文件夹组织

1. **多维筛选与排序**：在“我的应用”（`/dashboard/agent`）顶部，支持按应用类型（对话 Agent、对话 Agent V2、工作流）、名称关键词及排序规则定位目标资源。
2. **新建文件夹**：点击右上角“新建文件夹”，输入名称与描述，并选择是否继承父级目录权限，按业务部门、项目阶段或环境（开发 / 预发 / 生产）建立多级目录。
3. **权限继承与父目录所有者边界**：在文件夹上配置的协作者角色（可使用、可编辑、可管理）会自动向子级文件夹及文件夹内的资源继承；父级目录所有者（Owner）在子资源上继承为**可管理（`manage`）**权限，每个子资源保留各自的唯一创建者（Owner）。
4. **祖先路径只读导航**：当成员仅拥有某个深层子应用、工具、技能或知识库的访问权限而未获授父文件夹权限时，列表会将沿途的父文件夹作为只读导航入口展示（隐藏文件夹简介与管理菜单，禁用拖拽），支持成员沿目录面包屑逐级进入被授权的子资源，同时可在当前子树范围内搜索。详细权限矩阵见 [团队与权限设置](/zh-CN/guide/workspace/team/team_roles_permissions)。

## 批量移动与批量删除

1. 在应用列表右上角点击**批量管理**，进入多选模式。
2. 勾选一个或多个应用及文件夹，底部或顶部操作栏会显示当前已选数量。
3. **批量移动**：点击“移动”，选择目标文件夹或根目录。移动后资源将自动继承目标文件夹的协作权限。
4. **批量删除**：点击“删除”，核对弹窗列出的待删除资源清单，按提示输入确认口令后提交。删除操作会同步移除该应用关联的历史对话记录、评测任务与分享链接，执行前请先导出重要配置。

## 应用配置 JSON 导入与导出

工作流与 Agent 支持通过 JSON DSL 文件进行跨环境迁移、备份与团队间共享：

1. **导出配置**：打开目标应用编辑器，点击左上角应用名称旁的下拉菜单，选择**导出配置**，即可将当前画布节点、连线与参数保存为本地 `.json` 文件（自动剔除敏感密钥）。
2. **导入配置**：在目标工作流应用中打开左上角菜单，选择**导入配置**，上传本地 `.json` 文件或直接粘贴 JSON 文本，点击保存即可覆盖当前画布草稿。
3. **导入后核对**：导入跨团队或跨环境的 JSON 后，需重新绑定本团队可用的对话模型、知识库与工具集，再保存发布。

下一步：了解 [发布版本与发布渠道](/zh-CN/guide/build/publish/versions) 或配置 [团队角色与资源权限](/zh-CN/guide/workspace/team/team_roles_permissions)。
