对话门户是面向团队已登录成员的统一对话工作台，集中提供“新对话”“我的应用”“团队应用”“收藏应用”与历史会话管理能力。应用发布版本决定运行时的逻辑配置，门户可见度设置决定成员在对话界面可查看的运行详情与知识引用深度。

![门户中的运行状态与引用可见度设置](/imgs/optimized/current/portal-visibility.png.webp)

## 门户可见度配置项参考

| 配置开关 | 开启后成员可见内容 | 典型关闭场景 |
| --- | --- | --- |
| **显示运行状态** | 实时展示工作流节点执行进度、工具调用与 Agent 规划步骤卡片 | 仅需向业务人员呈现最终文字回答，隐藏底层编排拓扑 |
| **查看完整响应** | 允许展开消息底部的“完整响应”抽屉，查看每个节点的输入输出与耗时 | 内部节点包含中间提示词或辅助接口结构，无需向普通成员展示 |
| **显示引用片段** | 在回答末尾显示知识库引用角标与命中分块摘要 | 回答结果无需展示参考分块列表 |
| **可查看引用全文** | 允许点击引用卡片打开分块阅读器，浏览集合全文与命中高亮 | 允许核对引用片段，但限制浏览整篇源文档其余章节 |
| **可下载来源原文** | 在分块阅读器中提供原始上传文件（如 PDF、Word、表格）的签名下载入口 | 知识库文档属于受控内部资料，仅允许在线阅读禁止导出原件 |

## 配置与验证

1. 进入应用的“发布渠道 → 门户”，复制界面提供的跳转链接。
2. 按使用场景配置实时运行状态、完整响应、引用片段、引用全文及来源原文下载的可见范围。
3. 发布应用配置的修改后，使用具有应用权限的测试成员打开链接，开始新对话。
4. 核对答案以及该成员可见的运行和引用信息，确认与配置一致。

## 门户工作台导航与 URL 深链

- **左侧导航切换**：门户左侧栏支持在“最近对话”“我的应用”“团队应用”与“收藏夹”之间切换，成员可将高频使用的团队应用加入个人收藏。
- **URL 参数直达**：支持通过 `/chat?appId=<应用ID>` 直接打开指定应用对话，或携带 `pane` 参数直接定位到团队应用列表。
- **权限校验边界**：出现无权访问提示时，依次检查当前登录账号所属团队、应用的协作者读取权限（[团队权限](/zh-CN/guide/workspace/team/team_roles_permissions)）以及关联知识库的[集合级权限](/zh-CN/guide/dataset/collection_permission)。
