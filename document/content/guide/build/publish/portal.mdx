点击左侧主导航栏中的 **门户** 即可进入面向团队已登录成员的统一对话工作台，左侧栏提供 **首页**（商业版）、**全部应用** 与 **最近使用** 应用列表，并提供历史会话管理能力。应用发布版本决定运行时的逻辑配置（如文件上传能力直接复用应用自身在 AI 配置或系统配置中开启的 **文件上传** 设置），门户可见度设置决定成员在对话界面可查看的运行详情与知识引用深度。

![门户中的运行状态与引用可见度设置](/imgs/optimized/current/portal-visibility.png.webp)

## 门户可见度配置项参考

| 配置开关 | 开启后成员可见内容 | 典型关闭场景 |
| --- | --- | --- |
| **实时运行状态** | 实时展示工作流节点执行进度、工具调用与 Agent 规划步骤卡片 | 仅需向业务人员呈现最终文字回答，隐藏底层编排拓扑 |
| **显示完整响应** | 允许点击消息底部的 **运行详情**，查看每个节点的详细响应流程、输入输出与耗时 | 内部节点包含中间提示词或辅助接口结构，无需向普通成员展示 |
| **查看引用片段** | 在回答末尾显示知识库引用角标与命中分块摘要 | 回答结果无需展示参考分块列表 |
| **查看引用全文** | 允许点击引用卡片打开阅读器，查看引用内容所属的完整文件正文与命中高亮 | 允许核对引用片段，同时控制整篇源文档其余章节的浏览范围 |
| **下载/打开来源原文** | 在阅读器中提供原始上传文件（如 PDF、Word、表格）的下载入口或来源网站跳转 | 知识库文档属于受控内部资料，仅限在线阅读 |

## 配置与验证

1. 进入应用的“发布渠道 → 门户”，复制界面提供的跳转链接。
2. 按使用场景配置 **实时运行状态**、**显示完整响应**、**查看引用片段**、**查看引用全文** 及 **下载/打开来源原文** 的可见范围。
3. 发布应用配置的修改后，使用具有应用权限的测试成员打开链接，开始新对话。
4. 核对答案以及该成员可见的运行和引用信息，确认与配置一致。

## 门户工作台导航与 URL 深链

- **左侧导航切换**：门户左侧栏包含 **首页**（商业版）、**全部应用** 与 **最近使用** 列表；**全部应用** 内分 **精选应用** 与 **团队应用** 两个标签页。
- **URL 参数直达**：支持通过 `/chat?appId=<应用ID>` 直接打开指定应用对话，或携带 `pane` 参数定位侧栏页面：`h` 为首页（商业版）、`aa` 为全部应用、`ra` 为最近使用、`s` 为设置。
- **权限校验边界**：出现无权访问提示时，依次检查当前登录账号所属团队、应用的协作者读取权限（[团队权限](/zh-CN/guide/workspace/team/team_roles_permissions)）以及关联知识库的[集合级权限](/zh-CN/guide/dataset/collection_permission)。
