The conversation portal is the unified workspace for signed-in team members, bringing together New Conversation, My Applications, Team Applications, Favorites, and conversation history. The published application version governs runtime logic, while portal visibility settings control how much execution detail and source citation depth members can inspect.

![Portal visibility controls](/imgs/optimized/current/portal-visibility.png.webp)

## Portal Visibility Settings Reference

| Visibility Toggle | Visible to Signed-In Members When Enabled | When to Disable |
| --- | --- | --- |
| **Show running status** | Live node progress, tool invocations, and Agent plan cards during generation | Present only the final response text without exposing workflow steps |
| **View full response** | Access to the **Full Response** drawer showing per-node inputs, outputs, and latency | Hide intermediate prompts and internal node payloads from ordinary users |
| **Show citation excerpts** | Citation badges and matched chunk snippets below the answer | Deliver answers without displaying retrieved chunk cards |
| **View full citation text** | Access to the chunk reader showing the full collection text with highlighted matches | Allow snippet verification while restricting access to surrounding document sections |
| **Download source document** | Signed download link for the original uploaded file (such as PDF, DOCX, or XLSX) | Keep confidential source files view-only online without raw file downloads |

## Configure and verify

1. Open Application → Publishing Channels → Portal and copy the displayed access link.
2. Configure visibility for execution status, full response, citation excerpts, full citations, and source-document downloads according to the intended audience.
3. After publishing application configuration changes, open the link as a test member with application access and start a new conversation.
4. Check the answer and the execution and citation information visible to that member against your settings.

## Portal Navigation and Deep Links

- **Workspace navigation**: Switch between Recent Chats, My Applications, Team Applications, and Favorites in the left pane, and bookmark frequently used team apps.
- **Direct URL parameters**: Open a specific application directly via `/chat?appId=<appId>`, or pass the `pane` query parameter to open the team application directory.
- **Permission checks**: When a member encounters an access error, verify the active team, application collaborator permissions ([Team Permissions](/en/guide/workspace/team/team_roles_permissions)), and [collection-level permissions](/en/guide/dataset/collection_permission) on referenced knowledge bases.
