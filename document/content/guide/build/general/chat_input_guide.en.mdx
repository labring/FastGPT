## What is Custom Question Guidance?

You can preset questions for your app. As users type, the system dynamically searches these questions based on their input and displays them as suggestions, helping users ask questions faster.

You can configure the question list directly in FastGPT or provide a custom API endpoint.

## Custom Question List API

The endpoint must be accessible from the user's browser. Configure cross-origin resource sharing (CORS) to allow requests from the chat page's origin. After you set a custom API URL, the browser sends a GET request to it as the user types; no request is sent when the input exceeds 20 characters.

**Request:**

```bash
curl --location --request GET 'https://your-domain.com/api/input-guide?sourceType=app&sourceId=663c75302caf8315b1c00194&searchKey=you'
```

Where `sourceType` is the chat source type (`app` for app chats), `sourceId` is the app ID, and `searchKey` is the search keyword. Requests from a share link also include `outLinkAuthData` (the share authentication data as a JSON string).

**Response**

```json
{
  "code": 200,
  "statusText": "",
  "message": "",
  "data": ["it's you", "who are you", "you're great", "hello there", "hello"]
}
```

`data` is an array of matched questions. Your endpoint decides how many to return (the built-in FastGPT lexicon returns up to 6).

**Parameters:**

- sourceType - Chat source type, `app` for app chats
- sourceId - App ID
- searchKey - Search keyword
- outLinkAuthData - Share authentication data as a JSON string, sent only from share links
