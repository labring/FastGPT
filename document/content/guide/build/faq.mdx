## 应用构建与编排

## 多轮对话分类

问题分类节点具有获取上下文信息的能力，当处理两个关联性较大的问题时，模型的判断准确性往往依赖于这两个问题之间的联系和模型的能力。例如，当用户先问“我该如何使用这个功能？”接着又询问“这个功能有什么限制？”时，模型借助上下文信息，就能够更精准地理解并响应。

当连续问题之间的关联性较小时，可在工作流左上方“系统配置 → 全局变量”中新增一个文本变量（如 `category`）记录分类结果：首次通过“问题分类”节点后连接“变量更新”节点将该全局变量写入对应分类值；在“流程开始”节点后放置“判断器”节点读取该全局变量，已赋值时直接进入对应分支，为空时再进入“问题分类”节点由模型判断。

建议：构建批量运行脚本进行测试，评估问题分类的准确性。

## 定时执行触发时机

定时执行在应用保存并发布后生效，由后台按计划触发，与用户是否打开分享链接或停留在页面无关。

## 修改后未生效

应用变更后，需要点击 **保存 → 保存并发布**，聊天和发布渠道才会使用更新后的应用。

## 取消 Markdown 输出

打开应用编辑器，检查提示词中的格式要求；工作流应用还需打开 AI 对话节点的 **引用提示词配置**，检查 **引用模板提示词**。移除 Markdown 格式指令，再在调试区用同一问题验证。发布后复测分享链接：

![AI 对话节点配置界面示意](/imgs/optimized/current/node-ai-chat.png.webp)

![在引用提示词配置弹窗中检查引用模板提示词](/imgs/optimized/current/citation-prompt-settings.png.webp)

未自定义 **引用模板提示词** 时使用默认模板，默认模板要求使用 Markdown 语法，需自定义该提示词才能去掉这条要求。

## 不同来源效果不一致

Q: 应用在调试和正式发布后，效果不一致；在 API 调用时，效果不一致。

A: 打开应用的对话日志，按会话和请求时间定位两次执行，展开运行详情。比较应用发布版本、用户问题、历史记录、变量、检索片段、模型参数与工具结果，使用相同输入逐项排查。详见[日志排障](/zh-CN/guide/build/logs)。

## 后续问题跳过分类节点

在“流程开始”节点后添加“判断器”节点，条件变量绑定 `流程开始 > 历史记录` 并判断其长度是否为 `0`：为 `0`（首次提问）时连接“问题分类”节点；大于 `0`（后续追问）时直接连接“知识库搜索”与“AI 对话”节点。

## 公式无法正常显示

在应用的“提示词”（或工作流 AI 对话节点的“提示词”）输入框中补充格式要求，引导模型按以下 LaTeX / Markdown 语法输出公式：

```bash
Latex inline: \(x^2\)
Latex block: $$e=mc^2$$
```

## 对话界面与交互

### 浏览器不支持语音输入

1. 确认浏览器及操作系统的麦克风权限均已开启。
2. 确认浏览器允许当前站点访问麦克风，且选中了有效的麦克风输入设备。
3. 确认站点已配置 HTTPS（SSL 证书），现代浏览器仅在安全上下文（HTTPS 或 `localhost`）中开放麦克风接口。

### 模型开启思考后，对话未显示思考过程（4.15 之前）

适用版本：4.9.1～4.14.x。FastGPT 识别上游返回的 `reasoning_content` 字段，或正文中由 `<think></think>` 包裹的内容（需开启模型配置中的“支持输出思考”）。

在对应模型的“额外 Body 参数”中填写上游中转要求的思考开关（例如 `{"enable_thinking": true}` 或 `{"chat_template_kwargs": {"enable_thinking": true}}`），保存后重新发起对话。

### iOS 端点击引用“打开原文”无响应

适用版本：截至 4.17.0。iOS Safari（含企业微信内置浏览器）默认拦截异步请求返回链接后再打开新窗口的行为。

临时处理方式：点击右上角“…”选择使用系统浏览器打开，或在系统浏览器设置中关闭“阻止弹出式窗口”。

## 团队插件安装与管理

### 为什么没有“+ 安装工具”按钮？

显示“+ 安装工具”按钮需同时满足两个条件：当前账号为团队管理员或团队所有者，且系统管理员已在 **管理员 → 系统配置 → 功能清单** 中开启 **允许团队上传插件**（该开关仅商业版提供，关闭时按钮整体隐藏）。普通团队成员可直接在应用中调用已安装的团队插件。

### 为什么没有“从插件市场安装”选项？

“+ 安装工具”按钮可见时始终提供“从本地安装”入口；若下拉菜单中未显示“从插件市场安装”，说明当前部署环境已配置禁用插件市场（`DISABLE_MARKETPLACE`）。

### 上传本地插件包成功后为什么还不能使用？

上传并解析插件包后，还需在预览弹窗中点击确认安装；若插件包含必填密钥或运行参数，首次调用前需先完成参数配置。

### 删除团队插件会影响同 ID 的系统插件吗？

团队插件与系统插件使用独立的数据源与配置空间，删除团队插件仅移除当前团队的安装记录，系统插件及其他团队的插件保持可用。

### 团队插件会继承系统插件已配置的密钥吗？

团队插件与系统插件完全独立，需在团队内单独配置运行参数与密钥。

### 为什么在系统工具页看不到“+ 安装工具 → 从本地安装”入口？

系统工具管理页的本地上传与删除入口仅对系统 `root` 管理员账号展示，请使用 `root` 账号登录管理后台操作，详见 [手动上传系统工具](/zh-CN/guide/build/tools/system-plugins/upload_system_tool)。

## 第三方渠道集成

### 飞书、企业微信、钉钉或微信公众号发送消息后机器人无响应怎么办？

1. 核对第三方开放平台后台配置的回调 URL、可信域名、`Token`、`Encoding-AESKey` 或 `Client Secret` 是否与 FastGPT 发布渠道配置一致。
2. 打开 FastGPT 应用的 **对话日志**，查看是否已生成对应的提问记录。
3. 对话日志中已生成记录但第三方客户端未收到回复时，检查第三方平台是否已为机器人开通发送消息、读取单聊与群聊消息权限，并确认已发布应用版本。
4. 对话日志中无记录时，先用最简问答应用排除必填全局变量、文件或图片输入限制。

### 如何在飞书、钉钉、微信公众号或个人微信号中重置对话上下文？

向机器人直接发送 `Reset`（注意大小写；微信个人号同时支持 `/reset`），机器人会立即开启新的会话记录。飞书机器人的会话 `chatId` 按私聊窗口、话题群单话题或“群 ID + 个人 ID”隔离。

### 微信个人号接入时找不到 ClawBot 入口怎么办？

微信个人号桥接路径要求使用 iOS 设备与最新版微信客户端，入口展示取决于客户端版本与账号灰度开放情况。
