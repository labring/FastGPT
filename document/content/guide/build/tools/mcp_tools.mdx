---
title: 连接 MCP 工具集
description: 将外部 MCP 服务的工具接入 FastGPT，验证传输、认证与调用。
---

MCP 工具集把外部服务能力接入 FastGPT。向外部客户端提供 FastGPT 应用使用 [MCP 服务发布](/zh-CN/guide/build/publish/mcp_server)。工具集功能在 v4.9.6 引入；下述连接行为对应当前实现，旧部署应按对应版本核对。

## 创建一个 MCP 工具集

需要工具创建权限、外部服务地址及认证信息，并确保 FastGPT 服务端能访问该地址。

1. 在工作台创建 MCP 工具集。
2. 填写服务提供方给出的 MCP URL 和所需请求头。
3. 点击解析，检查返回的工具名称、用途与参数，再创建工具集。

当前连接优先使用 Streamable HTTP。当该传输返回 4xx 的协议错误时，客户端尝试兼容 SSE。认证、网络或服务端问题仍需根据返回错误处理；仅修改 URL 后缀无法确认协议兼容。

## 测试 MCP 工具

进入工具集，选择一个只读工具，按其参数契约填写已知输入并运行。预期返回服务声明的结构；将结果与服务文档对照，再接入应用。调试会调用真实外部服务，结果与费用取决于服务提供方。

## 模型调用工具

### 调用单个工具

在应用中选择所需工具，使用支持工具调用的模型。提出一个符合工具用途的问题，展开执行详情核对工具名、参数和返回值。

### 调用工具集

选择工具集以提供多个相关操作，检查工具描述能否清晰区分用途。工作流可以通过工具相关节点调用；Agent 会根据任务选择可用操作。

## 连接排障

| 异常现象 | 触发原因与排查步骤 |
| --- | --- |
| **点击解析报格式错误或连接失败** | 核对 URL 是否为合法的 MCP 端点、认证 Header 是否有效，以及 FastGPT 服务端到该地址的网络连通性；外部服务返回非标准 JSON-RPC 2.0 响应时会提示响应格式错误 |
| **SSE 会话返回 HTTP 404** | 外部 MCP Server 的 SSE 会话已过期或重启；重新发起请求建立新会话 |
| **工具列表可见但调用报错** | 展开对话运行详情查看 MCP 工具返回的错误文本（如上游限流、参数校验失败或业务权限不足）；系统会将模型生成的参数与节点预设固定参数合并（固定参数优先）后透传给 MCP 服务 |
| **请求超时** | 检查外部 MCP 服务响应延迟与网络链路，先在工具集调试面板使用最小输入参数单步验证 |

凭证只保存在受控配置中。外部工具的业务权限与 FastGPT 资源权限分别核对。
