工具是具有明确输入输出的可调用操作。Skill 将指令和支持文件统一版本化，供 Agent 在执行环境中使用。

| 需求 | 选择 | 需要确认 |
| --- | --- | --- |
| 使用平台已有操作 | 系统工具 | 安装、激活配置和工具权限 |
| 将已有流程提供给其他应用 | 工作流工具 | 输入参数、输出参数和发布版本 |
| 调用一个 HTTP 服务 | [HTTP 工具](/zh-CN/guide/build/tools/http_tools) | 地址、认证、请求和响应结构 |
| 连接外部 MCP 能力 | [MCP 工具集](/zh-CN/guide/build/tools/mcp_tools) | 服务地址、传输、请求头和网络 |
| 复用操作方法与文件 | [Skill](/zh-CN/guide/build/skill/intro) | 正式版本、执行环境与模型能力 |

## 工作流工具

创建工作流工具，在工具输入中声明调用者需要提供的参数及类型，在流程中引用这些参数，再通过工具输出声明返回值。先独立运行一个已知输入，核对输出结构；发布后从其他应用选择该工具，检查参数映射和执行结果。

工具描述帮助模型选择何时调用，参数说明帮助模型填写值。给会产生外部写入的操作写清楚作用，并在正式使用前验证权限与业务确认流程。

## 在应用中使用

对话 Agent 或 Agent V2 需要支持所选工具的模型及调用权限；工作流可以显式调用工具，Agent 节点可以按任务选择工具。先完成工具自身调试，再通过应用调试验证输入、输出及错误。

[团队工具安装](/zh-CN/plugin/team-installation)说明团队可用工具；[系统工具开发](/zh-CN/plugin/system-tool-development)说明扩展过程；[Skill 集成](/zh-CN/guide/build/skill/integration)说明两种 Agent 集成位置。
