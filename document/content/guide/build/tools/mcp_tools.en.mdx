MCP tool sets bring external capabilities into FastGPT. To expose FastGPT applications to another client, use [MCP service publishing](/en/guide/build/publish/mcp_server). Tool sets were introduced in v4.9.6; the connection behavior below describes the current implementation. Check the applicable release for older deployments.

## Create an MCP tool set

You need tool creation permission, an external service URL and credentials, and network access from the FastGPT server.

1. Create an MCP tool set in the workspace.
2. Enter the provider's MCP URL and required request headers.
3. Parse the service, inspect the returned tool names, purposes, and parameters, then create the set.

The current client tries Streamable HTTP first. A 4xx protocol error from that transport triggers an SSE compatibility attempt. Diagnose authentication, network, and service failures from their errors; changing a URL suffix alone does not establish transport compatibility.

## Test an MCP tool

Open the tool set, choose a read-only tool, supply a known input according to its contract, and run it. Expect the structure documented by the provider. Compare the result with the service documentation before using it in an application. Debugging invokes the real service; effects and charges follow the provider's behavior.

## Model tool calls

### Call one tool

Select the tool in an application using a model supporting tool calls. Ask a question matching the tool's purpose, then inspect execution details for its name, arguments, and returned value.

### Call a tool set

Select the set to make multiple related operations available. Ensure descriptions distinguish their purposes. Workflows can invoke tools through tool-related nodes; Agents select available operations according to the task.

## Troubleshoot connections

- Parsing failure: verify the MCP endpoint, authentication headers, and reachability from the server.
- Tools appear but execution fails: inspect arguments, external permissions, and the actual error.
- Timeout: inspect provider status and the network path, then retry with a small input.

Store credentials in controlled configuration. Check external business permissions and FastGPT resource permissions separately.
