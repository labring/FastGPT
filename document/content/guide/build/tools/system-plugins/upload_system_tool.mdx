> 从 FastGPT 4.14.0 版本开始，系统管理员可以通过 Web 界面直接上传和更新系统工具进行热更新

## 权限要求

⚠️ **重要提示**：只有 **root 用户** 才能使用在线上传系统工具功能。

- 确保您已使用 `root` 账户登录 FastGPT

## 支持的文件格式

- **文件类型**：`.pkg` 文件，或包含多个 `.pkg` 的 `.zip` 文件
- **文件大小**：由环境变量 `UPLOAD_FILE_MAX_SIZE` 控制，默认 1000 MB
- **文件数量**：由环境变量 `UPLOAD_FILE_MAX_AMOUNT` 控制，默认每次最多 1000 个文件

## 上传步骤

### 1. 进入配置页面


使用 `root` 登录，进入 **管理员 → 系统资源 → 系统工具**，点击右上角 **+ 安装工具**，在下拉菜单中选择 **从本地安装**（下拉菜单同时提供 **从插件市场安装**）。

![配置中的资源库与添加资源入口](/imgs/optimized/plugins/entry.png.webp)

### 2. 准备工具文件

准备来自可信作者的 `.pkg` 文件，并确认版本与目标环境兼容。自行开发的工具按[构建、检查与打包](/zh-CN/plugin/debugging-and-publishing#构建检查和打包)生成安装包，产物说明见[插件包与 SDK 参考](/zh-CN/plugin/package-reference)。

![2. 准备工具文件：界面示例](/imgs/optimized/plugins/files.png.webp)

### 3. 执行上传

1. 点击右上角 **+ 安装工具 → 从本地安装**
2. 在弹出的 **导入/更新插件** 抽屉中，点击文件选择区域
3. 选择您准备好的 `.pkg` 或 `.zip` 工具文件
4. 确认文件信息无误后，点击底部 **确认导入** 按钮

### 4. 上传过程

- 上传成功后会显示成功提示
- 页面自动刷新，新工具会出现在工具列表中

## 功能特点

### 工具管理

- **查看工具**：用户根据工具状态和权限查看可用的系统工具
- **上传工具**：仅 root 用户可以上传新工具或更新现有工具
- **删除工具**：仅 root 用户可以删除已上传的工具

## 安装后配置

root 管理员可以在工具配置页面管理状态、系统密钥和[运行参数](/zh-CN/plugin/runtime)。安装或更新后，在测试应用中验证一次调用。

| 状态 | 新增工具选择 | 已有调用 |
| --- | --- | --- |
| 正常 | 可以选择 | 继续运行 |
| 已隐藏 | 选择器中隐藏 | 继续运行 |
| 即将下线 (`SoonOffline`) | 选择器中隐藏 | 继续运行 |
| 已卸载 (`Offline`) | 无法选择 | 调用被拒绝 |

系统密钥由 root 统一配置，FastGPT 服务端保存，并在调用方选择使用系统密钥时读取。[团队安装](/zh-CN/plugin/team-installation)使用独立配置与密钥。

## 常见问题

### Q: 无法看到“+ 安装工具 → 从本地安装”入口

**原因：** 当前用户不是 root 用户

**解决方案：** 使用 root 账户重新登录
