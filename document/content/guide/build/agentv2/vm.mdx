虚拟机（VM）为对话 Agent V2 提供隔离的代码执行环境、文件读写支持与自定义环境依赖安装能力。

## 什么是虚拟机

Agent 在分析复杂表格、执行数学计算、生成动态图表或调用技能（Skill）时，需要借助真实的操作环境。虚拟机提供独立的容器化运行时（如 Python 3.11、Node.js 20），允许 Agent 自主编写并运行脚本、排查报错、产出可供用户下载的文件产物。

环境运行依赖后台配置的沙箱服务（如 OpenSandbox 或 Sealos Devbox）。自部署团队需根据 [服务配置指南](/zh-CN/self-host) 完成沙箱部署。

---

## 虚拟机架构与目录设计

系统按租户、应用与会话标识对虚拟机实行细粒度隔离：

```
<workspaceRoot>/
  ├── sessions/
  │     └── <chatId>/             # 当前对话专属工作目录，隔离用户上传与生成的临时文件
  └── projects/
        └── <versionId>/          # 共享技能代码目录，挂载已发布的 Skill 版本包
```

- **会话级隔离**：每个对话窗口分配专属的工作空间路径 `sessions/<chatId>`，用户上传的文件自动挂载入该目录。
- **状态存续与重置**：同一 `chatId` 复用会话目录。沙箱实例按来源、应用和用户标识管理，重开对话会切换会话上下文与目录；实例回收和持久卷保留由沙箱服务生命周期管理。

## 虚拟机生命周期

在环境初始化与执行过程中，系统严格按照既定时序管理沙箱生命周期：

```
[准备工作区] ──► [连接 / 创建 / 恢复沙箱] ──► [挂载工作区卷] ──► [执行启动脚本] ──► [就绪提供服务]
                                                               │
                                                               ▼ (状态记录与哈希去重)
                                                      [~/.fastgpt/runtime/state.json]
```

### 启动脚本与依赖管理
应用配置中的“启动脚本”在沙箱容器拉起后首先执行，用于预装 Python 依赖包（如 `pip install matplotlib pandas`）或系统工具：
- **状态去重机制**：脚本执行成功后，系统在沙箱内 `~/.fastgpt/runtime/state.json` 记录脚本内容的哈希值。同一会话内后续交互复用已就绪环境，避免重复执行安装耗时。
- **更新触发**：修改启动脚本内容时，系统自动识别哈希变化并重新触发执行。

### 执行限制与容错机制

- **启动超时防护**：启动脚本执行超时时间由环境变量 `AGENT_SANDBOX_ENTRYPOINT_TIMEOUT_SECONDS` 控制（默认 30 秒，系统允许设置范围为 1 ~ 600 秒）。
- **非阻塞容错**：启动脚本发生非零退出或超时不会强行中断主流程，系统记录警告日志并继续执行后续对话，由开发者在调试面板中核验依赖情况。
- **输出截断限制**：输出限制取决于具体执行服务。日志可能截断，大体积结果应写入文件并通过产物检查。

## 虚拟机调试与文件管理

1. **实时状态观察**：在调试抽屉中，系统直观展示虚拟机的启动进度（拉起容器、执行脚本、就绪）。
2. **虚拟机文件管理器**：点击调试窗口右上角的“查看虚拟机文件”，可以实时浏览沙箱内部的目录结构，在线预览生成的图片（如 `revenue.png`）或下载生成的数据表（如 `channel_summary.csv`）。
3. **状态诊断与排障**：当代码运行报错缺少模块时，首先检查启动脚本的执行日志与返回值，确认依赖库已成功安装。
