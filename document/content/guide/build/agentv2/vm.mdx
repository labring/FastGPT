虚拟机（VM）为对话 Agent V2 提供隔离的代码执行环境、文件读写支持与自定义环境依赖安装能力。

## 什么是虚拟机

Agent 在分析复杂表格、执行数学计算、生成动态图表或调用技能（Skill）时，需要借助真实的操作环境。虚拟机提供独立的容器化运行时（如 Python 3.11、Node.js 20），允许 Agent 自主编写并运行脚本、排查报错、产出可供用户下载的文件产物。

环境运行依赖后台配置的沙箱服务（如 OpenSandbox 或 Sealos Devbox）。自部署团队需根据 [服务配置指南](/zh-CN/self-host) 完成沙箱部署。

## 虚拟机架构与目录设计

系统按租户、应用与会话标识对虚拟机实行细粒度隔离：

```
<workspaceRoot>/
  ├── sessions/
  │     └── <chatId>/             # 当前对话专属工作目录，隔离用户上传与生成的临时文件
  └── projects/
        └── <versionId>/          # 共享技能代码目录，挂载已发布的 Skill 版本包
```

- **会话级隔离**：每个对话窗口分配专属的工作空间路径 `sessions/<chatId>`，用户上传的文件自动挂载入该目录。
- **对话上传文件自动注入**：用户在对话输入框中上传的测试或业务文件，会在对话开始前自动同步注入到会话工作空间的 `user_files/` 目录下，供 Agent 通过本地相对路径直接读取处理。
- **状态存续与重置**：同一 `chatId` 复用会话目录。沙箱实例按来源、应用和用户标识管理，重开对话会切换会话上下文与目录；实例回收和持久卷保留由沙箱服务生命周期管理。
- **安全防逃逸与命令编码**：容器受 CPU、内存、磁盘 I/O 配额与网络策略约束；执行的命令均经过 base64 编码后在容器内解码运行，消除 Shell 拼接风险。

![Agent 沙箱初始化](/imgs/diagrams/sandbox-initialization.zh-CN.light.svg)

### 启动脚本与依赖管理
应用配置中的“启动脚本”在运行态、初始化锁、配置与文件准备完成后执行，用于预装 Python 依赖包（如 `pip install matplotlib pandas`）或系统工具：
- **双层脚本执行顺序与原子部署**：
  1. **应用启动脚本**：首先在虚拟机工作目录（如 `/workspace`）下执行应用配置面板中编写的自定义 Shell 脚本。
  2. **技能入口脚本（Skill Entrypoint）**：若 Agent 关联了已发布的技能包，技能包先解压至临时目录（`.tmp-<versionId>-<random>`），解压完全成功后原子替换为正式版本目录 `projects/<versionId>`，随后在该技能包目录下自动执行其初始化脚本（如 `entrypoint.sh`）。
- **基于 `~/.fastgpt/runtime/state.json` 的双维状态去重**：
  - **应用启动脚本（SHA-256 哈希去重）**：系统计算应用启动脚本文本的 SHA-256 哈希值并与 `~/.fastgpt/runtime/state.json` 中的记录比对；内容未变时后续热启动交互自动跳过重复执行，修改脚本内容或重建沙箱时重新触发。
  - **技能入口脚本（技能版本 ID 去重）**：关联技能的入口脚本按不可变的**技能版本 ID** 比对去重，同一沙箱实例内每个已发布技能版本的初始化脚本仅在首次冷启动时执行一次。

### 执行限制与容错机制

- **准备失败**：运行态获取或初始化锁失败时，本轮准备返回错误。Skill 编辑调试使用独立准备分支。
- **启动超时防护**：启动脚本执行超时时间由环境变量 `AGENT_SANDBOX_ENTRYPOINT_TIMEOUT_SECONDS` 控制（默认 30 秒，系统允许设置范围为 1 ~ 600 秒）。
- **非阻塞容错**：启动脚本发生非零退出或超时不会强行中断主流程，系统记录警告日志并继续执行后续对话，由开发者在调试面板中核验依赖情况。
- **输出截断限制**：输出限制取决于具体执行服务。日志可能截断，大体积结果应写入文件并通过产物检查。

## 虚拟机调试与文件管理

1. **实时状态观察**：在调试抽屉中，系统直观展示虚拟机的启动进度（拉起容器、执行脚本、就绪）。
2. **虚拟机文件管理器**：点击调试窗口右上角的“查看虚拟机文件”，可以实时浏览沙箱内部的目录结构，在线预览生成的图片（如 `revenue.png`）或下载生成的数据表（如 `channel_summary.csv`）。
3. **状态诊断与排障**：当代码运行报错缺少模块时，首先检查启动脚本的执行日志与返回值，确认依赖库已成功安装。
