## 什么是虚拟机

Agent 通过虚拟机执行代码、读写文件并使用 Skill。需要部署配置提供相应 sandbox 服务，账号具有可用权限与额度。语言运行时、网络和资源限制由所选执行服务及镜像决定。

## 虚拟机设计

当前实现按来源、应用与用户标识定位运行实例，应用对话使用 `sessions/<chatId>` 形式的会话工作目录；共享 Skill 位于工作区下的 `projects/<versionId>`。旧版本的会话实例设计可能不同，排障时核对部署版本与文件管理器中的实际路径。

运行实例、会话目录和持久化存储具有不同生命周期。重开对话建立新的会话上下文；文件和依赖的保留、归档及恢复取决于执行服务和存储配置。清理或重置前保存所需产物。

## 虚拟机使用

在 Agent V2 配置中启用虚拟机，或在工作流 Agent 节点关联需要执行环境的 Skill。配置完成后用小文件和简单任务调试，观察初始化状态，再从虚拟机文件管理器检查输入文件、生成文件和执行日志。

任务示例：上传一份小型 CSV，要求计算某列合计并保存结果。核对列名、行数与人工计算值，确认输出文件可以下载。数据分析依赖所选镜像中的语言和库，缺失依赖可通过启动脚本准备。

## 虚拟机生命周期

应用启动脚本在准备执行环境时运行，成功状态按脚本内容记录。同一实例中的同一成功脚本会复用记录；脚本更新后重新执行。Skill 初始化以发布版本 ID 记录，见[初始化脚本](/zh-CN/guide/build/skill/initialization)。

### 执行限制与容错机制

初始化超时由 `AGENT_SANDBOX_ENTRYPOINT_TIMEOUT_SECONDS` 配置，当前实现将范围限制为 1–600 秒。执行输出有大小限制，服务日志还会截断长文本。初始化错误或超时记录日志，后续任务可能继续运行；任务启动成功后仍应验证依赖和结果。

## 虚拟机调试

1. 查看界面的准备状态和具体错误，确认执行服务、镜像、配额及存储可用。
2. 在文件管理器确认实际工作目录和输入文件。
3. 检查脚本退出码、网络、依赖与权限；状态记录位于虚拟机用户 HOME 下的 `~/.fastgpt/runtime/state.json`。
4. 使用同一小输入复验结果，再扩大任务规模。

隔离方式、出口控制和资源配额由执行服务提供，按部署配置核实。代码、依赖及工具可影响执行环境，配置时使用所需的最小访问范围。
