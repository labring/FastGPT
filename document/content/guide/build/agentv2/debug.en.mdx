Before publishing a Chat Agent V2 to production channels, use the "Debug Preview" drawer on the right side of the workspace to simulate user interactions and inspect the model's reasoning trace, tool invocation arguments, and execution latency step by step.

![Knowledge retrieval debug results and source citations](/imgs/optimized/current/agent-answer.png.webp)

## Step 1: Initiate Interactive Testing and Session Management

1. Open your target Chat Agent V2 workspace; the right-hand panel provides a real-time conversational test environment.
2. Click "Restart Chat" in the upper right corner to clear context history and initiate testing from a fresh, blank turn.
3. Submit a realistic operational prompt, such as: `Analyze the attached sales report and calculate ROI by marketing channel.`.

---

## Step 2: Track Execution Progress with Plan Cards

For complex multi-step tasks, planning-enabled models output structured "Plan Cards" streamed in real time:

- **In Progress**: Highlights the active sub-action (such as calling a specific tool or running an inline Python script).
- **Completed**: Marks successfully finalized steps that returned valid outputs.
- **Pending**: Lists subsequent tasks queued for future evaluation.
- **Blocked**: Appears when a tool throws errors, network connections time out, or parameters are missing. Use the diagnostic hint to locate bottlenecks and refine prompt instructions.

---

## Step 3: Expand Execution Details to Inspect Underlying Traces

Beneath each generated AI message bubble, click "Execution Details" to review the decision trace:

1. **Reasoning Content**:
   Inspect reasoning content returned by a supported model when reasoning display is enabled.
2. **Tool Arguments**:
   Verify that generated JSON payloads adhere strictly to target tool schemas, checking dates, IDs, and query terms.
3. **Tool Output**:
   Examine raw responses returned by tools or sandbox commands, confirming that outputs provide complete, valid factual evidence.
4. **Performance and Quota Auditing**:
   Inspect available model, latency, and usage fields. Record the request identifier when present and reconcile cost with usage records.

---

## Step 4: Diagnostic Utilities and Annotation

The toolbar beneath each AI message offers quick utilities:
- **Copy**: Copy raw generated Markdown text.
- **Read Aloud**: Play text back using text-to-speech synthesis.
- **Annotate**: Click the annotate button to save the current query and a corrected answer directly into a knowledge base, reinforcing factual accuracy in subsequent turns through RAG.
- **Retry**: Re-run planning and generation independently against the preceding query.
