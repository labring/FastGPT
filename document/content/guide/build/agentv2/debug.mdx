在将对话 Agent V2 正式发布上线前，利用应用工作台右侧的“调试预览”窗口能够模拟真实用户交互，逐层透视模型的推理规划、工具调用参数与单步执行耗时。

![知识检索调试结果与引用依据](/imgs/current/agent-answer.png)

## 步骤一：发起交互测试与会话管理

1. 打开目标 Agent V2 应用编排页面，右侧面板即为实时的调试交互区。
2. 点击调试窗口右上角的“重开对话”按钮，可以一键清空上下文历史，从全新的空白会话启动测试。
3. 输入代表真实业务场景的测试提问，例如：`请帮我分析附件中的销售报表，并统计各渠道的投入产出比。`。

---

## 步骤二：观察任务规划与步骤卡片（Plan Cards）

对于需要多步推理的复杂任务，具备规划能力的大模型在生成过程中会流式输出结构化的“计划步骤卡片”：

- **进行中**：展示当前正在执行的具体子动作（如正在调用某个特定工具或执行一段 Python 脚本）。
- **已完成**：展示已顺利执行完毕并获得有效返回值的步骤。
- **待处理**：展示模型推演出的后续任务队列。
- **已阻塞**：当工具执行报错、网络连接超时或参数缺失时，卡片呈现阻塞状态。此时可根据卡片提示定位断点并优化提示词约束。

---

## 步骤三：展开执行详情透视底层链路

在每次生成的 AI 消息气泡下方，点击展开“执行详情”，逐层审查完整的执行决策树：

1. **思维链展开（Reasoning Content）**：
   模型支持并启用推理内容展示时，查看模型返回的推理文本。
2. **工具调用入参审查（Tool Arguments）**：
   检查模型生成的结构化 JSON 入参是否精确符合目标工具的 Schema 契约，核实日期、ID 等关键参数提取是否准确。
3. **工具返回值核对（Tool Output）**：
   检查底层工具或沙箱命令返回的实际数据，验证返回结果是否完整、是否包含有效事实。
4. **性能与消耗审计**：
   查看详情中提供的模型、耗时与用量字段。可用时记录请求标识，费用核对以用量记录为准。

---

## 步骤四：常用调试操作与标注纠错

在 AI 回复气泡下方提供了一组高效的调试工具：
- **复制**：一键复制模型生成的 Markdown 文本。
- **朗读**：调用语音合成能力试听回复。
- **标注**：点击标注按钮，将当前提问与修正后的理想答案直接保存至关联知识库中，通过知识检索增强引导模型在后续对话中给出更精准的回答。
- **重试**：强制模型针对上一轮输入重新开展一次独立的推理规划与生成。
