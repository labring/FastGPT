对话 Agent V2 是具备自主规划与工具调用能力的智能体应用。通过专属配置面板，开发者可以精细化定义智能体的人设边界、工具可用范围、持久化执行环境与技能扩展包。

![提示词编辑器的资源引用菜单](/imgs/optimized/current/agent-prompt-reference.png.webp)

## 1. 结构化系统提示词（System Prompt）

系统提示词是引导 Agent V2 执行目标拆解与决策循环的核心依据：
- **角色定位与边界**：明确智能体的专业领域、服务定位与回复风格。
- **规划与决策流程**：指令模型在面对复杂指令时按照“思考 → 选择工具 → 观察返回值 → 总结结论”的顺序推进。
- **格式规范**：规定输出文本的排版要求（如分条列出、保留核心数据、输出标准表格等）。
- **资源快速引用**：在提示词输入框中输入 `@` 符号，系统将弹出上下文资源菜单，支持直接引用系统内置能力（**知识库搜索**、**子应用**、**沙箱**、**文件解析**）以及已关联的知识库、技能与工具。

点击模型选择器右侧的设置按钮可打开模型配置弹窗；对话 Agent V2 的模型配置弹窗提供 **AI 模型** 与 **记忆轮数** 两项配置。通用模型参数说明请参考 [AI 基础设置](/zh-CN/guide/build/general/ai_settings)。

## 2. 工具与知识库配置

在左侧配置面板中，工具与知识库分别通过独立区域管理：
- **挂载工具**：在 **工具** 区域点击 **+ 选择**，可从弹窗的 **系统工具** 与 **我的工具**（工作流工具、HTTP 工具集、MCP 工具集）中勾选挂载外部工具。
- **关联知识库**：在下方独立的 **知识库** 区域点击 **+ 选择** 关联当前团队知识库，并点击 **参数** 配置检索方式、引用上限与相关度阈值。

## 3. 虚拟机执行沙箱

开启虚拟机（VM）为 Agent 提供代码运行、持久化文件读写与环境隔离能力：
- **启用条件**：后台已配置并连通 Agent 沙箱服务（如 OpenSandbox 或 Sealos Devbox），且当前团队拥有对应的虚拟机使用权限与额度。
- **运行特征**：系统为每个会话分配专属的工作目录 `sessions/<chatId>`，用户对话上传的附件自动挂载入沙箱中，供 Agent 编写并执行 Python/Node 代码进行分析。
- 详细生命周期与启动脚本配置请参考 [虚拟机沙箱指南](/zh-CN/guide/build/agentv2/vm)。

---

## 4. 技能（Skill）扩展配置

技能是包含了专业指令、参考模板与自动化脚本的可复用能力包：
- **关联已发布技能**：在技能配置列表中勾选当前团队已发布的技能版本。
- **环境联动**：关联技能后，系统自动激活虚拟机沙箱并载入对应的技能版本包。
- 自定义编写、调试与打包技能请参考 [技能开发与调试](/zh-CN/guide/build/skill/development)。
