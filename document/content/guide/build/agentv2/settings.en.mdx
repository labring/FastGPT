Chat Agent V2 is an autonomous agent application equipped with dynamic planning and tool execution capabilities. Through the dedicated settings panel, builders define the agent's persona boundaries, tool availability, isolated runtime environments, and skill bundles.

![System prompt editor resource reference menu](/imgs/optimized/current/agent-prompt-reference.png.webp)

## 1. Structured System Prompts

System prompts provide the operational blueprint guiding the agent's goal decomposition and decision loops:
- **Role and Boundaries**: Define the agent's domain expertise, tone, and service scope explicitly.
- **Decision Workflow**: Instruct the model to execute tasks following the ReAct sequence: "Reason → Select Tool → Observe Output → Conclude".
- **Formatting Standards**: Establish structured presentation criteria (such as enumerated bullet points, preserved quantitative data, and markdown tables).
- **In-Prompt Resource Citations**: Type `@` within the prompt input to open the resource menu, allowing direct references to enabled tools and attached knowledge bases.

For general model settings (such as model selection, temperature, token limits, and reasoning content toggles), refer to [AI Settings](/en/guide/build/general/ai_settings).

---

## 2. Toolsets and Execution Step Quotas

Under the "Tools" section, builders grant the agent external execution powers:
- **Attaching Tools**: Attach knowledge base search tools, system utilities (such as web search or calculators), custom workflow tools, or third-party MCP endpoints.
- **Maximum Step Quota**: Execution limits follow the parameters supported by the deployed version. Test a multi-step task and inspect tool calls, completion status, latency, and usage before setting a production budget.

---

## 3. Virtual Machine Execution Sandbox

Enabling the Virtual Machine (VM) grants the agent programmatic code execution, persistent file I/O, and container isolation:
- **Prerequisites**: A connected backend sandbox service (such as OpenSandbox or Sealos Devbox) and active virtual machine quotas in your workspace.
- **Execution Characteristics**: The platform allocates a dedicated session directory `sessions/<chatId>` per conversation. Files uploaded by users mount directly into the sandbox for Python/Node analysis.
- For detailed lifecycle and startup script setup, review the [Virtual Machine Sandbox Guide](/en/guide/build/agentv2/vm).

---

## 4. Skill Extension Packages

Skills are versioned bundles combining expert instructions, reference templates, and executable scripts:
- **Attaching Published Skills**: Check published skill versions available in your workspace team.
- **Environment Automation**: Attaching a skill activates the virtual machine sandbox automatically and injects the corresponding skill package.
- To author, debug, and publish custom skills, consult [Skill Development and Debugging](/en/guide/build/skill/development).
