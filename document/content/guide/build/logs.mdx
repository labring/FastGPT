应用详情中的“对话日志”页面（`/app/detail?appId=<id>&currentTab=logs`）包含 **数据看板**（带 PRO 角标）与 **日志详情** 两个子标签，用于监控线上流量、消费积分、用户赞踩反馈，并逐节点回溯生产会话的执行详情。

## 数据看板

切换到 **数据看板** 子标签，可按来源渠道、日期范围与统计粒度（按天、按周、按月、按季度）查看三个看板区块的核心指标：

| 指标分组 | 核心观测项 | 运营与优化用途 |
| --- | --- | --- |
| **用户数据** | 活跃用户趋势、新增用户趋势、留存用户数、累计用户数，以及积分消耗、渠道用户与 Token 消耗趋势 | 评估用户增长、留存表现与各渠道活跃度 |
| **对话数据** | 对话次数、会话次数、对话报错比例（含报错总数）与单次会话平均积分消耗 | 及时发现因外部接口超时或模型限流引起的线上错误突增，核算单次会话成本 |
| **应用效果** | 用户反馈（赞/踩趋势）与平均运行时长 | 监控响应耗时，定位差评样本 |

## 日志列表多维筛选与导出

在 **日志详情** 视图中，可通过顶部筛选栏快速锁定目标会话：

1. **多维筛选条件**：支持按**来源渠道**（在线调试、在线使用、外部链接调用、API 调用、定时执行、飞书、公众号、企业微信、微信、MCP 调用）、**日期时间范围**、**标题/会话 ID 搜索**、**用户反馈状态**（**全部记录**、**包含反馈**、**包含赞**、**包含踩** 以及 **仅看未读** 复选框）及**仅看报错**过滤。
2. **自定义表头字段**：点击列表右上角字段配置图标，可按需开启或隐藏会话标题、来源、使用者、消息总数、赞踩反馈、自定义反馈、报错次数、客户端 IP、运行版本名称等列。
3. **导出 CSV**：点击“导出”，确认当前筛选命中的会话总数（单次导出每个会话最多包含 100 条消息记录），即可下载 CSV 文件用于离线质检或构建[评测数据集](/zh-CN/guide/build/evaluation)。

## 一次问题定位

1. 记录发生时间、应用、访问渠道、提问及预期答案，去除个人信息与凭证。
2. 在日志中找到对应会话，核对原始输入与回复。
3. 展开运行详情，沿执行顺序检查节点输入、工具调用、检索内容、模型输出和错误。
4. 使用同一输入在编辑器调试，记录草稿与发布版本的差异。
5. 修改最接近原因的配置，验证后发布，并从实际访问重新测试。

![展开会话运行详情查看节点输入输出与反馈](/imgs/optimized/current/feedback-run-detail.png.webp)

| 观察结果 | 下一步 |
| --- | --- |
| 检索内容缺失 | 检查资料处理、检索范围和参数 |
| 工具调用失败 | 查看该工具的输入、认证、网络和错误响应 |
| 结果与预期事实不符 | 对照来源、模型输入与提示词 |
| 只有旧会话出现差异 | 检查历史消息、变量和交互状态，使用新会话复验 |

反馈可帮助汇集待验证问题；使用[评测](/zh-CN/guide/build/evaluation)前，先准备具有预期结果的固定问题集，确认当前环境提供所需权限和能力。
