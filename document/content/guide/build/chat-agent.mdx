对话 Agent 围绕单个核心对话模型组织系统指令、知识库检索、工具调用与多模态输入，提供开箱即用的表单式编排体验。

## 适用场景与前提条件

- **适用场景**：制度与产品手册问答、固定格式文案生成、单模型挂载少量工具的轻量助手。
- **权限要求**：拥有当前团队的应用创建或编辑权限，以及所关联模型、知识库和工具的使用权限。
- **模型要求**：关联工具时，所选语言模型需支持工具调用（Function Calling）；开启图片或语音输入时，需选择具备视觉或音频能力的模型。

## 配置步骤

### 1. 选择模型与基础参数

1. 在工作台进入“应用”，点击右上角“创建应用”，选择**对话 Agent**。
2. 在左侧“AI 配置”面板点击模型选择器，挑选当前团队可用的语言模型。
3. 点击模型右侧的参数设置图标，按任务配置温度、最大回复 Token、历史聊天记录轮数、输出格式（Text / JSON Schema）及思考推理模式。完整参数见 [AI 配置说明](/zh-CN/guide/build/general/ai_settings)。

![选择对话模型并调整参数](/imgs/optimized/current/ai-model-selector.png.webp)

### 2. 编写系统提示词与全局变量

1. 在“提示词”输入框中定义助手角色、回答边界与输出格式。
2. 在提示词中输入 `/` 或点击插入变量按钮，引用已配置的[全局变量](/zh-CN/guide/build/workflow/variables)（如用户部门、语言偏好、业务单号）。
3. 需要用户在对话开始前填写参数时，在“变量”区域添加文本、单选、多选或文件类型的全局变量。

### 3. 关联知识库与检索策略

1. 在“关联知识库”区域点击“选择”，勾选一个或多个同团队知识库。
2. 点击“参数”打开检索配置弹窗，设置搜索模式（语义检索、全文检索、混合检索）、结果重排（Rerank）、引用上限（Token 预算）、最低相关度阈值、问题优化与[集合标签过滤](/zh-CN/guide/dataset/collection_tags)。
3. 在提示词设置中确认知识库引用的注入模板与引用严格约束。详细调优方法见 [将知识库接入应用](/zh-CN/guide/dataset/connect-application)。

![配置知识库检索模式与过滤条件](/imgs/optimized/current/dataset-search-mode.png.webp)

### 4. 挂载扩展工具

1. 在“工具调用”区域点击“添加”，从系统工具、团队已安装插件、工作流工具、HTTP 工具集或 MCP 工具集中选择所需工具。
2. 对需要密钥或固定参数的工具完成配置。
3. 在提示词中说明工具的触发条件，模型会在对话过程中按用户意图自动发起工具调用并汇总返回结果。

### 5. 配置对话体验与定时触发

| 配置项 | 作用 | 详细指南 |
| --- | --- | --- |
| **对话开场白** | 新会话首屏展示欢迎语、预设问题按钮与富文本引导 | [对话开场白](/zh-CN/guide/build/general/welcomeText) |
| **文件输入** | 允许用户在对话框上传文档或图片参与本轮问答 | [文件输入功能介绍](/zh-CN/guide/build/general/fileInput) |
| **语音输入 / 语音播报** | 开启麦克风语音转文字（STT）与回答语音合成（TTS） | [语音输入](/zh-CN/guide/build/general/voiceInput) |
| **猜你想问 / 输入引导** | 对话后自动生成追问建议，或在输入时提供词库自动补全 | [对话问题引导](/zh-CN/guide/build/general/chat_input_guide) |
| **定时执行** | 按设定时区与 Cron 计划自动触发预设提示词 | [配置定时触发](/zh-CN/guide/build/scheduled-triggers) |

## 调试、发布与转换为工作流

1. **右侧实时调试**：在右侧“调试预览”窗口发送测试问题，展开回答下方的引用标签与运行详情，核对知识召回分块、工具入参和模型输出。
2. **发布正式版本**：验证通过后点击右上角“保存并发布”。草稿修改在点击发布后正式对外部访问渠道生效，详见 [发布版本与发布渠道](/zh-CN/guide/build/publish/versions)。
3. **一键转换为工作流**：当业务需要增加确定性条件分支、循环批处理或人工表单介入时，打开应用左上角名称旁的菜单，选择**转成工作流**。系统会基于当前配置生成一份带 `Copy` 后缀的独立工作流应用副本，原对话 Agent 保持不变。

## 常见问题排查

| 现象 | 排查项 |
| --- | --- |
| 已修改提示词或知识库，分享链接仍按旧逻辑回复 | 编辑器修改默认保存在草稿，需点击右上角发布并在分享页开启新对话复测 |
| 挂载了工具但模型未触发调用 | 检查模型是否支持工具调用、工具描述是否清晰，以及必填密钥是否已填写 |
| 知识库有数据但回答未引用 | 在知识库“搜索测试”中核对召回得分，检查相关度阈值与集合标签过滤条件 |
