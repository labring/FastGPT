FastGPT provides a deterministic structured tabular data import engine. Standardized spreadsheet templates allow builders to ingest question-answer pairs, multi-route index variants, and structured metadata directly into knowledge bases.

## File Format and Parsing Constraints

The platform enforces strict validation rules on uploaded spreadsheet files:

| Check Item | Specification Rule |
| --- | --- |
| **File Format** | Standard CSV files (UTF-8 encoding without BOM recommended) or `.xlsx` workbooks |
| **Sheet Structure** | XLSX workbooks must contain exactly one worksheet and must not include merged cells |
| **Header Matching** | The parser trims whitespace and normalizes column headers to lowercase before matching |
| **Empty Rows** | Rows where both `q` and `a` cells are empty are skipped automatically |

## Core Column Definitions and Schema Contracts

The template schema accepts the following header declarations:

| Column Header | Occurrence Constraint | Data Type and Semantic Role |
| --- | --- | --- |
| `q` | **Exactly one column** | Question or primary index text. Vectors are computed on this column for semantic recall. |
| `a` | **Exactly one column** | Answer or complete body content. Combined with `q` to produce the full context chunk. |
| `index` | Multiple allowed, optional | Supplementary index. Each cell value is indexed as an independent vector query entry. |
| `indexes` | Multiple allowed, optional | Backward-compatible alias for `index`, sharing identical parsing logic and weights. |
| `metadata` | **At most one column** | Valid JSON string. Parsed key-value pairs are merged into the chunk metadata dictionary. |

---

## Supplementary Indexes and Tail Expansion

To map multiple synonymous questions or alternative phrasing to a single answer, use the supplementary index mechanism:

1. **Multi-Column Declarations**: Declare multiple independent columns named `index` (e.g., `q`, `a`, `index`, `index`). Each column cell holds a unique query variation.
2. **Tail Expansion Mode**: When the spreadsheet contains a single `index` (or `indexes`) column and **omits** the `metadata` column, the parser reads from that index column through the end of the row, treating all subsequent non-empty cells as individual index entries. When using this mode, place `q` and `a` to the left of the index column.

---

## Metadata Column Standards

The `metadata` column stores operational tags, department codes, timestamps, and external references:

```json
{
  "department": "Finance",
  "category": "Tax",
  "docId": "DOC-2026-001",
  "version": 2
}
```

- Top-level keys of valid JSON objects are merged directly into the chunk's `metadata` property.
- If formatting is invalid or non-object, the cell's raw text is retained as a string value.

---

## Formula Injection Escape Protection

To prevent formula execution vulnerabilities when spreadsheets are opened in desktop spreadsheet software, FastGPT's export and import utilities implement automatic escaping:
- Cell values starting with `=`, `+`, `-`, `@`, or `|` receive a prepended single quote `'` upon export.
- Fields containing commas, quotation marks, or line breaks are enclosed in double quotes following RFC 4180 standards.

## Standard CSV Sample

```csv
q,a,index,index,metadata
What is the annual leave policy?,Employees receive 5 days of paid annual leave after probation.,How is annual leave calculated,Paid vacation days,"{""category"":""HR"",""year"":2026}"
What is the company billing name?,The billing name is FastGPT Technologies Inc.,Company invoice title,Official business name,"{""category"":""Finance""}"
```

## Import Procedure

1. Open your target knowledge base, then click "New / Import → Text Dataset → Table Import".
2. Upload your prepared CSV or XLSX file.
3. The platform validates headers and generates a chunk preview. Confirm that question, answer, and index mappings align, then click "Confirm Import".
