本指南将一份本地资料导入为可检索的集合。首次体验可使用[首个知识库问答](/zh-CN/guide/getting-started/knowledge-qa)中的 `travel-policy.txt`。

## 开始前

准备知识库创建或目标知识库、文件夹的写入权限，以及可用的向量模型和额度。增强解析、问答拆分等处理方式还需要对应服务或模型。SaaS 的可选能力取决于团队配置；自部署请先核对[模型配置](/zh-CN/self-host/config/model/intro)和当前版本的导入入口。

## 1. 选择来源

| 资料来源 | 入口与检查 |
| --- | --- |
| 本地文件 | 新建/导入 → 文本数据集 → 本地文件；文件格式以上传框为准 |
| 整理好的问答对 | [模板导入](/zh-CN/guide/dataset/template)，先验证少量 CSV 或 XLSX 数据 |
| 少量人工资料 | 在集合中添加数据块，保留问题的条件和完整答案 |
| 网页 | 使用网页导入；持续更新见[网页同步](/zh-CN/guide/dataset/websync) |
| 企业资料系统 | 按[第三方知识库](/zh-CN/guide/dataset/third-party/third_dataset)检查授权与连接 |
| 程序写入 | 按[知识库 API 集成](/zh-CN/openapi/dataset)核对当前接口 |

## 2. 上传并预览

1. 在知识库列表新建普通知识库，填写名称并选择团队可用的向量模型；已有目标知识库可直接打开。
2. 进入目标文件夹，选择 **新建/导入 → 文本数据集 → 本地文件**，上传资料。
3. 先使用默认处理设置，进入预览。核对标题、正文、表格文字及分段边界。差旅示例中的 `15 calendar days`、发票和已批准差旅申请应保留完整语义。
4. 发现乱码时将文本另存为 UTF-8；扫描件缺少文字时检查增强解析能力。调整来源或处理设置后再次预览，确认内容正确再提交。

![导入预览显示差旅制度的期限和所需材料](/imgs/current/knowledge-preview.png)

图为示例界面；按正文定位上传、预览和提交操作，模型名称以当前团队为准。

## 3. 确认可以检索

上传文件后，集合还需完成解析、分块和索引。进入集合检查处理进度及失败提示，再打开数据块确认正文和索引状态。

| 观察到的状态 | 下一步 |
| --- | --- |
| 排队或处理中 | 等待该集合完成，查看进度是否继续变化 |
| 出现失败项 | 记录失败阶段和错误，按下节恢复 |
| 处理结束但集合为空 | 检查源文件是否有正文；模板应含有效数据行 |
| 数据块可读且索引完成 | 用资料中答案已知的问题检查原文；差旅示例可问“出差回来后多久提交报销？” |

完成标准：目标集合启用、预期数据块可读、处理完成，且已知问题能命中正确原文。集合创建成功只是处理过程中的一个检查点。

## 失败后恢复

检查失败阶段对应的文件、解析服务或向量模型，核对[团队模型](/zh-CN/guide/workspace/models)可用范围与额度。修复原因后使用界面提供的失败项重试入口；需要重新上传时，先记录旧集合名称，便于管理重复来源。重新打开数据块并重复已知问题，确认恢复。

同名文件再次上传会创建新集合。替换资料请按[更新资料](/zh-CN/guide/dataset/update-data)处理新旧集合。持续失败时保存脱敏错误、发生时间、格式及处理设置，交给管理员，详见[排障](/zh-CN/guide/dataset/faq)。
