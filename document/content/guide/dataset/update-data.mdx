企业知识资产随着制度更新与业务迭代持续变化。FastGPT 支持数据块级在线微调、文件覆盖更新与全量增量索引重建，确保知识库内容与线上生产环境保持同步。

## 场景一：单个数据块在线编辑与微调

当发现某一条特定条款的措辞需要小幅修订，或需要针对特定提问追加扩展问法时，使用在线数据块微调功能：

1. 进入目标知识库，点击目标集合展开数据块列表。
2. 找到需要修改的数据块，点击卡片右侧的“编辑”按钮。
3. **调整正文内容**：直接修改数据块的主要内容。系统保存时会自动计算新的文本特征。
4. **补充扩展索引（同义问法）**：在“扩展索引”区域添加用户日常可能使用的其他提问方式。这些扩展文本将作为独立的检索锚点参与向量计算。
5. **保存生效**：点击“确认保存”。等待保存与索引更新完成，再通过搜索测试核对更新后的分块。

## 场景二：整文件增量覆盖与哈希更新机制

按资料来源选择更新路径：

1. **上传文件**：保留旧版文件备份，导入修订版，等待处理完成并通过搜索测试验收。核对标签与权限后再移除旧集合；版本重叠期间，两份资料都可能参与检索。
2. **可同步的网页或 API 来源**：触发集合的同步操作。服务端读取来源正文并比对哈希，正文一致时可保留向量并更新标题。
3. **来源正文变化**：已有正文哈希检测到变化时，同步逻辑删除旧集合并以新 ID 重建集合，迁移标签与权限记录。训练异步执行，需预留检索空窗并检查完成状态。

## 场景三：批量数据块状态管理

知识库支持对数据块进行状态开关控制：

- **禁用数据块**：点击数据块卡片上的状态开关将其置为“已禁用”。被禁用的数据块将立即退出在线检索候选池，但在知识库中继续保留记录，便于后续重新启用。
- **删除数据块**：对于彻底废弃的条款，点击“删除”执行物理清理。系统同步从向量数据库与全文检索表中抹除对应的索引记录。

## 场景四：重建向量与扩展索引

需要刷新向量或扩展索引时，使用当前知识库支持的重建操作。更换向量模型或维度时，按所用版本的迁移流程执行：

1. 进入知识库设置面板，在“高级设置”中找到“索引重建”模块。
2. 选择“重建向量索引”或“重建同义词索引”。
3. 确认后，系统在后台为全库已就绪数据块生成批量消费任务。
4. Worker 按数据块重算索引，核对源内容与任务快照后逐块提交，再清理该块的旧向量。重建期间需关注部分完成状态，及时处理失败任务。

## 维护验收清单

- [ ] 索引更新完成后，编辑过的数据块在搜索测试中命中预期问题。
- [ ] 新版集合处理完成，标签、权限及外部引用的集合 ID 已核对。
- [ ] 禁用的数据块在搜索测试中不再出现在返回候选列表中。
- [ ] 索引重建任务全部处于“已就绪”状态，无未解决的失败记录。
