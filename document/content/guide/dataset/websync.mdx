网站知识库发现同域页面并导入正文，该功能需要相应商业版权限。优先使用可公开访问的静态页面，同步前确认目标内容允许访问和使用。

## 步骤一：创建网站知识库

1. 打开 **知识库 → 新建**，选择网站知识库类型。
2. 填写名称并选择索引模型、文本理解模型，按需选择图片理解模型。
3. 进入新建的知识库，点击 **开始配置**。

![创建网站知识库](/imgs/optimized/current/website-dataset-create.png.webp)

## 步骤二：配置根地址与抓取范围

填写起始页面 URL，例如 `https://docs.example.com/guide`。站点同步会发现同域子页面，当前发现上限为 200 页。同步后通过集合列表核对覆盖范围；单页面资料可使用网页链接导入流程。

![根地址和正文选择器配置](/imgs/optimized/current/website-dataset-url.png.webp)

## 步骤三：选择正文区域

检查目标页面的 HTML，在正文选择器中填写 `article`、`main` 或 `#content` 等 CSS 选择器，选中有用的正文容器。标题与正文分离时，可用逗号组合选择器，例如 `h1.page-title, article`。

在浏览器开发者工具中核对选中元素，再抽查导入的数据块，确认正文完整并清理重复导航。网站改版后重新验证选择器。

## 步骤四：配置处理参数并验收同步

1. 点击 **下一步**，选择分块存储或问答对提取，配置当前界面提供的处理与索引选项。
2. 开始同步，等待集合生成与训练完成。
3. 使用已知答案的问题测试，打开引用核对来源。
4. 周期更新按当前部署提供的自动同步设置配置。来源变化后检查最近同步结果和处理状态；哈希更新可能重建集合并重新训练，详见[数据维护](/zh-CN/guide/dataset/update-data)。

![网站知识库分块与索引配置](/imgs/optimized/current/website-dataset-settings.png.webp)

![网站知识库同步配置入口](/imgs/optimized/current/website-dataset-empty.png.webp)

## 抓取排障与常见问题

| 异常现象 | 核心排查方向 |
| --- | --- |
| 抓取正文为空 | 目标页面采用客户端纯 JavaScript 渲染（SPA），需改用服务端预渲染（SSR）链接或静态页面入口 |
| 抓取内容包含大量侧边栏导航 | 检查正文选择器配置，精准指定包含主文章的 HTML 标签 class 或 id |
| 爬虫请求返回 403 错误 | 确认站点允许抓取，并联系站点管理员获取授权访问方式 |
