网站知识库可以从一个入口地址发现同域页面，并将页面正文同步到知识库。该功能需要相应商业版权限。

## 什么是 Web 站点同步

Web 站点同步适合文档、博客等可公开读取的静态页面。当前最多发现 200 个子页面；登录态页面、纯客户端渲染内容和有访问限制的站点可能抓取失败。同步前确认目标内容允许访问和使用。

## 如何使用



### 1. 新建知识库，选择 Web 站点同步

打开 **知识库 → 新建**，选择网站知识库，填写名称并选择索引模型、文本理解模型；按需选择图片理解模型。

![创建网站知识库](/imgs/current/website-dataset-create.png)

### 2. 点击配置站点信息

进入新建的网站知识库，点击 **开始配置**。

![网站知识库的配置入口](/imgs/current/website-dataset-empty.png)

### 3. 填写网址和选择器

填写根地址，例如 `https://doc.fastgpt.io/guide/getting-started`。选择器用于限定正文区域，可以先填写 `article`，再检查目标站点的实际 HTML 结构。

![根地址和正文选择器](/imgs/current/website-dataset-url.png)

点击 **下一步**，选择分块存储或问答对提取，配置分块条件、索引增强及分块参数。确认抓取范围和处理配置后点击 **开始同步**，等待集合生成及训练完成。

![同步前的分块与索引配置](/imgs/current/website-dataset-settings.png)

截图展示提交前的配置状态。实际抓取结果取决于目标网站、网络和模型服务。

## 创建应用，绑定知识库

在应用编辑页的 **知识库** 区域关联刚同步的知识库，使用一条目标页面中能找到答案的问题测试，并打开引用核对正文。完整步骤见[首个知识库问答](/zh-CN/guide/getting-started/knowledge-qa)。

## 选择器如何使用

CSS 选择器用于指定网页中的正文元素。优先使用稳定的标签、ID 或属性；避免包含导航、页脚和重复侧栏。

### 首先打开浏览器调试面板（通常是 F12，或者【右键 - 检查】）

打开目标网页，通过浏览器的 **检查** 功能定位正文。在 Elements 面板中查看正文容器的标签、ID 和 class。此步骤检查目标站点自己的结构。

### 输入对应元素的选择器

例如下面的 HTML，正文容器可使用 `#article-content` 或 `article.docs-content`：

```html
<article id="article-content" class="docs-content">
  <h1>使用指南</h1>
  <p>需要同步的正文。</p>
</article>
```

在开发者工具 Console 中运行 `document.querySelectorAll('#article-content').length`，检查是否选中预期元素。目标网站改版后应重新验证选择器。

### 多选择器使用

需要同时获取两个区域时，用逗号组合选择器。例如标题在 `h1.page-title`、正文在 `article` 时，可填写：

```css
h1.page-title, article
```

同步后抽查生成的数据块，确认标题和正文完整，并排除菜单、页脚等重复内容。
