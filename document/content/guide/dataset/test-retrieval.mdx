---
title: 测试检索并改善命中结果
description: 用固定问题比较召回内容，每次调整一个因素并验证恢复。
---

本指南帮助你判断目标资料能否被检索到，并找出影响命中的设置。需要目标知识库的读取和搜索权限、可用模型，以及[已完成索引](/zh-CN/guide/dataset/import-data)的资料；保存应用设置还需要应用编辑权限；恢复演练中的停用与启用需要目标集合的写权限。

## 1. 固定问题与预期原文

使用[差旅示例](/zh-CN/guide/getting-started/knowledge-qa)时，保留以下测试集。使用自己的资料时，为每个问题写出应命中的条款。

| 问题 | 检索检查 | 应用回答检查 |
| --- | --- | --- |
| 出差回来后多久提交报销？ | 含 `15 calendar days` 的原文 | 15 个自然日，且引用支持期限 |
| 报销需要哪些材料？ | 发票和已批准差旅申请 | 两项材料完整 |
| 酒店住宿补贴是多少？ | 检查返回内容是否真的包含补贴标准 | 明确说明资料缺少该标准 |

知识库可能为第三个问题返回相关差旅内容。是否包含答案，需要阅读原文判断。

## 2. 记录基线

1. 打开目标知识库的搜索测试，输入第一个完整问题。需要隔离来源时使用专用测试知识库，再从结果中核对来源集合。
2. 记录搜索模式、最低相关度、引用上限，以及重排和问题优化开关。默认值以当前界面为准。
3. 打开返回结果，核对来源集合、正文、分数与排序。确认答案所需的条件在返回片段中。
4. 对其余问题重复测试，记录命中条款和遗漏内容。检索成功后再[接入应用](/zh-CN/guide/dataset/connect-application)，核对回答与引用。

## 3. 每次调整一个因素

| 现象 | 调整与复核 |
| --- | --- |
| 完全没有结果 | 先检查集合启用、处理完成、范围和权限，再检查阈值是否实际生效 |
| 编号、型号或原词难以命中 | 比较全文检索或混合检索，保持其他设置和问题相同 |
| 换一种问法就遗漏 | 比较语义检索或混合检索，检查分块是否保留完整语义 |
| 多轮追问丢失主体 | 在应用中检查问题优化后的查询；比较开启前后的命中与耗时 |
| 候选含正确条款但排序靠后 | 在模型可用时比较重排；检查本次结果和相关错误 |
| 所需条款被裁剪 | 在模型上下文允许范围内增加引用上限，检查是否同时带入无关内容 |

每次变更后重跑整组问题，保留能改善目标问题且维持其他已知答案的设置。搜索测试与应用的参数应分别核对；应用修改后按[发布流程](/zh-CN/guide/build/publish/versions)验收。

## 4. 判断参数是否生效

最低相关度需要本次有效的分数支持。重排成功时使用重排分数；纯语义检索可使用向量分数；混合检索重排失败后可能返回未应用阈值的结果。具体条件见[搜索参数](/zh-CN/guide/dataset/dataset_engine#搜索参数)。

检查当前界面可见的运行详情、错误和实际结果。界面未显示重排是否使用时，把该项记为待管理员核查；管理员可结合模型服务和调用记录确认。分数用于评估匹配，排序用于检查上下文顺序，最终答案需单独核对事实与引用。

## 恢复并验收

由具备集合写权限的维护者，仅在独立测试资料上临时停用测试集合，重复已知问题，观察目标来源消失的情况。按“处理状态 → 启用状态 → 范围与权限”检查后重新启用，确认相同问题再次返回原文。遇到其他失败按[排障指南](/zh-CN/guide/dataset/faq)操作，并重跑固定问题。
