A website dataset discovers pages on the same domain from a root URL and synchronizes their content into a knowledge base. This feature requires the corresponding commercial entitlement.

## What is Web Site Sync

Web Site Sync suits publicly readable static documentation and blogs. It currently discovers up to 200 child pages. Authentication, client-side rendering, or access restrictions can prevent crawling. Confirm permission to access and use the target content before syncing.

## How to Use



### 1. Create a New Dataset and Select Web Site Sync

Open **Knowledge → New**, select a website dataset, enter a name, and choose the index and text-understanding models. Select an image-understanding model when needed.

![Create a website dataset](/imgs/current/website-dataset-create.png)

### 2. Click to Configure Site Information

Open the new website dataset and click **Start configuration** (`开始配置`).

![Website dataset configuration entry](/imgs/current/website-dataset-empty.png)

### 3. Enter the URL and Selector

Enter a root URL such as `https://doc.fastgpt.io/guide/getting-started`. The selector limits extraction to the article. Start with `article` and verify it against the target site's HTML.

![Root URL and content selector](/imgs/current/website-dataset-url.png)

Click **Next**, choose chunk storage or QA extraction, and configure chunking, index enhancement, and processing parameters. Review the scope, click **Start sync**, and wait for collections to finish processing.

![Chunk and index settings before syncing](/imgs/current/website-dataset-settings.png)

These screenshots show configuration before submission. Crawling results depend on the target site, network, and model service.

## Create an App and Bind the Dataset

Associate the synchronized dataset in the app editor's **Knowledge** section. Ask a question answered by a source page, then inspect the citation. Follow [Your first knowledge chat](/en/guide/getting-started/knowledge-qa) for the complete sequence.

## How to Use Selectors

CSS selectors identify the content to extract. Prefer stable tags, IDs, or attributes and keep navigation, footers, and repeated sidebars outside the selection.

### Open the Browser DevTools (usually F12, or Right-click > Inspect)

Open the target webpage and use the browser's **Inspect** command on its article. In Elements, inspect the content container's tag, ID, and class. This verifies the structure of the target site itself.

### Enter the Element Selector

For the HTML below, use `#article-content` or `article.docs-content`:

```html
<article id="article-content" class="docs-content">
  <h1>User guide</h1>
  <p>The content to synchronize.</p>
</article>
```

Run `document.querySelectorAll('#article-content').length` in the DevTools Console and check that it selects the expected element. Recheck selectors after the target site changes its layout.

### Using Multiple Selectors

Separate selectors with a comma to extract multiple regions. For a title in `h1.page-title` and content in `article`, use:

```css
h1.page-title, article
```

After syncing, inspect the generated chunks for complete titles and content, and exclude repeated menus and footers.
