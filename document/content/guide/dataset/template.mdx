FastGPT 提供高确定性的结构化数据表格导入功能。使用标准化表格模板能够直接将成套问答对、自定义多路索引与业务元数据批量导入知识库。

## 文件格式与解析限制

系统对上传的表格文件执行严格的预检规则：

| 检查项 | 强制规范 |
| --- | --- |
| **文件格式** | 标准 CSV 文件（推荐 UTF-8 无 BOM 编码）或 `.xlsx` 工作簿 |
| **工作表结构** | XLSX 文件必须仅包含一个工作表，且严禁包含合并单元格 |
| **表头匹配** | 系统读取首行作为表头，匹配前会自动去除两侧空白并转换为全小写匹配 |
| **空行处理** | 当单行数据中的 `q` 与 `a` 均为空时，系统自动过滤该行 |

## 核心列名定义与契约

表格模板支持以下列名定义：

| 列名 | 出现频次要求 | 数据类型与业务含义 |
| --- | --- | --- |
| `q` | **恰好一列** | 问题或主索引正文。系统对此列文本计算向量并用于相关性召回。 |
| `a` | **恰好一列** | 答案或完整补充内容。此列与 `q` 共同组成完整数据块向模型输出。 |
| `index` | 可重复，可缺省 | 扩展索引列。每一列内容作为独立的辅助向量检索项附加至该数据块。 |
| `indexes` | 可重复，可缺省 | `index` 的兼容命名，与 `index` 共享相同的解析逻辑与索引权重。 |
| `metadata` | **至多一列** | 标准 JSON 字符串。系统将其解析并合并入该数据块的元数据字典中。 |

## 扩展索引与单列展开规则

在表格中为同一问答对配置多个同义问题或不同表达方式时，可使用扩展索引机制：

1. **多列索引模式**：在表格中声明多个名为 `index` 的独立列，例如 `q`, `a`, `index`, `index`。每列单元格填写不同的同义提问。
2. **尾部连续展开模式**：当表格仅包含单列 `index`（或 `indexes`）且**未声明** `metadata` 列时，解析器将从该索引列起一直向后读取至行尾，将所有后续非空单元格均作为独立扩展索引处理。需要使用此模式时，建议将 `q` 与 `a` 放在索引列左侧。

## 元数据（Metadata）规范

`metadata` 列用于保存业务标识、分类标签、时间戳或外部链接：

```json
{
  "department": "Finance",
  "category": "Tax",
  "docId": "DOC-2026-001",
  "version": 2
}
```

- 合法 JSON 格式的顶层键值对将直接合并至该数据块的 `metadata` 属性。
- 内容格式错误或非 JSON 对象时，系统自动将单元格原始文本作为字符串值完整保留。

---

## 防公式注入安全机制

为防止恶意 CSV 文本在 Excel 等客户端软件打开时触发宏或公式执行风险，FastGPT 的 CSV 导出与解析引擎内置转义保护：
- 以 `=`, `+`, `-`, `@`, `|` 字符开头的文本内容，系统将在导出时自动在开头添加单引号 `'`。
- 包含逗号、双引号或换行符的字段，系统严格按照 RFC 4180 标准以成对双引号进行转义封装。

```csv
q,a,index,index,metadata
什么是年假制度？,员工转正后享有每年 5 天带薪年假。,年休假怎么算,带薪年假天数,"{""category"":""HR"",""year"":2026}"
报销发票抬头是什么？,发票抬头为 FastGPT 软件技术有限公司。,公司开票信息,发票公司全称,"{""category"":""Finance""}"
```

## 导入操作流程

1. 进入目标知识库，点击“新建/导入 → 文本数据集 → 表格导入”。
2. 上传准备好的 CSV 或 XLSX 文件。
3. 系统自动完成表头契约校验并呈现数据块预览。确认问题、答案与索引映射正确后，点击“确认导入”。
