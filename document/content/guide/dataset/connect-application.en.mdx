---
title: Connect a Knowledge base to an Application
description: Configure a Chat Agent, check answers and citations, and verify published access.
---

Connect a Knowledge base that has passed [retrieval testing](/en/guide/dataset/test-retrieval) to a Chat Agent, then check its answers and citations before publishing. You need Application creation or editing permission, read access to the Knowledge base, and an available chat model with quota. Creating a sharing channel also requires the corresponding management permission.

## 1. Connect the Knowledge base

1. Create a **Chat Agent** in the Studio, or open an existing Chat Agent.
2. Choose a chat model available to your team and select the target Knowledge base in its knowledge configuration. Check Collection and tag filters so they include the required sources.
3. Check the Application's search mode, reranking, minimum relevance, and citation limit against the retrieval settings you verified.
4. Define how to use the material. For the travel example, use this prompt:

```text
Answer questions using the retrieved travel policy. State the deadline and
required documents precisely. Cite the available sources. When the policy
does not cover a question, explain what information is missing.
```

If the Knowledge base is missing from the selector, check the current team, [Collection permissions](/en/guide/dataset/collection_permission), and Knowledge base access. For failed model calls, check [team models](/en/guide/workspace/models) and quota.

## 2. Debug answers and citations

Start a new conversation in the debug panel. For `travel-policy.txt`, use the questions below. For your own material, reuse the questions and expected clauses already verified in retrieval, plus one question outside the source’s coverage.

| Question | Passing result |
| --- | --- |
| How long after returning must I submit travel expenses? | 15 calendar days, with that deadline in the cited passage |
| Which documents does a claim require? | Invoice and approved travel request, both supported by the citation |
| What is the hotel accommodation allowance? | Explains that the material lacks the allowance policy |

Open the cited passage and check its source and text. If only the source name appears, continue through the citation-viewing options available to you; visibility depends on channel settings and permissions.

For an incorrect answer, inspect the material passed to the model in the run details. Missing clauses require [retrieval checks](/en/guide/dataset/test-retrieval) for scope and parameters. When the clauses are present, inspect the prompt and the chat model's interpretation. Rerun your fixed question set in a new conversation after each change.

## 3. Publish and verify

Save and [publish the current configuration](/en/guide/build/publish/versions), then create or open a [shared link](/en/guide/build/publish/link). Start a new conversation through the channel, repeat the questions, and inspect answers and citations. An Application with an initial published version still needs this new Knowledge base configuration published.

For differences after publishing, check the channel's Application, current published version, message history, and knowledge processing status. Success means debug and actual access pass the same fact checks.
