将构建就绪的知识库关联至应用后，模型能够在回答用户问题前自动检索相关分块，将客观知识作为上下文注入生成过程。

## 场景一：在对话 Agent 中挂载知识库

对话 Agent（包含标准版与 Agent V2）支持直接挂载一个或多个知识库：

1. 进入“应用”控制台，打开目标对话 Agent。
2. 在应用配置面板左侧找到“知识库”模块，点击“添加”按钮。
3. 勾选需要关联的知识库集合。支持同时勾选多个知识库（例如同时挂载《产品使用手册》与《企业服务政策》）。
4. **配置检索运行参数**：
   - **引用上限**：按分块大小与模型上下文容量设置检索内容的 Token 预算。
   - **最低相似度**：用标注问题校准阈值，并核对得分过滤是否实际启用。
   - **搜索模式**：选择“混合检索”，兼顾泛化理解与专名匹配。

## 场景二：在工作流中编排知识库检索节点

在工作流中，知识库检索被封装为独立的逻辑节点，能够与其他数据处理节点灵活连线：

1. 打开目标工作流画布，右键或从左侧组件库中选择“核心节点 → 知识库搜索”。
2. 将“知识库搜索”节点拖拽至画布，并与上游节点建立执行连线（例如从“流程开始”或“问题意图分类”节点连入）。
3. **节点参数配置**：
   - **用户问题输入**：点击变量选择器，绑定为“流程开始”节点的“用户问题”，或绑定上游“意图提取”节点的改写输出。
   - **关联数据集**：选择一个或多个目标知识库。
   - **搜索参数**：配置引用 Token 预算与相似度阈值。
4. **多知识库合并检索**：
   当工作流涉及多个知识库并行检索时，在下游添加“知识库搜索合并”节点，将多路候选结果统一进行二次去重与分数对齐。
5. **下游连接**：
   将“知识库搜索”节点的执行输出连接至“AI 对话”节点，并在 AI 对话节点的“引用知识”输入中绑定该检索节点输出的上下文内容。

![工作流中的知识库搜索节点配置](/imgs/current/node-dataset-search.png)

## 步骤三：编写包含事实约束的提示词模板

为保障知识库内容发挥最大效能，在 AI 对话节点的系统提示词中设计严谨的事实约束指令：

```text
你是一个专业的业务知识顾问。你的职责是基于下方提供的参考文档回答用户提问。

参考资料：

回答原则：
1. 提取参考资料中明确记载的事实进行陈述。
2. 保持语言严谨、客观，直接指出具体的政策规定与操作步骤。
3. 若参考资料中未记载用户所需的信息，明确告知“当前知识库暂未收录相关信息”，建议用户联系人工服务。
```

将检索结果绑定到 AI 对话节点的知识输入。专用的知识库引用提示词通过 `{{quote}}` 注入格式化分块，可保留默认模板或在引用设置中编辑。

![提示词引用模板与参数设计](/imgs/current/citation-prompt-settings.png)

## 步骤四：端到端验证与发布

1. 在右侧调试对话框中输入典型业务问题，发起端到端测试。
2. 展开“执行详情”，逐项检查：
   - 知识库检索节点是否被正确触发。
   - 召回的候选分块是否与问题高度贴合。
   - 最终回答是否完整吸纳了分块中的客观事实。
3. 确认效果符合预期后，点击工作台右上角的“发布”按钮，将当前应用配置固化为正式版本。
