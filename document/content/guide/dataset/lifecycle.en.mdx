Start with your current task. For a first visit, follow [your first knowledge-backed Q&A](/en/guide/getting-started/knowledge-qa) to complete the journey with a fictional travel policy.

## Create and choose an import method

Prepare creation or write permission, an available embedding model, and quota. Use [Import material](/en/guide/dataset/import-data) to choose local files, templates, web pages, or external sources.

**Checkpoint:** The preview preserves complete clauses, and the target Collection has been submitted for processing.

## Segmentation and processing

Content Collections hold Data chunks; folder Collections organize other Collections. Indexed chunks become available to retrieval. See [RAG fundamentals](/en/guide/dataset/rag) for the relationships.

Follow the [retrieval-readiness checks](/en/guide/dataset/import-data#3-confirm-retrieval-readiness) for progress, failures, and indexes.

**Checkpoint:** The Collection is enabled, source text is readable, processing is complete, and a known question retrieves the expected clause.

## Retrieval and application association

| Current task | Guide | Completion check |
| --- | --- | --- |
| Improve matching | [Test retrieval](/en/guide/dataset/test-retrieval) | Fixed questions retrieve correct material and parameter changes are recorded |
| Generate answers | [Connect an Application](/en/guide/dataset/connect-application) | Answers, citations, and missing-information behavior pass |
| Provide actual access | [Published versions](/en/guide/build/publish/versions) and [shared links](/en/guide/build/publish/link) | A new conversation passes the same fact checks |

See [search parameters](/en/guide/dataset/dataset_engine#search-parameters) for meanings and effective conditions.

## Maintenance

Use [Update material](/en/guide/dataset/update-data) to choose chunk editing, file replacement, or reprocessing. Verify the update in retrieval and a new conversation.

Manage scope with [Collection tags](/en/guide/dataset/collection_tags) and access with [Collection permissions](/en/guide/dataset/collection_permission). Check connected Applications before deleting content. For failed processing, empty results, or stale answers, follow [troubleshooting](/en/guide/dataset/faq), then rerun the fixed questions.

**Checkpoint:** New clauses take effect, old clauses leave the intended scope, and the remaining questions still pass.
