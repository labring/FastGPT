# 1. Introduction

When answers depend on company documents, product manuals, or changing information, retrieve relevant material before asking a language model to answer. This page explains that process and its boundaries in FastGPT.

## 1.1 Definition of RAG

Retrieval-Augmented Generation (RAG) supplies retrieved material as context for a generative model. Answer quality depends on source quality, retrieval coverage, prompts, and model capability. Generated answers still require verification.

# 2. Core Mechanisms of RAG

A basic RAG pipeline contains a retriever and a generator. Document parsing, permission filters, and evaluation also affect the outcome.

## 2.1 Retriever

The retriever returns candidate chunks for a question. Vector search uses an Embedding model to encode queries and content, then compares vectors. Full-text search matches terms. Hybrid search combines both result sets. See [Dataset Search](/en/guide/dataset/dataset_engine) for FastGPT settings.

## 2.2 Generator

The generator receives the user question, system prompt, history, and retrieved chunks. Its context window limits the combined input and output budget. Reserve enough space for the answer.

## 2.3 RAG Workflow

1. Import documents and complete parsing, chunking, and indexing.
2. Retrieve chunks using the question and search configuration.
3. Pass the selected chunks to AI Chat.
4. Check the answer, citations, and Run Details.

# 3. How RAG Works

The following describes the current default FastGPT retrieval pipeline. Behavior depends on search mode, model capabilities, and node configuration.

## 3.1 Retrieval Phase

FastGPT optionally expands the query, runs vector or full-text recall, combines candidates, and optionally reranks user-text recall. It then removes duplicates, applies score filtering, and trims results to the token budget. Collection scope, tag conditions, and readable-Collection permissions constrain candidate data. A vision model can describe image queries; an Embedding model supporting images can also retrieve by image vectors.

## 3.2 Generation Phase

Connect Dataset Search results to the Dataset quote input of AI Chat and define answer rules in the prompt. When evidence is missing, state its limits and provide clarification or a human handoff path. Retrieval scores measure matching; answer accuracy needs separate evaluation.

## 3.3 Multi-Turn Interaction and Feedback

History can help query expansion resolve references and context. Maintainers use user feedback to update documents, retrieval settings, or prompts, then validate changes with regression questions. Model training and fine-tuning require a separately configured process.

# 4. Advantages and Limitations of RAG

Evaluate both the retrieved evidence and the final answer.

## 4.1 Advantages

RAG lets maintainers update the material available to a model and expose cited sources. It suits company-specific information, source verification, and continuously maintained knowledge.

## 4.2 Limitations

Incorrect sources, missed retrieval, permissions, context truncation, and model interpretation can all affect an answer. Prepare test questions and handling paths for these cases.

#### 4.2.1 Retriever Dependency and Quality Issues

Check that the target document finished importing, then inspect search scope and recall results. Embedding models generate vectors; vector indexes store and retrieve them. Validate both configurations and their compatibility.

#### 4.2.2 Generator Computational Complexity and Performance Bottlenecks

Query expansion, reranking, and generation can add latency and cost. Locate the slow stage in Run Details before adjusting chunk count, quote budget, concurrency, or model selection.

#### 4.2.3 Dataset Updates and Maintenance

After updating documents, confirm that parsing and indexing finish, then verify related questions. See [Dataset Lifecycle](/en/guide/dataset/lifecycle). Freshness depends on the source and sync frequency.

#### 4.2.4 Generated Content Controllability and Transparency

Citations help users verify evidence. Check that the cited chunk supports the answer and retain relevant version, date, and source information. Sensitive workflows also need human review and access control.

# 5. RAG Improvement Directions

Use a stable set of real questions to compare changes. Record expected evidence, retrieved chunks, the final answer, and latency.

## 5.1 Data Collection and Dataset Construction

Choose authorized, reliable, maintainable sources. Remove duplicates, outdated content, and contradictions, and record the owner and update time.

## 5.2 Data Chunking and Content Management

Chunk according to document structure while retaining headings, conditions, and necessary context. Test representative questions to detect information split across chunks.

## 5.3 Retrieval Optimization

Validate permissions and search scope, then compare vector, full-text, hybrid, and reranked results. Score thresholds depend on the model and search mode; tune them using test results.

## 5.4 Answer Generation and Optimization

Define how the prompt uses evidence, presents citations, and handles missing information. Diagnose retrieval omissions and generation mistakes separately before changing settings.

## 5.5 RAG Pipeline

Complete [Your First Dataset Q&A](/en/guide/getting-started/knowledge-qa), then inspect matches with [Dataset Search](/en/guide/dataset/dataset_engine). Review logs and feedback after publishing, and repeat acceptance checks when documents change.

# 6. RAG Case Studies

Example: import a product refund policy and test three questions: the refund deadline, special-product exceptions, and a policy absent from the document. Check normal retrieval, conditional rules, and the response to missing evidence.

# 7. RAG Use Cases

Document coverage, permissions, and acceptance results determine suitability.

## 7.1 Intelligent Q&A Systems

Company help centers, internal-policy lookup, and product support can retrieve relevant clauses and provide sources for users to verify.

## 7.2 Information Retrieval and Text Generation

Retrieve relevant chunks before producing a summary or draft report. Cross-document tasks require checks for coverage, conflicting information, and citation support.

## 7.3 Other Use Cases

Image documents can use vision models and image-capable Embedding models. Capabilities depend on the selected model and import method. Medical and legal workflows require review by qualified professionals.

## 8. Summary

Start with one trusted document and a testable question set. Verify import, retrieval, answers, and citations before expanding the Dataset.
