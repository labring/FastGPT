自 4.15.0 的文档体系迁移后，当前端点参考通过生成文档维护。System OpenAPI 覆盖明确开放给 API Key 的契约；Dev API 面向内部开发接口，各自的鉴权条件以操作声明为准。

- 自部署：`<instance>/apidoc/systemopenapi`、`<instance>/apidoc/devapi`。
- 中国大陆云：[System OpenAPI](https://cloud.fastgpt.cn/apidoc/systemopenapi)、[Dev API](https://cloud.fastgpt.cn/apidoc/devapi)。
- 国际云：[System OpenAPI](https://cloud.fastgpt.io/apidoc/systemopenapi)、[Dev API](https://cloud.fastgpt.io/apidoc/devapi)。

首次接入可从 [API 入门：完成首次请求](/zh-CN/openapi/intro) 开始。
