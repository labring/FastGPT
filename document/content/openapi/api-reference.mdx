## 鉴权与身份规范

System OpenAPI 统一通过 HTTP 请求头传递 API Key：

```http
Authorization: Bearer <apiKey>
```

- **个人 API Key**：在 **账号 → API 密钥** 创建，按归属成员在当前团队中的资源权限执行。调用应用对话等接口时需显式传入 `appId`（或使用 OpenAI SDK 兼容格式 `Bearer <apiKey>-<appId>`）。支持开启 `authProxy`（FastGPT >= v4.15.0）代理同团队成员身份，详见[身份代理](/zh-CN/openapi/identity-proxy)。
- **应用 API Key**（FastGPT >= v4.18.0）：在 **工作台 → 目标应用 → 发布渠道 → API 访问 → 应用 Key** 创建，绑定单个应用，可用于该应用的对话、会话管理与日志接口且无需传 `appId`。支持通过 `customUid` 标记外部业务用户。
- **首次接入**：如需端到端示例与 OpenAI SDK 配置，请先阅读 [API 入门：完成首次请求](/zh-CN/openapi/intro)。

## 在线调试（Scalar）与 Dev API 说明

- **Scalar 在线调试台**：每篇接口参考页的「端点概览」均附带直达云服务 Scalar 调试台的锚点链接，可在同源环境下填入 API Key 直接测试请求。私有化部署实例请访问 `<instance>/apidoc/systemopenapi`（原始 JSON 位于 `<instance>/api/apidoc/systemopenapi.json`）。
- **Dev API（内部开发与管理员接口）**：面向源码二开、前端内部交互与 Root 运维管理，依赖登录态 Cookie（`fastgpt_token`）或 `rootkey`。为避免与 API Key 开放接口混用鉴权方式，Dev API 不收录于公开静态文档与默认 AI 语料，需在你所部署的实例上访问 `<instance>/apidoc/devapi`（或云服务对应 `/apidoc/devapi`）查阅。
- **历史接口迁移**：旧版手写参数归档见[历史 API 参数与迁移](/zh-CN/openapi/legacy)。
