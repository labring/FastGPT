## 迁移检查

1. 在部署实例的 `/apidoc/systemopenapi` 查找所用接口，核对方法、路径、鉴权与参数。
2. 为当前成员创建团队级 API Key；调用应用时显式提供 `body.appId`。
3. 兼容只能配置密钥的客户端时可使用 `<apiKey>-<appId>`。应用选择优先级为请求体、Bearer 后缀、旧密钥绑定。
4. 用固定输入验证结果、会话归属及错误处理，再迁移业务流量。

旧应用绑定密钥可以继续提供兼容的应用选择来源。身份代理需要启用该能力的团队级凭证，详见[身份代理](/zh-CN/openapi/identity-proxy)。
