## Authentication and Identity Rules

Pass your API key in the standard `Authorization` HTTP header:

```http
Authorization: Bearer <apiKey>
```

- **Personal API Key**: Created under **Account → API Keys**, executing with the issuing team member's resource permissions. Pass `appId` explicitly when calling application chat endpoints (or use the OpenAI SDK compatibility suffix `Bearer <apiKey>-<appId>`). Supports `authProxy` (FastGPT >= v4.15.0) to delegate identity to another active team member; see [API and MCP identity proxy](/en/openapi/identity-proxy).
- **App API Key** (FastGPT >= v4.18.0): Created under **Studio → Target App → Publish Channels → API Access → App keys**. Bound to a single application for chat, history, and log endpoints without passing `appId`, and supports `customUid` to identify external end users.
- **First Integration**: Start with [API getting started: make your first request](/en/openapi/intro) for end-to-end cURL and OpenAI SDK examples.

## Machine-Readable Discovery (GEO & Tooling)

- **Root LLM Index**: [https://doc.fastgpt.io/llms.txt](https://doc.fastgpt.io/llms.txt) (`/llms.txt`).
- **Single-Page Markdown**: Append `.md` to any endpoint reference URL (for example, `https://doc.fastgpt.io/openapi/reference/dataset-search/search.md`) or send `Accept: text/markdown`.

## Interactive Scalar Consoles and Dev API

- **Scalar API Explorer**: Each endpoint reference page includes a direct anchor link to the cloud Scalar explorer so you can supply an API key and test requests interactively. On self-hosted deployments, open `<instance>/apidoc/systemopenapi` (or `<instance>/api/apidoc/systemopenapi.json` for the instance-local JSON).
- **Dev API (Internal & Administrative Operations)**: Covers source-code customization, web UI RPCs, and root maintenance operations secured by session cookies (`fastgpt_token`) or `rootkey`. To keep authentication scopes unambiguous, Dev API is excluded from static public docs and default AI corpora; inspect it directly on your deployment at `<instance>/apidoc/devapi` (or on FastGPT Cloud `/apidoc/devapi`).
- **Legacy Reference**: Handwritten historical parameter docs remain archived in [Historical API parameters and migration](/en/openapi/legacy).
