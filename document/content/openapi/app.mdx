## 调用前检查

完成[首次请求](/zh-CN/openapi/intro)，确认当前成员拥有目标应用的读取权限。应用编辑与发布管理有各自权限要求。实际调用使用发布的运行配置，详情见[发布版本](/zh-CN/guide/build/publish/versions)。

## 对话应用

通过 `/api/v1/chat/completions` 指定 `appId`，在 `messages` 中传入用户问题。适用于当前接口支持的对话 Agent、对话 Agent V2 和工作流应用。界面选型与 API 中的资源标识分开理解：接口还识别工作流工具类型。

需要全局变量时在 `variables` 中提供与应用声明匹配的键和值。先用应用中的固定测试输入比对 API 结果，再加入业务侧数据。

```json
{
  "appId": "YOUR_APP_ID",
  "messages": [
    { "role": "user", "content": "请分析本季度的报销数据" }
  ],
  "variables": {
    "department": "技术研发部",
    "fiscalYear": 2026
  },
  "stream": false
}
```

## 工作流工具

工作流工具通过声明的工具输入和输出定义调用契约，也可独立执行。调用前在界面调试该工具，发布配置，再按当前生成参考提供 `appId` 与输入变量。检查详细返回结构中的工具输出，完整字段以部署实例的 System OpenAPI 为准。

## 运行与管理

需要会话复用和流式内容时阅读[对话集成](/zh-CN/openapi/chat)；需要处理交互节点挂起与文件传参时阅读[交互挂起恢复与文件传参](/zh-CN/openapi/interactive-and-variables)。

## 开放接口端点参考（应用日志与统计）

以下端点均支持团队级 `Authorization: Bearer <apiKey>` 鉴权（商业版统计接口以 `/api/proApi/` 为前缀）：

| 方法 | 完整路径 | 摘要与用途 | 核心请求参数（Query / Body） |
| --- | --- | --- | --- |
| `POST` | `/api/core/app/logs/list` | 分页获取应用对话日志列表 | Body: `appId`（必填）、`dateStart`、`dateEnd`、`sources`、`logUser`、`errorFilter`、`unreadOnly`、`offset` / `pageNum`、`pageSize` |
| `POST` | `/api/core/app/logs/getUsers` | 获取应用日志中的活跃用户列表 | Body: `appId`（必填）、`dateStart`、`dateEnd`、`searchKey` |
| `GET` | `/api/proApi/core/app/logs/getTotalData` | 获取应用总体统计数据（总用户数、总对话数、总积分消耗） | Query: `appId`（必填） |
| `POST` | `/api/proApi/core/app/logs/getChartData` | 获取应用时序图表统计数据（用户、对话、效果与消耗趋势） | Body: `appId`（必填）、`dateStart`、`dateEnd`、`source` |

[历史应用参数](/zh-CN/openapi/legacy/app)保留旧日志接口说明，供维护已有集成时对照。
