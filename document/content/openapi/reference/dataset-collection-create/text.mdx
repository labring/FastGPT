## 端点概览

- **HTTP 方法**：`POST`
- **请求路径**：`/api/core/dataset/collection/create/text`
- **所属模块**：知识库 / 集合创建
- **鉴权方式**：`Authorization: Bearer <apiKey>`—个人密钥（按归属团队成员资源权限校验）（详见 [API 入门：完成首次请求](/zh-CN/openapi/intro)）
- **在线调试**：[在云服务 Scalar 调试台打开](https://cloud.fastgpt.cn/apidoc/systemopenapi#tag/%E9%9B%86%E5%90%88%E5%88%9B%E5%BB%BA/POST/core/dataset/collection/create/text)（自部署实例请将域名替换为 `<instance>/apidoc/systemopenapi#tag/%E9%9B%86%E5%90%88%E5%88%9B%E5%BB%BA/POST/core/dataset/collection/create/text`）

## 接口说明与注意事项

将文本内容存储为文件后创建集合并触发训练

## 请求参数

### Request Body 请求体（`application/json`）

| 字段                        | 类型                 | 必填 | 默认值 | 约束与说明                                                                                                                           |
| --------------------------- | -------------------- | ---- | ------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| `trainingType`              | `string` (enum)      | 否   | -      | 训练类型。可选值：`chunk` , `qa` , `imageParse` , `backup` , `template` , `auto`                                                     |
| `chunkTriggerType`          | `string` (enum)      | 否   | -      | 分块触发时机。可选值：`minSize` , `forceChunk` , `maxSize`                                                                           |
| `chunkTriggerMinSize`       | `number`             | 否   | -      | 分块触发最小大小                                                                                                                     |
| `dataEnhanceCollectionName` | `boolean`            | 否   | -      | 增加集合名到分块里                                                                                                                   |
| `imageIndex`                | `boolean`            | 否   | -      | 图片索引                                                                                                                             |
| `autoIndexes`               | `boolean`            | 否   | -      | 自动生成索引                                                                                                                         |
| `indexPrefixTitle`          | `boolean`            | 否   | -      | 索引前缀标题                                                                                                                         |
| `chunkSettingMode`          | `string` (enum)      | 否   | -      | 系统参数/自定义参数。可选值：`auto` , `custom` , `intelligent`                                                                       |
| `chunkSplitMode`            | `string` (enum)      | 否   | -      | 分块拆分模式。可选值：`paragraph` , `size` , `char`                                                                                  |
| `paragraphChunkAIMode`      | `string` (enum)      | 否   | -      | 段落分块 AI 模式。可选值：`auto` , `force` , `forbid`                                                                                |
| `paragraphChunkDeep`        | `number`             | 否   | -      | 段落分块深度                                                                                                                         |
| `paragraphChunkMinSize`     | `number`             | 否   | -      | 段落分块最小大小                                                                                                                     |
| `chunkSize`                 | `number`             | 否   | -      | 分块大小                                                                                                                             |
| `chunkSplitter`             | `string`             | 否   | -      | 自定义最高优先分割符号                                                                                                               |
| `indexSize`                 | `number`             | 否   | -      | 索引大小                                                                                                                             |
| `qaPrompt`                  | `string`             | 否   | -      | QA 拆分提示词                                                                                                                        |
| `parentId`                  | `string \| null`     | 否   | -      | 父级目录 ID                                                                                                                          |
| `metadata`                  | `object`             | 否   | -      | 元数据                                                                                                                               |
| `customPdfParse`            | `boolean`            | 否   | -      | 自定义 PDF 解析                                                                                                                      |
| `datasetId`                 | `string`             | 是   | -      | 数据集 ID                                                                                                                            |
| `tags`                      | `string \| object[]` | 否   | -      | 标签列表。字符串元素为旧格式标签名（按名称归并到 default_tag array 标签）；对象元素为 \{ tag: 标签名, value: 标签值 \}，按标签名解析 |
| `name`                      | `string`             | 是   | -      | 集合名称                                                                                                                             |
| `text`                      | `string`             | 是   | -      | 文本内容                                                                                                                             |

## 请求示例

调用前请将 `YOUR_API_KEY` 与示例 ID 替换为真实值；私有化部署实例请将基础域名替换为 `<instance>/api`。

### cURL 请求示例

```bash
curl --fail-with-body -X POST "https://cloud.fastgpt.cn/api/core/dataset/collection/create/text" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "datasetId": "string",
  "name": "string",
  "text": "string"
}'
```

### 最小合法 JSON 请求体示例

```json
{
  "datasetId": "string",
  "name": "string",
  "text": "string"
}
```

## 响应结构与示例

除兼容 OpenAI 协议的对话补全或二进制下载接口外，成功响应统一包裹在 `{ "code": 200, "statusText": "", "message": "", "data": ... }` 标准结构中；下方 `200` 字段表对应 `data` 载荷结构（无数据返回时 `data` 为 `null`）。

### HTTP 200

成功返回集合 ID 及数据插入结果

返回标准成功响应（`data: null`）。
