## Endpoint Overview

- **Method** : `POST`
- **Path** : `/api/core/dataset/collection/create`
- **Module** : Datasets / Create Collections
- **Authentication** : `Authorization: Bearer <apiKey>`—Personal API Key (access scoped by team member permissions) (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E9%9B%86%E5%90%88%E5%88%9B%E5%BB%BA/POST/core/dataset/collection/create) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E9%9B%86%E5%90%88%E5%88%9B%E5%BB%BA/POST/core/dataset/collection/create` )

## Description & Notes

Create an empty virtual dataset collection or folder.

## Request Parameters

### Request Body ( `application/json` )

| Field               | Type                 | Required | Default | Constraints & Description                                                                                                                                                                                                                                                                                                  |
| ------------------- | -------------------- | -------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `datasetId`         | `string`             | Yes      | -       | Dataset ID                                                                                                                                                                                                                                                                                                                 |
| `parentId`          | `string \| null`     | No       | -       | Parent folder ID                                                                                                                                                                                                                                                                                                           |
| `name`              | `string`             | Yes      | -       | Collection name                                                                                                                                                                                                                                                                                                            |
| `type`              | `string` (enum)      | Yes      | -       | Collection type ( `folder` or `virtual` manual collection). Allowed values: `folder` , `virtual`                                                                                                                                                                                                                           |
| `tags`              | `string \| object[]` | No       | -       | List of collection tags. String items map to legacy `default_tag` tags; object items `{ tag, value }` resolve by tag name.                                                                                                                                                                                                 |
| `inheritPermission` | `boolean`            | No       | -       | Whether to inherit parent permissions (default `true` , applies only when `type=folder` ). `true` inherits from parent/dataset; `false` creates an isolated folder with creator `owner` permission only (requires collection-level permissions enabled on the dataset, otherwise returns `collectionPermissionDisabled` ). |
