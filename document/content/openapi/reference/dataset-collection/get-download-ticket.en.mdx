## Description & Notes

Validate access permissions and issue a short-lived single-use ticket for batch downloading dataset collections.

## Request Parameters

### Request Body ( `application/json` )

| Field           | Type       | Required | Default | Constraints & Description                       |
| --------------- | ---------- | -------- | ------- | ----------------------------------------------- |
| `datasetId`     | `string`   | Yes      | -       | Dataset ID. pattern: `^[0-9a-fA-F]{24}$`        |
| `collectionIds` | `string[]` | Yes      | -       | List of collection IDs to download. minItems: 1 |
