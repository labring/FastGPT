## Endpoint Overview

- **Method** : `POST`
- **Path** : `/api/core/dataset/collection/update`
- **Module** : Datasets / Collections
- **Authentication** : `Authorization: Bearer <apiKey>`—Personal API Key (access scoped by team member permissions) (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E9%9B%86%E5%90%88%E7%AE%A1%E7%90%86/POST/core/dataset/collection/update) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E9%9B%86%E5%90%88%E7%AE%A1%E7%90%86/POST/core/dataset/collection/update` )

## Description & Notes

Update collection metadata by collection ID or `datasetId` + `externalFileId` (requires collection write permission). Changing `parentId` moves the collection, requiring manage permissions on source and target parents (plus team dataset creation permission when moving between root and a folder); `inheritPermission` is not accepted and existing inheritance mode is preserved.

## Request Parameters

### Request Body ( `application/json` )

#### Shared Parameters Across Branches

| Field        | Type                 | Required | Default | Constraints & Description                                           |
| ------------ | -------------------- | -------- | ------- | ------------------------------------------------------------------- |
| `parentId`   | `string \| null`     | No       | -       | Parent folder ID                                                    |
| `name`       | `string`             | No       | -       | Collection name                                                     |
| `tags`       | `string \| object[]` | No       | -       | Tag list (supports legacy string names or `{ tag, value }` objects) |
| `forbid`     | `boolean`            | No       | -       | Whether the collection is disabled                                  |
| `createTime` | `string`             | No       | -       | Creation time                                                       |

**Mutually Exclusive Branches ( `anyOf` )**

- **Identify by `id`**

| Field            | Type     | Required | Default | Constraints & Description                                                                             |
| ---------------- | -------- | -------- | ------- | ----------------------------------------------------------------------------------------------------- |
| `id`             | `string` | Yes      | -       | Collection ID (mutually exclusive with `datasetId` + `externalFileId` ). pattern: `^[0-9a-fA-F]{24}$` |
| `datasetId`      | `string` | No       | -       | Dataset ID used together with `externalFileId`                                                        |
| `externalFileId` | `string` | No       | -       | External file ID used together with `datasetId`                                                       |

- **Identify by `datasetId` & `externalFileId`**

| Field            | Type     | Required | Default | Constraints & Description                                                                             |
| ---------------- | -------- | -------- | ------- | ----------------------------------------------------------------------------------------------------- |
| `datasetId`      | `string` | Yes      | -       | Dataset ID used together with `externalFileId`                                                        |
| `externalFileId` | `string` | Yes      | -       | External file ID used together with `datasetId`                                                       |
| `id`             | `string` | No       | -       | Collection ID (mutually exclusive with `datasetId` + `externalFileId` ). pattern: `^[0-9a-fA-F]{24}$` |
