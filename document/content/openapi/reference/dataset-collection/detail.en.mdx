## Endpoint Overview

- **Method** : `GET`
- **Path** : `/api/core/dataset/collection/detail`
- **Module** : Datasets / Collections
- **Authentication** : `Authorization: Bearer <apiKey>`—Personal API Key (access scoped by team member permissions) (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E9%9B%86%E5%90%88%E7%AE%A1%E7%90%86/GET/core/dataset/collection/detail) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E9%9B%86%E5%90%88%E7%AE%A1%E7%90%86/GET/core/dataset/collection/detail` )

## Description & Notes

Retrieve detailed collection metadata including index counts, error counts, and file details (requires dataset and collection read access).

## Request Parameters

### Query Parameters

| Field | Type     | Required | Default | Constraints & Description |
| ----- | -------- | -------- | ------- | ------------------------- |
| `id`  | `string` | Yes      | -       | Collection ID             |
