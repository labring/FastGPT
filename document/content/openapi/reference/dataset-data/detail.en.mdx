## Endpoint Overview

- **Method** : `GET`
- **Path** : `/api/core/dataset/data/detail`
- **Module** : Datasets / Dataset Data
- **Authentication** : `Authorization: Bearer <apiKey>`—Personal API Key (access scoped by team member permissions) (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E6%95%B0%E6%8D%AE%E7%AE%A1%E7%90%86/GET/core/dataset/data/detail) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E6%95%B0%E6%8D%AE%E7%AE%A1%E7%90%86/GET/core/dataset/data/detail` )

## Description & Notes

Retrieve detailed content and vector indexes for a single dataset data item.

## Request Parameters

### Query Parameters

| Field | Type     | Required | Default | Constraints & Description                  |
| ----- | -------- | -------- | ------- | ------------------------------------------ |
| `id`  | `string` | Yes      | -       | Data item ID. pattern: `^[0-9a-fA-F]{24}$` |

## Request Examples

Replace `YOUR_API_KEY` and placeholder IDs before running. Self-hosted users should replace the base URL with `<instance>/api` .

### cURL Example

```bash
curl --fail-with-body -X GET "https://cloud.fastgpt.io/api/core/dataset/data/detail?id=68ad85a7463006c963799a05" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
