## Endpoint Overview

- **Method** : `GET`
- **Path** : `/api/core/ai/model/catalog`
- **Module** : Core Features / Models
- **Authentication** : `Authorization: Bearer <apiKey>`—Personal API Key (access scoped by team member permissions) (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E6%A8%A1%E5%9E%8B%E7%AE%A1%E7%90%86/GET/core/ai/model/catalog) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E6%A8%A1%E5%9E%8B%E7%AE%A1%E7%90%86/GET/core/ai/model/catalog` )

## Description & Notes

Returns available models, providers, and effective default model IDs for the authenticated member or share-link identity in a single request, with content version negotiation. Passing `orderBy=custom` orders by own team models, shared team models, and system models sorted by `rank` ; omitting preserves runtime order. Members may pass `includeSourceMember=true` to attach creator details (always returning the full catalog; ignored for share links).

## Request Parameters

### Query Parameters

| Field                 | Type       | Required | Default | Constraints & Description                                                                                                                |
| --------------------- | ---------- | -------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `version`             | `string`   | No       | -       | Client-cached catalog version hash. minLength: 1                                                                                         |
| `includeSourceMember` | `boolean`  | No       | -       | Attach source member metadata (members only; always returns the full catalog without version cache)                                      |
| `orderBy`             | `"custom"` | No       | -       | Catalog display sorting: `custom` orders own team, shared team, and system models by rank; omit to keep runtime order. Fixed: `"custom"` |
| `outLinkAuthData`     | `string`   | No       | -       | Share-link auth payload used to evaluate permissions via the link publisher identity                                                     |

## Request Examples
