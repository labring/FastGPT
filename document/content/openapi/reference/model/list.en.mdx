## Endpoint Overview

- **Method** : `GET`
- **Path** : `/api/core/ai/model/list`
- **Module** : Core Features / Models
- **Authentication** : No authentication required (public endpoint) (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E6%A8%A1%E5%9E%8B%E7%AE%A1%E7%90%86/GET/core/ai/model/list) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E6%A8%A1%E5%9E%8B%E7%AE%A1%E7%90%86/GET/core/ai/model/list` )

## Description & Notes

Return minimal active system model and pricing metadata for public pricing pages without authentication.

## Request Parameters

This endpoint does not require request parameters or a request body.

## Request Examples

Replace `YOUR_API_KEY` and placeholder IDs before running. Self-hosted users should replace the base URL with `<instance>/api` .

### cURL Example

```bash
curl --fail-with-body -X GET "https://cloud.fastgpt.io/api/core/ai/model/list"
```
