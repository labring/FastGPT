## Endpoint Overview

- **Method** : `POST`
- **Path** : `/api/core/app/logs/search`
- **Module** : Applications / App Logs
- **Authentication** : `Authorization: Bearer <apiKey>`—Supports **App API Key** ( `appId` optional) and **Personal API Key** ( `appId` required) (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E5%BA%94%E7%94%A8%E6%97%A5%E5%BF%97/POST/core/app/logs/search) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E5%BA%94%E7%94%A8%E6%97%A5%E5%BF%97/POST/core/app/logs/search` )

## Description & Notes

Search app chat logs with cursor-based pagination. The page size is fixed at 50 and the response does not include a total count.

## Request Parameters

### Request Body ( `application/json` )

| Field              | Type               | Required | Default | Constraints & Description                                                                                                                                                  |
| ------------------ | ------------------ | -------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `feedbackType`     | `string` (enum)    | No       | -       | Feedback filter: `all` (all logs), `has_feedback` (logs with feedback), `good` (likes), `bad` (dislikes). Allowed values: `all` , `has_feedback` , `good` , `bad`          |
| `unreadOnly`       | `boolean`          | No       | -       | Whether to return only unread feedback (ignored when `feedbackType` is `all` )                                                                                             |
| `errorFilter`      | `string` (enum)    | No       | -       | Error filter: `all` (all logs), `has_error` (error logs only). Allowed values: `all` , `has_error`                                                                         |
| `dateStart`        | `string`           | Yes      | -       | Start time                                                                                                                                                                 |
| `dateEnd`          | `string`           | Yes      | -       | End time                                                                                                                                                                   |
| `sources`          | `string` (enum)[]` | No       | -       | Chat source filter                                                                                                                                                         |
| `tmbIds`           | `string[]`         | No       | -       | List of team member IDs                                                                                                                                                    |
| `outLinkUids`      | `string[]`         | No       | -       | List of external user IDs                                                                                                                                                  |
| `chatSearch`       | `string`           | No       | -       | Search term. Use with `searchType` to search titles or match a session ID exactly.                                                                                         |
| `searchType`       | `string` (enum)    | No       | -       | Search mode. Use `title` to search titles or `chatId` to match a session ID exactly. Omit this field to use the legacy search behavior. Allowed values: `title` , `chatId` |
| `cursor`           | `object`           | No       | -       | The `nextCursor` from the previous response. Omit this field on the first page and pass the cursor unchanged for subsequent pages.                                         |
| `cursor.timestamp` | `integer`          | Yes      | -       | Cursor timestamp in milliseconds. min: 0; max: 9007199254740991                                                                                                            |
| `cursor.id`        | `string`           | Yes      | -       | Log ID in the cursor. pattern: `^[a-f\d]{24}$`                                                                                                                             |

**Mutually Exclusive Branches ( `anyOf` )**

- **Explicit App ID**

Personal API keys and login sessions must pass `appId` ; an App API Key always uses the bound application.

| Field   | Type     | Required | Default | Constraints & Description    |
| ------- | -------- | -------- | ------- | ---------------------------- |
| `appId` | `string` | Yes      | -       | Application ID. minLength: 1 |

- **App API Key (no appId required)**

When authorizing with an app-bound App API Key, omit `appId` and `sourceType` ; the server resolves the bound app with `sourceType` fixed to `app` . Personal keys and login sessions cannot omit `appId` , and an explicit `appId` does not override an App API Key binding.

No extra branch-specific fields are required.
