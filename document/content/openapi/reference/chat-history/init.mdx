## 端点概览

- **HTTP 方法**：`GET`
- **请求路径**：`/api/core/chat/init`
- **所属模块**：对话 / 会话管理
- **鉴权方式**：`Authorization: Bearer <apiKey>`—支持 **应用 API Key**（无需 `appId`）与 **个人密钥**（需传 `appId`）；另支持 `authProxy` 团队成员代理（详见 [API 入门：完成首次请求](/zh-CN/openapi/intro)）
- **在线调试**：[在云服务 Scalar 调试台打开](https://cloud.fastgpt.cn/apidoc/systemopenapi#tag/%E4%BC%9A%E8%AF%9D%E7%AE%A1%E7%90%86/GET/core/chat/init)（自部署实例请将域名替换为 `<instance>/apidoc/systemopenapi#tag/%E4%BC%9A%E8%AF%9D%E7%AE%A1%E7%90%86/GET/core/chat/init`）

## 接口说明与注意事项

初始化应用会话或 Skill 编辑调试会话，返回会话配置、变量和已有会话状态。

Query 身份二选一：应用会话传 appId；Skill 调试会话传 skillId，两种模式均需传 chatId。使用登录态或接口允许的 API Key 鉴权；同时传入 appId 和 skillId 时优先使用 skillId。

应用辅助生成会话通过 appId 与 sourceType 指定，sourceType 支持 chatAgentHelper、workflowBuilder；普通应用会话省略 sourceType。

外链分享会话使用 GET /api/core/chat/outLink/init，传入 JSON 序列化的 outLinkAuthData。

Skill 编辑沙盒的启动、恢复或复用使用 POST /api/core/ai/skill/runtime/init，与本接口的会话初始化用途不同。

## 请求参数

### Query 查询参数

#### 各分支公共字段

| 字段                  | 类型      | 必填 | 默认值 | 约束与说明                           |
| --------------------- | --------- | ---- | ------ | ------------------------------------ |
| `chatId`              | `string`  | 是   | -      | 会话 ID。最小长度：1；最大长度：1024 |
| `loadCustomFeedbacks` | `boolean` | 否   | -      | 是否加载自定义反馈                   |

**互斥参数分支（`anyOf` 选填其一）**

- **应用会话**

通过 appId 定位会话。接口同时支持 API Key 和登录态时，Authorization 优先于 token/Cookie。

| 字段         | 类型            | 必填 | 默认值 | 约束与说明                                                                                                                      |
| ------------ | --------------- | ---- | ------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `appId`      | `string`        | 是   | -      | 应用 ID，使用接口允许的请求头凭证鉴权。正则：`^[0-9a-fA-F]{24}$`                                                                |
| `sourceType` | `string` (enum) | 否   | -      | appId 对应的会话资源类型。缺省为 App 会话；辅助生成会话传对应 sourceType。可选值：`app` , `chatAgentHelper` , `workflowBuilder` |

**默认身份**: 不传 customUid 和 authProxy，沿用凭证对应的团队成员身份。适用于直接以当前鉴权成员调用应用。

**自定义使用者**: 通过 customUid 对接自己平台的使用者，不改变鉴权成员及权限。发起对话时作为使用者和工作流 userId；管理对话时按该值限制使用者范围。

| 字段        | 类型     | 必填 | 默认值 | 约束与说明                                                                                                                                                                                                                   |
| ----------- | -------- | ---- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `customUid` | `string` | 是   | -      | 仅普通应用的 API Key 调用支持。精确匹配对话的外部使用者 ID（outLinkUid），不匹配 tmbId；省略时保留原访问范围，传入时限制读取、修改及删除。最长 1024 字符，不接受空字符串或 null，不改变鉴权成员。最小长度：1；最大长度：1024 |

**代理团队成员**: 通过 authProxy 代表同团队成员执行，解析出有效 tmbId 后按该成员权限校验。仅开启代理权限的个人密钥可用，与 customUid 互斥。

| 字段        | 类型     | 必填 | 默认值 | 约束与说明                                                                        |
| ----------- | -------- | ---- | ------ | --------------------------------------------------------------------------------- |
| `authProxy` | `string` | 是   | -      | 代理身份的 JSON 字符串，例如 \{"tmbId":"团队成员 ID"\} 或 \{"username":"用户名"\} |

- **Skill 调试会话**

通过 skillId 定位调试会话，优先于 appId 并忽略其 sourceType，使用接口允许的请求头凭证鉴权。

| 字段      | 类型     | 必填 | 默认值 | 约束与说明                                                                  |
| --------- | -------- | ---- | ------ | --------------------------------------------------------------------------- |
| `skillId` | `string` | 是   | -      | Skill Edit 调试 ID，使用接口允许的请求头凭证鉴权。正则：`^[0-9a-fA-F]{24}$` |

- **应用 API Key（无需 appId）**

Authorization 使用绑定应用的 APP API Key 时无需传 appId 或 sourceType，服务端从 Key 绑定取得应用，sourceType 固定为 app。个人密钥和登录态不能使用此省略方式；显式传入 appId 时仍以 Key 绑定为准。

**默认身份**: 不传 customUid 和 authProxy，沿用凭证对应的团队成员身份。适用于直接以当前鉴权成员调用应用。

**自定义使用者**: 通过 customUid 对接自己平台的使用者，不改变鉴权成员及权限。发起对话时作为使用者和工作流 userId；管理对话时按该值限制使用者范围。

| 字段        | 类型     | 必填 | 默认值 | 约束与说明                                                                                                                                                                                                                   |
| ----------- | -------- | ---- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `customUid` | `string` | 是   | -      | 仅普通应用的 API Key 调用支持。精确匹配对话的外部使用者 ID（outLinkUid），不匹配 tmbId；省略时保留原访问范围，传入时限制读取、修改及删除。最长 1024 字符，不接受空字符串或 null，不改变鉴权成员。最小长度：1；最大长度：1024 |
