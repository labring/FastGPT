## Endpoint Overview

- **Method** : `GET`
- **Path** : `/api/core/dataset/detail`
- **Module** : Datasets / Datasets
- **Authentication** : `Authorization: Bearer <apiKey>`—Personal API Key (access scoped by team member permissions) (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E7%AE%A1%E7%90%86/GET/core/dataset/detail) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E7%AE%A1%E7%90%86/GET/core/dataset/detail` )

## Description & Notes

Retrieve full dataset configuration including model bindings, permissions, and synchronization status.

## Request Parameters

### Query Parameters

| Field | Type     | Required | Default | Constraints & Description                |
| ----- | -------- | -------- | ------- | ---------------------------------------- |
| `id`  | `string` | Yes      | -       | Dataset ID. pattern: `^[0-9a-fA-F]{24}$` |

## Request Examples

Replace `YOUR_API_KEY` and placeholder IDs before running. Self-hosted users should replace the base URL with `<instance>/api` .

### cURL Example

```bash
curl --fail-with-body -X GET "https://cloud.fastgpt.io/api/core/dataset/detail?id=68ad85a7463006c963799a05" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
