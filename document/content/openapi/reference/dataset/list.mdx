## 端点概览

- **HTTP 方法**：`POST`
- **请求路径**：`/api/core/dataset/list`
- **所属模块**：知识库 / 知识库管理
- **鉴权方式**：`Authorization: Bearer <apiKey>`—个人密钥（按归属团队成员资源权限校验）（详见 [API 入门：完成首次请求](/zh-CN/openapi/intro)）
- **在线调试**：[在云服务 Scalar 调试台打开](https://cloud.fastgpt.cn/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E7%AE%A1%E7%90%86/POST/core/dataset/list)（自部署实例请将域名替换为 `<instance>/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E7%AE%A1%E7%90%86/POST/core/dataset/list`）

## 接口说明与注意事项

已弃用，请使用 POST /core/dataset/listV2。旧接口保留兼容，返回当前用户有权限访问的知识库数组，支持按类型和关键词筛选；V2 返回分页结构 \{ list, total \}

## 请求参数

### Request Body 请求体（`application/json`）

| 字段        | 类型              | 必填 | 默认值             | 约束与说明                                                                                                                                                                                                       |
| ----------- | ----------------- | ---- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `parentId`  | `string \| null`  | 否   | -                  | 父级文件夹 ID,null 或不传表示根目录                                                                                                                                                                              |
| `type`      | `string \| array` | 否   | -                  | 知识库类型筛选                                                                                                                                                                                                   |
| `searchKey` | `string`          | 否   | -                  | 搜索关键词,按名称和简介模糊匹配                                                                                                                                                                                  |
| `sort`      | `string` (enum)   | 否   | `"updateTimeDesc"` | 列表排序，缺省按最近修改倒序。可选值：`updateTimeDesc` (按修改时间倒序，最近修改的排在前面（默认）), `createTimeDesc` (按创建时间倒序，最新创建的排在前面), `createTimeAsc` (按创建时间升序，最早创建的排在前面) |
| `tmbIds`    | `string[]`        | 否   | -                  | 按创建者筛选；空数组返回空列表                                                                                                                                                                                   |
