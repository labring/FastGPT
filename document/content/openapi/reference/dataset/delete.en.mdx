## Description & Notes

Delete a dataset or folder and all nested child datasets (requires owner permission).

## Request Parameters

### Query Parameters

| Field | Type     | Required | Default | Constraints & Description                |
| ----- | -------- | -------- | ------- | ---------------------------------------- |
| `id`  | `string` | Yes      | -       | Dataset ID. pattern: `^[0-9a-fA-F]{24}$` |
