## Endpoint Overview

- **Method** : `POST`
- **Path** : `/api/core/dataset/listV2`
- **Module** : Datasets / Datasets
- **Authentication** : `Authorization: Bearer <apiKey>`—Personal API Key (access scoped by team member permissions) (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E7%AE%A1%E7%90%86/POST/core/dataset/listV2) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E7%AE%A1%E7%90%86/POST/core/dataset/listV2` )

## Description & Notes

Queries accessible datasets with pagination or exact `datasetIds` lookup. When `datasetIds` is passed, `parentId` and pagination parameters are ignored while shared filters remain active.

## Request Parameters

### Request Body ( `application/json` )

#### Shared Parameters Across Branches

| Field           | Type              | Required | Default            | Constraints & Description                                                                                                                                                                                                                                                                                 |
| --------------- | ----------------- | -------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `type`          | `string \| array` | No       | -                  | Dataset type filter                                                                                                                                                                                                                                                                                       |
| `searchKey`     | `string`          | No       | -                  | Search keyword matching dataset name and introduction                                                                                                                                                                                                                                                     |
| `sort`          | `string` (enum)   | No       | `"updateTimeDesc"` | Sort order; defaults to most recently updated descending. Allowed values: `updateTimeDesc` (Sort by update time descending (most recently modified first, default)), `createTimeDesc` (Sort by creation time descending (newest first)), `createTimeAsc` (Sort by creation time ascending (oldest first)) |
| `tmbIds`        | `string[]`        | No       | -                  | Filter by creator member IDs; an empty array returns an empty list                                                                                                                                                                                                                                        |
| `withAppCount`  | `boolean`         | No       | -                  | Whether to count referencing published apps (default `false` ; visible to non-folder owners only)                                                                                                                                                                                                         |
| `withFileCount` | `boolean`         | No       | -                  | Whether to compute total non-folder collection count across all depths (default `false` )                                                                                                                                                                                                                 |

**Mutually Exclusive Branches ( `anyOf` )**

- **Lookup by IDs**

| Field        | Type       | Required | Default | Constraints & Description                                                                                                                                                           |
| ------------ | ---------- | -------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `datasetIds` | `string[]` | Yes      | -       | Exact lookup by up to 500 dataset or folder IDs; takes precedence over pagination and strips `parentId` /pagination fields while keeping shared filters. minItems: 1; maxItems: 500 |

- **Paginated Lookup**

| Field      | Type             | Required | Default | Constraints & Description                                                                                                                |
| ---------- | ---------------- | -------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `parentId` | `string \| null` | No       | -       | Parent folder ID ( `null` or empty for root); omit to search across all readable datasets, or set to restrict search to a folder subtree |

**Offset Pagination** : Specify the 0-based starting offset; when both `offset` and `pageNum` are provided, `offset` takes precedence.

| Field      | Type      | Required | Default | Constraints & Description                                                                                                                        |
| ---------- | --------- | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `offset`   | `integer` | Yes      | -       | **Mutually Exclusive Group: Pagination Parameters** . 0-based offset. min: 0; max: 9007199254740991                                              |
| `pageSize` | `integer` | No       | `20`    | **Mutually Exclusive Group: Pagination Parameters** . Items per page. Defaults to 20, capped at 500 (larger values are clamped to 500). max: 500 |

**Page-Number Pagination** : Paginate by page number (starts at page 1); `pageSize` controls items per page.

| Field      | Type      | Required | Default | Constraints & Description                                                                                                                        |
| ---------- | --------- | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `pageNum`  | `integer` | No       | `1`     | **Mutually Exclusive Group: Pagination Parameters** . 1-based page number; ignored when `offset` is provided. max: 9007199254740991              |
| `pageSize` | `integer` | No       | `20`    | **Mutually Exclusive Group: Pagination Parameters** . Items per page. Defaults to 20, capped at 500 (larger values are clamped to 500). max: 500 |

## Request Examples

Replace `YOUR_API_KEY` and placeholder IDs before running. Self-hosted users should replace the base URL with `<instance>/api` .

### cURL Example

```bash
curl --fail-with-body -X POST "https://cloud.fastgpt.io/api/core/dataset/listV2" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "datasetIds": [
    "68ad85a7463006c963799a05"
  ]
}'
```

  "datasetIds": ["68ad85a7463006c963799a05"]
