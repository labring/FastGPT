## 端点概览

- **HTTP 方法**：`POST`
- **请求路径**：`/api/core/dataset/batch/delete`
- **所属模块**：知识库 / 知识库管理
- **鉴权方式**：`Authorization: Bearer <apiKey>`—个人密钥（按归属团队成员资源权限校验）（详见 [API 入门：完成首次请求](/zh-CN/openapi/intro)）
- **在线调试**：[在云服务 Scalar 调试台打开](https://cloud.fastgpt.cn/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E7%AE%A1%E7%90%86/POST/core/dataset/batch/delete)（自部署实例请将域名替换为 `<instance>/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E7%AE%A1%E7%90%86/POST/core/dataset/batch/delete`）

## 接口说明与注意事项

批量删除知识库或文件夹，具体子树处理和异步清理由知识库模块负责

## 请求参数

### Request Body 请求体（`application/json`）

| 字段  | 类型       | 必填 | 默认值 | 约束与说明                              |
| ----- | ---------- | ---- | ------ | --------------------------------------- |
| `ids` | `string[]` | 是   | -      | 需要批量操作的资源 ID 列表。最少项数：1 |

## 请求示例

调用前请将 `YOUR_API_KEY` 与示例 ID 替换为真实值；私有化部署实例请将基础域名替换为 `<instance>/api`。

### cURL 请求示例

```bash
curl --fail-with-body -X POST "https://cloud.fastgpt.cn/api/core/dataset/batch/delete" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "ids": [
    "68ad85a7463006c963799a05"
  ]
}'
```

### 最小合法 JSON 请求体示例

```json
{
  "ids": ["68ad85a7463006c963799a05"]
}
```

## 响应结构与示例

除兼容 OpenAI 协议的对话补全或二进制下载接口外，成功响应统一包裹在 `{ "code": 200, "statusText": "", "message": "", "data": ... }` 标准结构中；下方 `200` 字段表对应 `data` 载荷结构（若契约未声明具体载荷结构，请以上方状态描述及实际响应为准）。

### HTTP 200

成功删除知识库

**Content-Type** : `application/json`

| 字段          | 类型       | 必填 | 默认值 | 约束与说明                                                  |
| ------------- | ---------- | ---- | ------ | ----------------------------------------------------------- |
| `successIds`  | `string[]` | 是   | -      | 成功处理的请求资源 ID 列表                                  |
| `failedIds`   | `string[]` | 是   | -      | 处理失败的请求资源 ID 列表                                  |
| `affectedIds` | `string[]` | 是   | -      | 实际发生变化的资源 ID 列表；删除操作可包含被删除的子资源 ID |
