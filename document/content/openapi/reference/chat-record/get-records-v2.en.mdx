## Endpoint Overview

- **Method** : `POST`
- **Path** : `/api/core/chat/record/getRecords_v2`
- **Module** : Chat / Chat Records
- **Authentication** : `Authorization: Bearer <apiKey>`—Supports **App API Key** ( `appId` optional) and **Personal API Key** ( `appId` required); also supports `authProxy` team member proxy and `outLinkAuthData` share link (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E5%AF%B9%E8%AF%9D%E7%AE%A1%E7%90%86/POST/core/chat/record/getRecords_v2) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E5%AF%B9%E8%AF%9D%E7%AE%A1%E7%90%86/POST/core/chat/record/getRecords_v2` )

## Description & Notes

Fetches the latest messages by default in chronological order. Provide at most one of `prevId` (targets Human turn boundary), `nextId` , or `initialId` (targets AI turn boundary). Pass `prevCursor` / `nextCursor` directly to `prevId` / `nextId` ( `null` when no further page exists). Returned count may slightly exceed `pageSize` to complete turn boundaries.
