## Endpoint Overview

- **Method** : `POST`
- **Path** : `/api/core/chat/record/getCollectionQuote`
- **Module** : Chat / Chat Records
- **Authentication** : `Authorization: Bearer <apiKey>`—Supports **App API Key** ( `appId` optional) and **Personal API Key** ( `appId` required); also supports `authProxy` team member proxy and `outLinkAuthData` share link (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E5%AF%B9%E8%AF%9D%E7%AE%A1%E7%90%86/POST/core/chat/record/getCollectionQuote) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E5%AF%B9%E8%AF%9D%E7%AE%A1%E7%90%86/POST/core/chat/record/getCollectionQuote` )

## Description & Notes

Paginate forward or backward around a cited chunk index inside a collection (requires chat access).
