## 端点概览

- **HTTP 方法**：`POST`
- **请求路径**：`/api/core/chat/record/getRecords_v2`
- **所属模块**：对话 / 对话管理
- **鉴权方式**：`Authorization: Bearer <apiKey>`—支持 **应用 API Key**（无需 `appId`）与 **个人密钥**（需传 `appId`）；另支持 `authProxy` 团队成员代理与 `outLinkAuthData` 外链分享（详见 [API 入门：完成首次请求](/zh-CN/openapi/intro)）
- **在线调试**：[在云服务 Scalar 调试台打开](https://cloud.fastgpt.cn/apidoc/systemopenapi#tag/%E5%AF%B9%E8%AF%9D%E7%AE%A1%E7%90%86/POST/core/chat/record/getRecords_v2)（自部署实例请将域名替换为 `<instance>/apidoc/systemopenapi#tag/%E5%AF%B9%E8%AF%9D%E7%AE%A1%E7%90%86/POST/core/chat/record/getRecords_v2`）

## 接口说明与注意事项

默认读取最新消息，按时间正序返回。prevId、nextId、initialId 三选一，也可均不传；角色由方向确定，prevId 定位 Human，nextId 和 initialId 定位 AI。将 prevCursor/nextCursor 直接传入 prevId/nextId；无对应方向的下一页时为 null。为补齐轮次边界，返回条数可能略超 pageSize。支持多种鉴权模式。

**默认身份**: 不传 customUid 和 authProxy，沿用凭证对应的团队成员身份。适用于直接以当前鉴权成员调用应用。

**代理团队成员**: 通过 authProxy 代表同团队成员执行，解析出有效 tmbId 后按该成员权限校验。仅开启代理权限的个人密钥可用，与 customUid 互斥。
