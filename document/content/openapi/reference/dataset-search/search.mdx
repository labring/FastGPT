## 端点概览

- **HTTP 方法**：`POST`
- **请求路径**：`/api/core/dataset/search`
- **所属模块**：知识库 / 知识库搜索
- **鉴权方式**：`Authorization: Bearer <apiKey>`—个人密钥（按归属团队成员资源权限校验）（详见 [API 入门：完成首次请求](/zh-CN/openapi/intro)）
- **在线调试**：[在云服务 Scalar 调试台打开](https://cloud.fastgpt.cn/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E6%90%9C%E7%B4%A2/POST/core/dataset/search)（自部署实例请将域名替换为 `<instance>/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E6%90%9C%E7%B4%A2/POST/core/dataset/search`）

## 接口说明与注意事项

使用 API Key 或登录态联合检索多个可读知识库。向量召回要求有效 embedding 模型一致；结果按集合权限过滤。`result.topk` 与 `result.maxTokens` 二选一；都不传时默认 topk=20，不设置 token 预算。topk 返回排序后的前 1–100 条，不做 token 过滤；maxTokens 按完整数据块 token 预算截断，无业务上限。为兼容同时传入两种预算的请求，HTTP 入口优先保留 topk 并忽略 maxTokens。响应 meta 只包含实际执行信息。

## 请求参数

| ----------------------------- | --------------- | ---- | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `scope`                       | `object`        | 是   | -                   | 搜索范围                                                                                                                                                                                                                                                                                                                                              |
| `scope.datasetIds`            | `string[]`      | 是   | -                   | 目标知识库 ID，最多 100 个；服务端去重，逐个校验读取权限。最少项数：1；最多项数：100                                                                                                                                                                                                                                                                  |

| `scope.filter.collectionIds`  | `string[]`      | 否   | -                   | 限制在这些集合或目录内搜索，与其他筛选条件求交集。最少项数：1；最多项数：500                                                                                                                                                                                                                                                                          |
| `scope.filter.createTime`     | `object`        | 否   | -                   | 集合创建时间范围                                                                                                                                                                                                                                                                                                                                      |

#### 多态字段明细：`query`

- **变体 1** : `text` , `imageKeys`
- **变体 2** : `imageKeys` , `text`

#### 多态字段明细：`rerank`

- **变体 1** ( `enabled=false` ): `enabled`
- **变体 2** ( `enabled=true` ): `enabled` , `modelId` , `candidateNum` , `weight`

#### 多态字段明细：`queryExtension`

- **变体 1** ( `enabled=false` ): `enabled`
- **变体 2** ( `enabled=true` ): `enabled` , `modelId` , `background`

#### 多态字段明细：`result`

- **变体 1** : `maxTokens` , `similarity`
- **变体 2** : `topk` , `similarity`

## 请求示例

调用前请将 `YOUR_API_KEY` 与示例 ID 替换为真实值；私有化部署实例请将基础域名替换为 `<instance>/api`。

### cURL 请求示例

```bash
curl --fail-with-body -X POST "https://cloud.fastgpt.cn/api/core/dataset/search" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "scope": {
    "datasetIds": [
      "507f1f77bcf86cd799439011"
    ]
  },
  "query": {
    "text": "如何创建知识库？"
  }
}'
```

### 最小合法 JSON 请求体示例

```json
{
  "scope": {
    "datasetIds": ["507f1f77bcf86cd799439011"]
  },
  "query": {
    "text": "如何创建知识库？"
  }
}
```
