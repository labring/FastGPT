## Endpoint Overview

- **Method** : `POST`
- **Path** : `/api/core/dataset/search`
- **Module** : Datasets / Dataset Search
- **Authentication** : `Authorization: Bearer <apiKey>`—Personal API Key (access scoped by team member permissions) (see [API Getting Started](/en/openapi/intro) )
- **Interactive Try-It-Out** : [Open in Scalar API Explorer](https://cloud.fastgpt.io/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E6%90%9C%E7%B4%A2/POST/core/dataset/search) (self-hosted instances: replace the origin with `<instance>/apidoc/systemopenapi#tag/%E7%9F%A5%E8%AF%86%E5%BA%93%E6%90%9C%E7%B4%A2/POST/core/dataset/search` )

## Description & Notes

Search across one or more readable datasets using an API Key or login session. Vector recall requires matching active embedding models across target datasets, and results respect collection-level permissions. Choose either `result.topk` (returns top 1–100 items without token truncation) or `result.maxTokens` (truncates on complete chunks with no fixed cap); defaults to `topk=20` when omitted, and prioritizes `topk` if both are sent. Response `meta` reports effective execution parameters.

#### Polymorphic Field: `query`

- **Variant 1** : `text` , `imageKeys`
- **Variant 2** : `imageKeys` , `text`

#### Polymorphic Field: `rerank`

- **Variant 1** ( `enabled=false` ): `enabled`
- **Variant 2** ( `enabled=true` ): `enabled` , `modelId` , `candidateNum` , `weight`

#### Polymorphic Field: `queryExtension`

- **Variant 1** ( `enabled=false` ): `enabled`
- **Variant 2** ( `enabled=true` ): `enabled` , `modelId` , `background`

#### Polymorphic Field: `result`

- **Variant 1** : `maxTokens` , `similarity`
- **Variant 2** : `topk` , `similarity`

## Request Examples

Replace `YOUR_API_KEY` and placeholder IDs before running. Self-hosted users should replace the base URL with `<instance>/api` .

### cURL Example

```bash
curl --fail-with-body -X POST "https://cloud.fastgpt.io/api/core/dataset/search" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "scope": {
    "datasetIds": [
      "507f1f77bcf86cd799439011"
    ]
  },
  "query": {
    "text": "How do I create a dataset?"
  }
}'
```
